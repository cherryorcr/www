# CoTAG-Q：面向历史受限持续式 TAG 凝聚的图文支持学习

以下为当前英文论文版本的完整中文翻译。公式、方法名、数据集名和引用键保留原文形式，便于与正式英文稿逐段对照。

## 摘要

静态文本属性图（Text-Attributed Graph, TAG）凝聚旨在完整源图可用时学习紧凑的图文数据，而持续式图凝聚则在图数据分阶段到达时维护一个小型记忆。将两者结合具有挑战性：当历史原始节点、边和文本无法再次访问时，每个新的记忆项仍需同时作为图派生特征和可读文本负载发挥作用。

本文提出 **CoTAG-Q**，一种面向历史受限持续式 TAG 凝聚的方法。该方法从当前图结构、特征和文本中学习类别约束、容量平衡的支持分配 (Q)。同一个分配矩阵同时用于特征凝聚和真实文本路由，并通过循环内分布匹配目标以及与 Student 兼容的目标共同优化构造过程。新生成的记忆项被追加到冻结的 synthetic prefix 中；主记忆不保存合成边，但构造阶段仍使用当前图结构。

在精确累计 5\% 节点保留率、三种类别顺序和三个构造种子的协议下，CoTAG-Q 在 ArXiv、SportsFit 和 BookHis 上相对于匹配的 CaT 适配版本提升了 5.58--19.66 个 Macro-F1 百分点。相对于更强的 GECC-hard-TAG 适配版本，CoTAG-Q 在 BookHis 的九个配对单元中均提升 3.47 个百分点；在 ArXiv 上基本持平，在 SportsFit 上低 0.49 个百分点。固定 (Q) 或移除循环内分布匹配会使 Macro-F1 分别下降 8.91--21.67 和 1.30--14.74 个百分点。相同的 ArXiv 记忆还可以迁移到 GraphSAGE Student；在匹配的有限 Student 训练预算下，5\% 记忆相对于 full-history 参考保留了 98.23--103.33\% 的 Macro-F1。

这些结果表明，在受限历史访问条件下，可学习的图文支持关系可以作为持续式 TAG 凝聚的有效构造接口。

**关键词：** 文本属性图；持续学习；图凝聚；多模态记忆；可微分配。

## 1 引言

### 1.1 研究动机

文本属性图（TAG）将关系结构与节点级语言信息结合起来。当完整源图可用时，静态 TAG 凝聚可以同时构造图文数据 [TAGSAM, STAD]。不断演化的 Web 目录和相互链接的文档集合会持续累积关系与文本。当学习器无法保留历史原始快照时，一个关键的 Web 图学习挑战是：如何在紧凑、逐步构造的记忆中保留历史多模态信息的联合训练效用。持续式图凝聚通常维护一个随着数据分阶段到达而更新的紧凑记忆，主要面向图特征 [CaT, PUMA]。联邦 TAG 凝聚研究了相关但不同的数据访问边界 [DANCE]。

在本文的问题中，即使构造器无法重新访问早期阶段的原始特征、文本或边，新的凝聚项仍需同时保留数值表示、标签和可读文本负载。因此，记忆不只是一个更小的训练集；它还是历史多模态信息影响后续构造的持久接口。

本文在一个具体的访问规则下研究这一接口。在阶段 (t)，构造器可以获得当前增量数据以及阶段 (t-1) 保存的 synthetic memory，但不能访问历史原始数据。它必须追加一小批记忆项，同时保持类别覆盖，并且不能隐式使用原始历史。本文关注的问题不是静态 TAG 方法能否利用文本，而是：在持续式构造过程中，构造器如何决定哪些当前节点为每个新的合成特征提供支持，以及哪些真实文本应该与该特征一同保存。

### 1.2 问题与设计目标

本文的核心设计目标，是学习当前原始节点与合成槽位之间的支持关系。先进行图凝聚、再用独立规则附加文本，是一个强且有用的控制方法；但在这种做法中，文本附加过程没有参与特征构造目标。我们进一步考察：一个统一、可审计的分配关系，能否在 current-delta-only 访问约束下，同时提供特征支持和文本支持。

这一目标并不意味着所有文本感知 TAG 方法都存在结构性解耦问题；TAGSAM 和 STAD 已经包含了实质性的文本机制。本文的贡献在于提出持续式构造接口，并在相同历史访问边界下对其进行评估。

### 1.3 方法概述

我们提出 CoTAG-Q，一种具有 edge-free 主记忆的图感知持续式 TAG 凝聚方法。当前节点特征、一跳图消息和冻结的 MiniLM 文本嵌入共同初始化一个类别约束的分配矩阵 (Q)。容量平衡的 Sinkhorn 算子将分配 logits 转换为可用的支持权重。同一个 (Q) 随后被用于：

1. 将当前特征凝聚成新的合成行；
2. 路由真实文本嵌入并选择可审计的源文本字符串；
3. 提供槽位级的图消息目标；
4. 接收循环内构造目标产生的梯度。

分配矩阵与有界的特征修正量联合优化。循环内目标包括 CaT 风格的类别统计分布匹配、传播匹配以及与 Student 兼容的图文目标。最终保存的文本负载来自与硬构造前向过程相同的清洗后源文本，而软路由为 (Q) 提供替代梯度。因此，方法不会先生成一个不可解释的文本向量，再在最后替换成无关的字符串。

主记忆保存特征、标签、真实文本和审计元数据，但不保存合成邻接关系。这是方法明确的范围边界。当前增量图仍然会在构造阶段使用，同时我们提供一个独立的 CoTAG-Q-T 分支，为结构任务生成合成边。本文的主要结论针对 edge-free、基于 prompt 的节点分类；拓扑保持只作为扩展进行评估，而不是并入主方法主张。

### 1.4 贡献与范围

本文有三点贡献：

1. 我们定义并审计了历史受限的持续式 TAG 凝聚问题，明确采用 current-delta-only 构造、累计固定比例记忆和冻结 synthetic prefix，使记忆中实际保留的信息变得清晰且可复现。
2. 我们提出 CoTAG-Q。其可学习的类别约束支持关系同时组织图感知特征凝聚和真实文本路由，将支持关系从固定池化或事后文本附加规则转化为一个可优化的构造变量。
3. 我们将机制证据与基准覆盖范围区分开来。在三个大图上的九个顺序/种子单元中，CoTAG-Q 稳定优于匹配的 CaT 适配版本，并在 BookHis 上比 GECC-hard-TAG 高 3.47 个 Macro-F1 百分点。受控实验表明，学习 (Q) 和循环内分布匹配是最稳定的预测机制；相同记忆的 GraphSAGE 迁移和与 full-history 的保留率比较，则用于评估方法的稳健性和压缩效用。

本文结果不支持“在所有场景都达到 SOTA”的表述。GECC-hard-TAG 在 SportsFit 上更强，在主要比较中与 CoTAG-Q 在 ArXiv 上统计持平。同样，消融实验没有显示共享两个分配关系、额外的配对反馈路径或单独的梯度匹配一定带来普遍精度优势。我们仍将这些组件保留在完整方法定义中，因为它们共同实现了统一的构造接口，并明确报告其代价，而不是将其表述为已经被单独证明的精度来源。

本文的主要下游任务是使用图感知 edge-free 记忆进行基于 prompt 的节点分类。带拓扑的 CoTAG-Q-T 分支是独立扩展；prompt 读出也不被宣称为严格的未见类别 zero-shot 学习。

## 2 问题定义与持续式协议

### 2.1 持续式 TAG 凝聚

设在阶段 (t) 到达的合法构造数据为

\[
\Delta_t=(V_t,X_t,T_t,Y_t,E_t),
\]

其中 (E_t) 只包含当前增量中可用的边，验证节点已从构造池中排除。设 (M_{t-1}) 是上一阶段保存的记忆。合法构造器接收 ({\Delta_t,M_{t-1}})，不能重新访问历史原始数据，并输出

\[
M_t=M_{t-1}\oplus M_t^+.
\]

主 edge-free 记忆保存的行是

\[
M_t^+=\{(x_j^{\rm syn},t_j^{\rm syn},y_j)\},
\]

不保存合成邻接关系。不过，输入图仍通过局部消息和传播目标参与构造。

### 2.2 固定比例记忆与阶段分配

我们使用累计保留率而不是固定行数。如果截至阶段 (t) 已观察到的合法构造节点数为 (N_t)，则目标记忆大小为

\[
\bar K_t=\operatorname{round}(\rho N_t),\qquad
K_t=\max\{\bar K_t,|M_{t-1}|+|\mathcal C_t|\},
\]

其中 (mathcal C_t) 是当前增量中的类别集合，第二项是类别覆盖下限。新增槽位数量为

\[
m_t=K_t-|M_{t-1}|.
\]

首先为当前每个类别预留一个槽位；剩余槽位根据当前类别计数，使用最大余数规则分配，并受可用行数限制。当类别覆盖下限改变了名义目标时，记录实际保留率。

主实验采用预先指定的累计 (ho=5\%)。这是 CaT 使用的按比例持续记忆约定：记忆随数据流规模增长，同时不同数据集上的压缩程度保持可比。附录中的保留率实验只用于敏感性分析，不参与方法选择循环。

### 2.3 访问边界与评估

构造新块时，synthetic prefix 只读。追加式设计能够在原始文本不再可用时保留已经材料化的文本，并隔离当前增量的影响；它并不意味着刷新旧记忆在理论上不可能。附录报告了一个刷新实验。

所有匹配方法使用相同的文本清洗规则、冻结的 MiniLM 编码器、记忆比例、类别顺序、Student 架构、优化步数和评估掩码。我们报告最终 Macro-F1 和 Accuracy，并将 Old/New F1 作为持续学习诊断指标。prompt 读出比较节点图表示与类别 prompt 表示：

\[
\hat y_i=\arg\max_c\cos(h_i^g,p_c).
\]

这是基于 prompt 的分类器，而不是严格的未见类别 zero-shot 学习：在给定协议下，构造和 Student 训练仍使用标签。GraphSAGE 迁移和拓扑感知结构探针作为独立稳健性检查报告。

## 3 相关工作与基线适配

### 3.1 图凝聚与持续式记忆

GCond 和 GCond-x 表明，在构造凝聚训练集时可以使用图，并得到近似 edge-free 的训练数据 [GCond]。SFGC 则沿着图自由的轨迹匹配方向发展。CaT 是最接近的持续式先例：它结合分布匹配和 Training-in-Memory，按类别平衡地追加记忆。PUMA 进一步使用伪标签和高效传播进行持续式图学习。

这些方法提供了特征凝聚的一侧，但没有在历史原始数据不能重新访问的条件下，定义一个可读文本负载接口。

### 3.2 静态与多模态 TAG 方法

TAGSAM 通过文本选择和属性匹配进行静态 TAG 凝聚；STAD 结合半监督图文蒸馏、图结构 sketch 和文本生成；DANCE 研究带邻居文本和拓扑机制的联邦 TAG 凝聚；SR-GM 处理多模态梯度冲突。它们的源图和优化协议都不同于带冻结 synthetic prefix 的持续式数据流。

GraphCLIP 是图文迁移模型而不是凝聚方法，它为本文的 prompt 读出提供了动机，但不是直接的记忆基线。

### 3.3 基线适配与公平性

我们区分三种证据等级。

- **官方复现（official reproduction）**：保持论文发表时的任务、访问假设、核心目标、Student 和评价指标。
- **匹配机制适配（matched mechanism adaptation）**：保留方法的核心构造机制，但将原始访问限制为当前增量，并使用本任务共同的记忆接口和 Prompt Student。
- **简化启发式控制（simplified inspired control）**：只保留高层思想，不能据此证明优于原论文的完整方法。

主表使用两个匹配的持续式适配版本。CaT-CCTP 保留 CaT 的按类别分布匹配，并从当前增量中附加五个同类文本源。GECC-hard-TAG 使用 GECC 派生的平衡硬聚类和中心池化，将原生的模糊成员关系和累计中心修正替换为硬分配与冻结历史 prefix。它们都使用相同的文本附加规则和共同 Student。

这两个方法都不能被称为官方 TAG 复现，因为原论文没有定义与本文完全相同的持续式 TAG 接口。主表保留五源文本适配器作为强控制；固定特征加单一最近文本的 replay 版本只作为诊断报告。

附录记录了受 PUMA、DANCE 和 SR-GM 启发的控制，以及有界 TAGSAM、STAD-core、GCond-x、SFGC 和 GraphCLIP 参考。对于监督信号、原生预算或模型契约发生改变的结果，文中会在数字旁明确说明。特别是，简化适配器的低分不能解释为发表方法本身较弱。

### 3.4 与 CoTAG-Q 的关系

CoTAG-Q 的各个组成元素本身并非全部全新：图感知池化、Sinkhorn 归一化、分布匹配、梯度匹配和源文本选择都已有先例。本文的方法贡献在于持续式构造接口：当历史原始节点不能再次访问时，让同一个类别约束分配 (Q) 成为图特征、真实文本和构造反馈共同使用的支持变量。实验将这一结构性提议与“共享 (Q) 是否总能提升精度”这一更窄的问题区分开来。

## 4 方法

### 4.1 构造接口

在阶段 \(t\)，方法读取当前增量 \(\Delta_t\) 和冻结的历史前缀 \(M_{t-1}\)，分配 \(m_t\) 个带类别标签的新槽位，并联合优化分配 logits \(Z\in\mathbb R^{n\times m}\) 与有界的特征残差 \(R\in\mathbb R^{m\times d_x}\)。掩码 Sinkhorn 算子将 \(Z\) 映射为 \(Q\)，其中 \(Q_{ij}\) 表示当前节点 \(i\) 分配给槽位 \(j\) 的质量。特征和文本两个模态使用同一个 \(Q\)：

\[
M_t=M_{t-1}\oplus
\{(x_j^{\rm syn},t_j^{\rm syn},y_j)\}_{j=1}^{m}.
\]

方法不会先执行一次独立的 CaT 优化，再在结果上附加文本。CaT 风格的分布匹配只是同一个循环内更新目标中的一项。方法流程图将一次性的缓存步骤、反复执行的 \(Q\) 计算与损失更新，以及最后的 memory 材料化分开表示。图中的 \(X^+\) 表示新的合成特征，\(E\) 表示当前文本的编码，\(S^+\) 表示送入 Student proxy 的新行。\(Q\) 及其 logits 都不是邻接矩阵。

### 4.2 图文联合初始化

首先将每条当前文本清洗并截断到 320 个字符，然后使用冻结的 MiniLM 编码一次：

\[
e_i=\operatorname{Norm}(\operatorname{MiniLM}(t_i)).
\]

令 \(A\) 为当前无向邻接矩阵，令
\(\widehat A=D^{-1/2}(A+I)D^{-1/2}\)。我们计算局部结构信号

\[
h_i=\operatorname{Norm}((AU)_i+10^{-6}u_i),
\qquad u_i=\operatorname{Norm}(x_i),
\]

以及传播目标 \(H=\widehat A X\)。在每个类别内部，根据联合签名

\[
v_i=\operatorname{Norm}
[\sqrt{w_x}u_i;\sqrt{w_h}h_i;\sqrt{w_e}e_i]
\]

执行最远点原型选择，为每个槽位初始化一个原型。首先选择最接近归一化类别均值的节点，再贪心地选择剩余联合签名中距离最远的节点。三个原型分量都来自同一个被选中的真实节点。初始化 logits 为

\[
Z_{ij}^{0}=w_xu_i^\top p_j^x+w_hh_i^\top p_j^h+w_ee_i^\top p_j^e,
\qquad (w_x,w_h,w_e)=(1,0.75,0.35).
\]

这一步只提供初始化先验；后续仍会学习支持关系。

### 4.3 平衡支持分配

对于类别 \(c\)，设当前有 \(n_c\) 行、\(m_c\) 个槽位。Sinkhorn 使用逐元素指数以及正的行、列缩放向量 \(\alpha_c,\beta_c\)：

\[
\begin{gathered}
Q_c=\operatorname{diag}(\alpha_c)\exp(Z_c/\tau)
\operatorname{diag}(\beta_c),\\
Q_c\mathbf 1=\mathbf 1,\qquad
Q_c^\top\mathbf 1=(n_c/m_c)\mathbf 1 .
\end{gathered}
\]

类别掩码使跨类别质量严格为零；每行质量为 1，每个同类槽位获得相同容量。实现采用 log-space 行列缩放，温度为 \(\tau=0.35\)，并将迭代轮数从 30 增加到最多 2,048 轮，直到边际误差达到 \(10^{-4}\) 的容差。每个阶段都会记录实际误差。相同的列容量防止支持质量集中到少数槽位。

从直观上看，Sinkhorn 在两个约束之间寻找平衡：每个真实节点必须把自己的质量分配出去，而每个合成槽位只能接收预先规定的同类节点总质量。因此 \(Q\) 不是任意的注意力矩阵，也不是图的边，而是一个受到类别和容量约束的软支持关系。

### 4.4 特征池化与真实文本路由

令 \(a_j=\sum_iQ_{ij}\)。合成特征为

\[
\bar x_j(Q)=\frac{\sum_iQ_{ij}x_i}{a_j},\qquad
x_j^{\rm syn}=\bar x_j(Q)+r_j,
\]

其中

\[
\|r_j\|_2\leq 0.05\max(\|\bar x_j\|_2,10^{-3}).
\]

因此，流程图中的 \(D_a^{-1}Q^\top\) 对当前节点逐列求加权均值，为每个槽位得到一个新的特征；它不会创建合成边。残差允许合成特征在池化均值附近进行小幅修正，而文本路由仍然使用同一组支持权重。

同一个支持关系给出软文本表示

\[
\widetilde e_j(Q)=\operatorname{Norm}
\left(\frac{\sum_iQ_{ij}e_i}{a_j}\right).
\]

为了让 memory 中的文本可读且可审计，最终保存的是拥有最大分配质量的真实源文本：

\[
i_j^\star=\arg\max_{i:y_i=y_j}Q_{ij},\qquad
t_j^{\rm syn}=t_{i_j^\star}.
\]

构造过程中使用 straight-through 表示

\[
e_j^{\rm ST}=e_{i_j^\star}+\widetilde e_j-
\operatorname{sg}(\widetilde e_j).
\]

它的前向值是真实被选中的文本嵌入，但反向传播使用软路由作为替代梯度：
\[
\frac{\partial e_j^{\rm ST}}{\partial Z}
\]
通过
\(\partial\widetilde e_j/\partial Q\cdot\partial Q/\partial Z\)
传递。离散的源文本索引本身不求导，文本编码器保持冻结。最后一次更新后，方法重新计算 \(Q\)，使用同一源文本规则选择并重新编码保存的字符串，再验证嵌入契约。整个过程不会生成新文本，也不会引入已经无法访问的历史原始文本。

### 4.5 循环内构造目标

我们使用一个随机初始化、固定参数的两层图文 Student proxy，隐藏层和输出维度均为 384。其损失为

\[
L_{\rm proxy}=0.5L_{\rm pair}+L_{\rm prompt}+0.1L_{\rm margin}.
\]

其中，\(L_{\rm pair}\) 是图文对比损失，同类别项目作为正样本；\(L_{\rm prompt}\) 是类别 prompt 交叉熵；\(L_{\rm margin}\) 使用 0.20 的间隔约束当前类别 prompt 与最强错误 prompt 之间的差异。旧数据组和当前数据组获得相同总权重，组内类别等权。

在固定 proxy 参数的情况下，先缓存真实数据上的梯度

\[
g_r=\nabla_\theta L_{\rm proxy}(M_{t-1}\oplus\Delta_t),
\]

并在每个构造步骤中重新计算合成数据上的梯度 \(g_s\)。梯度匹配损失为

\[
L_{\rm GM}=1-\cos(g_r,g_s)+0.25
\left|\log\|g_r\|_2-\log\|g_s\|_2\right|.
\]

由于 \(Q\) 同时控制 \(x_j^{\rm syn}\) 和 \(e_j^{\rm ST}\)，梯度会从图特征和文本两条路径回到同一组 logits。这里的参数梯度表示 Student proxy 将接收到的学习信号，但不会更新 proxy 本身。对 \(L_{\rm GM}\) 关于 \(g_s\) 求导会为 \(Z,R\) 的更新引入二阶导数。

按照 CaT 的做法，分布匹配在四个固定的随机 ReLU 投影中比较类别统计量：

\[
L_{\rm DM}=\frac{1}{B}\sum_{b,c}
\|\mu_{bc}^{\rm syn}-\mu_{bc}^{\rm real}\|_2^2,
\]

其中 \(B=4\)，
\(\phi_b(x)=\operatorname{Norm}(\operatorname{ReLU}(xW_b))\)，每个固定的 Xavier 初始化矩阵 \(W_b\) 的宽度为 512。类别 \(c\) 的 \(\mu_{bc}\) 是投影后表示的类别内均值。真实统计量使用当前 \(H=\widehat A X\)，合成统计量使用新的 edge-free 行。

槽位级传播项为

\[
L_{\rm prop}=\frac{1}{m}\sum_j\left[
1-\cos\left(\frac{\sum_iQ_{ij}H_i}{a_j},x_j^{\rm syn}\right)\right].
\]

因此，流程图中传播匹配一行比较的是“先对真实传播表示按 \(Q\) 池化”与“最终槽位特征”之间的差异。尽管 \(H\) 本身已经缓存，但其按 \(Q\) 池化的参考 \(D_a^{-1}Q^\top H\) 会随着 \(Q\) 改变，所以梯度会经过两个输入。相比之下，真实侧的 proxy 梯度和投影后的类别统计量是缓存的。

令 \(R\) 从零初始化，并以初始池化特征尺度归一化残差惩罚：

\[
s_j^0=\max(\|\bar x_j(Q_0)\|_2,10^{-3}),\qquad
L_R=\frac{1}{md_x}\sum_j\|r_j/s_j^0\|_2^2.
\]

完整目标函数为

\[
L=L_{\rm GM}+L_{\rm DM}+0.5L_{\rm prop}
+0.1\|Q-Q_0\|_F^2/(nm)+0.1L_R.
\]

Adam 联合更新 \(Z\) 和 \(R\) 30 步，学习率分别为 0.15 和 0.005，并进行最大范数为 5 的梯度裁剪。这是同步的可微优化，而不是 EM：文本编码器、原始数据、历史前缀和 proxy 参数均保持固定。

### 4.6 阶段算法与方法范围

每个阶段的实现包括：

1. 分配槽位，读取当前增量和冻结的历史前缀；
2. 缓存文本和图结构信号，初始化 \(Z,Q_0,R\)；
3. 缓存真实 proxy 梯度和类别统计量目标；
4. 循环计算 \(Q\)、池化特征、straight-through 文本和三个主要损失，然后更新 \(Z,R\)；
5. 材料化新行，写入审计字段并追加到 memory。

构造结束后会释放 dense \(Q\) 和临时 proxy 张量。若当前节点数为 \(n\)、槽位数为 \(m\)，则稠密分配的工作内存为 \(O(nm)\)，池化时间为 \(O(nm(d_x+d_e))\)。梯度匹配还会引入二阶求导。这解释了为什么 5\% 的保存率并不意味着构造过程只需要 5\% 的显存。主 memory 是 edge-free 的，主要用于基于 prompt 的节点分类。CoTAG-Q-T 作为独立分支保存由 \(Q\) 诱导的拓扑，供结构任务使用，不改变 edge-free 主方法的声明。

## 5 实验设置

### 5.1 数据集与评估面板

主面板包括 ArXiv、SportsFit 和 BookHis 三个大规模 TAG，覆盖不同领域和类别分布。WikiCS、Cora 和 Citeseer 作为小图和历史对照保留在附录中。数据流按照类别顺序划分；构造器只能读取当前增量和已经保存的 synthetic prefix。

| 数据集 | 合法构造池 | 主实验单元数 |
|---|---:|---:|
| ArXiv | 118,539 | 9 |
| SportsFit | 121,137 | 9 |
| BookHis | 29,086 | 9 |

### 5.2 Student 与评价指标

主下游模型是两层 Prompt GCN，使用冻结的 MiniLM 文本编码器和类别 prompt 余弦读出。Prompt GraphSAGE 只用于相同 memory 的迁移实验。所有构造器共享相同的 prompt 定义、文本预处理、2,048 步 Student 训练、批大小 24，以及 Student seeds 150、151、152。GraphSAGE 只将图塔替换为两层均值聚合器，memory 和训练协议保持不变。

我们报告最终 Macro-F1 和 Accuracy；Old/New F1 以及阶段平均 F1 作为持续式学习诊断。Student seeds 在每个顺序/构造单元内取平均；均值、样本标准差和配对 95\% \(t\) 区间在这些单元均值上计算。

### 5.3 协议与基线

主实验使用合法构造池的精确累计 5\% 记忆率，并记录类别覆盖下限。主比较包含三种类别顺序、三个构造种子和三个 Student 种子。测试掩码在当前比较之前固定，因此这里属于“事后固定掩码证据”，不是新的一次盲测。Full-history 行是更高访问权限的参考，不参与持续式构造。

外部主基线为 CaT-CCTP 和 GECC-hard-TAG。二者保留原方法的核心特征机制，并使用相同的 current-delta-only 包装、memory 格式、五源文本附加规则和 Prompt Student。更宽的机制适配、官方 checkpoint 参考以及原生预算结果在附录中单独报告，不与主排名混合。

### 5.4 可复现性

构造器使用四个宽度为 512 的固定随机投影进行分布匹配，\(\tau=0.35\)，30 次联合 Adam 更新，并在不同数据集间使用相同超参数。文本在 MiniLM 编码前清洗并截断到 320 个字符。每次运行记录类别顺序、构造和 Student seed、实际保留率、类别配额、Sinkhorn 边际误差、源文本标识符以及配置哈希。构造时间和峰值 CUDA 分配与 Student 训练分别测量。

## 6 主要结果

### 6.1 三个大规模 TAG 上的主比较

表 1 是主比较。三个方法使用相同的合法构造池、累计 5\% 记忆率、九个顺序/构造单元、每个单元三个 Student seed、文本编码器和 prompt 读出。外部方法均为机制匹配适配，而不是官方 TAG 复现。

| 数据集 | 方法 | Macro-F1 | SD | Accuracy | Old F1 | New F1 |
|---|---|---:|---:|---:|---:|---:|
| ArXiv | CoTAG-Q | **52.91** | 0.73 | **71.15** | **52.25** | 54.27 |
|  | GECC-hard-TAG | 52.68 | 0.45 | 70.94 | 51.45 | **55.24** |
|  | CaT-CCTP | 34.98 | 1.79 | 60.41 | 33.77 | 37.50 |
| SportsFit | CoTAG-Q | 80.08 | 0.60 | 85.52 | 80.00 | 80.51 |
|  | GECC-hard-TAG | **80.57** | 1.16 | **89.01** | **80.57** | 80.58 |
|  | CaT-CCTP | 74.50 | 2.14 | 85.56 | 74.31 | 75.52 |
| BookHis | CoTAG-Q | **48.81** | 1.57 | 81.05 | **48.39** | **53.45** |
|  | GECC-hard-TAG | 45.34 | 0.74 | **81.26** | 45.48 | 43.86 |
|  | CaT-CCTP | 29.16 | 1.05 | 79.23 | 29.16 | 29.09 |

CoTAG-Q 在三个大图上都明显强于 graph-first 的 CaT 控制：配对 Macro-F1 提升分别为 17.93、5.58 和 19.66 个百分点，并且九个单元中的每一个都为正。与更强的 GECC 适配相比，收益依赖数据集。在 BookHis 上提升 3.47 个百分点，九个单元全部为正，配对 95\% 区间为 \([2.20,4.74]\)；ArXiv 基本持平，提升 0.22 个百分点，区间为 \([-0.34,0.79]\)；SportsFit 则低 0.49 个百分点，区间为 \([-1.50,0.52]\)。因此，CoTAG-Q 相对于 GECC 最清晰的优势出现在 BookHis，在该数据集上 Old F1 和 New F1 也同时改善，而整体 Accuracy 基本相当。

### 6.2 Student 迁移与 full-history 效用

相同的 ArXiv memory 被迁移到 Prompt GraphSAGE，构造器、prompt、文本编码器和 memory 都不改变。对于 CoTAG-Q、GECC-hard-TAG 和 CaT-CCTP，Prompt GCN 的 Macro-F1 分别为 52.91、52.68 和 34.98；Prompt GraphSAGE 下分别为 53.93、52.60 和 50.24。因此，在 GraphSAGE 上 CoTAG-Q 领先 GECC 1.34 个百分点，结果并非只由单一 GCN 读出器产生。附录给出两种 Student 的完整指标。

表 2 比较 5\% memory 与 full history 在相同有限 Student 预算下的表现。Full history 是访问权限更高的参考：它可以重新访问全部训练节点和边，并不是一个持续式构造器。

| 数据集 | Full-history F1 | 5\% F1 | F1 保留率 | Accuracy 保留率 |
|---|---:|---:|---:|---:|
| ArXiv | 53.47 | 52.96 | 99.04\% | 97.60\% |
| SportsFit | 81.46 | 80.02 | 98.23\% | 95.58\% |
| BookHis | 46.96 | 48.53 | 103.33\% | 99.14\% |

在这些参考条件下，5\% memory 保留了 98.23--103.33\% 的 Macro-F1 和 95.58--99.14\% 的 Accuracy。这是有限 Student 预算下的效用比较，不表示压缩 memory 在所有任务上都能普遍超过 fully optimized full graph。

### 6.3 构造成本

CoTAG-Q 的峰值 CUDA 分配在 ArXiv、SportsFit 和 BookHis 上分别为 17.33、24.08 和 2.91 GiB，而两个匹配基线均低于 1.1 GiB。主要开销来自 dense \(Q\)、其可微归一化状态以及 proxy 的二阶求导。将稠密 synthetic identity 替换为稀疏算子，在 ArXiv 和 SportsFit 的阶段零审计中只分别节省 0.06 和 0.11 GiB，说明更大的瓶颈仍是稠密分配状态。稀疏或分块分配，以及带检查点的 proxy 更新，是下一步的主要工程方向。

保留率敏感性、更广泛的数据集、TAGSAM/STAD 参考和详细成本审计分别放在附录中。

### 6.4 构造更新步数敏感性

主实验仍使用 30 次构造更新。report-development 敏感性实验在相同的数据访问规则、累计记忆率、构造种子和 Student 评估协议下比较 30、60 和 100 步。目标函数在早期下降较快，后期明显变平，但更多更新没有带来一致的下游收益：ArXiv 上从 30 步到 60 步，Macro-F1 配对变化为 -0.14 个百分点；BookHis 上 60 步和 100 步分别比 30 步低 2.25 和 1.58 个百分点。因此，30 步被保留为 accuracy--cost operating point，而不是声称所有阶段在相同预算下都严格数学收敛。完整的 loss 轨迹和成本表放在附录。
