# arxiv Anchored 优化扫描：优化收益需要真实表征漂移，锚定会抹掉收益

日期：2026-09-10
数据：服务器 `problem_validation_results/arxiv_anchored_2026_09_10/`（本地镜像 `arxiv_anchored/results.json`）
动机：X-only 实验证明 arxiv 上 ASM 是方向有效的真优化。本实验检验修正后方法的自然形态——**构造式初始化 + 少量 ASM steps**（可选 proximity 锚 $\lambda\|X-X_{init}\|^2$），扫描步数与锚强度，测 F1 与 X 漂移的关系。

## 1. 设置

所有 arm 共享同一构造式初始化（k=6773，rate=5%），复用与 +3.31/21.86 完全相同的 `asm_optimize` 内外循环；唯一变量是**步数**与**锚强度 λ**。3 个 student seeds。

## 2. 结果

## 3. 三个清晰结论

**结论 1：收益随步数单调爬升，饱和于 ≈50 步。** λ=0 时 F1 从 18.50（0 步）→18.49（5 步）→20.38（20 步）→**21.96（50 步）**→21.85（100 步）。50 步即达峰值，再多无益。这与"ASM 是真实优化"一致——需要足够步数才能走到有效方向，命中后饱和。

**结论 2：proximity 锚是纯有害的。** λ=1e-2 把所有步数的 F1 压到 17.0–18.7（**低于 frozen 18.50**），且把漂移锁死到 ~0（X 几乎没动）。**锚定越强、越接近 frozen、F1 越差**——这从反面再次证明：收益**恰恰来自真实表征漂移**，把 X 绑在构造式起点上就等于放弃收益。

**结论 3：ASM loss 是坏的进度指标。** 全部 arm 的 loss 都收敛到 0.0078（完全相同的值），**与 F1 完全无关**（λ=1e-2、F1=17.0 与 λ=0、F1=22.0 的 loss 一模一样）。这再次印证"loss 不降/收敛不代表下游有效"，且**任何基于该 loss 的早停或模型选择都会失效**——它无法区分最好的和最差的 arm。

## 4. 修正后方法的最终形态

> **构造式初始化 + 约 50 步无锚 ASM 优化**（arxiv 大图）。 
> - 构造式提供稳定、合规、确定性的起点（小图上直接用它）；
> - 大图上追加 ~50 步 ASM，F1 从 18.5 → 22.0（**+3.5**），收益大于此前 X-only 的 +2.1 和纯 ASM 的 +3.31；
> - **不要**加 proximity 锚（有害）；
> - **不要**用 ASM loss 做早停/选择（与 F1 无关），需用 held-out dev F1 或固定步数。

这个配方在合规性（构造式起点）、有效性（大图 +3.5）、成本（50 步远少于 100）上都优于纯 ASM 和纯构造式，是"两者并用"的最优折中。

## 5. 边界与待补

- 3 seeds，方差可见（steps50 的 20.2–22.9）；需扩到 5 seeds 并做显著性检验；
- 50 步的饱和点可能随 rate/k 变化，需在其它 rate（如 10%）复核；
- 锚有害这一结论在仅 λ∈{0,1e-2} 两点上得出，需补中间值（1e-3）确认是单调有害还是存在弱锚最优；
- loss 无诊断性 → 需补"用 dev F1 做早停"的版本，验证能否再省步数。
