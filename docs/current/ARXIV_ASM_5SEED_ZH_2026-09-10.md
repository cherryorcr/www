## 3. 两个必须执行的修正（针对昨天的文档）

### 修正 1：随机扰动**不是**无收益——昨天的结论错误

`ARXIV_XONLY_AND_WEAK_PERTURBATION_ZH_2026-09-10.md` 依据**单 seed、单 draw** 得出"随机扰动与 frozen 持平（19.84/19.30）、ASM 有真方向"的结论。5 seeds × 5 draws 的配对检验直接推翻：

> **同幅随机扰动带来 +2.00（CI 不含 0）。** 那个单点结论是噪声（seed200 上 ASM 与 rand 的差恰好不在，其它 seed 上 rand 也能涨 3–4 分）。

### 修正 2：ASM 只有 +1.30 超出随机扰动，不是全部收益

ASM 相对 frozen 的 +3.29 中，**约 +2.00 可由任意同幅漂移复现**，只有 **+1.30（CI [+0.46, +2.28]，5/5 一致）**是 ASM 方向特有的。所以准确表述是：

> ASM 的收益**大部分是"离开构造式初始化"这一动作本身带来的**（任何足够幅度的漂移都行），**一小部分是 ASM 方向特有的**（+1.30，统计显著但不大）。

## 4. 机制含义（重新理解构造式初始化）

这个结果反而给主方法一个更清晰、也更诚实的画像：

1. **构造式初始化的 X 是"欠适配"的**：它是真实 X 的簇均值，与冻结 MiniLM 融合文本处在不同的几何尺度上。任何让它离开初始位置的漂移（随机的或优化的）都让 student 更容易训练——这解释了大图上 +2.0 的"免费"收益；
2. **ASM 的额外 +1.30 说明方向有信息**，但远不是"优化解决了问题"；
3. **这同时解释了小图为什么无收益**：小图上 student 容量有限、每行暴露高，漂移既无免费收益、方向优势也被方差吞掉（Cora/Citeseer −0.25）。

**修正后的模块叙事**：不是"构造式 + ASM 优化"，而是"**构造式 + 欠适配释放**"——大图需要让 X 离开簇均值这个不利位置；ASM 是做到这件事的一种有信息的方式，但不是唯一方式（随机漂移已拿到 2/3 的收益）。这降低了对 ASM 的依赖，也提示可以用**更便宜、更可控的确定性去偏置**替代 ASM（见 §6）。

## 5. 对主方法（v1.2）判定的影响

- ✅ **条件优化模块可以进主方法**：asm − frozen 的 CI 不含 0、5/5 一致、均值 +3.29，满足 §6 的"CI 不含 0 或全一致 + >1pp"；
- ⚠️ **但定位必须下调**：它不是一个"优化器解锁了收益"，而是一个"让欠适配的簇均值 X 离开初始位置"的修正。论文中应如实报告随机扰动对照（这本身是有价值的发现：构造式初始化的 X 尺度/位置对下游不利）；
- ⚠️ **必须补的对照**：既然随机漂移拿到 +2.0，需要测**零成本的确定性去偏置**（例如对 X 做白化/标准化、或把簇均值 X 投影到与融合文本同尺度），看能否直接拿到这 +2.0，从而把 ASM 的必要性进一步压缩。

## 6. 下一步（优先级已变）

1. **（新，最高）测确定性去偏置**：X 白化 / 尺度对齐 / 与 text_emb 的 Procrustes 对齐，零成本、零随机，看能否拿到随机扰动的 +2.0。若拿到，则"条件优化模块"可改为"条件去偏模块"，成本更低且确定性；
2. **asm − rand = +1.30 的机理**：把 ASM 方向投影到 X 的主成分上，看它是否是一个"去偏置方向"而非"任务方向"；
3. 中间尺度定位规模门槛（由负转正的转折点）；
4. 持续场景接入（teacher 的合法性设计仍待定）。

## 7. 边界

- 5 seeds、5 draws 仍是小样本，+1.30 的 CI 下界 +0.46 较薄，需扩到 10 seeds 复核；
- 随机扰动的模长是按 **ASM 的逐行 ΔX 范数**匹配的，不同去偏置方式（白化）的范数不同，跨方式比较需要重新标定；
- 所有结论仍在 arxiv 单数据集、dev 分区上，test（%10==2）未读；
- 本修正同时使 `ARXIV_XONLY_AND_WEAK_PERTURBATION_ZH_2026-09-10.md` 的 §3 "弱扰动被推翻"表述失效，该文档需加注更正。
