# arxiv 零成本去偏置实验：几何去偏假设被证伪，"漂移收益"不是尺度错配

日期：2026-09-10
数据：服务器 `problem_validation_results/arxiv_debias_2026_09_10/`（本地镜像 `docs/current/asm_debias_2026_09_10/results.json`）
代码：`code/v2_llm_fusion/run_arxiv_debias.py`
动机：5-seed 判定显示"同幅随机扰动 +2.00、ASM 额外 +1.30"。若 +2.0 来自"簇均值 X 与融合文本几何错配"，则零成本确定性去偏置（白化/尺度对齐/Procrustes）应能复现它。

## 1. 设计

同一构造 artifact，只对 X 做变换（文本/边/mass 不变）。5 student seeds 配对：

| arm | 变换 |
|---|---|
| frozen | 原簇均值 X（row norm 0.805） |
| scale_align | 逐维零均值单位方差后重标到 text_emb 的逐维统计（row norm 0.995） |
| procrustes | 正交 W 最小化 $\|XW-T\|_F$（row norm 0.823） |
| whiten | PCA 白化到逐维单位方差（row norm 18.80） |
| whiten_scale | 白化后再尺度对齐（row norm 0.969） |
| rand_0..4 | 逐行高斯噪声，模长匹配 ASM 的 $\|\Delta X\|$ |
| asm | 50 步无锚 ASM |

参照点：text_emb 的 row norm = 1.0002（**注意：这是每个 384 维向量都被 L2 归一化后的结果**）。

## 3. 结论：几何去偏假设被证伪

**（1）三个几何去偏 arm 全部失败。** scale_align（−0.13）、procrustes（+0.31）都在噪声水平；whiten 更是把 F1 打到 **0.6–1.0**（近乎随机，40 类随机基线 2.5），0/5。白化把 X 逐维方差拉到 1，使整体范数从 0.8 膨胀到 18.8，彻底破坏了与文本塔的兼容。

**（2）所以 +2.0 不是"修复几何错配"带来的。** 如果是尺度/旋转错配，Procrustes 和尺度对齐应该部分恢复它——它们没有。**唯一能稳定拿到 +2.0 的是各向同性随机噪声。**

**（3）"漂移收益"的正确机制表述**：随机噪声的作用不是修正几何，而是**在 X 上做各向同性增量扰动**，使簇均值 X 的**逐行方向发生随机旋转**。收益来自"扰动本身"（可能是打破簇均值的过度平滑/rg 结构），而非任何可计算的目标几何。

**（4）一个必须写进文档的自证**：本 run 的 asm 只 +1.56（4/5，CI 下界 +0.18），而 rand_2/rand_3 达到 +2.02/+2.09——**ASM 在一个独立 run 里被随机扰动反超**。结合 5-seed run（asm−rand = +1.30，CI [+0.46,+2.28]），跨 run 的一致图景是：**ASM ≈ 随机漂移，两者都 +1.5~2.0；ASM 的方向优势存在但脆弱（run 间从 +1.30 摆到 −0.5）。**

**（5）同时也修正了 5-seed 文档的口径**：那里把 +2.0 说成"离开簇均值位置的收益"，本 run 否定了几何解释（去偏无效），所以更准确的说法是"**各向异性随机的方向扰动收益**"。

## 4. 对主方法（v1.2）的判决

- ❌ **"条件去偏模块"不成立**——去掉偏置的确定性变换不工作；
- ⚠️ **"条件优化模块"的定位也要再降**：ASM 相对随机扰动没有稳定优势（run 间 +1.30 ~ −0.5），单独看 ASM vs frozen 则在 +1.6~+3.3 波动。当前证据不足以把 ASM 作为主方法的正式组件；
- ✅ **可以确立的是一个更朴素的经验**：大图上**任何足够幅度的 X 扰动**（随机或 ASM）都带来 +1.5~2.0，且极便宜。若要把这个收益纳入方法，最简形式是**在构造后施加固定的（确定性伪随机、可复现 seed 的）各向同性扰动**——零优化成本、零 teacher、确定性（seed 固定）。

这反而是个干净、可辩护的方法组件：**"构造式 + 轻量 X 扰动（deterministic jitter）"**，比 ASM 便宜、比随机 draw 可复现。但它必须诚实标注：**它不是一个有方向的优化，只是一个经验有效的扰动。**

## 5. 下一步

1. **jitter 的稳健性**：固定 seed 的 jitter 在多 seed/多 rate 下是否稳定 +1.5~2.0（当前 rand 的 5 draw 方差不小，CI 下界低到 −0.63 出现在 rand_0）；
2. **扰动幅度曲线**：$\|\Delta X\|$ 从 0.2 到 2.0 扫描，找最优幅度（当前固定匹配 ASM 的 1.79）；
3. **小图检查**：Cora/Citeseer 上 jitter 是否也无害（若有害则必须是"大图专属"组件）；
4. **判据问题**：既然 ASM ≈ 随机，主方法里要么放确定性 jitter，要么两者都作为消融，**不要**写成一个优化器；
5. 中间尺度定位规模门槛。

## 6. 边界

- 5 seeds，单数据集（arxiv），dev 分区，test 未读；
- 白化失败有明确实现原因（范数膨胀），但这也意味着"去偏"这一族的其它形式（如只旋转不缩放、Sinkhorn 等）**未被穷尽**，只能说"本实验测的三种几何去偏不工作"；
- rand 与 ASM 谁更优在本项目内**不稳定**（两个 run 给出不同符号），任何"ASM 优于随机"的表述目前都不成立。
