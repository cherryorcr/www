# 方向E：ogbn-arxiv（169k 节点）规模化 Gate 结果

日期：2026-09-09
数据：服务器 `problem_validation_results/arxiv_gate_2026_09_09/`（本地镜像 `results_arxiv_gate.json`）
设置：ogbn-arxiv 169,343 节点、40 类、232 万边；MiniLM 特征版（node_f 384 维）+ 原始文本；语义类名 prompt（"a computer science paper about {Numerical Analysis 等}"）。dev = node_id%10==1，test = %10==2 **封存未读**，凝聚池 = 其余 80%（约 135k 节点）。frozen_v1 构造器的 GPU 适配版（分块 cdist、index_add Lloyd、分块 kNN），3 student seeds × 2048 步。

## 1. Scalability 结论：完全不是瓶颈（这是本 gate 的主答案）

**63 倍节点规模下，全流程 212 秒**：

| 阶段 | 耗时 | 备注 |
|---|---:|---|
| 编码全部 169k 文本 | 84s | 一次性，可缓存 |
| 聚类 k=1354（1%） | 5s | GPU maxmin+Lloyd |
| 聚类 k=6773（5%） | 26s | 同上 |
| 融合+拓扑 | 1–3s | 分块 kNN |
| student 训练×3（每 arm） | ~15s | 稀疏邻接全图传播 |
| **总计（2 个 rate × 3 arms）** | **212s** | 单张 4090 |

**外推**：主导项是文本编码（O(n)）与聚类（O(nk)每轮）。MAG240M 采样 1M 子图 ≈ 编码 8 分钟 + 聚类分钟级——**方法对"更大规模"没有算法障碍**，确定性构造的零训练特性在规模上是压倒性优势（对照：GCond/SFGC 在 arxiv 上凝聚需要小时级 GPU 优化）。这是可写进论文的效率主张：**k=6773 的凝聚 30 秒完成**。

## 2. 质量结果（dev Macro-F1，40 类零样本）

| rate | arm | Macro-F1 | Acc | std |
|---|---|---:|---:|---:|
| 1% (k=1354) | construct | 16.17 | 18.22 | 0.50 |
| 1% | random ×2 | 17.7–17.9 | 21.6–22.6 | 1.1 |
| 5% (k=6773) | **construct** | **19.74** | 24.84 | **0.16** |
| 5% | random ×2 | 17.6–18.6 | 23.6–24.0 | 0.6–0.9 |

- **5% 下 construct 稳定超过两个 random 抽签**（+1.1~+2.1），且 std 只有 0.16（random 的 1/4~1/5）——核心质量主张在 63× 规模上成立；
- **1% 下 construct 反而略低于 random**（16.2 vs 17.7–17.9）：k=1354 对 40 类是每类平均 34 簇，maxmin 的覆盖优先在类多、预算极紧时会把簇花在语义外围，random 按数据密度采样反而更贴近类先验。这是一个诚实的边界条件：**构造器优势随 rate 增大而显现，极低预算下与 random 持平或略逊**（Cora 5% 也是它的验证点位，一致）。

## 3. 绝对值解读（防误读）

16–20 的 Macro-F1 看似低，但口径是 **40 类零样本 prompt 分类 + MiniLM-tiny 文本塔**（随机基线 2.5%）。此前 arxiv 上的旧管线记录（native/GraphCLIP 派生诸实验）同量级。它与 GCond/SFGC 报告的监督训练 Accuracy（60%+）**完全不可比**——本文的下游始终是零样本图文对齐，论文中需要专门一段说明该口径差异，避免审稿人拿监督数字横比。

## 4. 对照缺口（后补清单）

按方向E原计划，本轮完成了"构造 vs random，1%/5%，全阶段耗时"。尚缺：
1. **raw 直训参照**（135k 池直训，预计单 arm ~1 分钟，下轮补）；
2. GCond/SFGC 外部基线：口径不同（监督 vs 零样本），改为**只比凝聚耗时**（引用其论文报告的凝聚时间 vs 我们的 30s）；
3. 10% rate 点位（k≈13.5k，聚类预计 ~1 分钟，可行）；
4. 持续场景（arxiv 有天然 node_year 时间维度，temporal3 划分数据已在服务器上——这是把持续实验搬到大图的现成材料，作为 v2 阶段工作）。

## 5. 判定

- **Scalability gate：通过**。169k 节点全流程 3.5 分钟、凝聚本体 30 秒，MAG240M 采样子图在当前单卡上可行；
- **质量 gate：5% 通过（+1.1~2.1 且 std 最低），1% 不通过（−1.5）**——rate-优势关系作为发现如实报告；
- 更大规模（Reddit/MAG240M）的决策：**技术上已无障碍**，做不做取决于论文篇幅需要，优先级低于补 raw 参照与 arxiv 持续场景。
