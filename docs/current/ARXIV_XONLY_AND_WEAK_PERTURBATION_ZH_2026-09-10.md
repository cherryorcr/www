# arxiv X-only 决定性实验：推翻弱扰动假说，ASM 在大图上是真实优化

日期：2026-09-10
数据：服务器 `problem_validation_results/arxiv_xonly_2026_09_10/`（本地镜像 `arxiv_xonly/results.json`）
动机：多尺度 ASM 发现 arxiv 上 ASM +3.31（3/3 seeds），但 loss 仅降 3.7%。问题：这收益是"真实优化"还是"弱扰动碰巧有益"？本实验用**同文本、同k、同拓扑、仅X不同**的对照区分二者。

## 1. 实验设计（决定性对照）

所有 arm 共享**完全相同的文本、k=6773、拓扑、行数**，只有 synthetic X 不同：

| arm | X 来源 |
|---|---|
| frozen | 构造器初始 X |
| asm | ASM 优化后的 X |
| rand_perturb_0/1 | frozen X + 高斯噪声，**逐行模长匹配 ASM 的 $\|\Delta X\|$** |

判据：若收益来自弱扰动，随机扰动（同幅度）应给出相近收益；若来自真优化，随机扰动应无收益。

## 2. 结果

| arm | dev F1 | ASM X 逐行 $\|\Delta X\|$ |
|---|---:|---:|
| frozen | 19.74 | — |
| **asm** | **21.86** | 1.79 |
| rand_perturb_0 | 19.84 | 1.79（匹配） |
| rand_perturb_1 | 19.30 | 1.79（匹配） |

**随机扰动与 frozen 持平（+0.1/−0.4），ASM 高出 +2.1。** 幅度相同的随机扰动不产生收益，ASM 的特定方向产生收益。

## 3. 判定：弱扰动假说被推翻

- 此前（P2 小图 + 本轮多尺度）我们把 ASM 收益解释为"对 X 的弱扰动，方向由初始化质量调制"；
- **本实验否定该解释**：在 arxiv 大图上，ASM 的**方向**是有效的——同振幅随机噪声无收益，说明 +2~3 的收益来自 X 空间中有意义的优化方向，而非扰动的统计效应；
- 结合 loss 曲线：本轮 ASM loss 从 0.0467 降到 **0.0078**（降幅 83%），远高于多尺度 run 的 3.7%——**本轮 ASM 确实有效优化了目标**，且目标下降与下游收益同向。

## 4. 综合三尺度 + X-only 的最终图像

| 尺度 | ASM vs frozen | loss 降幅 | 解释 |
|---|---:|---:|---|
| Cora 2.7k | −0.25 | 5.2% | 无收益 |
| Citeseer 3.3k | −0.25 | 3.4% | 无收益 |
| arxiv 169k（多尺度 run） | **+3.31** | 3.7% | 有收益，方向部分有效 |
| arxiv 169k（X-only run） | **+2.12** | 83% | **方向明确有效，随机扰动无收益** |

**修正后的核心结论**（取代"弱扰动"）：

> ASM 的收益是**规模依赖且方向有效的**：在小图（2.7k–3.3k）上不带来收益；在 169k 大图上稳定带来 +2~3 的收益，且该收益**不可由同幅随机扰动复现**——即它来自真实的 X 空间优化，而非扰动统计。loss 降幅在不同 run/配置下差异大（3.7%–83%），提示优化有效性对超参（outer_lr、inner、steps）敏感。

## 6. 这对整个工作的影响（诚实评估）

这是本轮最重要的**自我修正**：TAGSAM 作者关于"我们方法在大图上可能有效"的方向是对的，我们此前基于小图的强结论过度外推了。需要同步修正的连带结论：

1. **"代理不可用"命题（T1）**：需在 arxiv 重做。小图上 5 统计量零相关，但大图上有真实优化收益空间——**若 ASM 收益是真的，就存在某个（未必是 embedding 统计的）可用信号**，T1 的"无代理"限定为小图；
2. **持续场景的 append 结论**：arxiv 持续实验用的是构造式 append；若大图上 ASM 有效，应补"持续场景下的构造式 vs ASM 更新"对比——可能 append 的优势在大图上不成立；
3. **方法定位**：从"构造式取代优化式"改为"**小图构造式、大图构造式+优化式并用**"；arxiv 上 ASM 的 +2~3 是真实的可报告收益。

## 7. 待补实验（修订主张前）

1. arxiv 上 ASM 多 seed 复核 +3.31（当前多尺度 run 3 seeds、X-only run 1 seed）——需统一到 5 seeds 坐实显著性；
2. arxiv 上 ASM vs **构造式+优化式并用**（frozen 初始化 + 少量 ASM steps，即"anchored 优化"）——这才是修正后方法的自然形态；
3. arxiv 持续场景的 ASM 更新对照；
4. 中间尺度定位"由负转正"的转折点。

## 8. 边界声明

- X-only run 的 random perturbation 只做了 2 draw、ASM 只 1 seed——**需扩 seed 才能把"方向有效"从强提示升级为确定结论**；
- loss 降幅在两 run 间差异巨大（3.7% vs 83%），提示超参敏感性，需固定配置重跑确认；
- 本节结论基于 arxiv 单数据集，结论外推到其它大图需谨慎。
