## 2. 三个结论

### 结论1（意外但证据充分）：凝聚小图直训超过全部 raw 直训

raw 上界只有 45.3——**低于四个 compact arm 中的三个**，且这次训练预算已配平（steps=16×2437 capped 8192），不是欠训假象。机制与 Gate 1'' 发现3同源：全 raw 图上做 batch CLIP InfoNCE 时，大量同类相似文本互为负例（2437 节点里 818 个 Neural Networks），对比目标本身被污染；凝聚后的 121 个融合簇文本彼此语义分离，负例干净。**在 CLIP 式 TAG 训练下，"凝聚"不只是压缩，还是去噪**——这个观察可以作为论文的独立卖点（compact ≥ raw 在图凝聚文献中通常只在优化式方法+监督下游中声称，我们在零样本文本下游给出构造式证据）。

也因此，"塑性差距"的参照系要修正：之前引用的 66 是 full-history（一次性重新凝聚）的当前阶段，不是 raw；raw 自己的当前阶段只有 43.7。**append 现状的 48.0 已经超过 raw 上界的当前阶段**。

### 结论2：预算分配存在小幅可得收益，最优在 keep77_new44 附近

- 34→44 行：当前 +6.0（48.0→54.1），累计基本不变（−0.4），旧阶段付出 −7.7；
- 继续扩到 54/64 行：全面变差（新块簇过细，每簇成员太少，融合文本退化为单条短文本）。
- **非单调**：塑性收益只在"每新类 11→15 行"的窄区间内存在，不支持任何激进的动态再分配。

### 结论3：确定性分配规则已足够，动态机制不立项

按预注册判定：这属于"结局一"（小幅可得+快速饱和）。采用静态规则并冻结：

```
新块配额 = max(每新类 c 行, 预算余量)，c=15（由本消融 dev 选出）
旧块收缩 = 按 mass 升序删行（只删行，不重组，不改文本）
```

无 per-stage 动态选择、无多预算训练搜索。理由：(a) 收益窗口窄且两侧都是坑；(b) 动态选择需要阶段内 dev 驱动的 memory 构造，协议上是灰色地带；(c) 确定性规则保持整链可复现。累计 vs 塑性的取舍（53.6/48.0 vs 53.1/54.1）作为一个显式报告的 trade-off 点，由应用方选 c。

## 3. 对照体系修正（记录在案）

Gate 1'' 的 "full_history" 是"允许重读历史时一次性重新凝聚到同预算"，**不是 raw 直训**。完整三层对照现已齐备：

| 对照 | s2 累计 | 含义 |
|---|---:|---|
| raw 直训（本实验补全） | 45.3 | 无凝聚、无持续约束 |
| full-history 重凝聚（Gate 1''） | 51.6 | 有凝聚、无持续约束 |
| **append-构造式（方法）** | **53.6** | 有凝聚、有持续约束 |

方法 ≥ 两个"违规上界"——当前管线下持续约束的代价已被完全消除，这是 Gate 1'' 结论的最强版本。
