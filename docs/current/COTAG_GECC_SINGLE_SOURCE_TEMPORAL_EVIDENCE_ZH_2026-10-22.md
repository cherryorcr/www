# GECC 单来源近邻文本适配：时间流配对实验

完成日期：2026-10-22。本批只增加对照实验与结果报告，没有修改论文或推送 Overleaf。

## 1. 结论

已完成 ArXiv、ACM、DBLP 三个发表年份时间流上的单来源近邻文本适配。复用每个数据集的三份原始 GECC 聚类记忆，每个阶段重新训练三个 student 种子，共九条完整五阶段序列、45 份记忆和 135 次 student 训练，没有 OOM 或运行失败。

**简化为单来源后，GECC 的最终累计 Macro-F1 基本不变，没有实质改变原有比较结论。** 单来源减五来源的差值为 ArXiv -0.0172、ACM +0.0099、DBLP -0.0114 个百分点。三个配对 95% 区间均跨零。这不是正式的等效性检验，但不支持“原五来源文本附着是 GECC 在 ACM、DBLP 上领先的主要原因”这一解释。

CoTAG-Q 对单来源 GECC 的最终累计 F1 差值为 ArXiv +0.77、ACM -0.52、DBLP -0.73 个百分点。ArXiv 的配对区间为 [0.27, 1.27]；ACM、DBLP 的区间跨零。DBLP 在仅当前快照下的五阶段平均仍落后，不能用最终阶段区间跨零代替完整过程的结论。

原五来源结果完整保留。单来源是一个额外的简洁适配版本和文本附着敏感性对照，不是为了替换较强结果而选择的新基线。

## 2. 到底改了什么

原 GECC-hard 适配先在当前阶段训练图上进行特征传播，再按类别分配记忆配额并聚类。传播特征为一跳和二跳归一化传播结果的加权和，权重分别为 0.3 和 0.9。每个类别进行 20 次随机初始化的硬 K-means，每次最多 300 次迭代，用簇内平方误差与簇大小不平衡惩罚选择结果。这是当前访问协议下的机制适配，不是完整原生 GECC 或其 soft 分支复现。

本次直接读取这些已经保存的聚类中心，不重新聚类。每个阶段的 `x`、`labels`、`mass`、`stage`、`depth` 和 `edge_index` 都与原记忆逐元素相同。

| 项目 | 原五来源适配 | 新单来源适配 |
|---|---|---|
| 合成数值特征 | 原 GECC 聚类中心 | 完全相同 |
| 文本候选池 | 当前合法训练池中的同类节点 | 完全相同 |
| 近邻度量 | 传播特征空间中与合成中心的余弦相似度 | 完全相同 |
| 文本来源 | 最邻近的至多五个节点 | 最邻近的一个节点 |
| 总文本上限 | 320 字符，来源之间平分，含分隔空格 | 320 字符，来自该单个节点 |
| 文本编码 | 冻结 MiniLM | 同一编码器 |
| 历史记忆 | 自己的历史前缀冻结 | 自己的单来源历史前缀冻结 |

候选池是整个当前同类池，不限于该中心的聚类成员。选择器没有训练参数，也没有 prompt 排序、图到文本映射或按下游分数选择文本。这里的“单来源”指单个真实节点的文本片段，不保证保留该节点的完整文本。

五来源通常保留每个来源前 63 个字符及四个空格，总计 319 字符；单来源最多保留同一来源前 320 个字符。因此实验同时改变了来源多样性和单篇文本的保留长度，不能将它解释成其他文本内容完全固定时的纯来源数量因果效应。

为排除选错来源或数值实现漂移，每个阶段先按原规则重建五来源文本，要求与旧记忆中的字符串完全一致，重新编码的向量满足预设误差界。单来源必须等于这个已核验五来源列表的第一项，再检查所有数值张量相同、自己的历史前缀不变，最后训练 student。

## 3. 固定协议与统计口径

- 三个数据集都沿用原来的五阶段发表年份划分、训练池、测试节点、类别 prompt 和两种推断快照。不使用未来节点进行推断。
- 固定累计合法训练池的 5% 记忆率，沿用原有取整预算。最终条目数为 ArXiv 5,927、ACM 592、DBLP 2,011。
- 复用构造种子 271006、271108、271109 的原始数值记忆；每份记忆使用 student seeds 150、151、152，2048 次更新、batch size 24、学习率 0.001。没有新增独立聚类或按结果调整训练预算。
- 先平均同一份记忆的三个 student 分数，再报告三个构造均值的平均值和样本标准差。配对区间使用三个匹配构造的差值，t 分布自由度为 2，未做多重比较校正。
- 五阶段平均是在每个构造种子内对五个阶段等权平均，再跨构造汇总。阶段和 student 重复不被当成额外独立构造。

两种推断条件分别是“已到达快照上的累计节点”和“仅当前快照上的当前节点”。它们的查询节点集合不同，不能直接用两列成绩之差衡量历史图不可访问的影响。

本次在已有时间流结果被查看后提出，属于事后敏感性实验。ArXiv 沿用以前的 `historical_test` 掩码，新输出统一写为 `test`，其哈希完全相同；ACM、DBLP 的 test 掩码也已在前一批中查看过。这里没有新增盲测数据。`report_dev` 另存，不混入 test 统计。

CoTAG-Q 和 CaT 表项复用前一批原始结果。CoTAG-Q 保留 GM 和 30 次构造更新，沿用 float64 Sinkhorn 归一化及 16384 求解上限的数值修复，没有因本次对照更改主方法。

## 5. 对论文结论的影响

这项实验解决的是“GECC 的比较结果是否严重依赖多来源文本附着”这个具体疑问。在当前三个时间流和共同 student 下，没有观察到这样的依赖。它不能证明文本完全无用，也不能从中单独确定传播、聚类或类别监督各自贡献了多少。

主方法相对单来源 GECC 的证据应分开解释：

- ArXiv 最终累计 F1 提高 0.77 个百分点，三个构造差值均为正，配对区间 [0.27, 1.27]。五阶段累计均值差值为 +0.75，区间 [-0.50, 2.01]，不能扩大成整个过程稳定显著领先。
- ACM 最终累计差值为 -0.52，区间 [-1.51, 0.48]。五阶段仅当前快照差值为 +0.42，区间 [-0.57, 1.42]，说明收益随评估对象变化，尚不能宣称普遍优势。
- DBLP 最终累计差值为 -0.73，区间 [-4.02, 2.56]；仅当前快照的五阶段均值差值为 -0.94，区间 [-1.76, -0.13]。后者仍是需要保留的局限。

建议将本实验作为文本适配敏感性分析，说明单来源已经是有竞争力的简单对照。时间流部分继续定位为对重复类别和时间到达条件的适用性验证，结合 ArXiv 上的具体收益报告，不写成对所有时间流数据的全面领先。原五来源 GECC 不因本次补实验而删除。

可使用的英文结果表述：

> Replacing the five-source text attachment in the GECC adaptation with a single nearest source changes final cumulative Macro-F1 by less than 0.02 percentage points on each of the three chronological streams. All paired 95% confidence intervals for these differences include zero. The comparison therefore remains largely unchanged under the simpler attachment rule.

## 6. 核验与归档

全部 45 份新记忆都通过数值张量一致性、历史前缀冻结、来源类别和访问范围检查。全部 45 份预测归档通过 SHA256 核验，用独立混淆矩阵计算重算了 2,592 个 F1/Accuracy 标量，与保存结果一致。九项单元测试在本地和远程均通过。原始参考成绩没有重新训练，也没有被覆盖。

最终单来源文本的平均长度为 ArXiv 319.69、ACM 275.47、DBLP 293.25 字符；完整记忆的文本唯一率分别为 97.44%、98.65%、97.71%。与原五来源相比，字符串实际改变比例分别为 99.98%、100%、100%。因此分数近似不变不是因为文本干预没有实施。

本批复用了聚类结果，只计时传播重建、文本核验、文本附着和 student 评估，不能据此声称完整 GECC 构造更快。原始聚类成本仍属于前一批实验。资源记录逐阶段保留。
