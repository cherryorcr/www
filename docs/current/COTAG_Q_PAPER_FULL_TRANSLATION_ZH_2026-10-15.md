## 摘要

持续式文本属性图（TAG）凝聚需要在历史原始节点和边不再可供构造器访问时，保留有用的多模态信息。本文研究这一历史访问受限设定，提出以可学习图文支持关系为核心的持续式 TAG 凝聚器 CoTAG-Q。每个阶段，一个类别受限、容量平衡的分配矩阵 \(Q\) 通过同一支持关系池化当前图特征，并路由真实文本负载。CaT 风格的循环内分布匹配和学生模型兼容的构造目标共同更新 \(Q\) 与受限特征修正；最终记忆从学习后的分配中材料化具有可审计来源的真实文本。新增行追加到冻结的历史前缀。主记忆不保存显式边，但构造过程使用当前阶段的图结构。

在精确的累计 5% 节点保留率、三种类别顺序和三个构造种子下，CoTAG-Q 在 ArXiv、SportsFit、BookHis 上比匹配的 CaT 适配版本提高 5.58–19.66 个 Macro-F1 百分点。相对 GECC-hard-TAG，在 BookHis 上九个配对单元均取得提升，平均提高 3.47 点；ArXiv 和 SportsFit 的排名则依赖数据集。保留可训练特征修正但固定 \(Q\) 会使 Macro-F1 下降 8.91–21.67 点，去除分布匹配会下降 1.30–14.74 点，说明学习支持关系和循环内分布匹配是最可靠的性能来源。同一批 ArXiv 记忆迁移到 GraphSAGE 学生模型后，比 GECC-hard-TAG 高 1.34 点。在相同有限训练预算下，相对保留训练池诱导拓扑的匹配完整历史参考，5% 记忆保留了 98.23–103.33% 的 Macro-F1 和 95.58–99.14% 的 Accuracy。结果表明，可学习图文支持关系是历史访问受限持续式 TAG 凝聚中有用的构造接口，但不表示在所有数据集或任务上都一致占优。

**关键词：**文本属性图；持续式图凝聚；历史访问受限；可学习图文支持关系；可微文本路由；基于 prompt 的读出。

## 1 引言

### 1.1 研究动机

文本属性图（TAG）结合了关系结构与节点级语言。有效的凝聚条目必须保留对下游学生模型有用、且相互兼容的数值表示、标签和可读文本负载。在持续式凝聚中，图分阶段到达，构造器可能无法重访早期阶段的原始特征、文本或边。此时记忆不只是更小的图，更是过去的多模态信息影响未来构造的持久接口。

本文在一个明确的访问规则下研究这一接口：阶段 \(t\) 的构造器得到当前增量与阶段 \(t-1\) 保存的合成记忆，而不接触历史原始数据。它必须追加小规模记忆块、保留类别覆盖，且不能暗中使用原始历史。关键问题并非静态 TAG 方法能否使用文本，而是持续式构造器如何决定哪些当前节点支持每个新特征、以及应随该特征保存哪条真实文本。

### 1.2 问题与设计目标

核心设计目标是在当前原始节点与合成槽位之间建立可学习的支持关系。仅图凝聚器加独立文本附着是一项有力且合理的对照，但这样选择的文本不参与特征构造目标。我们要检验的是：在仅访问当前增量的条件下，一个可审计的分配是否可以同时提供特征支持与文本支持。这不是说所有文本感知 TAG 方法都将两者割裂；TAGSAM、STAD 已包含实质性的文本机制。本文贡献聚焦在持续式构造接口及其在同一访问边界下的评估。

### 1.3 我们的方法

我们提出 CoTAG-Q，一种主记忆不保存显式边、但构造过程感知图结构的持续式 TAG 凝聚器。当前节点特征、一跳图消息和冻结 MiniLM 文本嵌入共同初始化类别受限的分配 \(Q\)。容量平衡的 Sinkhorn 算子将 logits 转成可用的支持权重。同一个 \(Q\)：

1. 将当前特征池化为新增合成行；
2. 路由真实文本嵌入，并选择可审计的源字符串；
3. 为槽位提供图消息匹配目标；
4. 接收循环内构造目标的梯度。

该分配与受限特征修正共同优化。循环包含 CaT 风格的类别统计分布匹配、传播匹配，以及与学生模型兼容的图文目标。最终文本负载由硬前向所用的同一条清理后源文本材料化，软路由为 \(Q\) 提供代理梯度。因此，方法不会先生成不可读向量再换成无关字符串。

主记忆保存特征、真实文本、标签和审计元数据，不保存合成邻接。这是明确的范围边界：构造仍使用当前增量图。独立的 CoTAG-Q-T 分支为结构任务材料化合成边。本文主要结论关于无显式边记忆的 prompt 节点分类；拓扑保留作为扩展单独评估。

### 1.4 贡献与研究范围

本文有三项贡献：

1. 定义并审计历史访问受限的持续式 TAG 凝聚协议：构造只访问当前增量，使用固定比例的累计记忆，冻结历史合成前缀；让记忆中保留的信息明确且可复现。
2. 提出 CoTAG-Q，通过一个可学习的类别受限支持关系共同组织图感知特征池化与真实文本路由。支持关系是可优化的构造变量，而非固定池化或事后文本附着规则。
3. 区分机制证据与基准覆盖。三张大图的九个顺序/种子单元中，方法始终优于匹配的 CaT 适配，在 BookHis 上比 GECC-hard-TAG 高 3.47 个 Macro-F1 百分点。受控实验显示学习 \(Q\) 和循环内分布匹配是最可靠的性能机制；同记忆 GraphSAGE 迁移和匹配完整历史保留率检验稳健性与压缩效用。

结果并不支持普遍 SOTA：在主比较中，GECC-hard-TAG 在 SportsFit 更强，在 ArXiv 与本方法统计上相近。消融也未表明共享两个分配、额外配对反馈路径或单独的梯度匹配能普遍提高精度。我们将这些组件保留在完整方法中，是因为它们定义了统一构造接口，并明确报告其取舍，而不将其表述为各自被证实的增益来源。

主要下游任务是图感知无显式边记忆上的 prompt 节点分类。带拓扑的 CoTAG-Q-T 分支单独研究；本文的 prompt 读出不声称严格的未见类别零样本学习。

## 2 问题定义与持续式协议

### 2.1 持续式 TAG 凝聚

令阶段 \(t\) 到达的合法构造数据为

\[
\Delta_t=(V_t^{\rm raw},X_t^{\rm raw},T_t^{\rm raw},Y_t^{\rm raw},E_t^{\rm raw}),
\]

其中，\(V_t^{\rm raw}\) 包含当前构造池节点，\(E_t^{\rm raw}\) 包含该阶段可用的边。验证和测试节点不进入构造池。令 \(M_{t-1}\) 表示上一阶段结束后保存的合成记忆。合法构造器接收

\[
\mathcal I_t=\{\Delta_t,M_{t-1}\},
\]

并输出追加后的记忆

\[
M_t=M_{t-1}\oplus M_t^+.
\]

对于无显式边主方法，新行包含特征、文本负载和标签：

\[
M_t^+=(X_t^{\rm syn},T_t^{\rm syn},Y_t^{\rm syn}),\qquad A_t^{\rm syn}=\varnothing.
\]

空合成邻接隐式表示，不予保存。这并不意味着输入增量没有图：构造器可以使用 \(E_t^{\rm raw}\)，并将其用于局部结构信号和传播目标。

### 2.2 固定比例的累计预算

我们使用固定比例的累计节点预算，而非固定绝对大小的记忆。令 \(\rho\) 在构造之前确定，并令

\[
N_t^{\rm pool}=\sum_{s\le t}|V_s^{\rm raw}|
\]

为截至阶段 \(t\) 已观察的合法构造节点数。名义累计目标为

\[
\bar K_t=\operatorname{round}(\rho N_t^{\rm pool}).
\]

为避免取整使某个类别从类别增量记忆中消失，我们采用明确记录的类别覆盖下限：

\[
K_t=\max\{\bar K_t,\ |M_{t-1}|+|\mathcal C_t|\},\qquad m_t=K_t-|M_{t-1}|,
\]

其中，\(m_t\) 是新增槽位数，\(\mathcal C_t\) 是当前增量中出现的类别集合。若覆盖下限使 \(K_t\) 超过名义目标，审计清单会记录实际比例。主要比较中，\(\rho=5\%\)，分母为合法构造池，而非包含留出节点的完整图。

当前每个类别先分配一个槽位。剩余槽位根据当前类别节点数，使用最大余数法按比例分配；每类配额不超过该类可用原始节点数。这避免了“每类三个槽位”等手工规则，同时防止小类消失。若某个调度无法在可用原始行数内覆盖所有当前类别，则拒绝并报告该调度，而非悄悄改变任务。

固定比例形式遵循 CaT [1] 使用的基于比例的持续记忆设计：记忆随数据流增长，但不同数据集、阶段的压缩程度保持可比。主要比较采用预先指定的 5% 工作点。第 6.4 节单独的报告开发集比例敏感性研究考察性能与构造成本之间的取舍；它不是对比例选择过程的独立测试。

### 2.3 访问边界与记忆语义

构造访问规则为

\[
\operatorname{Input}_t=\{\Delta_t,M_{t-1}\}.
\]

不能重新读取历史原始特征、文本和边。在主协议中，合成前缀只读：其行可作为已保存的上下文使用，但添加新块时不重新优化。仅追加是在原始数据访问边界之上另加的设计选择，并非唯一的持续学习策略。冻结将每个新增量的构造隔离开来，并在原始来源不可用时保留先前存储的负载。使用更早的带拓扑实现进行的旧记忆更新试验，在两个数据集上获得了更低的 Macro-F1（附录 A）。它支持将刷新单独报告，但不能证明刷新会损害最终方法。

构造时，当前增量可以用于计算图消息。学生模型训练时，各方法通过共同接口、训练预算、文本编码器和 prompt 定义使用各自保存的记忆。评估时，传导式评估器可以根据数据集协议使用完整图的特征和邻接；这种评估器侧访问与构造器边界分开，不会让构造器获得历史原始数据。

因此，主方法存储接口为

\[
M_t=\{X_t^{\rm syn},T_t^{\rm syn},Y_t^{\rm syn},\text{audit}_t\},
\]

其中，审计字段包括源标识、划分掩码、实际预算和构造哈希。CoTAG-Q 不保留合成边。带拓扑分支 CoTAG-Q-T 构造并保存独立的合成邻接，将其作为扩展评估，而不并入无显式边主方法的结论。

### 2.4 文本处理与学生模型读出

在匹配的 Prompt Student 实验组中，各方法使用相同的冻结 MiniLM 编码器 [13]。文本经共同预处理规则清理，并在编码前限制为 320 个字符。这是控制记忆和分词器开销的实现设置，并非认为更长文本没有信息；这些实验组中所有携带文本的方法均采用同一规则。历史 Legacy Student 实验和本地 Qwen 的 STAD 参考采用不同模型约定，单独报告。

主要下游模型是基于 prompt 的图文学生模型。训练使用记忆标签、类别 prompt 和图文配对损失。预测时不再拟合额外的任务专用分类头，而是将图表示 \(h_i^g\) 与每个类别 prompt 的归一化表示 \(p_c\) 比较：

\[
\hat y_i=\arg\max_c\cos(h_i^g,p_c).
\]

这是一种基于 prompt 的余弦读出。它与 GraphCLIP [11] 的读出有关，但不等同于严格的未见类别零样本学习：构造和学生模型训练仍使用当前评估协议中的标签。主要比较使用 Prompt-GCN，迁移和稳健性检查使用 Prompt-SGC 和 Prompt-GraphSAGE，同时保持相同的记忆和文本接口。

### 2.5 评估协议

我们报告最终 Macro-F1 和 Accuracy。持续式分析另外报告 Old F1 和 New F1，两个类别组由类别到达的阶段定义。主要报告区分三层证据：

1. **事后固定掩码配对评估：**注册了比例、合法构造池、类别顺序集合、构造种子集合和学生模型种子集合。留出掩码已被反复查看，不是新的盲测或封存测试。
2. **报告开发集比较：**用于调试、比例敏感性分析和方法开发，但不据此改写主要固定掩码表。
3. **仅供参考的评估：**官方检查点、简化的启发式对照，或原始任务与访问边界不同于持续式 TAG 凝聚的方法。

主要九单元比较包含共同学生模型和访问边界下的 CaT-CCTP、GECC-hard-TAG。另一个单顺序、五数据集实验组，在相同学生模型下增加选择对照、PUMA-inspired、GCond-x core 和 SFGC bounded core，但构造预算不相等。TAGSAM、STAD、DANCE、SR-GM 和 GraphCLIP 的不同实现或评估状态在第 3 节说明；适配版本绝不称为官方复现。独立分配、no-GM、no-DM、fixed-Q、类别共享文本和随机文本等内部变体属于组件消融，而非外部基线。

## 3 相关工作与基线适配

### 3.1 图凝聚与无显式边记忆

图凝聚构造小型训练集，使其效用接近大图。GCond 匹配真实图与合成图产生的梯度，并能联合优化合成特征和参数化邻接 [9]。其 GCond-x 设定已经表明：构造时可以使用图，而下游凝聚表示实际上不保存显式边。SFGC 通过训练轨迹匹配研究了相关的无图方向 [12]。这些工作说明，图感知构造但不保存合成边是已有设计选择，本文不将其作为新原语。GCondenser 是这类方法的基准和评估工具包，而非额外构造器 [10]。

CaT 是最接近的持续式图凝聚先例 [1]。它通过类别级分布匹配和 Training-in-Memory，为到达的数据构建凝聚图记忆，并跨阶段累积记忆。其特征更新基于梯度，但核心操作不同于 GCond 使用的完整参数梯度场匹配。CaT 没有为 TAG 学生模型规定可读文本负载接口。因此，我们的 CaT-CCTP 保留 CaT 风格的特征构造，并添加 TAG 评估所需的共同当前增量文本附着。

PUMA 通过伪标签、高效传播和重新训练策略扩展持续图学习 [3]。其原始假设不同于历史访问受限的 TAG 记忆。我们的单顺序 PUMA-inspired 使用本地伪教师封装，而非完整官方方法；它是有用且在部分数据集上有竞争力的参考。

GECC 面向图和记忆规模不断增长时的可扩展凝聚 [2]。它在类内对传播特征聚类，包含硬分配与软分配变体，并在演化过程中池化聚类代表。因此，类别级软分配和质心池化均属于已有技术。我们主要匹配的 GECC-hard-TAG 基线保留硬聚类分支，并添加与本文方法相同的文本接口和学生模型；不声称复现了所有原生 GECC 变体。

### 3.2 静态与多模态 TAG 方法

TAGSAM 是静态 TAG 凝聚方法，选择并合并文本块，进行属性相似性匹配 [4]。它直接处理可读文本和图文学习，因此本文贡献不能仅概括为“使用文本”。区别在访问边界：TAGSAM 可以基于静态源图构造，本文则必须在不重新读取历史原始节点的情况下追加新块。受限适配从当前增量中随机选择中心并保留其标签，不施加本文方法的类别槽位配额；将构造限制在每个增量并冻结前缀会改变静态方法的访问和优化假设。

STAD 研究半监督静态 TAG 蒸馏 [5]，结合图感知和无图编码器、协同自训练、Wasserstein 风格的摘要以及基于聚类关键词的文本合成。用本地特征聚类和源文本选择替代这些组件，可提供参考，但不是忠实复现。因此，我们将简化的大图行称为 STAD-inspired。另一个 STAD core 适配版本使用本地 Qwen 生成和改变后的内部半监督划分；二者均未复现原始静态协议。

DANCE 面向联邦 TAG 学习 [6]。其按轮次进行的设定、分层邻居文本证据、可读摘要及自表达拓扑重建，解决的是不同的系统问题。将根节点文本与邻居文本拼接的本地持续式封装不能复现这些机制；此类行明确标为 DANCE-inspired。

SR-GM 研究静态多模态凝聚，采用模态梯度冲突投影和梯度场的 Dirichlet 阻尼 [7]。它启发了对图与文本目标冲突的测量，但其原始优化调度和模态不同于本文持续式 TAG 协议。小规模代理细化可以作为机制参考，不能作为官方复现。

GraphCLIP 是图文预训练和迁移模型，而非凝聚算法 [11]。其 prompt 读出启发了我们的学生模型接口；但在本地子集上使用冻结 GraphCLIP 检查点，仅是官方检查点参考，不是共同预算下的凝聚基线。

### 3.3 什么才是公平基线

数值比较采用三种标签：

1. **官方复现：**保留已发表工作的任务、数据访问假设、核心目标、下游模型和评估协议。任务改变后，仅使用官方代码或权重不足以使实验成为官方复现。
2. **匹配的机制适配：**保留核心机制，但改变访问封装、记忆格式、文本接口和学生模型，从而能在持续式 TAG 协议下比较。
3. **简化的启发式对照：**只保留高层思想，省略某个原生核心模块。它有参考价值，但不能证明优于已发表算法。

### 3.4 已实现的外部适配

对 CaT-CCTP，合成特征由当前真实特征初始化，并通过随机线性和 ReLU 投影中的类别级分布匹配，逼近一跳传播目标。随后，CCTP 按图特征相似性对同类当前增量节点排序，选择最多五条源文本，分配总计 320 字符的预算，拼接选中的字符串，再用共同 MiniLM 编码器重新编码。文本负载在特征构造之后附着，不反馈到 CaT 更新中。

对 GECC-hard-TAG，我们在每类内部对当前增量传播特征进行平衡硬聚类，使用簇内误差和大小惩罚，从经审计的硬聚类重启中选择最佳结果，再采用相同的五源文本适配器。该封装使用共同冻结前缀和学生模型，因此属于匹配机制适配，而非原生 GECC 基准的复现声明。

较早的简化 STAD、DANCE、SR-GM-inspired 行使用 Legacy Student，保留为单独历史参考。相比之下，更新的五数据集实验组中，PUMA-inspired、四个选择对照、GCond-x core 和 SFGC bounded core，使用共同 Prompt Student 和掩码，进行单顺序评估。受限 TAGSAM 和本地 Qwen STAD 核心也在三张大图上使用这一学生模型，但构造预算或监督不同，列入独立参考表。冻结 GraphCLIP 检查点属于不同模型参考，而非构造器比较。

受限 TAGSAM 核心保留前驱邻域构建、句子分组、GPT-2-large 词级 PMI 得分、相关性/冗余贪心选择和加权特征初始化。封装将每个邻域限制为四个节点和四跳，使用共同的 320 字符负载与 MiniLM，并修复尾批次和空组情况。其响应匹配采用 100 次外层更新、每次 10 次内层更新和 256 行参考上限，而非官方的 5,000×15 调度及原生下游学习率。附录 B 的末阶段 100/500 次更新诊断检验这一预算敏感性，不构成原生复现。

STAD 核心保留图自训练、伪标签、加权粗化、双重平滑、关键词提取、文本候选生成和 Wasserstein 风格候选选择。它使用本地 Qwen2.5-1.5B 和 MiniLM 而非原生模型；内部按类约 10% 训练、10% 验证，其余可用于伪标签，单节点类别只提供训练样本，双节点类别各提供一个训练和验证样本。这与主方法全监督构造池的监督条件不同，此外还改成冻结前缀和共同最终学生模型。其低分不衡量 STAD 原论文协议下的性能。

### 3.5 与 CoTAG-Q 的关系

本文方法在上述基线未直接提供相应交互的设定下，组合了已有构件。Sinkhorn 归一化 [8]、池化、梯度匹配、分布匹配以及选择可读源文本，均是已知操作。方法贡献在于：历史原始数据不可用时，使同一个类别受限分配 \(Q\)，成为特征支持、文本支持和构造反馈的共同接口。这样得到的记忆具有可审计文本来源，构造目标也引用同一分配关系。

共享分配是一种结构性假设，不是保证精度提升的机制。因此，我们包含独立特征/文本分配以及随机或固定分配对照。已有独立分配结果未证明单纯共享会带来 F1 优势。无显式边 CoTAG-Q 与带拓扑 CoTAG-Q-T 分别评估，因为二者支持的下游结论不同。

## 4 方法：学习图文支持关系

### 4.1 构造接口与可训练变量

**图 `fig:method_flow`：CoTAG-Q 的构造。** 当前图、特征和文本证据初始化类别受限分配。循环内目标联合更新其 logits 与受限特征修正。保存的记忆包含特征、真实文本负载和标签；合成边属于独立的 CoTAG-Q-T 扩展。

[查看原图](D:/Aprojects/continue_tag_condensation/paper_www/figures/unified_q_flow.png)

在阶段 \(t\)，CoTAG-Q 读取当前合法增量 \(\Delta_t\) 和冻结合成前缀 \(M_{t-1}\)。第 2 节的固定比例调度为 \(n_t\) 个当前节点分配 \(m_t\) 个新槽位。当前每类至少获得一个槽位，剩余槽位按其节点数比例分配。用 \(\mathcal I_c\)、\(\mathcal J_c\) 分别表示类别 \(c\) 的原始行和槽位。下文在上下文明确时省略阶段下标。

构造变量为分配 logits \(Z\in\mathbb R^{n\times m}\) 和特征修正 \(R\in\mathbb R^{m\times d_x}\)。类别掩码 Sinkhorn 算子将 \(Z\) 映射为 \(Q\)，其中 \(Q_{ij}\) 表示原始节点 \(i\) 对槽位 \(j\) 的贡献。同一个 \(Q\) 用于池化特征和路由文本。原始特征与文本编码器均不更新，历史记忆行和构造代理参数在此循环中也固定。输出为追加的特征、可读文本与标签块：

\[
M_t=M_{t-1}\oplus\{(x_j^{\rm syn},t_j^{\rm syn},y_j^{\rm slot})\}_{j=1}^{m}.
\]

循环前不单独执行 CaT 优化：CaT 风格分布匹配直接放在联合更新内部。图用于构造记忆，但主方法最终保存的记忆没有合成边。

### 4.2 图文证据与原型初始化

令 \(\operatorname{Norm}(v)\) 表示带数值保护的逐行欧氏归一化。区分原始特征 \(x_i^{\rm raw}\) 及其单位长度版本 \(u_i=\operatorname{Norm}(x_i^{\rm raw})\)。当前文本通过合并空白清理，最多保留 320 字符，尽可能退回单词边界截断。冻结 MiniLM 编码器产生

\[
e_i=\operatorname{Norm}(\operatorname{MiniLM}(t_i^{\rm clean})).
\]

候选池由当前合法增量中的全部文本组成。文本在预处理后编码，因此构造中使用的嵌入与可保存字符串对应。不需要生成文本，也不访问历史原始文本。

我们为不同目的使用两个结构信号。令 \(A\) 为当前增量去重、无向、无自环的二值邻接矩阵。初始化消息为

\[
h_i=\operatorname{Norm}\big((AU)_i+10^{-6}u_i\big),\qquad U=[u_1;\ldots;u_n].
\]

它描述邻居特征的方向；很小的自特征项为孤立节点提供回退。匹配目标使用含自环的归一化算子：

\[
\widehat A=D^{-1/2}(A+I)D^{-1/2},\qquad H=\widehat A X^{\rm raw},
\]

其中 \(D\) 为 \(A+I\) 的度矩阵。这里 \(H\) 由原始、未归一化特征计算，因此初始化方向与传播匹配目标明确是不同量。

为初始化槽位，定义联合签名

\[
v_i=\operatorname{Norm}\big([\sqrt{w_x}u_i;\sqrt{w_h}h_i;\sqrt{w_e}e_i]\big).
\]

每类第一个原型选择与归一化类别平均签名余弦相似度最高的节点。后续原型最大化其与已选签名之间的最小余弦距离：

\[
i_{r+1}=\arg\max_{i\in\mathcal I_c\setminus\mathcal P_r}\min_{\ell\in\mathcal P_r}(1-v_i^{\mathsf T}v_\ell).
\]

每个选中节点提供特征、消息与文本原型 \((p_j^x,p_j^h,p_j^e)\)。初始类内 logits 为

\[
Z_{ij}^{0}=w_xu_i^{\mathsf T}p_j^x+w_hh_i^{\mathsf T}p_j^h+w_ee_i^{\mathsf T}p_j^e,
\quad i\in\mathcal I_c,\ j\in\mathcal J_c.
\]

所有数据集的主配置均使用 \((w_x,w_h,w_e)=(1,0.75,0.35)\)。原型确定初始化后保持固定；后续循环学习 \(Z\) 和 \(R\)，而不是反复选择新原型。

这一初始化提供图文支持先验，而非已经完成的凝聚特征。初始池化特征可以随分配改变。文本首先参与原型和兼容性评分，随后参与可微代理损失。

### 4.3 类别受限、容量平衡的分配

对于含 \(n_c\) 个原始行和 \(m_c\) 个槽位的类别，对 \(Z_c/\tau\) 进行 Sinkhorn 归一化 [8]，边缘约束为

\[
Q_c\mathbf 1=\mathbf 1,\qquad Q_c^{\mathsf T}\mathbf 1=\frac{n_c}{m_c}\mathbf 1.
\tag{Q 边缘约束}
\]

每个原始节点贡献单位总质量，同类各槽位接收相同总容量。等价地，这是在上述约束下，最大化 \(\langle Q_c,Z_c\rangle+\tau\mathcal H(Q_c)\) 的熵正则分配，其中

\[
\mathcal H(Q_c)=-\sum_{ij}Q_{ij}\log Q_{ij}.
\]

实现从 \(L=Z_c/\tau\) 开始，交替进行对数空间的行、列缩放：

\[
\begin{aligned}
L_{ij}&\leftarrow L_{ij}-\operatorname{LSE}_kL_{ik},\\
L_{ij}&\leftarrow L_{ij}+\log(n_c/m_c)-\operatorname{LSE}_kL_{kj}.
\end{aligned}
\]

\(\operatorname{LSE}\) 为 log-sum-exp。先执行 30 轮缩放；若最大行质量误差或相对列质量误差超过 \(10^{-4}\)，则增加迭代，最终确认配置最多 4,096 轮。主温度为 \(\tau=0.35\)。

只有合法类别块参与计算。虽然未使用 logits 以有限哨兵值 \(-10^4\) 分配，但完整 \(Q\) 先初始化为零，仅填入合法块：跨类别贡献严格为零，而不是小的负池化权重。

这种平衡避免几乎所有原始质量集中到少量槽位，而其他槽位没有支持。它不要求不同槽位必须选择不同硬文本；文本来源多样性单独测量。用 \(Q_0\) 表示由 \(Z^0\) 得到并停止梯度的分配。

### 4.4 共享特征支持与真实文本路由

令 \(a_j=\sum_iQ_{ij}\)。特征在原始尺度上池化：

\[
\bar x_j(Q)=\frac{\sum_iQ_{ij}x_i^{\rm raw}}{a_j},\qquad x_j^{\rm syn}=\bar x_j(Q)+r_j.
\tag{Q 特征构造}
\]

初始化 \(R=0\)，并对每个修正施加约束：

\[
\|r_j\|_2\leq\epsilon_x\max(\|\bar x_j(Q)\|_2,10^{-3}),\qquad\epsilon_x=0.05.
\tag{残差半径}
\]

修正使槽位能够超出严格平均值移动，同时避免变成可自由优化、与支持节点无关的特征。每次更新后，投影尺度都根据当前池化特征重新计算。

共享分配同时定义软文本表示：

\[
\widetilde e_j(Q)=\operatorname{Norm}\left(\frac{\sum_iQ_{ij}e_i}{a_j}\right).
\]

为保留可读负载，主方法选择一个同类来源：

\[
i_j^\star=\arg\max_{i\in\mathcal I_{y_j^{\rm slot}}}Q_{ij},\qquad t_j^{\rm syn}=t_{i_j^\star}^{\rm clean}.
\]

不同槽位可以选择不同文本；若同一文本在多个列中得到最大质量，也可能被重复选择。这是节点专属选择，而不是预设的类别共享负载。

argmax 没有有用的普通导数，因此构造时采用直通文本值：

\[
e_j^{\rm ST}=e_{i_j^\star}+\widetilde e_j-\operatorname{sg}(\widetilde e_j),
\tag{文本直通估计}
\]

其中 \(\operatorname{sg}\) 表示停止梯度。数值前向值是选中真实文本的嵌入；对于 \(Z\) 的反向导数，则由经过 \(Q\) 的软路由提供。并不对 argmax 本身求导。这是代理梯度，而非离散文本选择的精确导数。

最后一次更新后，重新计算 \(Q\)，按同一选择规则保存清理后的字符串、源标识及重新编码的嵌入。检查保存嵌入与选中构造嵌入的差异在 \(10^{-4}\) 内。这一材料化约定避免训练中使用软表示、保存时换成另一负载而不加说明。优化全程中，编码器与原始文本字符串保持固定。

### 4.5 循环内图文匹配

目标有三种设计作用：梯度匹配比较图文记忆产生的学习信号，分布匹配约束当前类别级图统计量，传播匹配约束各槽位表示的图消息。第 7 节评估其预测效果；这些作用并不预设每一项都独立必要。

**与学生模型兼容的梯度匹配。** 使用随机初始化的两层 GCN 代理，图和文本投影参数记为 \(\theta\)。真实输入是冻结前缀（仅自环）与采用 \(\widehat A\) 的当前原始图组成的块对角并集。合成输入为相同前缀和新槽位，全部采用单位传播。主方法两侧均不增加跨阶段边。

代理损失为

\[
L_{\rm proxy}=0.5L_{\rm pair}+L_{\rm prompt}+0.1L_{\rm margin}.
\]

\(L_{\rm pair}\) 为双向多正例图文 InfoNCE，同类样本为正例；\(L_{\rm prompt}\) 是对投影后类别 prompt 余弦相似度的交叉熵；\(L_{\rm margin}\) 对正确 prompt 和最强错误 prompt 使用 0.20 的间隔。当旧类和新类同时存在时，两组各占一半损失质量。组内先按类别等权，再对类内节点均匀加权。这避免较大的当前类别压过已保存的历史监督。

固定代理参数，计算参数梯度：

\[
\begin{aligned}
g_r&=\nabla_\theta L_{\rm proxy}(M_{t-1}\oplus\Delta_t),\\
g_s&=\nabla_\theta L_{\rm proxy}(M_{t-1}\oplus M_t^+).
\end{aligned}
\]

真实梯度停止梯度，每阶段仅缓存一次。每个构造步骤重新计算合成梯度，并保留其求导图。最小化

\[
L_{\rm GM}=1-\cos(g_r,g_s)+0.25\left|\log\max(\|g_r\|_2,\eta)-\log\max(\|g_s\|_2,\eta)\right|,
\qquad\eta=10^{-8}.
\tag{GM}
\]

对此损失反向传播涉及二阶导数：反馈经池化特征和直通文本路径到达 \(Z\)，经合成特征到达 \(R\)。代理仅用于构造；下游学生模型在已保存记忆上重新训练。

明确地说，特征路径为

\[
Z\rightarrow Q\rightarrow X^{\rm syn}\rightarrow g_s,
\]

文本路径为

\[
Z\rightarrow Q\rightarrow\widetilde E\rightarrow E^{\rm ST}\rightarrow g_s.
\]

两条路径在同一个代理梯度和同一次分配更新中汇合。文本损失梯度因此能改变同时用于池化特征的支持权重，后续更新也可以改变选中的源文本。源字符串固定，词元和生成文档均非优化变量。

**CaT 风格分布匹配。** 遵循 CaT [1] 的随机投影类别统计匹配，采样固定投影矩阵 \(W_b\)，并定义 \(\phi_b(v)=\operatorname{Norm}(\operatorname{ReLU}(vW_b))\)。对当前每类：

\[
\mu_{bc}^{r}=\frac{1}{n_c}\sum_{i\in\mathcal I_c}\phi_b(H_i),\qquad
\mu_{bc}^{s}=\frac{1}{m_c}\sum_{j\in\mathcal J_c}\phi_b(x_j^{\rm syn}).
\]

损失为

\[
L_{\rm DM}=\frac{1}{B}\sum_{b=1}^{B}\sum_{c\in\mathcal C_t}\|\mu_{bc}^{s}-\mu_{bc}^{r}\|_2^2.
\tag{DM}
\]

主配置使用四个宽度为 512、Xavier 初始化的投影。真实目标是固定的当前图消息；单位传播下，合成消息就是特征本身。这一项在循环内更新 \(Z\) 和 \(R\)。它是图特征分布匹配，不是另一个节点级图文联合分布目标。

**槽位级传播匹配。** 每个槽位计算路由图目标与合成方向：

\[
h_j^{\rm target}(Q)=\operatorname{Norm}\left(\frac{\sum_iQ_{ij}H_i}{a_j}\right),\qquad
h_j^{\rm syn}=\operatorname{Norm}(x_j^{\rm syn}).
\]

余弦损失为

\[
L_{\rm prop}=\frac{1}{m}\sum_j\left(1-(h_j^{\rm target})^{\mathsf T}h_j^{\rm syn}\right).
\tag{传播匹配}
\]

不同于类别均值匹配，该项作用于单个槽位。目标路由与合成特征均依赖 \(Q\)，因此也影响分配。它将当前结构信息转移到特征中，而不重建或保存合成边。

### 4.6 联合更新与记忆材料化

主方法完整目标为

\[
L=L_{\rm GM}+L_{\rm DM}+0.5L_{\rm prop}+0.1L_Q+0.1L_X,
\tag{总目标}
\]

初始化与修正惩罚为

\[
\begin{aligned}
L_Q&=\frac{\|Q-Q_0\|_F^2}{nm},\\
L_X&=\frac{1}{md_x}\sum_j\frac{\|r_j\|_2^2}{\max(\|\bar x_j(Q_0)\|_2,10^{-3})^2}.
\end{aligned}
\]

修正惩罚使用初始池化尺度，而残差半径硬约束使用当前池化尺度。由于旧行不可变，不存在旧记忆刷新损失；由于没有提供预训练 CaT 特征，也不存在 CaT 热启动锚定。

Adam 对 \(Z\)、\(R\) 联合更新 30 个构造步骤，学习率分别为 0.15 和 0.005，总梯度范数裁剪阈值为 5。代理隐藏层与输出维度均为 384。每次更新后，将修正投影回半径约束。主要数据集共享全部设置。这是同时可微优化，不是 EM 过程，也不是对文本编码器和图特征进行交替优化。

阶段级算法如下：

1. 按固定比例累计调度分配有标签槽位，加载当前增量和只读合成前缀。
2. 编码清理后的当前文本，计算图信号，选择联合原型，初始化 \(Z^0,Q_0,R=0\)。
3. 缓存真实代理梯度及随机投影类别目标。
4. 重新计算 \(Q\)、池化特征、硬前向/软反向文本及各项损失；联合更新 \(Z,R\)，再投影 \(R\)。按固定构造预算重复。
5. 重新计算最终分配，材料化特征和真实文本，验证文本嵌入约定，追加新块。

保存的审计字段包括源标识、类别配额、边缘误差、构造种子和配置哈希。构造结束后丢弃稠密 logits 和分配。历史前缀在每个阶段保持不变，仅优化新增行。

### 4.7 研究范围、拓扑扩展与计算成本

共享分配是耦合机制：\(Z\) 改变时，特征支持、文本路由和路由传播目标一起改变。这不同于向已经完成的仅图记忆附着文本。Sinkhorn 归一化、梯度匹配和 CaT 风格类别统计是构件；在共享真实文本构造接口下整合它们，构成方法设计。对于 \(n\) 个当前节点、\(m\) 个槽位，共享使用 \(nm\) 个分配 logits，而独立特征与文本分配需要 \(2nm\)。这减半的是分配 logits 数量，不是总模型参数或峰值工作内存。组件研究分别比较预测效果和实际构造成本。

但共享 \(Q\) 并没有在受控对比中表现出稳定的精度优势。现有最强的机制证据支持的是**学习分配关系**以及**循环内分布匹配（DM）**，而不是共享本身带来预测增益。

CoTAG-Q 主要用于图文节点分类。图感知构造不意味着保存的记忆保留显式边集。CoTAG-Q-T 使用 \(Q\) 诱导的当前边；其 boundary 变体还使用历史支持摘要，保存合成拓扑。这些变体改变存储接口，针对结构任务单独评估。

稠密 logits 和分配需要 \(O(nm)\) 工作存储；一次 Sinkhorn 迭代访问 \(\sum_cn_cm_c\) 个合法条目。稠密实现中特征与文本池化的成本为 \(O(nm(d_x+d_e))\)。梯度匹配增加二阶代理求导，共用代理实现还分配大小为 \(O((|M_{t-1}|+m)^2)\) 的稠密合成算子，即使其值只是单位矩阵。冻结文本编码和当前图消息可以在阶段内缓存。检查点机制可减少保留激活，但不能消除这些稠密工作张量。保存的无显式边记忆随合成行数增长，而非随临时分配矩阵增长；构造时间与峰值内存和存储预算分开报告。

### 5.2 下游学生模型

主要使用的 Prompt GraphText 学生模型，将两层 GCN 风格的图编码塔与冻结的 MiniLM 文本嵌入、可训练的共享文本投影相结合 [minilm]。它使用双向多正例图文对齐、类别 prompt 交叉熵和 prompt 间隔损失。预测时，将图表示与类别 prompt 比较，不再额外拟合分类头。这种读出方式受到 GraphCLIP 等图文迁移模型的启发 [graphclip]，但不复现 GraphCLIP 的预训练或未见类别零样本协议。

所有当前统一学生模型实验组均使用 2,048 个训练步骤、24 的批大小、相同的 MiniLM 编码器和类别 prompt，以及学生模型种子 150/151/152。多正例对齐允许重复文本或同类文本，而不是将其他所有记忆行都作为负例。冻结文本编码使不同构造器共享同一个表示空间。附录 A 报告了与早期学生模型配置的匹配比较。

跨架构评估仅将图编码塔替换为两层 PyG SAGEConv 均值聚合器，保持记忆、训练预算、文本编码器、prompt 和种子不变。实现同时包含显式自环邻居和根节点变换，这就是本文测试的 Prompt GraphSAGE 变体。没有重新构造记忆，也没有重新调整方法参数。当前 ArXiv 迁移审计检查了两种学生模型间的记忆/归档哈希和掩码。

### 5.3 访问边界、预算与评估

阶段 \(t\) 的构造仅访问当前增量和已保存的合成前缀，不重新读取历史原始特征、文本和边。旧合成行不可修改，每种方法都追加一个新块。累计 5% 比例约束保留的节点行数，而非绝对记忆大小、字节数或构造工作存储。预先登记的累计调度可以在中间阶段呈现依赖顺序的比例，但共享相同的最终目标。比例敏感性与早期历史记忆更新对照分别列于第 6.4 节和附录 A。

我们报告最终 Macro-F1、Accuracy、旧类 F1、新类 F1 和阶段平均 F1。先在每个构造单元内对三个学生模型种子取平均，再用这些单元均值计算总体均值和样本标准差。主要比较与组件比较的配对 95% \(t\) 区间，分别使用九个和三个单元差值。迁移实验还报告了对类别顺序和构造种子进行交叉因素 bootstrap 所得的探索性区间，并将其与 \(t\) 区间明确区分。

开发评估（report-development）与留出评估使用同一批已训练学生模型上的不同掩码。这两组掩码在项目过程中均被查看过，因此固定掩码结果和区间是条件性的事后证据，不是新的盲测确认，也没有校正适应性方法开发带来的影响。本文报告的实验没有利用这些读数选择新的方法变体。

### 5.4 外部比较与内部对照

按照图凝聚评估惯例 [gcond, sfgc, gcondenser]，我们区分四类证据。第一，主要比较对 CoTAG-Q、CaT-CCTP 和 GECC-hard-TAG 的访问边界、节点预算、学生模型、掩码、顺序和种子进行匹配。后两者是持续式 TAG 适配方法；第 3 节说明其保留的机制及文本附着方式。它们的构造目标和计算预算并不相同。

第二，五数据集统一学生模型实验组增加了选择对照、PUMA-inspired，以及预算受限的 GCond-x/SFGC 核心。预算受限 TAGSAM 和 local-Qwen STAD 是带有适用限定的参考，分别缩减了构造预算或改变了监督。GECC-soft 在唯一完成的 BookHis 单元中保留原生模糊 c-means；其 ArXiv 和 SportsFit 运行已停止。这些适配均未被标为官方端到端复现。使用旧学生模型的 STAD/DANCE/SR-GM 参考及冻结 GraphCLIP 检查点采用不同评估器，仅列于附录 B。

第三，完整历史原始数据提供独立的压缩参考：它允许保留并重新访问历史原始数据。当前对比使用同一合法训练池、类别顺序 9101、评估掩码、文本编码器以及 2,048 步学生模型训练预算；分别报告无训练边和保留训练池诱导边的完整历史参考。三个数据集的压缩记忆均为当前合法池的精确 5%（整数取整），而不是归档 ArXiv 调度的 5.71%。这仍不是充分收敛的完整图上界。最后，消融是在 CoTAG-Q 内部进行的干预，不是额外的外部基线。其单顺序、多构造种子的证据不与九单元主要比较合并。

### 5.5 实现与可复现性

构造器在 `unified_q_multimodal.py` 中实现；Prompt 学生模型与迁移入口分别为 `graphtext_prompt_student.py` 和 `graphtext_sage_transfer.py`。预先登记的配置保留池标识、行数调度、源文本标识、种子和冻结前缀检查。不可变更的报告提供单元级指标、配对差值和构造成本；配套结果登记表将每张论文表格和图片映射到来源快照。稠密分配与代理求导计入构造成本，共同的数据加载和文本缓存准备不计入。

## 7 消融与讨论

本节检验构造机制，区别于第 6.1 节的外部比较。核心对照使用未修改的主构造器、一个类别顺序、三个构造种子，以及每个构造单元内三个学生模型种子。因此，其不确定性覆盖该顺序下的构造种子变化，而非主要表格的九单元顺序/种子变化。

### 7.2 文本是否影响构造？

### 7.3 共享支持与材料化的权衡

共享 Q 使特征与文本路由使用相同支持权重，并将分配 logits 从 2nm 减少到 nm。一个独立的、匹配的共享/独立实现记录到：共享在三张图上均降低构造时间和峰值分配。但精度差异并非一致为正，完整比较见表 `tab:q_controlled`。因此，共享是一种共同支持与资源设计，而表 `tab:loss_controls` 确立的是学习分配的价值。

同一受控实现还比较了硬前向/硬存储文本与软前向/软存储嵌入，两种表示都未在三张图上一致提高精度。我们保留硬材料化，以获得可读、可重新编码的来源信息。软存储、无残差及初始化控制详见附录 B，它们不改变主要方法。

### 7.4 分配与文本诊断

表 `tab:assignment_diagnostics` 描述受控共享实现中的新增块分配，在已记录阶段/种子块之间等权平均。硬槽位覆盖率是至少被某个原始行的最大分配选中的槽位比例。归一化熵平均

\[
-\frac{\sum_jQ_{ij}\log Q_{ij}}{\log m_{y_i}},
\]

其中单槽位类别的熵记为零。文本唯一性统计每个槽位对应的不同保存字符串。平均文本余弦使用每块的前至多 512 个保存槽位，包含跨类配对。软/硬差异为

\[
1-\cos(\widetilde e_j,e_{i_j^\star}),
\]

并在槽位之间平均。

## 8 局限与未来方向

### 8.1 构造成本与组件证据范围

累计 5% 比例限制保留的节点行数，而非存储字节数或构造工作内存。稠密分配需要 O(nm) 存储，当前代理即使使用单位邻接也分配稠密合成算子。主要 SportsFit 构造达到 24.08 GiB，10% 配置显存不足。第零阶段将稠密单位算子替换为稀疏单位算子的诊断仅将 ArXiv 峰值显存从 11.56 降至 11.50 GiB、SportsFit 从 23.44 降至 23.33 GiB，也未观察到明确的时间收益。更大的存储项仍是稠密分配张量；算子和导数等价亦不保证优化轨迹及最终硬文本选择相同（附录 B.8）。按类分块或稀疏化分配仍待实现和检验。共享支持所需的分配 logits 少于独立图文路由，但并不使完整构造器比所有基线都便宜。

组件研究在受测配置下支持学习 Q 和循环内 DM，没有确立共享或 GM 的独立精度收益。构造阶段文本的最明确收益出现在 SportsFit 的文本感知初始化；额外的节点—文本配对梯度没有一致的独立收益。因此，共享、硬材料化和 GM 是具有已测权衡的完整构造接口组成部分，而非分别得到普遍精度增益证明的模块。选择一个可读来源也会丢失软文本混合中的信息；三种子硬/软存储比较的结果依赖数据集。这些发现将共同支持设计与获得实证支持的预测改进来源区分开来。

### 8.2 拓扑与任务覆盖

主记忆冻结历史行，不保存合成边。当前增量的图消息用于构造，但不会重建不可见跨阶段边，也不会针对后续数据修订旧支持关系。单独的 CoTAG-Q-T 扩展材料化

\[
Q^{\mathsf T}A_{\Delta}Q,
\]

并可以使用 boundary sketch 保存合法的当前到历史支持。其节点分类效果在不同数据集间并不一致。三个 split 的槽位级链路探针将 Cora AUC 从 0.8325 提高到 0.8591，却使 Citeseer AUC 从 0.8479 降至 0.8388。这不是训练式 GAE/GNN 评估，因此当前结果支持的是节点分类，而非一般链路预测效用。

主要数据集覆盖引文图和产品类别图，包括 SportsFit 与 BookHis 商业领域。对社交或用户交互 TAG 流的泛化仍未测试。prompt 读出使用监督构造和学生模型训练，并不是严格未见类别或跨数据集零样本学习。

### 8.3 适配保真度与统计范围

共同下游训练并不消除构造机制与预算差异。CaT-CCTP 和 GECC-hard-TAG 是持续式 TAG 适配；后者省略原生模糊聚类和累计质心修订。预算受限 TAGSAM、local-Qwen STAD 及预算受限 GCond-x/SFGC，只在改变后的协议下保留已经说明的原生核心。尤其是，BookHis 的单类别最后阶段无法为 GCond-x/SFGC 代理提供有判别力的特征梯度。因此，其分数比较的是这些实现，而非原生协议下完整发表方法。TAGSAM 的末阶段响应预算从 100 增至 500 次外层更新，没有在三张图上改善 F1；这只是局部敏感性检查，不能替代所有阶段采用原生预算的完整复现。

评估掩码被反复查看过。区间描述的是以这些掩码为条件、在抽样顺序和构造种子间的变化，不校正适应性方法选择。组件对照覆盖一个顺序下三个构造种子，主要比较覆盖九个顺序/种子单元。当前完整历史效用在同一合法池和一个类别顺序上比较；历史归档调度及架构检查单独报告。完整历史参考仅训练 2,048 步，并未确立充分收敛后的性能上界。对改变后的方法进行新确认，需要独立固定的评估数据与协议。

## 9 结论

我们提出用于历史访问受限持续式 TAG 凝聚的 CoTAG-Q。可学习的类别受限分配将图感知特征池化与可读文本路由相连接，使文本反馈能够影响用于构造数值特征的支持关系。循环内匹配更新分配和受限特征修正；新增行追加到冻结、无显式边的记忆中，不重新访问历史原始数据。

累计节点保留率为 5% 时，九单元比较在三张大图上均比 CaT-CCTP 提高 Macro-F1。在 BookHis 上，全部九个配对单元均超过 GECC-hard-TAG，平均高 3.47 个百分点；ArXiv 与 SportsFit 的排名则依赖数据集。即使保留可训练特征修正，固定 Q 仍使 Macro-F1 下降 8.91 至 21.67 个百分点；去除 DM 也使所有受测构造种子的性能下降。同一批 ArXiv 记忆迁移到 GraphSAGE 后，比 GECC-hard-TAG 高 1.34 个百分点。当前合法池上的完整历史对比表明，精确 5% 的保存行数在有限学生模型预算下，相对保留训练边的完整历史保留 98.23%–103.33% 的 Macro-F1 和 95.58%–99.14% 的 Accuracy。这些发现共同支持了受限历史访问下，可学习图文支持关系作为构造机制的价值。降低稠密分配成本，并将记忆扩展到结构任务，仍是开放方向。
