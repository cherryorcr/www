# ACM 与 DBLP 时间流补充实验

登记、运行与核验日期：2026-10-22。本批只补实验和整理证据，没有修改论文或推送 Overleaf。

## 1. 结论

两组新增时间流实验已全部完成，共 18 条完整五阶段序列、90 次阶段构造和 270 次 student 训练，没有报告 OOM 或数值失败。所有阶段记忆、预测归档和结果均已保留。

**这些结果补充了真实发表年份下的适用性证据，但没有证明 CoTAG-Q 稳定优于强基线。** 在最终已到达快照的累计测试节点上，CoTAG-Q 相对 GECC-hard 的 Macro-F1 差值为 ACM -0.51、DBLP -0.74 个百分点，两者的配对区间均跨零。均值接近不等于经过了等效性验证。

在更严格的仅当前快照推断下，ACM 最终结果接近；DBLP 的最终点估计和五阶段均值均落后于 GECC-hard 与 CaT。不能以更好的开发集结果替代测试结果，也不应仅因新增结果较弱而删除数据集或改动停止条件。

结合已有 ArXiv 时间流，当前可以写成“方法能够用于按时间到达、类别重复出现的 TAG，收益依赖数据分布与推断访问条件”。不能写成“三个时间数据集都稳定领先”，也不能据此宣称覆盖了多种真实 Web 应用领域。

## 2. 数据来源与协议

### 2.1 两个有明确时间字段的图

SportsFit、BookHis 的现有发布文件缺少经过核验的节点时间戳，因此经用户同意，本批采用另外两个数据源，不将行号或随机顺序充当时间。

- ACM 数据源：[AMiner ACM v9](https://lfs.aminer.cn/lab-datasets/citation/acm.v9.zip)。
- DBLP 数据源：[AMiner DBLP v10](https://lfs.aminer.cn/lab-datasets/citation/dblp.v10.zip)。

这两组任务是从版本化档案中构造的 **ACM temporal domain subset** 和 **DBLP temporal domain subset**，不是未改动的官方基准划分。节点为论文，文本为题目及可用摘要，关系为保留论文之间的引用。类别由固定会议、期刊别名映射为研究领域，不是逐篇论文的专家主题标注。

| 项目 | ACM 子集 | DBLP 子集 |
|---|---:|---:|
| 节点数 | 16,928 | 57,520 |
| 类别数 | 3 | 4 |
| 原始方向的保留引用 | 66,303 | 297,223 |
| 对称化后存储的有向边 | 132,378 | 593,138 |
| 有摘要的节点 | 14,293 | 51,071 |
| 合法构造节点合计 | 11,848 | 40,227 |
| 最终记忆条目 | 592 | 2,011 |
| 实际最终记忆率 | 4.9966% | 4.9991% |

ACM 的三个领域为数据库、数据挖掘和计算机网络；DBLP 的四个领域为人工智能、计算机视觉、自然语言处理和机器学习。两者均为学术文献网络。它们扩大了时间数据的覆盖范围，但不代表电商、社交网络或其他 Web 场景的独立验证。

保留 1990 至 2015 年的有效论文，合并同年同类别的同题记录，剔除含糊重复。DBLP 另去掉 5 条与保留 ACM 标题重复的记录。归一化标题检查显示两个最终子集之间没有完全同题记录；这不是模糊语义去重保证。预先规定的 60,000 节点上限在两个数据集上均未触发。

文本中没有额外加入 venue、作者、年份、节点 ID 或引用次数。数值特征和文本向量均使用同一冻结 MiniLM。按已发表档案提供的题目、摘要构造文本，不意味着获得了每个历史时点的原始文本版本。

### 2.2 时间、划分与访问边界

节点时间使用真实发表年份，不是网站实际采集、上传或入库时间。边采用“引用论文发表时，该引用关系可用”的假设；没有观测到的逐边事件时间。ACM 删除了 73 条引用未来年份的关系和 100 条自引用，DBLP 分别删除 1,195 条和 4 条。

用数据集名和源节点 ID 的 SHA256 稳定划分节点，模 10 余 1、3、2 分别为 selector-dev、report-dev、test，其余为训练池。仅用训练池年份的 40%、55%、70%、85%、100% 最近秩分位点确定五个阶段，不拆开同一年。规则在下游结果产生前登记，没有按测试成绩挑选领域、阶段边界或模型参数。

| 数据集 | 五个阶段的年份上界 | 各阶段合法构造节点 | 各阶段累计记忆条目 |
|---|---|---|---|
| ACM | 2005 / 2008 / 2010 / 2012 / 2015 | 5099 / 2088 / 1624 / 1311 / 1726 | 255 / 359 / 441 / 506 / 592 |
| DBLP | 2008 / 2010 / 2012 / 2014 / 2015 | 17901 / 5458 / 6005 / 6438 / 4425 | 895 / 1168 / 1468 / 1790 / 2011 |

每个阶段均有全部类别。因此这是已知类别反复出现的时间流，与原论文中的类别增量设置互补，不能将其描述成另一组类别顺序实验。各数据集只有一条固定时间顺序和一次固定数据划分。

构造器只能取得当前阶段合法训练节点、这些节点的诱导边，以及各方法自己的冻结历史记忆。记忆按累计合法训练节点数的固定 5% 比例四舍五入增长。本批没有触发类别最低配额调整。

推断分为两种条件，使用同一个训练好的 student，不按条件重新构造或调参。

| 条件 | 推断可用数据 | 可评估节点 |
|---|---|---|
| 已到达快照 | 截至当前阶段已到达的原始节点及其诱导边 | 累计、当前到达、历史到达节点 |
| 仅当前快照 | 仅本阶段到达的原始节点及其诱导边 | 当前到达节点 |

二者均排除未来节点。第一种允许服务侧访问历史图，但不允许构造器访问历史原始数据；第二种不依赖历史图回答当前查询，也不能评价已不可访问的历史查询。本文档的“历史/当前”指到达时间，不是旧类别/新类别。

离线准备器在 CPU 保留完整文件供切片，未来图没有整体预缓存到 GPU。不能把这种访问受控的实验框架描述成已经实现了原始数据物理删除或端到端流式存储系统。

### 2.3 方法与统计口径

比较 CoTAG-Q、CaT 适配和 GECC-hard 适配，均使用共同访问协议、记忆率、冻结文本编码器及 student。后两者不是未经修改的官方复现；本批也不包含 GECC 原生 soft 分支。

CoTAG-Q 保持 30 次构造更新和原有完整目标，**不是 no-GM 版本**。沿用已经核验的数值修复：Sinkhorn 内部采用 float64，求解迭代上限由 4096 改为 16384，容差仍为 1e-4，输出 Q 转回 float32。应称为“精度与求解上限修复”，不能称为完全未改动的原始求解器。其他方法参数没有针对这两个数据集重新搜索。

所有方法使用相同 GCN prompt student，2048 次更新、batch size 24。三个构造种子为 271006、271108、271109，每份记忆使用 student seeds 150、151、152。

表中先平均同一份记忆的三个 student 分数，再计算三个构造均值的平均值与样本标准差。配对 95% t 区间基于三个匹配构造种子的差值，自由度为 2，没有做多重比较校正；它只描述固定划分和时间顺序下的随机种子变异。不是九次独立构造，也不能把五个阶段视为五个独立数据集。

### 3.4 开发集不替代测试集

完整开发集单独列于结果目录的 `summary.md`。例如 ACM 开发集最终累计 F1 为 CoTAG-Q 88.83、GECC-hard 88.55；仅当前快照为 85.40、83.31。测试集对应的优势并未复现。需要同时保留这两种结果，不能在论文中择优切换掩码。本批没有按该差异重新调参或追加择优种子。

## 4. 对挑战的直接数据支撑

统计合法训练池内，与当前节点关联且端点已经到达的边。分母为“当前阶段内部边 + 当前到历史的边”，不是整个图的所有边。下表是 current-delta-only 访问约束排除的关联边占比，独立于模型分数。

| 数据集 | 第 1 次增量 | 第 2 次增量 | 第 3 次增量 | 第 4 次增量 |
|---|---:|---:|---:|---:|
| ACM | 83.32% | 90.35% | 91.97% | 90.41% |
| DBLP | 86.80% | 90.08% | 89.29% | 93.95% |

这能具体说明历史访问限制会削弱新节点可用的邻域上下文，比单纯说“数据持续到达导致遗忘”更直接。但被排除的边不一定都提供有效监督，比例本身不等于准确率损失，更不能证明 Q 还原了这些边。

需要区分已经测量的现象与待验证的原因。已测量的是访问约束、边比例、两种推断模式的分数和配对差值。新任务只有 3 至 4 类且类别持续重复，可能影响不同构造方式的相对优势；这只是解释假设。本批没有相应消融，不能把这种假设写成 DBLP 落后的确定原因，也不能认定是基线文本附着过强造成。

## 5. 资源开销

以下为本次运行的描述性记录，构造时间是五阶段之和，显存是每条完整序列的阶段峰值最大值，再对三个构造种子取均值。单位为 GiB。均为 PyTorch allocated memory，不是整卡显存；reserved 峰值另保存在完整 CSV 中。

| 数据集 | 方法 | 五阶段构造时间（秒） | 构造峰值 | Student 训练峰值 | 已到达快照推断峰值 |
|---|---|---:|---:|---:|---:|
| ACM | CaT 适配 | 25.55 | 0.311 | 0.114 | 0.253 |
| ACM | GECC-hard 适配 | 3.40 | 0.283 | 0.114 | 0.253 |
| ACM | CoTAG-Q | 73.70 | 0.701 | 0.114 | 0.253 |
| DBLP | CaT 适配 | 33.30 | 0.360 | 0.132 | 0.613 |
| DBLP | GECC-hard 适配 | 21.27 | 0.295 | 0.133 | 0.613 |
| DBLP | CoTAG-Q | 73.58 | 2.220 | 0.132 | 0.613 |

共同 student 每个种子完成五个阶段的训练共约 36 秒，各方法接近。最终压缩记忆归档约为 ACM 1.65 至 1.68 MiB、DBLP 5.64 至 5.69 MiB。这是压缩文件大小，不是未压缩训练张量占用，也不包含冻结编码器权重或原始数据。

本批构造阶段没有完整未来图的 GPU 缓存，但冻结文本编码器仍常驻 GPU，因此测量包含它的常驻分配。离线 CPU 档案、CUDA 上下文等不在 allocated 数字内。预先的数据准备和整库点式特征编码时间不包含在构造秒数中。

这些记录支持“凝聚后 student 训练的绝对显存需求较小”，但同一预算的两个适配基线也有类似收益。CoTAG-Q 的构造开销更大，尤其不能在这两个数据集上以总构造成本宣称效率优势。本批没有匹配的全历史训练或静态整图凝聚对照，所以不能给出相对这两者的实测节省百分比。更小的当期问题规模与旧实验的 GPU 缓存差异都可能影响峰值，不能仅用跨批次数字归因于方法优化。

## 6. 核验与复现

- 独立脚本不导入构造器，也不调用原评估的 sklearn 指标函数，使用混淆矩阵重新计算固定类别 Macro-F1 与 Accuracy。
- 重新扫描 ACM 2,385,022 条、DBLP 3,079,007 条原始记录。核对所有保留节点的题目、摘要、年份和 venue，并重建其引用关系。该检查没有独立复核所有被排除记录的资格决定。
- 重新计算源 ID 哈希划分、仅训练年份的阶段边界、阶段节点 ID 和累计记忆预算，核对编码数据及模型文件哈希。
- 全部 90 份记忆通过数值有限性、无合成边、记忆大小、冻结前缀及哈希核验；核对保存的协议和代码哈希。
- 从全部预测归档重新核验 5,184 个已保存的 F1/Accuracy 标量，包括不同 cohort 输出。这个数量不是独立实验数。
- 检查未来节点不进入已保存的推断索引，当前快照不存在历史节点分数。
- 13 个准备与统计单元测试在本地和远程均通过。
- 910 个证据文件已下载到本地并逐项核对文件大小与 SHA256，包含全部阶段记忆和预测。原始大型 ZIP、编码特征文件和预训练权重仍在远程，哈希已记录。
- 本地重新汇总生成的七张 CSV 与远程汇总逐字节一致；从保留节点和边重新计算的跨阶段边排除比例也与表中数值一致。

这些核验不替代运行期访问的系统级审计，也没有重新计算每个 MiniLM 向量；该范围应与“算法数据访问逻辑正确”的声明区分。

## 7. 接下来如何修改论文

建议开始整理现有证据，不继续为了得到正结果盲目追加数据集或调整方法。论文修改可以围绕以下结构进行，但本次尚未落笔修改正文。

1. **主结果保持原来的类别增量任务。** 新增独立的时间流小节，把 ArXiv、ACM 子集和 DBLP 子集放在一起交代，不与类别顺序实验混合统计。
2. **在设置中明确两个访问层次。** 构造的历史原始数据限制与服务侧推断的可访问图不同。时间流小节分别报告已到达快照与仅当前快照，不再笼统声称全流程不访问历史数据。
3. **主文用一张紧凑表呈现最终 F1/Accuracy 和五阶段均值。** 各种子、各阶段、配对区间、数据筛选及失败记录放附录；不能只选更有利的开发集或最终阶段。
4. **方法优势依然由原有匹配基线和机制消融支撑。** 新时间流结果承担适用范围检验，跨阶段边统计承担挑战动机支撑，不把它们转述为共享 Q 必然提高精度的证据。
5. **资源部分区分构造、student 训练和推断。** 本轮的低 student 训练开销不等于低构造成本，也不是相对同预算基线的专属优势。
6. **讨论中保留 DBLP 的边界。** 当前快照上的性能落后说明该设置下没有统一优势。已有 ArXiv 最终阶段的正向区间仍成立，但五阶段区间跨零，且此前测试掩码已被查看，不能与这两个新掩码任务混称为统一盲测。

可采用的结果表述是：“在发表年份构造的时间流中，该方法完成了五阶段记忆构造，并在 ArXiv 上取得相对优势；在两个新增文献网络子集上，累计评估表现接近强适配基线，但更严格的当前快照推断显示其收益并非一致。”其中“接近”只描述点估计，不表示统计等价。
