# T+degree 块保持追加：新顺序与跨任务确认结果

日期：2026-09-20。状态：**1080 次正式训练、1080 次 checkpoint 重载、60 份 memory 审计全部完成；预先指定的 T+degree 通过本轮研究推进标准。**

## 1. 结论与方法定位

**可以将 T+degree append 作为下一轮主方法基础，不再只围绕 C0 推进；C0 保留为冻结对照。** 这不是宣称新方法在所有条件下更优，也不是将旧 C0 的结果改名。

- BookChild：两个新顺序上，节点分类和链路预测均改善；平均最终 F1 +1.546 pp，LP AUC/AP +0.723/+0.980 pp。
- arXiv：平均最终 LP AUC/AP -0.011/-0.050 pp，接近持平，但存在明显顺序依赖；分类最终 F1 -0.662 pp，阶段平均 -0.208 pp。
- 构造总成本约为 C0 的 1.42 倍和 1.15 倍；student 训练时间基本相同，持久 memory 文件大小基本相同。
- 因此，这是**有数据集依赖的改进，达到事先约定的收益/退化容忍标准**，不是“跨数据集全部上涨”或统计意义上的非劣性证明。

本轮候选准确名称为“文本核度均衡块保持追加”。它来自此前 block-preserving 系列，但默认核只有 T，**不是原始 X+T+graph-signature 联合核**。XT 作为预先列入的对照保留，不根据结果临时替换默认候选。

## 2. 实际执行范围

依据结果产生前冻结的 [确认协议](DEGREE_CROSS_TASK_CONFIRMATION_PROTOCOL_ZH_2026-09-20.md)，没有改动方法参数、报告种子或验收阈值。

| 项目 | 实际设置 |
|---|---|
| 数据集 | arXiv：40 类；BookChild：24 类 |
| 类别增量 | base+4；arXiv 每阶段 16/6/6/6/6 类，BookChild 10/4/4/3/3 类 |
| 新类别顺序 | 49011、49012；打乱全部类别后按上述大小分块，不再固定最大类为 base |
| 新 student seeds | 210–215，共六个；不继承上阶段参数，不挑最佳 seed |
| 新 LP edge splits | 49101、49102；按端点到达阶段分层 80/10/10，正负例 1:1 |
| 构造 seed | 9001 不变；本轮没有验证 construction-seed 泛化 |
| Memory | floor(5% × 累计 pool 节点数)，保留旧行、旧旧边 |
| 方法 | C0、T+degree、XT+degree；共享 X/text/mass/depth/stage、行顺序，rows 和无向边数相同，仅边端点不同 |
| 分类 student | 现有两层 CLIPStudent，图文双向 InfoNCE，2048 steps，batch 16，lr 0.001 |
| 分类指标 | report-dev 累计 Macro-F1；主判断为 all-class prompt 竞争，seen-class 单列 |
| LP student | GAE，GCN 384/128 + 内积解码，256 steps，edge batch ≤256，lr 0.001 |
| LP 指标 | held-out real edges 上 ROC-AUC/AP；并报告 old/new/cross/within-new |
| 训练数量 | 每图 180 NC + 360 LP；总计 360 NC + 720 LP = 1080 |

分类属于现有 transductive 条件：真实全图的 X/边用于推理，包含未到达节点；不评价分类 test 标签，不是 strict-inductive 结果。构造使用当前 pool 的类别标签分配预算，所以不能把整个凝聚算法称为无监督；分类 student 本身没有监督分类损失。

LP 推理只使用已见 pool 节点和真实 train edges 传播。构造函数不输入真实边，因此同一份 memory 可以跨 edge split、跨 NC/LP 两任务使用。两个任务分别训练自己的 student，**共享的是 SHA256 相同的 memory，不是模型权重**。

协议和工件中的“同 pairs”指无向边数量相同，不是三种方法的边集合相同；不同方法的拓扑及 memory SHA256 可以不同。同 SHA256 的要求针对同一方法、顺序和阶段在两个任务间的复用。

新顺序、新 seed、新 edge split 是未用于选择本轮候选的随机配置，但仍使用既有数据集/节点划分，不等于全新数据集或完全未触达的样本集合。

所有值均为百分数，差值为百分点。先在匹配条件中配对，再对两个顺序等权汇总；阶段平均对五个阶段等权。分类每个最终值含 2 orders × 6 seeds，LP 含 2 orders × 2 splits × 6 seeds。不能把这些共享 memory 的训练重复当成独立数据集。

## 4. 当前方法究竟改了什么

1. 当前阶段仅用合法 pool 的 X/text/y。总预算按累计节点数的 5% 增长，旧合成行不收缩；新增 rows 使用原有 dispersion 配额。
2. 类别内部在图文联合空间聚类。每个簇仍产生 mean-X、中心代表文本拼接并冻结 MiniLM 重编码的合成行；不换成真实 coreset 节点。
3. 新 block 内，按文本余弦排序选边，限制每个节点的度不超过 2、选取过程中不提前成环。形成连通路径后闭合，得到内部环；本轮每个 block 都有足够节点。
4. 每个新节点追加一条无向跨块边。按 T 相似度贪心分配给尚有容量的旧节点，每个旧节点本次可接收量最多 ceil(新 rows / 旧 rows)。
5. 旧 X/text/mass/stage 和旧旧边逐元素冻结；新增内部边、跨块边与旧图组成当前合成 memory。
6. 同一份 memory 分别重训分类 student 与 LP student。没有 response selector、额外预算、旧行 refresh、graph signature 或 student-guided attention。

C0 的区别是：内部取全局最高文本相似度的相同数量边，跨块使用每个新节点的最近旧邻居，没有上述度/容量约束。

保持旧旧边不等于保持归一化旧传播块。新跨边仍会改变旧节点的度；这是有界容量可能缓解、但并未完全消除的问题。当前操作不保证全局最优 kernel 图，也不保证所有下游指标单调改善。

## 5. Memory、拓扑与成本

### 5.1 新旧数据到达与预算

| 数据集/顺序 | 各阶段新增原始 pool 节点 | 各阶段累计合成 rows |
|---|---|---|
| arXiv / 49011 | 68398, 6937, 12941, 21230, 9033 | 3419, 3766, 4413, 5475, 5926 |
| arXiv / 49012 | 52233, 26629, 24117, 7590, 7970 | 2611, 3943, 5148, 5528, 5926 |
| BookChild / 49011 | 34968, 2029, 4963, 898, 10953 | 1748, 1849, 2098, 2142, 2690 |
| BookChild / 49012 | 12051, 5673, 14452, 1548, 20087 | 602, 886, 1608, 1686, 2690 |

新顺序确实重新凝聚，不是仅更换 student seed。不同顺序的最终跨块边数也不同，因此只在同一顺序内作方法配对，不能直接与上一轮绝对分数相减。

### 5.2 同 rows、同 pairs 下的拓扑差异

| 数据集/顺序 | 最终 rows / pairs（三臂相同） | C0 孤立节点 / 最大度 | T+degree 孤立节点 / 最大度 | 最终文件大小（三臂近似相同） |
|---|---:|---:|---:|---:|
| arXiv / 49011 | 5926 / 8433 | 978 / 32 | 0 / 6 | 19.613 MiB |
| arXiv / 49012 | 5926 / 9241 | 612 / 58 | 0 / 6 | 19.638 MiB |
| BookChild / 49011 | 2690 / 3632 | 880 / 88 | 0 / 6 | 8.897 MiB |
| BookChild / 49012 | 2690 / 4778 | 161 / 82 | 0 / 6 | 8.931 MiB |

这证明差异不是增加节点/边数量带来的。它仍不能证明“消除孤立点”单独造成收益，因为内部环、跨块容量和相应训练正负边集合同时变化；本轮是拓扑方案整体的受控比较。

### 5.3 成本账

构造时间为一条五阶段链的共同 X/text 构造时间加各自拓扑时间，再平均两个顺序。共同构造在实验中复用，但给每个独立方法均计一次，不能把它记成零。

| 数据集 | C0 构造秒 | T+degree 构造秒 | 构造倍率 | 分类每 fit 秒：C0 / T | LP 每 fit 秒：C0 / T |
|---|---:|---:|---:|---:|---:|
| arXiv | 77.076 | 109.306 | 1.42× | 4.967 / 4.934 | 0.641 / 0.642 |
| BookChild | 34.852 | 39.922 | 1.15× | 4.583 / 4.537 | 0.581 / 0.582 |

新增代价主要在拓扑构造，不是额外 student 重训。训练耗时的小差异不足以称为加速。上述计时不含复用文本缓存的原始编码成本、数据加载、最终推理和独立审计，不能作为端到端完整总成本；GPU 峰值是含 encoder/推理图缓冲区的进程峰值，不是隔离后的合成训练显存。原始分项见 [完整生成表](../../results/degree_confirmation_20260920/comparison_tables.md)。

审计范围是源码读取路径、合法 stage source IDs、工件与结果重载；没有逐簇重建所有成员分配并重凝聚 X/text，也不是历史原始数据的操作系统级访问隔离。上游原始特征预处理沿用现有工件，不由本轮排除所有上游泄漏风险。

本轮没有新跑匹配这两个顺序的 full-raw、k-center 或静态 TAG 强基线，**不能据此报告新的完整图性能保留率，也不能将上一轮完整图分数直接放进这张配对主表**。两个顺序及两个数据集不足以支持普适/SOTA 或统计显著非劣性结论。

## 7. 后续推进

1. **冻结 T+degree 为新的研究主线基础，C0 为对照。** 默认仍是 mean-X、concat/re-encode、dispersion、5% growing、无 response。小图旧版本和失败结果保留原名，不追溯改写。
2. **优先做拓扑算子拆分。** 固定 T、X/text/rows/pairs，做“C0/环形内部边 × C0/容量受限跨边”的 2×2 比较；补固定度序列的端点打乱，记录旧传播块漂移、旧/新类 F1、LP old/new/cross。这样才能分清语义边、覆盖和跨块负载均衡的作用。
3. **解决 arXiv 的边界，而不是叠加更多模块。** 当前两个顺序的新类 F1 都下降，LP 一个顺序退化。检查被迫闭合的低质量内部边、跨类混合、跨块传播的影响；原因尚属待验证假说。后续若用本轮结果调参，本轮条件应归为开发条件，再留新确认配置。
4. **补性能与预算定位。** 新主线固定后做大图 1%/5%/10%，配套同协议 k-center/medoid 与完整数据 student，回答多少压缩代价、保留多少效用。外部 TAGSAM/STAD 补强不自动重启，按此前用户决定仍需单独安排。
5. **论文主线可以升级，但创新论证仍要补。** 可围绕“历史不可回读下的合成拓扑可重训效用、容量约束与归一化传播扰动、跨任务收益及边界”组织。度上限带来的传播扰动界不自动推出 F1/AUC 提升，需要算子消融和文献核验，不能仅凭本次通过就宣称 WWW 长论文贡献已经充分。

以上是后续任务安排，本轮没有暗中执行新模块、修改当前核权重或扩大实验矩阵。
