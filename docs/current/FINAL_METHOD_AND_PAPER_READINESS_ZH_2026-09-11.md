# 第一部分：最终方法（唯一存活形态）

## 1.1 方法定义

```
输入：当前 delta（本阶段新到达的节点）、上一阶段 memory、总预算 B

# 静态构造器（对 delta）
1. 冻结 MiniLM 编码 delta 文本 → text_emb
2. joint = [L2norm(X) ‖ text_emb]                # 768 维
3. assign = maxmin_lloyd(joint, k=floor(0.05·n_pool))   # 确定性、无标签
4. 每簇 j：
     x_j     = mean({X_i : i ∈ 簇 j})              # 原始 X 的均值
     texts_j = 拼接(pool 中最靠近簇心的至多 5 篇原文，各截断至 320/g 字符)
     emb_j   = MiniLM.encode(texts_j)              # 重新编码，保证图文对应
     mass_j  = |簇 j|
     stage_j = 当前阶段
     depth_j = 0

# 持续算子（append）
5. new_quota = max(B - |旧memory|, 15 × 本阶段新类数)
6. 若容量不足：按 mass 升序删除旧行（只删行，留存行 X/text 逐字节不变）
7. memory = 旧行（不变） ++ 新块（步骤 1–4 的产物）
8. 在全体 memory 的融合文本上重建 top-E 文本相似边（E ≈ |memory|）

输出：memory（可被任意独立初始化的 student 从头训练）

# 下游（评测协议的一部分，不是方法本身）
9. 独立初始化 2 层 GCN + 文本投影，在 synthetic 图上用双向 InfoNCE 训练
10. 在真实图上 transductive 前向，与类别 prompt 比相似度取 argmax
```

# 第二部分：论文的四条主张（全部有充分证据）

## 主张 1（理论）：持续约束的代价恒等于零

**陈述**：在确定性构造器下，"在线 append（历史不可重读）"与"允许重读历史、按阶段配额分别聚类"产生**逐字段相同**的 memory。

**证据**：`run_corrections.py` 用 `allclose(atol=1e-5)` 比较 x/text_emb/mass/stage、`==` 比较 texts，全部相等。

**证明思路**：构造器 $C(\cdot)$ 是无状态确定性函数，配额只依赖 delta 与剩余容量。因此

$$\text{append} = [\,C(\delta_0), C(\delta_1), C(\delta_2)\,]\big|_{\text{配额}} = \text{分层配额一次性凝聚}$$

两边是同一函数在同一样本上的求值。**代价恒等于零，不是近似。**

**边界（重要）**：full_history 更差的真实原因**不是重读历史**，而是**混合池联合聚类的类别主导效应**——temporal 划分下每阶段同分布，这个效应消失（arxiv temporal s2：full_history 18.52 > append 17.89）；类别增量下它出现（arxiv classincr s2：18.89 < 19.64，**大图上首次复现小图模式**）。

## 主张 2（否定）：任何形式的 X 优化都不能带来稳定收益

**陈述**：对合成特征做优化（ASM）或扰动（jitter）都无法在跨数据集意义上获益。

**证据链**：
- ASM 在 7 个数据集中 6 个有害/无效；唯一有效的 arxiv 也可由**同幅随机扰动复制大半**（随机 +2.00，ASM 额外仅 +1.30）；独立 run 中随机反超 ASM；
- 扰动模块在 16 个格点中仅 2 个显著为正，且被孪生对照证伪；
- **两者的共同失效模式**：ASM loss 跨数据集恒在 0.3–1.5%（"几乎不降"）却有时有效益——说明有效性不来自目标下降。

**理论解释（无代理命题）**：teacher 参数含材料看不出的知识，因此"冻结模型仍能给出原答案"与"新学生能从材料学会"**解耦**。11 artifact × 5 预测器全部失效是量化证据。

## 主张 3（否定，方法学）：判据不稳健

**陈述**："何时该干预"在此设定下没有稳定的单变量判据。

**证据**：四次修正、四次证伪，每次败于"几乎相同但结论相反"的对照（最新一对：k=6,901 vs 6,922）。

**价值**：这解释了**为什么这个领域普遍用人工指定的压缩率与固定的手工模块**——不是懒惰，而是几何量与下游效用在结构化数据上解耦。

## 主张 4（方法）：确定性构造 + 零成本持续算子

**陈述**：一个不含任何 X 优化的确定性构造器，在两个开发数据集上超过全部违规参照（full_history 重凝聚、raw 直训），历史保持最优，且持续约束代价为零。

**证据**：Gate 3'' test 一次性确认（Cora 58.07/61.56、Citeseer 56.99/61.18，两指标均居首）；与官方预训练 GraphCLIP 差距 <3 pp；arxiv 上 5% 凝聚 = raw 上界 94.6%、成本 1/28。

# 第三部分：现在能否开始写论文

## 3.1 结论：**可以开始写，但必须先做一件事**

**可以开始写**——四条主张的证据都已充分，方法已收敛，超参数全部为常数，结果表格完整（含 Macro-F1 与 Accuracy）。

**但必须先做一件事：在四个全新数据集上读取 test（一次性）**。理由：

- 当前所有"方法有效"的证据都在**开发数据集**（Cora/Citeseer，test 已消耗）或**dev 分区**（arxiv/新数据集，test 未读）；
- 冻结声明自己把"补一个完全未接触的数据集作为最干净的泛化证据"列为待办；
- 现在手上有**四个从未接触的数据集**，这是论文最强的一张牌——**必须用上**；
- 如果不做，审稿人会说"主结果数据集已污染"，这一条足以致命。

## 3.2 论文骨架建议

**标题方向**：*Deterministic Graph Condensation for Continual Text-Attributed Graphs: On the Necessity (or Not) of Optimizing Synthetic Features*

**结构**：

1. **引言**：持续 TAG 凝聚的两个基本问题——"历史不可重读的代价有多大"、"优化合成特征是否可行"
2. **预备**：设定、预算、协议、评测口径
3. **主张 1**：持续约束零代价（构造性等价定理）
4. **主张 2**：优化 X 不可行（ASM + 扰动的双重否定 + 无代理命题）
5. **主张 3**：判据不稳健（四次修正史 + 孪生对照）
6. **主张 4**：方法（确定性构造 + append）与结果
7. **边界与负结果**：full_history 的适用边界（类别增量特有）、recluster 的 trade-off、率-失真的失败
8. **结论**

**这个结构的核心是把方法从主角降为配角**，让四条结构性结论成为论文主体。这既解决了"方法无新算子"的指控，也符合 WWW 对 analysis + simple-method 类论文的接受度。

## 3.4 诚实评估

**当前形态投 WWW**：估计 **2–3 分（borderline reject）**——主因是缺口 1、2，而非方法本身。

**补齐缺口 1+2 后**：可进入 **borderline ~ weak accept 区间**。论文的独特价值在于**四条结论全部是可证伪的、机制性的**，且作者主动做了大量自我否证（这在审稿中是罕见的加分项）。

**最需要警惕的一点**：不要把论文写成"我们的方法很好"。**它的方法部分其实很朴素**，真正的贡献是"我们澄清了这个问题的结构，并证明了一条捷径不存在"。这个定位下，"朴素"反而是优点——因为主张 2 说明复杂化没有回报。
