## 2. Gate 判定与核心发现

### 发现1（主结论）：构造版 Append 是最佳持续算子，stage-2 累计追平 full-history

append_fixed 在 s1、s2 的累计 dev 都是 compact 方法最优，s2 累计 52.26 vs full-history 52.28——**在这个管线里，"旧 synthetic 冻结 + 新 delta 独立构造"几乎消除了与违规上界的差距**（旧 native/ASM 管线中这个差距是 ~10-12 pp）。代价是当前阶段塑性低于 full-history（50.0 vs 66.4）：新块预算只有 121−87=34 行给 3 个新类。

### 发现2：再聚类混合旧 memory 有害（与 P2/P5 同构的第三次验证）

recluster 让旧合成行参与再聚类/合并/文本再融合，结果全面差于不动旧行的 append（s1 −6.6、s2 −8.0）。这与"ASM 更新旧X有害"（P2）、"响应约束保不住可重训性"（P5）构成同一模式的第三个实例：**对已导出的合成 memory 做任何再加工——无论是优化、约束还是重聚类——都劣于原样保留**。合成 TAG memory 的正确操作语义是"只追加、不重组"。

### 发现3（协议问题，需修复后复核）：小图长训练崩溃

stage-0（32 行、2 类）在 2048 步下 cum=28.7，而 smoke 的 64 步下是 70.1——**小合成图上过训练导致 CLIP student 崩溃**（可能是 logit_scale 发散/表征坍缩）。当前 runner 没有 checkpoint 选择（native 管线有 dev-checkpoint 机制）。这不影响三 arm 的相对比较（同一 student 协议），但绝对值被压低，且可能改变各 arm 的最优表现。**复核项：给 student 加 dev-checkpoint 选择或按图大小缩放步数后重跑。**

## 3. 修订后的持续方法形态

```
持续算子 v1.1（依据本 gate）：
  阶段更新 = 旧合成 memory 原样冻结
           + 新 delta 用 v1 静态构造器独立凝聚到预算余量
           + 拓扑只在新块内部与新旧文本 kNN 补边
  再聚类/再融合/质量自适应收缩 → 降级为消融
  （P3 的自适应分配问题转化为"新块预算是否够"——
    发现1显示旧块冻结时唯一的短板是新类塑性，
    这用预算分配调整而不是旧行重组来解决）
```

## 6. Gate 1'' 最终判定：通过

持续算子冻结为 **append-构造式 v1.1**：旧合成 memory 原样冻结 + 新 delta 独立构造到预算余量。已确认的三层证据（P2 优化、P5 响应约束、本 gate 再聚类）共同支持"合成 TAG memory 只追加、不重组"。剩余研究问题收敛为一个：**新类塑性预算**（s2 当前 48 vs full-history 66），这由预算分配（只删旧行、不重组）解决，属于 Gate 2'' 之前的最后一个消融。
