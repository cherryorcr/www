## 2. Gate 判定：三个组件全部未通过，v2 整体否决，v1（A0）维持为现行方法

预注册标准是"每组件 ≥4 seeds 稳定不降级才并入"。实际结果是三个组件在单点上就全部显著降级（−6.2 ~ −13.0 pp），无需扩 seed 即可否决。组件间叠加还会进一步变差（A5 最差），说明损害独立且可加。

## 3. 逐组件失败归因（初步）

### det-CMI（−7.2）
选择标准是"相对 medoid 的条件 NLL 高 = 信息增量大"。问题：**高条件 NLL 同时也捕捉离题与噪声文本**——novelty 与 off-topic 在这个打分下不可分。TAGSAM 原版 CMI 有 GPT-2 逐词概率链的更细粒度机制且服务于不同的融合下游；在"拼接后重编码"的融合方式下，掺入一条离题文本会直接污染融合 embedding。几何近邻虽然"笨"，但保证语义同质——对embedding级融合而言同质比信息量更重要。

### 粗化拓扑 P^TAP（−10.4）
Cora 引用边在 k=135 的簇间投影非常稀疏且不均匀：少数大簇对占据几乎全部边计数，top-int(k·deg) 选边后拓扑高度偏斜（hub 化）。文本 kNN 边在语义空间均匀展开，对比之下更适合 CLIP 式对比训练的消息传播。混合版(A3)介于两者之间，符合该解释。**"真实结构投影"在低预算下反而不如语义 kNN**——这与 plain-graph 粗化文献的常识相反，是 TAG 特有的观察（消息传播服务于图文对齐而非标签平滑）。

### 一阶精炼X（−13.0，损害最大）
精炼目标（随机投影算子下的图文 InfoNCE + 成员均值 L2）确实可优化，但它把 X 拉向"在那个固定随机算子下与文本对齐"的方向——**student 的 GCN 不是那个算子**。这与 P5 的结论完全同构：可满足的代理目标 ≠ 可重训性。至此，"精炼合成X"已在三种通路上失败：bi-level unrolled（P2）、冻结 teacher 响应（P5）、固定随机算子一阶（本轮）。证据已足够把"簇均值X不可被廉价精炼改进"当作结论性发现。

## 4. 对方法与论文的含义

1. **现行静态方法冻结为 v1**：maxmin+Lloyd 联合聚类 + 几何 top-g 融合文本 + 文本 kNN 拓扑 + 簇均值合成X。它在两个管线（native 77.2、GraphCLIP 54.2/54.5）都稳定胜出各自基线；
2. **负结果的价值升级**：TAGSAM 三个组件的确定性回收全部降级 + 三条 X 精炼通路全部失败，构成一个系统性结论——**小预算 TAG 凝聚中，任何"超越一阶统计量的加工"（无论选择、拓扑学习还是特征精炼）目前都不能兑现为可重训性**。这与"响应约束≠可重训性"（P5）合并成论文诊断章节的主干；
3. **对持续规划的修订**：DETFUSE_V2 计划中的三个静态升级组件移除；持续设计（加权再聚类、质量自适应分配、fusion_depth 防稀释、mass 继承）不受影响——它们不依赖任何被否决的组件。Gate 1'' 直接基于 v1 构造器执行。

## 5. 边界与待办

- 单数据集单预算点；CMI 的 ctx/guard 超参未扫（但 −7.2 的缺口不太可能由调参翻转）；
- 粗化拓扑可在"高预算、簇更细"的场景重测（预期随 k 增大而改善），记为扩展实验不阻塞主线；
- fuse_g、degree 的 dev 选择规则保持 v1 现状。
