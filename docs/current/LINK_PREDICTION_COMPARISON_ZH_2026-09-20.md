# C0 与块保持联合核：链路预测比较报告

日期：2026-09-20。状态：正式 540 次训练完成，72 份分阶段 memory 完成重建核验，所有 checkpoint 完成重载与独立 CPU 双精度推理。分类实验不变。

## 1. 核心结论

**“分类没有稳定晋升，但其它任务可能受益”的判断得到本轮实验支持。** coverage 在两个数据集、三个隐藏边划分上，相对 C0 的最终 AUC 和 AP 的 split 均值全部为正。

但应区分三个结论：

1. **已验证：** 在共同 GCN 图自编码器下，degree-balanced/coverage 合成拓扑比 C0 的拓扑更适合链路预测训练；coverage 最终 AP 在 Cora/Citeseer 分别提高 **2.47/3.26 个百分点**。
2. **未验证：** 联合核的结构签名本身是否有不可替代的贡献。原始 joint_kernel 没有稳定收益，度均衡版本已经实现大部分提升。
3. **尚不能宣称：** 超过强链路预测方法、任务无关凝聚已成立、普遍优于完整图训练。尤其 Citeseer 的无训练文本余弦对照比所有 GAE 版本都强。

因此，不应把整个联合核方向判为“无用”；也不能因本轮有提升就把分类的稳定性问题抹掉。合理定位是：**块保持、度与覆盖受控的合成图，在另一种下游训练任务上具有实测收益，值得进一步做机制确认。**

## 2. 这次怎么比较

| 项目 | 设置 |
|---|---|
| 数据集 | Cora、Citeseer |
| 持续阶段 | 原 canonical 三阶段，按原类别顺序到达 |
| 节点预算 | 已见合法 pool 节点约 5%；最终 94/1895、111/2229 个合成/真实节点 |
| 方法 | C0、joint_kernel、degree_balanced、coverage、full_raw_equal |
| 真实边划分 | 3 个随机 seed：29001、29002、29003；按两端到达阶段分层的约 80/10/10 train/val/test |
| Student seeds | 每个条件 100..105，共 6 个 |
| 总训练数 | 2 数据集 × 3 划分 × 3 阶段 × 5 方法 × 6 seeds = 540 |
| 输入 | 分别归一化的 X 与冻结 MiniLM 文本表示拼接 |
| 模型 | PyG GAE；GCNConv 两层，hidden 384、输出 128，内积边 decoder |
| 训练 | 正负边 BCE，Adam 0.001，每阶段从头训练 256 次更新；每步最多 256 条正边及等量负边 |
| 测试 | 在真实已见 pool 节点和 train-only 真实图上编码，预测未见过的边 |
| 指标 | ROC-AUC、AP，数值越高越好；测试正负边 1:1 |

这不是原来的图文 InfoNCE 分类模型换个评价指标，而是**保持凝聚构造规则，换成共同的链路预测训练任务**。凝聚版 student 只在合成图上训练，full_raw_equal 在完整已见真实训练图上训练。推理时二者都能使用真实节点属性、文本及真实训练边。

公平控制：四个合成臂的 X、text、row order、mass、rows 完全一致；最终无向边数也相同，Cora 163、Citeseer 184。改变的是合成图的连边。联合核持久 memory 比 C0 多 graph signature，因此这里只是**等节点/等边数，不是等字节**。

### 防泄漏与权限

不能直接拿原来的联合核 memory 测隐藏边：原 memory 的图签名可能已经见过这些边。本轮先拆边，再从 train-only 当前 delta 重算图签名和联合核连边；每阶段的旧 synthetic rows 和旧旧边保持冻结。

C0 的图文聚类、拼接文本和文本相似度连边不依赖真实边，因此可以复用既有 C0 memory。复用前核对内容哈希；联合核复用同一源簇，并逐行核验源 X 均值与 mass，源簇 ID 不进入持久 memory 或 student。

测试边双向一起隐藏；负例排除所有真实边；原图训练负例还排除验证/测试负例。模型和 checkpoint 不由验证或测试分数选择。所有阶段都排除未来节点。

这里测试的是 **construction pool 内的未知边**，不是原节点分类 report/test 节点，也不是未来时间边预测。原类别标签仍用于到达顺序、分组凝聚，故不能称整个凝聚器为无监督。原始图的推理读取属于下游评估器，不代表凝聚器回读了历史原始数据。

## 3. 最终阶段主结果

以下为 3 个划分 × 6 个 student seeds 的均值；括号内是先平均各划分内 6 seeds 后，三个 split 均值的样本标准差，不是置信区间。全部按百分制报告。

| 方法 | Cora AUC | Cora AP | Citeseer AUC | Citeseer AP |
|---|---:|---:|---:|---:|
| C0 | 85.90 (0.78) | 84.04 (1.93) | 87.00 (1.95) | 85.15 (2.24) |
| 原始联合核 | 84.68 (0.59) | 82.82 (1.57) | 87.04 (1.33) | 84.63 (2.11) |
| 联合核 + 度均衡 | 87.11 (0.81) | 85.68 (1.26) | 90.31 (1.51) | 88.04 (2.35) |
| 联合核 + 度均衡 + coverage | **87.57 (1.42)** | **86.51 (2.29)** | **90.33 (1.70)** | **88.41 (2.39)** |
| 完整已见原始图，同更新次数 | 90.71 (0.37) | 90.81 (0.42) | 92.64 (1.30) | 91.99 (2.14) |

| 相对 C0 | Cora AUC 增量 | Cora AP 增量 | Citeseer AUC 增量 | Citeseer AP 增量 |
|---|---:|---:|---:|---:|
| 原始联合核 | -1.22 | -1.21 | +0.04 | -0.52 |
| 度均衡 | +1.21 | +1.64 | +3.31 | +2.89 |
| coverage | **+1.68** | **+2.47** | **+3.33** | **+3.26** |

本轮 coverage 的“额外覆盖惩罚”相对 degree_balanced 的最终增量为 Cora AUC/AP **+0.47/+0.83**，Citeseer **+0.02/+0.37**。这比 coverage 对 C0 的整体差值小得多。不能把全部提升都归因于覆盖惩罚或结构签名。

| 数据集 | split | coverage 相对 C0 AUC | coverage 相对 C0 AP |
|---|---:|---:|---:|
| Cora | 29001 | +0.71 | +0.46 |
| Cora | 29002 | +3.40 | +5.18 |
| Cora | 29003 | +0.92 | +1.76 |
| Citeseer | 29001 | +4.04 | +3.43 |
| Citeseer | 29002 | +3.57 | +3.05 |

Cora 的 18 对 seed 比较中，AUC 和 AP 分别有 15/18 为正；Citeseer 两个指标均为 18/18 为正。这是有用的稳定性证据，但 18 次训练共享数据，不能称为 18 个独立泛化任务；三次边划分也不替代新的类别顺序和新数据集。

## 5. 能复现完整图多少性能

仅相对于本轮同模型、同 256 更新次数的完整图参考计算分数比值：

| 数据集 | 方法 | AUC / 完整图 AUC | AP / 完整图 AP |
|---|---|---:|---:|
| Cora | C0 | 94.70% | 92.54% |
| Cora | coverage | **96.55%** | **95.26%** |
| Citeseer | C0 | 93.92% | 92.56% |
| Citeseer | coverage | **97.51%** | **96.10%** |

coverage 的最终 AP 仍低于完整图参考 **4.30/3.59 pp**，相比 C0 分别缩小约 **36.46%/47.58%** 的 AP 差距。

这些“保留率”是指标比值，不是信息保留比例，也不是理论最优性能复现比例。AUC 与平衡负例 AP 有约 0.5 的随机基准，直接比值会显得偏高，因此必须同时展示绝对分数与差值。完整图也未充分调参或搜索训练时长。

另外，这里压缩的是**训练 memory**；测试时仍使用真实节点属性、文本及 train-only 图，不能称推理端只需 5% 原图。

## 6. 为什么会改善：可支持与不可支持的解释

最终合成图的直接统计：

| 数据集 | 方法 | 孤立节点 | 连通分量 | 最大度 |
|---|---|---:|---:|---:|
| Cora | C0 | 3 | 8 | 12 |
| Cora | 原始联合核 | 6 | 9 | 14 |
| Cora | degree_balanced / coverage | 0 | 1 | 5 |
| Citeseer | C0 | 5 | 10 | 16 |
| Citeseer | 原始联合核 | 5–6 | 11 | 13–14 |
| Citeseer | degree_balanced / coverage | 0 | 1 | 5 |

C0 和原始联合核按相似度优先取边，有限边预算容易集中在一部分高度相似节点。度均衡约束让新 block 内所有行都参与关系，同时限制新旧连接向少数旧节点聚集。对以边重建为目标的 student，这能改变训练正边的覆盖范围和消息传播覆盖。

这解释与本轮观测一致，但还不是完整因果证明：degree-balanced 同时改变连通性、度分布和边身份。尚未做“C0 文本核 + 同样度约束”“同度序列随机连边”“去掉图签名但保留覆盖约束”等控制。

coverage 与 degree-balanced 最终边集合 Jaccard 约 0.84–0.92，两者本来就很接近。后者已实现多数收益，是下一轮最重要的低复杂度控制，不能只比较 coverage 与 C0 就宣称复杂核机制得到证明。

## 7. 必须保留的强对照：无需训练的余弦打分

对同一批真实测试节点对，直接计算输入向量余弦，不训练模型：

| 打分方法 | Cora AUC | Cora AP | Citeseer AUC | Citeseer AP |
|---|---:|---:|---:|---:|
| X cosine | 86.72 | 87.74 | 94.86 | 95.04 |
| 文本 cosine | 86.84 | 87.91 | 94.83 | 94.99 |
| X+文本 cosine | 86.85 | 87.90 | 94.85 | 95.02 |
| coverage 训练 GAE | 87.57 | 86.51 | 90.33 | 88.41 |
| 完整图训练 GAE | 90.71 | 90.81 | 92.64 | 91.99 |

这不是可以忽略的“非模型方法”：全部 student 在推理时也读取了相同真实节点特征，因此余弦是合法且很强的对照。

- Cora：coverage 的 AUC 高于余弦，但 AP 低约 1.40 pp。
- Citeseer：连完整图 GAE 都低于余弦，说明这套下游模型/目标/固定训练时长未充分保留已有语义信号，不能把其分数当理想模型上限。
- 均匀、到达阶段匹配的非边可能较容易被文本语义区分。是否由负例难度、图卷积平滑或训练目标导致，需要额外控制，不能据此直接断言唯一原因。

因此当前结论是 **condensed-memory-to-common-student transfer 更好**，不是“总体链路预测超过简单强基线”。这两者可以同时成立。

- 从保存逐边分数独立计算 AUC/AP，与全部主表记录精确一致。
- GPU 重载最大 logit 绝对误差 Cora 3.82e-6、Citeseer 1.91e-6；少数近似并列排序造成 AP 差异，最大 **0.01684 pp**。保留 11 个切片/指标告警，不宣称严格排序完全复现。

## 10. 下一步建议

本轮完成比较，不自动追加其它训练。建议优先顺序：

1. **机制必要性：** 在同样 rows/edges 下增加 C0+degree-balanced、无 graph signature 的 XT+degree-balanced、随机同度拓扑。先回答收益是否只需简单的度/连通性控制。
2. **更强任务控制：** 保留文本余弦主表项；新增语义相近非边、二跳非边等明确候选集协议，避免只测易区分非边。所有方法共同使用新协议。
3. **共同下游可靠性：** 单列训练时长曲线和不传播/残差保留输入语义的共同模型控制，先解释完整图 GAE 为何不敌余弦；不只给新方法换 student。
4. **泛化确认：** 锁定候选后再做新类别顺序、1%/10% rate、更多阶段及新数据集。当前三次边划分不替代这些验证。
5. **论文表述：** 将“分类与关系任务对 synthetic topology 的需求不同”作为可检验机制假设，而不是将此前分类门禁不通过改写为算法完全失败。晋升应明确是针对哪种任务和条件。
