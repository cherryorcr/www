# 第一部分：方法全流程（结合代码）

代码入口：`code/frozen_v1_2026_09_09/run_gate1_continual.py`（主体）、`run_gate3_test.py`（c 规则落地）、`code/v2_llm_fusion/run_scale_gate.py`（扰动模块）。

## 0. 符号与设定

| 符号 | 含义 |
|---|---|
| `X` | 节点数字特征（arxiv 用 ogbn 原始特征，Cora/Citeseer 用 GraphCLIP 派生特征） |
| `text` | 节点原始文本（标题/摘要） |
| `text_emb` | 冻结 MiniLM 对文本的编码（384 维，L2 归一化） |
| `pool` | 允许进入凝聚的节点（排除 dev 与 test：`node_id%10 ∉ {1,2}`） |
| `delta` | 当前阶段新到达的节点 |
| `memory` | 输出的合成小图 artifact |
| `k` | 预算 = $\lfloor 0.05 \times$ 累计 pool$\rfloor$ |

三阶段流（类别增量）：Cora `[0,1]→[2,3]→[4,5,6]`，预算 32→87→121；Citeseer 6 类三阶段，预算 50→110→143。arxiv 用 temporal 三阶段，预算 2258→4514→6773。

## 1. 文本编码（冻结 MiniLM）

```python
class FrozenMiniLM:
    def encode(self, texts, batch_size=64, max_length=256):
        # tokenize -> last_hidden_state -> attention-mask mean pooling -> L2 normalize
```

关键：**全程 `eval()` + `no_grad()`**，文本塔不参与任何训练。它同时服务于三处：(a) 聚类空间的文本侧；(b) 融合文本的重编码；(c) 评测时类别 prompt 的编码。**同一个塔编码节点文本和类别 prompt**，这是零样本评测能成立的前提。

## 2. 联合聚类（确定性）

```python
joint = torch.cat((F.normalize(x.float(), dim=1), text_emb), dim=1)   # 384+384=768
assign = maxmin_lloyd_gpu(joint, k, device)
```

`maxmin_lloyd_gpu` 两段：

- **max-min 播种**：首中心取固定输入顺序的第一个点；之后每次选**离已有中心集合最远**的点（farthest-point）。这消除了"随机初始化中心"这个凝聚随机性来源——旧版跨 seed std 11.74、最差 49.92，确定性版 std≈0。
- **Lloyd 迭代**：分配 → 更新中心 → 再分配，最多 25 轮；强制最初选出的种子保留在自己簇，避免空簇。

注意 `F.normalize(..., dim=1)` 是**逐行** L2 归一化（写成 `1` 会被当成 `p=1`，是历史坑）。X 与 text_emb 两块各自归一化后再拼接，使两侧在联合空间里权重相当。

## 3. 每簇 → 一张合成卡片

```python
syn_x.append(x[members].float().mean(0))          # ① X = 簇内原始 X 均值
mg = joint_gpu[members]                            # ② 在 joint 空间找最近簇心的至多 5 篇
order = members[d.argsort().cpu()][:5]
per = max(48, 320 // max(1, len(order)))           # ③ 均分 320 字符（每篇≥48）
fused.append(" ".join(texts[int(i)][:per] for i in order))
fused_emb = encoder.encode(fused)                  # ④ 对拼接串重新编码
weights.append(float(len(members)))                # ⑤ mass = 簇内真实节点数
```

四个要点：**X 用原始 X 的均值**（不是归一化 joint 中心）；**文本是摘录拼接**，不是 LLM 改写；**融合文本重新过一遍 MiniLM**（不是平均 5 个 embedding），保证 `texts` 与 `text_emb` 严格对应；**mass** 记录代表人数，供后续容量决策。

## 4. 拓扑：融合文本 kNN

```python
edges = knn_topology_gpu(fused_emb, degree=1.0, device)
```

在全 memory 的融合文本上算余弦相似度，取全局 top-$E$（$E\approx k\times1.0$）对，补反向边，GCN 归一化时加自环。**"degree=1.0" 不是每点 1 个邻居**——121 节点选 121 条无向边时平均非自环度为 2，且度不均匀。

**关键细节**：拓扑**不作为 memory 的持久字段**，每阶段在全体文本上重建。所以旧行的 X/text 逐字节不变，但**旧节点的 GCN 邻居可能改变**——"保留旧数据内容"不等于"保留旧节点响应"。

## 5. 持续算子：append（只追加，必要时只删行）

```python
# 新块配额
new_quota = max(budget_remaining, 15 * n_new_classes)
# 容量不足时：按 mass 升序删旧行，留存行 X/text 不改写
memory = concat(kept_old_rows, construct(delta, quota=new_quota))
```

Cora stage-2：余量 34，但 3 个新类需下限 45 → 旧 memory 从 87 行按 mass 删到 76 行，新块 45 行。Citeseer stage-2：余量 33 ≥ 下限 30 → 不触发，不删行。

**`append ≡ 分层配额的一次性凝聚`（已审计）**：`run_corrections.py` 用 `allclose(atol=1e-5)` 比较 x/text_emb/mass/stage、`==` 比较 texts，全部相等。即"历史不可重读"这个持续约束的代价**恒等于零**——这在确定性构造器下是构造性的，不是逐点测出来的。

## 6. 下游 student 的训练与评测

```python
class CLIPStudent(nn.Module):     # 两层 GCN + 文本投影 + 温度
    def encode_graph(self, x, adj):
        return F.normalize(self.g2(F.relu(self.g1(x, adj)), adj), dim=1)
    def encode_text(self, t):
        return F.normalize(self.text_proj(t), dim=1)
    def logits(self, x, adj, t):  # 零样本分类
        return self.logit_scale.exp().clamp(max=100) * (self.encode_graph(x,adj) @ self.encode_text(t).T)

# 训练：双向 InfoNCE（图找文本 + 文本找图）
g = model.encode_graph(x, adj)[rows]; tt = model.encode_text(t[rows])
logits = scale * g @ tt.T
target = arange(len(rows))
loss = (CE(logits, target) + CE(logits.T, target)) / 2
```

- **训练只用合成图**，步数 `min(2048, 16×roots)`（自适应，防止小图被训练过头：32 行时 512 步，121 行时 1936 步）；
- **类别标签不参与训练 loss**（自由配对，对角线是正例）；
- **mass 虽传入但未被 `train_student` 读取**——各合成行均匀采样，`mass=20` 不等于重复 20 次；
- **评测**：student 在**整张真实图**上传播（transductive），与类别 prompt 的 text_emb 比相似度取 argmax，只在指定 mask 上统计。

## 7. v1.2 新增：条件扰动模块

```python
# 判定（本次实验确定）
if n_pool < S:            # S ≈ 3–5×10^4 条凝聚源
    X = X0                                          # 纯构造式，扰动关闭
else:
    g = torch.Generator().manual_seed(9001)         # 固定 seed，确定性可复现
    noise = torch.randn(X0.shape, generator=g)
    noise = noise / noise.norm(dim=1, keepdim=True).clamp_min(1e-9) * eta
    X = X0 + noise                                  # eta ≈ 1.79（n_pool≈1.35e5 标定）
memory = {"x": X, "text_emb": …不变, "texts": …不变, "edge_index": …不变}
```

**只改 X，文本框不动**——这是与所有 ASM 类方法的根本区别：不引入任何需要 teacher 的梯度通路，代价为零（毫秒级），且完全确定。

# 第三部分：理论解释——方法为什么成立

## 1. 构造器为什么有效：图文同源 + 几何概括

主方法的每个组件都能给出"为什么必须这样"的解释：

**（a）为什么在"归一化 X ‖ text_emb"的联合空间聚类？** 因为下游 student 学的正是图文对比目标。在它将要学习的那个几何里做聚类，等于**让构造目标与训练目标在同一个度量下对齐**。若改用 X 本身或文本本身的单一空间，簇内成员对图文对比任务不一定是"相似"的。

**（b）为什么 X 取原始 X 的均值，而文本要重新编码？** 均值是对簇内特征的一阶充分统计量——它最小化簇内平方误差，是"用一行代表一簇"的无偏选择。文本则不同：字符串不能平均，但**必须保证 `texts` 与 `text_emb` 严格对应**（否则第 5 节的图文配对失效），所以拼接后重新过一遍编码器。论文里"图文一一对应是有用信息"这一条由文本置换实验直接支持（同阶段内打乱配对，当前阶段 test 平均掉 11.20 pp）。

**（c）为什么拓扑用文本 kNN 而不是真实边粗化？** 真实边投影到簇级会产生高度集中的 hub（很多真实引用汇成少数簇间连接），GCN 消息传播被少数 hub 主导；而文本相似度边在**同一个几何**里衡量"这两张卡片是否该互相传递消息"，与图文对比目标一致。实测真实边粗化 54.17→43.74。

**（d）为什么确定性播种（max-min）优于随机初始化？** 因为初始化质量是**下游方差的主要来源**：旧随机版跨凝聚 seed 从 49.9 到 80.1，这个方差远大于任何优化能提供的稳定收益（ASM 的收益幅度在 ±1.3 内摆动）。确定性构造把"抽签"从流程里移除，把方差收敛到只剩 student 训练的随机性。

## 2. 持续约束为什么免费：分层构造的交换性

附录里的等价审计给出的不是经验观察，而是**构造性事实**：

> 在确定性构造器下，"在线 append"与"允许重读历史的、按阶段配额分别聚类"产生**逐字段相同**的 memory。

证明思路：构造器是输入的确定性函数 $C(\cdot)$，且 append 的新块只依赖当前 delta 与配额。因此

$$\text{append} = \big[\,C(\text{delta}_0),\ C(\text{delta}_1),\ C(\text{delta}_2)\,\big]\Big|_{\text{配额}} = \text{分层配额一次性凝聚}$$

两边是对同一个函数在同一样本上的求值，只是求值顺序不同——而 $C$ 无状态、无跨阶段耦合，所以顺序不影响结果。**"历史不可重读"这一持续约束的代价因此恒等于零**，不是"近似为零"。

这也精确解释了 full_history 为什么**在类别增量上**更差：它不是"重读历史"的错，而是**混合池联合聚类**的类别主导效应——新类节点数量占优时，联合聚类会把旧类的簇吞掉。temporal 划分下每阶段同分布，这个效应消失，full_history 就不再崩溃。**这是对该主张最重要的边界限定。**

## 3. 扰动为什么有效且规模依赖：冗余度—平滑度假说

这是 v1.2 新增模块的理论依据，由四轮实验共同支撑：

**（a）簇均值 X 是"过度平滑"的。** 簇均值是簇内特征的最优一阶概括，但它抹掉了行间差异。当簇很大（大图的簇远大于小图），均值行会变得彼此高度相似——**图的 40 类判别信息被压缩掉了**。

**（b）InfoNCE 的假负例污染随类内冗余放大。** 大图每类有数千节点，同类节点在对比学习中被大量互相当作负例。这是"凝聚即去噪"效应在大图上更强的原因，也是 raw 在大图上反超 compact 的原因。但同时，簇均值自身的过度平滑又成了新的损失来源——**两者在大图上同时达到最大**。

**（c）扰动正好打破这个平滑**，而**几何去偏置不能**：白化/尺度/旋转只改变 X 的全局姿态，不改变"行与行之间有多相似"；只有**逐行独立的随机扰动**才能重新引入行间差异。这解释了为什么去偏置实验全部失败而随机噪声有效——**这是本工作里最有信息量的一个负对照**。

**（d）规模依赖由冗余度决定。** 小图上簇内节点少、冗余低，簇均值本就不那么平滑，扰动只带来破坏（Cora −8.15、Citeseer −9.48）；大图上冗余高，扰动收益 +1.6~2.0。门槛 $S$ 就是这对效应的交叉点（实测在 $3\text{–}5\times10^4$ 条凝聚源之间）。

**（e）为什么必须"构造后"扰动、且不能锚定。** 构造器给出的是几何正确的起点（同源、概括、确定），扰动只在**这个正确起点上**重新引入行间差异。Proximity 锚（λ=1e-2）把 X 拉回起点，等于取消扰动（17.0–18.7 < frozen 18.30）——**这从反面证明了收益来自"离开起点"，而不是"接近某个目标"。**

## 4. 为什么不能用冻结响应来优化（T1 无代理命题）

11 个 artifact × 5 类预测器全部失效，且 response-retention 的 KL 被优化到 0.001（降 92–99%）而下游毫无改善。理论的解释是**可重训性与响应保持是两件事**：

> 一个已经训练好的 teacher 面对改后的材料仍能给出原答案，不代表一个**从头训练的新学生**能靠这些材料学会。teacher 的参数里已经包含了材料看不出来的知识。

所以任何以"冻结模型的前向响应"为目标的优化，其最优解与新学生的可训练性是**解耦**的。这既是本项目放弃 ASM 主线的依据，也解释了 ASM loss 与下游 F1 的完全无关（loss 恒为 0.0078，F1 差 5 分）。

# 第四部分：创新点与贡献

## 创新点（与 TAGSAM 及同期工作相比的差异）

**创新点 1 · 消解了双层优化在 TAG 凝聚中的必要性——用一套统一机制解释它为何失败**

不是"我们的 ASM 没调好"，而是给出了一个结构性结论加一个可检验的替代解释：ASM 的有效成分是"把 X 推离簇均值到最优扰动幅度"，而非"梯度找到了好方向"。证据链完整：ASM 自发漂移幅度（1.79）恰好等于扰动幅度曲线的峰值；其 loss 全程不降（3.7%）却有效益；锚定会抹掉全部收益；小图上 ASM 同样无收益。**这是对 TAGSAM 核心机制的一个可证伪的重新解释**，并给出了明确的适用边界（小图无效、大图有效但等价于扰动）。

**创新点 2 · "持续约束代价恒为零"的构造性等价定理**

在确定性构造器下证明 append（在线、历史不可重读）与分层配额一次性凝聚**逐字段相同**。这把持续学习里最常见的一类担忧（"不能重读历史会损失信息"）从经验问题变成构造问题，并精确定位了 full_history 的真实劣势来源（混合池的类别主导，而非重读历史）。**这个等价是小图和大图都成立的，不是规模依赖的。**

**创新点 3 · 门槛式的条件模块，以及"凝聚即去噪"的冗余度判据**

提出并测量了扰动收益的规模门槛（$S\approx3\text{–}5\times10^4$ 条凝聚源），并给出统一机制：类内文本冗余度决定"凝聚是净化还是损失"。这解释了三个此前互相独立的观察——Cora 上 compact > raw、arxiv 上 raw > compact、小图扰动有害而大图有益——**它们是同一个冗余度参数的不同取值**。

**创新点 4 · 零成本确定性模块替代昂贵的双层优化**

v1.2 的扰动模块：毫秒级、无 teacher、无随机性（固定 seed）、无标签。在 arxiv 上拿到 +1.64（CI [+1.03,+2.29]），而 ASM 需要 50 步双层反传才拿到 +1.30~1.56。**这是"用结构洞察换计算成本"的典型**，工程上也更容易部署（不需要在持续流程里保留 teacher）。

## 贡献点（可直接写入论文的清单）

1. **方法**：frozen_v1 —— 确定性联合聚类 + 均值 X + 几何近邻文本融合 + 文本 kNN 拓扑 + append（只追加、必要时只删行）的持续 TAG 凝聚流程；以及 v1.2 的条件扰动扩展。
2. **理论**：（i）持续约束零代价的构造性等价；（ii）可重训性与响应保持的解耦（无代理命题）；（iii）扰动收益的冗余度—平滑度机制与规模门槛。
3. **实验**：Cora/Citeseer 的 test 一次性确认（两指标居首，含 Accuracy 与 Macro-F1）；arxiv 169k 的静态（5% 凝聚 = raw 上界 94.6%）与 temporal 持续（约束代价 −0.63）验证；与官方 GraphCLIP 的绝对水平对比（差距 <3 pp）；扰动模块的幅度/稳健性/门槛/负对照四组判定。
4. **负结果**：ASM 在受控协议下的全面失效及其机制解释；几何去偏置的三个失败臂；recluster 的塑性 trade-off 边界。
5. **方法与工具**：可审计的持续 TAG 凝聚后端（native v1 + frozen_v1 两套）、等价性审计脚本、预注册的判定规则（PROTOCOL v2 §6）。

## 必须同时声明的边界

- Cora/Citeseer 均为开发数据集，test 分区（`node_id%10==2`）已消耗；最终论文需补一个全新数据集（Photo/Computers）；
- 评测为 whole-graph transductive，不是严格 inductive；类别 prompt 在训练中作为图文配对内容出现，不是"从未见过类别"；
- arxiv 上的持续场景是 temporal 三阶段，与 Cora/Citeseer 的类别增量**不是同一种流**，两者结论需分别表述；
- v1.2 的扰动模块尚未跑 Gate 序列，其门槛 $S$ 与幅度 $\eta$ 只在 arxiv 子采样上标定，2.7 万点的回落未解释；
- "凝聚 > raw"只在本文的 GCN student + 图文对比协议下成立，不是普适结论。
