# 三尺度 ASM 探针：回应 TAGSAM 作者"数据量小"批评

日期：2026-09-10
数据：服务器 `problem_validation_results/multiscale_asm_2026_09_10/`（本地镜像 `asm_{cora,citeseer,arxiv}.json`）
动机：TAGSAM 作者提出我们的"ASM 失效"结论可能是 Cora 数据量小（2.7k）造成的。此前全部证伪证据都在 2.7k–3.3k 上，**ASM 从未在大图上跑过**。本实验在三个尺度跑同一 ASM 流程（同 rate=5%、同 inner=10、同 100 outer steps、同 teacher 协议），测两件事：(a) ASM 自身 loss 是否随规模开始有效下降；(b) 优化后 artifact 是否优于 frozen 初始化。

## 1. 结果

| 数据集 | n | k | frozen dev F1 | ASM dev F1 | 差值 | ASM loss 降幅 | 3 seeds 方向 |
|---|---:|---:|---:|---:|---:|---:|---|
| Cora | 2,708 | 108 | 33.13±1.30 | 32.88±0.76 | **−0.25** | 5.2% | 2 正 1 负 |
| Citeseer | 3,186 | 127 | 47.64±1.21 | 47.40±2.26 | **−0.25** | 3.4% | 2 正 1 负 |
| **ogbn-arxiv** | **169,343** | **6,773** | 19.74±0.16 | **23.05±0.76** | **+3.31** | 3.7% | **3/3 全正** |

## 2. 两个必须分开的结论（这是关键）

### 结论 A（不变，已获规模鲁棒性）：ASM 自身 loss 在所有尺度都几乎不下降

| 尺度 | loss 相对降幅 |
|---|---:|
| Cora 2.7k | 5.2% |
| Citeseer 3.3k | 3.4% |
| arxiv 169k | 3.7% |

**"外层梯度几乎不降低 matching 目标"这一诊断在 169k 节点上依然成立**（此前 P2 在 native 管线的 0.2%–1.2% 亦然）。代理目标的梯度通路问题与数据规模无关。作者的"数据量小"假说**不能**解释 loss 不降。

### 结论 B（被推翻，必须修正）：ASM 的下游效果是**规模依赖**的，在大图上转为正

- 小图（Cora/Citeseer）：ASM 与 frozen 基本持平（−0.25，方向不一致）；
- **大图（arxiv 169k）：ASM 稳定优于 frozen +3.31，3/3 seeds 全正**。

**因此"ASM 从不带来收益"的表述是错误的，必须缩窄为"ASM 在小图上不带来收益"。** TAGSAM 作者的批评在大图这一点上**部分成立**。

## 3. 机制：与 P2 的弱扰动假说自洽，而非"优化终于生效"

关键观察：**arxiv 上 loss 依然只降 3.7%，却带来 +3.31 收益**——收益不是来自目标下降（那是同一数量级的噪声），而是来自**对 X 的弱扰动方向在特定条件下有利**。这与 P2 机制一致：

- P2 结论：ASM ≈ X 空间弱扰动，**方向由初始化质量与下游容量决定**；
- arxiv 的 frozen 基线低（19.74，40 类困难、初始化弱、下游空间大）→ 扰动有改善余地 → +3.31；
- Cora/Citeseer 的 frozen 基线相对不弱 → 扰动无稳定方向 → ±0.25。

**诚实的统一表述**：

> ASM 的目标梯度在所有尺度都近乎无效（loss 降幅 3–5%）；它对下游的影响是一种弱扰动，其收益的正负由数据规模/任务难度调制——小图上与初始化打平，169k 大图上稳定为正（+3.3）。因此 ASM **不是**无效算子，而是"低效但有条件有益的扰动式优化"。

## 4. 对论文主张的修正（必须执行）

| 原主张 | 修正后 |
|---|---|
| "ASM 优化梯度近乎失效，收益来自弱扰动，方向由初始化决定" | ✅ 保留（loss 不降已获规模鲁棒性） |
| "ASM 不带来稳定收益 / 构造式严格优于 ASM" | ⚠️ **缩窄为"在小图上"**；大图上 ASM 有 +3.3 的稳定收益 |
| "代理不可用"（T1 无代理命题） | 需重新审视：T1 的 5 个统计量在**小图 artifact** 上零相关；arxiv 上未重做，且 ASM 在大图上的 +3.3 提示"扰动式收益"可能不受 embedding 统计预测——**需在 arxiv 上重做 T1** |
| "构造式范式优于优化范式" | 改为"构造式在合规性/确定性/成本上占优；优化式（ASM）在小图上无收益、大图上有小幅扰动式收益" |

## 5. 待补实验（修正主张前必须做）

1. **arxiv 上的 T1**（无代理命题在大图是否成立）——用 arxiv 的 frozen vs ASM artifact + 若干构造变体，测 embedding 统计与 F1 的相关性；
2. **arxiv 上的 ASM vs 构造式直接对比**（当前是 ASM vs frozen，需补 ASM vs 完全构造式、以及更多 seed 把 +3.31 的显著性坐实，n=3 偏少）；
3. **中间尺度**（如 30k–60k）确认"由负转正"的转折点，支撑"规模调制"叙事；
4. **扰动假说的直接检验**：给 frozen artifact 加可控随机扰动，看是否复现"低基线→扰动有益、高基线→扰动无益"的模式（若复现，则 +3.3 确为扰动收益而非优化收益）。

## 6. 学术价值

这个结果**增强**而非削弱论文：它展示了对作者批评的诚实回应，把"ASM 完全无效"的过强主张修正为"ASM 低效且效应规模调制"的精确主张，并用统一机制（弱扰动）解释了三尺度全部数据。修正后的叙事更有说服力，也更难被反驳。
