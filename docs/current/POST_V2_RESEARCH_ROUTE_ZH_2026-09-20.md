# V2 之后的研究路线与冻结决定

日期：2026-09-20

## 1. 当前决定

块保持联合核 V2 已完成小图正式矩阵、独立 checkpoint 重载审计和本地汇总复算。`C0` 继续作为唯一共同控制和当前主方法；本轮没有候选达到晋升门禁，因此不启动大图确认、不组合 response selector、动态预算、attention 或旧行 refresh。

这不是“所有候选都没有平均收益”。`coverage` 和 `degree-balanced` 在部分 Cora、低压缩率和五阶段条件上有平均提升，但最差条件和 old-class guard 失败。它们适合作为条件性诊断，不适合作为论文主方法。

## 2. 已验证的边界

| 方向 | 当前证据 | 研究定位 |
|---|---|---|
| 联合 X/T/G 核选边 | 平均可正，但跨数据集和条件不稳定；持久字节约为 C0 的 1.89 倍 | 机制诊断，不晋升 |
| 度平衡与 coverage | 平均 F1 高于 C0，但存在明显最差条件退化 | 条件性候选，不作为默认规则 |
| 单向/算子保持 | 静态旧算子可保持，但重训后的 F1 明显下降 | 负结果：算子保持不推出函数保持 |
| drift gate | 能回退部分案例，但仍有大幅退化 | 负结果：当前漂移量不是可靠安全判据 |
| FP16/sketch64 | 可改变存储或边集合，但没有性能晋升证据 | 暂不做存储主线 |
| response / attention / dynamic budget | 历史小图实验已显示成本高或不稳定 | 不与 V2 叠加 |

## 3. 下一次创新应满足的条件

下一步不再优先增加新的局部拓扑规则。若继续追求 CCFA/WWW 长文，应先提出可检验的机制假设：

> 合成记忆的质量不应由静态相似度或结构漂移单独定义，而应由多个独立 student 重训轨迹下的可重训性、旧类保持和新类塑性共同定义。

这个假设必须落实为新的目标或理论分析，并同时报告：

- 预训练/选择成本与最终 student 训练成本；
- memory 字节和合成行数；
- old/new/pooled Macro-F1；
- 独立 selection seeds 下的 regret、回退率和最坏条件；
- 与 C0、强 coreset、全局重凝聚和完整原始图参考的严格对照。

如果新机制仍只有单数据集或单顺序的平均提升，就保留为诊断，不进入主方法。

## 4. 执行顺序

1. 封存 C0、V2 结果和所有旧候选，冻结现有指标与协议。
2. 整理“静态结构相似度 -> student 可重训性”之间的失败案例和理论解释，形成新机制的预注册假设。
3. 只实现一个最小的新目标，先在 Cora/Citeseer 小图、独立顺序和独立 selection seeds 上验证。
4. 通过性能、最坏条件、old-class guard、成本和强 baseline 门禁后，才考虑大图 base+4。
5. 若没有新机制通过，论文主线采用“持续合成追加的协议、系统对照与负结果/机制分析”，不宣称 SOTA。

## 5. 证据范围

本路线基于开发条件，不能称为独立泛化确认。V2 正式结果为 3012 次 student fit、502 条阶段记录、21 项测试通过；本地汇总与远程 summary 的主指标差异为 0。远程 `.pt` 序列化文件仍是完整 serialized-byte 证据来源，本地复算只重新核对 audited JSON/CSV 和 logical payload。
