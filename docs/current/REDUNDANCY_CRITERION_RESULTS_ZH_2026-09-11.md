## 2. 三个候选判据的检验

| 判据 | 结果 | 失败点 |
|---|---|---|
| `n_pool ≥ S`（原规则） | ❌ | bookchild（61k 池却有害） |
| `T_paircos ≥ τ`（文本冗余度） | ❌ **4/5** | **arxiv**（T=0.133 却有效）——判据被自己的反例推翻 |
| **`k ≥ 4000`（簇数）** | ✅ **5/5** | 无（在 5 个已知点上） |

**`k ≥ 4000` 在全部已知数据集上正确**：k=108/127/468/1,662/3,074 全部关闭（这些数据集上扰动有害或无效），k=6,773/6,922 全部开启（有效）。阈值取 4000–6000 都给出 5/5。

## 3. 为什么是 k 而不是池规模或文本相似度

**机制上说得通**：扰动的收益来自"簇均值的行间差异被抹平，student 缺少可对比的负例"。这个效应需要**足够多的合成行**才能形成规模——k 就是合成图的行数，也就是 student 训练时可用负例的池子大小。

- **为什么池规模不对**：池规模决定的是"压缩前的数据量"，而 student 见到的是压缩**后**的 k 行。bookchild 有 61k 池，但摊到 24 类、压成 3,074 行后，每行的信息量仍高、行间差异仍够——扰动只会破坏。
- **为什么文本相似度不对**：arxiv 是直接反例（T=0.133 最低，却有效）。arxiv 的文本是"标题+摘要"、领域跨度大，融合文本天然分化；但它的 **k 高达 6,773**，行数足够，扰动仍能起作用。**这说明"行间相似度高"既非必要也非充分**。
- **为什么 k 合理**：k 同时编码了"数据规模"与"压缩后行数"两个因素，且它与 student 实际面对的负例池规模直接对应。

## 4. 修正后的 v1.2 模块定义

```
若 k < 4000:      memory = construct(delta)                    # 纯构造式
否则:             X ← X + η·R  (η≈1.79 相对幅度、seed 固定)     # 确定性扰动
```

**注意 η 与 k 的关系**：此前发现"固定绝对幅度在小池上过强"，现在用**相对幅度**（η × 该图 X 的平均行模长）已在四个新数据集上跑通，说明相对幅度是跨数据集可用的标定方式。

## 5. 必须承认的局限

**（a）5 个数据点太少，且分布极不均匀。** 关闭侧有 5 个点（108–3,074），开启侧只有 2 个（6,773/6,922）。**阈值 4000 落在一个宽空隙里，没有被逼近过**——需要 k 在 3,500–6,500 之间的数据集来收紧。

**（b）量级差异巨大。** wikics 的 −32.85 与其他所有点都不在一个量级（可能是 X 为 300 维、与 384 维文本塔不匹配导致的特殊失效），它作为"关闭"样本会主导任何相关性分析。

**（c）cora/citeseer 的收益值来自不同实验**（rel=2.0 的相对幅度），严格来说不能与其他的 η=1.79 直接并列。虽然两者都指向"关闭"，但数值上不可比。

**（d）这仍是黑箱阈值。** 我们已经两次修正判据（n_pool → 每类节点数 → k），每次都因新数据而失效。**在论文中应如实写成"经验判据 + 明确的失效记录"，而不是声称找到了机制律。**

## 6. 对论文的净影响

**（a）正向**：jitter 的收益现在在 **sportsfit 这个全新数据集上独立复现**（+3.63，4/5，CI 不含 0）；同时拿到了 4 个全新数据集，其中一个（sportsfit）与 arxiv 同规模。

**（b）负向但诚实**：判据的两次修正史本身就是有价值的记录——它说明**"什么时候该扰动"这个问题比预期难**，任何一个单变量代理都会在新数据上失效。这个诚实性对审稿是加分项。

**（c）ASM 的最终图景**：7 个数据集中 **6 个 ASM 有害或无效**（wikics −20.43、bookhis −2.63、sportsfit −4.89、cora/citeseer −0.25、以及它们全部 loss 只降 0.3–1.5%），唯一有效的 arxiv 也可由随机扰动复现。**这比之前的表述硬得多，可以作为一个独立结论写入。**

## 7. 待补（按优先级）

1. **找 k ∈ [3,500, 6,500] 的数据集**收紧阈值——可通过对 sportsfit/bookchild 做类别子集构造；
2. **复核 wikics 的 −32.85 是否为维度不匹配伪影**（X 300 维 vs 文本 384 维）——若是，需从判据样本中剔除并重新计数；
3. 用 `k ≥ 4000` 重跑 scale-gate 子采样，检验非单调性是否消失；
4. 四个新数据集的 test 一次性读取（主方法冻结后）。
