# 块保持联合核局部优化：实验与机制报告

日期：2026-09-20。本文对应上一轮 Phase-12 之后的联合核局部优化，不是历史文本 P2，也不为项目另立一个已晋升的版本号。

状态：正式矩阵、独立 checkpoint 重载审计和汇总均已完成。结论：所有新候选均未通过晋升门禁，C0 保持当前主线。

## 1. 本轮回答什么问题

上一轮联合核在 36 条件上平均略有收益，但最差条件退化较大，且持久图签名增加约 89% 的记忆字节。本轮不叠加 response、动态预算、attention 或旧行更新，只检验度约束、边覆盖、单向传播、漂移回退及签名压缩。

| 实验 | 相对原始联合核改变什么 | 要回答的问题 |
|---|---|---|
| degree_balanced | 新块内部度上限 2；跨块旧端点容量限制 | 高相似选边是否过度集中在少数节点上 |
| coverage | 在相同度约束上加入边中点核冗余惩罚 | 减少重复关系能否额外改善任务效用 |
| operator_stable | 内部边不变；每个新行只接收两个旧行的单向消息 | 保持旧归一化算子能否改善旧类保持 |
| drift_gated | 相对同一旧 memory 的 C0 追加，漂移更大时回退 | 不训练 student 的结构 gate 能否降低坏案例 |
| X / T / G / X+T | 固定预算和合成内容，仅改变选边核分量 | 结构签名是否提供单纯属性、文本之外的增益 |
| FP16 / sketch64 | 只压缩持久 G 签名 | 能否减轻额外存储且保持边和性能 |
| equal-byte | 在每阶段 C0 字节上限内减少新增行 | 签名带来的收益是否值得牺牲合成节点容量 |

“块保持”指旧合成行、属性、文本、签名与旧旧边不被改写。它本身不保证归一化旧块、训练梯度或旧类分类性能不变。

## 2. 共同协议与证据边界

- 两图：Cora、Citeseer；顺序为 canonical、order19102；节点率为 1%、5%；阶段数为 3、5，共 16 个开发条件。
- 每条件 7 个主臂；各图 canonical/5%/3-stage 另有 9 个分量和存储对照。每阶段 student seeds 为 100--105。
- 正式计划为 502 份阶段 memory、3012 次 student fit。工程 smoke 的 48 次单 seed fit 单列，不混入主表。
- 所有等节点候选逐字段复用 C0 的 X、文本、mass、行顺序；总边 entry 数相同。k-center 是真实节点 coreset，独立标识，不称为合成方法。
- C0 使用增长节点预算、dispersion 类配额、类内 joint clustering、Mean-X、joint_g5_c320 拼接后 MiniLM 重编码、冻结追加；没有 response。
- Student 为两层 GCN，hidden/out=384，可训练文本投影，冻结 MiniLM，双向 InfoNCE；Adam lr=0.001，batch=min(16,rows)，steps=max(50,min(2048,16*rows))，每阶段从头训练。
- 等字节分支仍使用完整行数 C0 的 student steps；实际 batch 仍按其真实 rows 取 min(16,rows)。字节预算不是等节点预算，也不保证计算量相等。
- 主指标由冻结代码的 `metrics["all"]` 定义：全部类别 prompt 竞争下，已见目标节点上的 pooled report-dev Macro-F1；old/new 从同一个已见节点混淆矩阵按类汇总。不是 task-slice 指标。
- 冻结协议表中的“所有已见 prompt”措辞不准确：实际 runner、freeze.json 的 all-prompt 字段及上一轮共同指标均为全部类别 prompt。本报告澄清文字，不改动冻结源码或数字。最终阶段所有类已见，两种 prompt 范围相同。
- 构造可以使用合法 pool 的类别标签做分块；student 不用分类标签训练，选边不看 report-dev 标签。推理在真实全图上完成，属于 transductive 设置。
- 本轮不读取 test 标签；项目历史曾接触 test，不能称为全项目未污染的盲测。顺序和 seeds 也已用于开发，本轮不是独立确认。

## 3. 算法细节

### 3.1 联合核和度约束

原始核为 `K = 0.4 K_X + 0.3 K_T + 0.3 K_G`，各项为归一化表示的 Gram 矩阵。G 来源于当前 delta 合法诱导图上的局部传播摘要，不回读旧 raw nodes。X+T 分量归一化为 4/7 与 3/7。

原始版本按 K 从高到低选择固定数量的新块无向边，每新行再连接一个旧行，补反向 entry。度约束版本在选内部边时维护路径森林，禁止提前成环，最后闭环；跨边按固定新行顺序，选择仍有容量的最高核相似旧行，旧端点容量为 `ceil(new_rows/old_rows)`。

需要注意：当新块 n>=3、要求 n 条无向边且最大度为 2 时，该实现实际上得到覆盖所有新节点的一个环。这不只是温和地减少高度节点，而是很强的结构限制，可能强迫不相似节点相连。小块的可行边集也可能极少。

### 3.2 Coverage

在上述可行约束内，用 `K(i,j) - 0.15 * redundancy(i,j)` 排序。冗余定义为候选边与已选边在核空间中的中点余弦相似度，而不是恒为 1 的端点自相似。它是确定性启发式，没有分类收益或最优覆盖保证。

### 3.3 单向传播

采用矩阵行表示接收节点的约定。每个新行连接两个旧行，方向仅为“新接收旧”；不再反向传入旧行。这样与一个双向旧邻居具有相同的交叉 edge entry 数，但独特端点对更多、方向不同，不能说只改了一个方向开关。

其新块内部边与原始联合核严格相同。对当前 student 的归一化实现，有 `A_new[old,old] = A_old` 且 `A_new[old,new] = 0`，旧节点的输入消息精确不变。旧行不足 2 时明确拒绝，不偷偷改变边数。

### 3.4 漂移 gate

从同一份上一阶段候选 memory，分别构造联合核追加与 C0 追加。比较旧块归一化相对漂移和旧节点有效输入消息相对漂移；联合核任一项超过 C0 加 1e-8，即采用后者。它不访问 student F1，也不重新选择历史路径。

因此，回退得到的是“在本臂既有历史上做 C0 追加”，不一定等于从 stage0 起一直运行 C0。stage0 没有旧块，也不回退。

### 3.5 存储对照

FP16 仅改变持久图签名的 dtype，不把 student 的 X/T 改成半精度。sketch64 用固定 seed=20260920 的 Rademacher 投影，再归一化；投影配置元数据也计入字节。

Equal-byte 每阶段以 C0 的 tensor bytes + UTF-8 文本 bytes 为上限，额外计入签名与配置；从最大可用新增 rows 开始递减重建，直到首次满足上限。旧行不删，搜索重建成本完整计入。序列化文件大小另外报告，不能与 logical payload 混用。

## 5. 如何解释理论与实测

1. 正定核不等于优质 student 图。非负加权 Gram 具有 PSD 性质，但截取最高分边得到的稀疏无权邻接矩阵不继承分类性能保证。表示相似度、传播质量和 InfoNCE 训练后的类别 margin 是不同对象。
2. 保持算子不等于保持重新训练后的函数。固定参数 W 时，单向规则可以使旧节点多层表示不受新增节点输入影响；但本任务重新训练 W，且新文本引入新的负样本竞争，旧节点输出仍会改变。不能用静态算子不变推出旧类 F1 下界。
3. G 不是完全独立的新模态。它由 X/T 的局部图平滑生成，与 X/T 有相关性；加 G 可能只是重复强调平滑分量，而不一定补齐分类所需的关系。
4. 容量也有机会成本。签名若占用持久预算，等节点优势必须和等字节时损失的 rows 一起评价。未加入对应的 row-matched C0 拓扑控制时，等字节性能差不能全部归因于签名或某一种选边算法。
5. 相关性不是因果。上一轮 36 个条件中，最终新块内部度 Gini 与联合核增益相关系数为 -0.427，旧块归一化漂移为 -0.217。它们提出了诊断假设，不足以证明“消除 Gini/漂移即可提升 F1”。数据集、rate、阶段和新块大小均可能混杂。

## 6. 成本、验收与复现

本轮正式结果已经完成审计。远程结果包保留了每个 memory 的 `.pt` 文件；本地同步包包含审计 JSON、CSV 和阶段结果，但没有同步这些较大的序列化模型文件。为避免把缺失的 `.pt` 误报成完整本地复现，汇总工具默认仍严格要求序列化文件；本地复算使用显式的 `--allow-missing-serialized` 选项，仅将序列化字节字段置空，逻辑 payload 字节仍来自审计结果。
