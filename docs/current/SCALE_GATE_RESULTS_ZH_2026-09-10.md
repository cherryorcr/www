# 规模门槛 S 定位：扰动收益在池规模 2.7万→5.4万 之间由负转正

日期：2026-09-10
数据：服务器 `problem_validation_results/scale_gate_2026_09_10/`（本地镜像 `docs/current/scale_gate_2026_09_10/results.json`）
代码：`code/v2_llm_fusion/run_scale_gate.py`
动机：只有 Cora 2.7k（jitter 有害）与 arxiv 169k（jitter 有效）两个点，需要中间尺度定位门槛。做法：**对 arxiv 池做子采样**（同分布、同 40 类、同策略、同 rate=5%），隔离"规模"为唯一变量；teacher 在子采样后的真实诱导图上训练；评测始终用**同一份全量 dev**。

## 1. 结果

| 池规模 $n_{pool}$ | $k$ | amp=0.9 | amp=1.79 |
|---:|---:|---|---|
| 6,773 | 338 | +0.01 (3/5) | **−5.14 (0/5)** |
| 13,547 | 677 | +0.54 (4/5) | −1.34 (2/5) |
| 27,094 | 1,354 | **−0.60 (1/5)** | **−2.02 (0/5)** |
| 54,189 | 2,709 | **+1.17 (4/5)** | **+1.76 (4/5)** |

（括号内为 5 个 student seed 中扰动优于 frozen 的个数）

## 2. 三个结论

**结论 1：存在由负转正的转折，位置在 $n_{pool}\in(27\text{k},54\text{k})$。** 5.4 万池（k=2709）上两个幅度都显著为正（+1.17/+1.76，4/5），2.7 万池上两个幅度都为负（−0.60/−2.02）。**规模门槛 $S\approx 3\text{–}5\times10^4$ 条凝聚源**——论文可写为"约 4 万量级"。

**结论 2：幅度必须随规模标定。** amp=1.79 在 6.8k 池上崩掉 −5.14（0/5），在 13.5k 上 −1.34，在 135k 上 +1.97。**固定幅度在小池上从"过强"变成"破坏性"**。这与小图实验一致（Cora rel=2.0 → −8.15）。所以 η 不是常数，而是随规模增长的量——这与"池越大、簇均值越平滑、越需要扰动打破"的机制吻合。

**结论 3（必须谨慎表述）：曲线不单调，2.7 万点的负值不应过度解读。** 13.5k 微弱正（+0.54）、27k 负（−0.60）、54k 正（+1.17）——在 27k 处的回落在 3 个数据点（13.5k/27k/54k）上无法与噪声完全区分（该点 CI 上界刚好压 0）。稳妥的表述是："**5.4 万以上稳定为正；1.35 万以下不显著或为负；两者之间的 2.7 万点出现回落，其成因（子采样带来的类内冗余下降、诱导子图的度分布变化）未定，需要更多尺度点**。"

## 3. 机制解释（与类内冗余度一致）

子采样会**同时**降低类内文本冗余（每类节点数随 frac 线性下降）。这解释了两件事：

- 为什么小池上扰动有害：冗余低 → InfoNCE 的假负例污染本来就轻 → 簇均值 X 的"过度平滑"问题不存在 → 扰动只带来破坏；
- 为什么大池上扰动有益：冗余高 → 大量同类节点互相当负例 → 簇均值把这种冗余压得更平 → 需要扰动重新引入行间差异。

这与 arxiv 静态实验的既有结论**完全自洽**：Cora 上 compact 反超 raw（冗余低，凝聚是净化），arxiv 上 raw 反超 compact（冗余高，凝聚损失显性）。

## 4. v1.2 门槛的最终定义

```
若 n_pool < S（S ≈ 3–5万）:
    memory = construct(delta)                      # 纯构造式
否则:
    X ← X + η·R，η 随规模标定（n_pool≈5.4万 → 1.79；更大图需重标定）
    memory = {X, 文本/边/mass 不变}
```

**遗留**：η(规模) 的函数形式未定（只有 5.4 万与 13.5 万两点可用）；2.7 万点的回落未解释；全部为 arxiv 子采样，跨数据集泛化未验证。
