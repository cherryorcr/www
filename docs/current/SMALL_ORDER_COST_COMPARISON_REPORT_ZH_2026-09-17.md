# 冻结 v4 的小图扩展、基线比较与完整成本评估

日期：2026-09-17。范围：Cora / Citeseer，三种预先固定的类别顺序，5% 累计合法训练池节点预算。

状态：实验与独立产物验收完成。1404 次报告训练均已保存模型并复载核对；本报告区分实验完整性通过与方法优势是否成立，不把二者混为一谈。

## 1. 核心结论

**当前方法能用约 5% 的合成节点保留较多下游性能，但尚未证明稳定优于简单 coreset；response 的成本明显高于其已证实收益。**

| 三顺序平均，共同 student | Cora | Citeseer |
|---|---:|---:|
| v4 最终 Macro-F1 | 47.47 | 55.48 |
| 完整 pool、8192 步内选择检查点 | 52.20 | 55.41 |
| v4 最终性能保留率 | 90.93% | 100.13% |
| v4 阶段平均性能保留率 | 92.95% | 108.20% |
| 同 rows 的 k-center 最终 F1 | 49.40 | 57.73 |
| v4 相对 k-center 的最终差值 | -1.93 pp | -2.26 pp |
| v4 一次构造 + 一次三阶段 student 轨迹 | 264.55 s | 239.26 s |
| 完整 pool 长训的相应时间 | 55.30 s | 56.47 s |

结论分成四层：

1. **凝聚有效性有证据。** 最终只有 94/111 个合成节点；Citeseer 三个顺序均优于随机存储，并达到本轮完整数据长训平均水平。Cora 保留约九成性能，但最困难顺序仅保留 74.86%，不能只报平均。
2. **相对强简单基线的优势不成立。** 三顺序平均最终分数上，k-center 在两图均更高；Cora 的 kmeans-medoid 还达到 54.24。它们是评价基线，不改变主方法必须使用合成节点的约束。
3. **当前不是一次使用的计算加速方案。** response 占构造时间约 99%；包括构造后，v4 比完整数据长训慢约 4.78/4.24 倍。训练输入小不等于总训练流程便宜。
4. **下一步先解决可解释的差距。** 优先统一行枚举、诊断顺序敏感与选择可靠性并压缩 selector 成本，然后研究受控拓扑、预算与图条件文本；不立即扩到大图，也不增加一批无界搜索候选。

以上完整数据参考是相同 student、相同 InfoNCE 任务的有限长训参考，不是理论上限。原始顺序的旧结论与外部 TAG 比较保留在第 6 节，不与三顺序均值混写。

## 2. 本轮做了什么，没有做什么

本轮不升级方法，不补强 TAGSAM，不重新检查或搜索 STAD，不训练官方 GraphCLIP，也不启动大图。当前 v4 的构造、文本、选择器、student 和超参数冻结，只改变预先登记的类别到达顺序，重新构造相应记忆。

新增确认包括两数据集、三个类别顺序、13 个方法、三个阶段、六个报告 student seeds，共 1404 次报告训练；v4 的候选选择训练另计。每个报告模型均保存检查点并复载重算指标，另行重建合成记忆、检查源节点权限和历史冻结。原始顺序用于回归，两个额外顺序用于初步稳健性检查，不是增加了两个独立数据集。

这次“扩展小图”具体指多顺序确认，**不包括** 1%/10% 压缩率扫描、更多构造随机种子或长阶段实验。TAGSAM/STAD 仅保留此前原始顺序结果，不能混写成也完成了三顺序重跑。

## 3. 通俗地理解当前方法

可以把不断到来的原图看作分批到达的教材。v4 每批制作一小份新的“合成教材”，与旧教材一起保存；每个阶段都找一个全新的学生，仅用这份小教材学习，再去真实图上完成节点分类。完整数据参考则让同一个学生读截至当前阶段的全部合法原始教材。

具体流程：

1. 按累计合法训练节点数计算总额度 `K_t=floor(0.05*N_t)`，新增额度为总额度减旧记忆行数。当前主线不默认剪掉旧合成节点。
2. 当前批次按类划分，用类别大小平方根与离散度形成配额，在图文联合空间内聚类。类别标签可参与构造，因此不是全流程无标签。
3. 每个簇生成一个新的合成节点，属性取簇均值，不把某个真实节点直接当凝聚节点。
4. 每簇至多取五篇代表文本，在总计约 320 **字符**的额度内拼接，再由冻结 MiniLM 重编码。旧文本及其表示保持不变。
5. 保留旧行和旧旧边，构造新块内部语义边与受控跨块边，cross-degree=1。旧边不变不意味着归一化传播完全不变。
6. 在相同新增总额度内尝试少量类间配额转移。用独立 selector seeds300..302、batch8/16/32、多训练长度、风险代理和最差长度检查决定是否接受；否则回退到 dispersion。当前不启用额外预算 reserve。
7. 在累计合成图上从头训练 GCN 图文 student，再用类别 prompt 在真实全图上分类。

dispersion 与 v4 的设计区别主要在第 6 步：dispersion 直接采用先验配额，v4 额外花训练成本判断是否应转移配额。“安全回退”是算法规则，不是对任何数据集都不退化的统计保证。

实现审查还发现：普通 dispersion 按传入的阶段类别列表拼接类块，v4 显式配额构造按类别 ID 排序；原始顺序下二者相同，新增随机顺序下未必相同。固定 seed 的 minibatch 对行排列敏感，语义边的并列处理也可能受影响。本轮保留两种现有实现，不事后改主方法；因此新增顺序的 v4-versus-dispersion 是**完整配置比较**，不是纯粹“打开 response”的消融。后续 P3 必须固定类块和节点枚举后再判断 selector 的独立贡献。

## 4. 如何保证比较回答的是凝聚效果

### 4.1 相同学生和任务

共同 student 为两层 GCN，hidden/output384；冻结 MiniLM384 文本编码器、可训练文本投影；双向图文 InfoNCE，Adam0.001，batch16，报告 seeds100..105。普通臂每阶段步数为 `max(50,min(2048,16*K_t))`，从头训练；微调臂才继承上一阶段模型，重置 Adam 后只训练新数据。

所谓“完整 TAG 训练同一个 student”，是完整累计合法 pool 的节点属性、文本表示与诱导真实边参与训练。每一步在完整训练支持图上做图传播，从其中抽取 16 个节点形成图文对比损失。不是只用类别名训练，也不是监督分类交叉熵；完整数据参考不包含 selector/report/test 节点作为训练样本。

长训参考每阶段训练 8192 个 optimizer steps，每 512 步用 selector-dev 选择检查点，然后在 report-dev 上报告。它是有限训练预算内的经验参考，不是理论上限或已证明收敛的理想最优模型。

### 4.2 指标和权限

- Macro-F1 是节点分类指标：先计算每类 F1，再对当前评价的已见类别等权平均。它不是训练时 InfoNCE 的数值，也不是图文检索分数。
- 主指标在全部类别 prompt 竞争下计算累计已见节点得分；seen-only prompt 指标作为补充。最终所有类别已见，两种口径相同。
- 最终性能保留率 = 方法最终 F1 均值 / 本轮完整数据长训所选检查点 F1 均值。阶段平均保留率则用两个阶段平均 F1 相除。跨顺序先平均各顺序六种子的得分，再作比值。
- 保留率不是信息保留百分数，也不是预测一致率。超过 100% 仅表示超过当前经验参考，不能解释为超过理想模型。
- 原始素材限于 pool；构造允许 pool 标签，选择使用独立 selector-dev，report-dev 不参与这轮候选选择。本轮不评价 test 标签，但项目历史有 test 接触，不能宣称完全未触碰的盲测。
- 推理使用真实全图，属于 transductive。历史数据不可回读的约束针对凝聚构造器，**不是整个系统部署推理时不再需要原图**。

### 4.3 各基线究竟比较什么

| 方法 | 做法 | 原始历史访问 / 旧记忆改写 | 回答的问题 |
|---|---|---|---|
| v4 | 合成追加 + 保守 response 配额转移 | 不回读 / 不改写旧行与旧旧边 | 当前完整主方法能否用少量合成记忆保留任务效用 |
| dispersion | 同类合成追加，不作 response 配额搜索 | 不回读 / 不改写 | 额外筛选成本是否值得 |
| random_real | 从当前新数据随机选真实节点并追加 | 不回读 / 保留旧节点 | 是否比随便保留少量样本好 |
| k-center | 几何覆盖选点并追加 | 不回读 / 保留旧节点 | 是否比简单覆盖有优势 |
| k_center_class | 按类进行覆盖选点并追加 | 不回读 / 保留旧节点 | 优势是否只是因为构造知道类别 |
| herding | 按均值代表性选择真实样本 | 不回读 / 保留旧节点 | 合成簇均值是否比真实代表点有价值 |
| kmeans_medoid | 聚类后选择真实中心样本 | 不回读 / 保留旧节点 | 合成节点与真实中心节点的差异 |
| recluster | 旧合成记忆与新原始数据联合再聚类 | 不回读 / 可改写旧记忆 | 不冻结旧记忆的启发式方案表现如何 |
| full_history_syn | 每阶段用全部已见原始 pool 重凝聚 | 可回读 / 可全部改写 | 当前启发式全历史构造参照 |
| raw_equal | 完整累计 pool，从头训练，等 optimizer 步数 | 可回读 / 无凝聚 | 同训练步数下压缩后的效用 |
| raw_long | 完整累计 pool，8192 步内选检查点 | 可回读 / 无凝聚 | 本轮性能保留率的经验分母 |
| raw_finetune | 第零阶段完整数据训练，之后只用当前 delta 微调 | 后续不回读 / 继承模型参数 | 用模型参数代替记忆回放是否足够 |
| v4_init_finetune | 第零阶段 v4 初始化，之后只用 delta 微调 | 后续不回读 / 继承模型参数 | 好的初始合成图能否替代后续记忆 |

真实节点基线采用同一语义追加拓扑，不是原图诱导边。这控制了一部分边规则差异，但并非每种 coreset 在所有可能拓扑下的最优版本。重凝聚臂与 v4 还存在分配、文本和拓扑重建等差异，不是仅放开历史读取权限的严格单因素因果实验。

Cora 的平均新类差距仍突出：v4 比完整数据低 8.34 pp，比 k-center 低 5.73 pp；但不能再将问题概括成“只缺新类塑性”。Cora 1702 中 v4 旧类为 36.11，完整数据为 44.89，旧类也低 8.78 pp；其新类为 45.12，对照为 64.74。Citeseer 新顺序则同时出现保持与塑性不足，应先做单阶段同起点诊断。

选择记录显示，18 个构造阶段中只有 5 个阶段最终改变了 dispersion 先验配额，每次净移动 1 row；其余 13 个阶段最终配额不变。改变发生在 Cora 1702 的前两阶段、Citeseer canonical 的第二阶段、1701 的第三阶段、1702 的第二阶段。

v4 相对 dispersion 的最终平均差值为 Cora -0.42 pp、Citeseer +1.17 pp。**不能据此宣称 selector 单独贡献了这些差值：** Cora 1701 的三个阶段配额都没变，最终仍出现 +1.14 pp 差值，体现了第 3 节所述类块排列及后续拓扑路径的实现混杂。该配置比较有报告价值，但 selector 贡献必须在统一枚举后重做严格控制。

v4 的最终训练输入逻辑字节约为完整 pool 的 4.17%/4.16%，即约 24 倍压缩。两个数据集所有 student 的 `state_dict` tensor payload 均为 1774084 bytes，约 1.69 MiB；模型权重没有因训练图缩小而一起消失。

这是 PyTorch `max_memory_allocated`，包含当时仍驻留的共享编码器/图数据，不是进程全部显存、reserved 显存或该方法单独增量；也不等于部署内存。微调链的初始化构造峰值不在其单独区间字段中，故这里不列微调显存作严格比较。

共享数据/模型加载为 Cora 1.23 s、Citeseer 1.20 s；合法 pool 文本编码为 0.85/1.07 s，均使用已有本地模型、热 kernel。上游数据文件中已有特征的预计算成本不在本轮测量中；启动暖机、prompt 编码及评价图归一化也没有单独完整计时，因此表中“合计”是**明确边界的实测小计**，不是从下载原始数据开始的全生命周期耗时。

成本口径：构造完整计一次；学生训练以六个报告种子的平均估计一次三阶段轨迹，不能把 v4 构造成本除以六来得到好看的加速比。共享 encoder 加载和合法 pool 文本编码单列。一次部署成本不包含本研究独立复载审计、诊断复跑、暂停恢复和所有开发试错。

微调初始化的 stage0 构造已补计，但少量依赖保存/包装开销没有单独计入，因此其总耗时为近似值。`raw_long` 训练时间包含训练中 selector 检查点评估，不等同纯 optimizer FLOPs。两张同型号 GPU 分别运行两个数据集，CPU/主机仍共享，本轮不是跨硬件性能基准。

逻辑 payload 为保存的全部 tensor 字段和 UTF-8 文本字节，未含解释器、序列化或模型权重。微调臂最后阶段输入是当前 delta，不是其永久 replay memory；跨阶段保存的模型参数必须另作理解。由于真实全图仍用于推理，这张训练输入表也不是部署系统的总存储占用。

若将相同合成记忆用于多个独立 student，构造成本可以摊销。可按 `T(n)=T_build+n*T_student` 估算何时收回构造成本，但必须标为固定记忆重复使用的情景计算，不能将研究中的六种子直接包装成一次部署的免费收益。

以表中含报告/保存的一次轨迹成本估算，相对每次都运行 raw_long，固定三阶段记忆复用约需 Cora 6 次、Citeseer 5 次才达到时间交点。该情景没有校正二者性能差距，也没有实测任意多次复用；它不证明更换模型或部署任务仍可获得相同结果。相对已经很便宜的 raw_equal，没有当前已验证的实用摊销优势。

## 8. 方法评价与后续优先级

### 8.1 对当前方法的评价

**保留合成追加作为研究对象，但暂不把昂贵 response 当成已成立的核心增益。** v4 仍是冻结比较版本，不能事后把较好的 dispersion 或 coreset 分数换成“当前主方法”；后续实验应将 dispersion 作为低成本合成控制、k-center/medoid 作为强效果参照。

当前可以支持的贡献是：受历史原始数据不可回读约束的合成图文追加流程；保留旧行/旧旧边的可审计实现；约 5% 节点下的可重训任务效用；以及选择排序、预算和文本机制的失效边界。只有本地工程与这组实验还不能确立文献层面的算法新颖性，更不能宣称 SOTA、普遍超过完整数据或总计算高效。

这轮对后续方向有三项具体影响：

1. Cora 1702 与 Citeseer 两个新顺序应作为**已知失败诊断条件**。可以在这些条件上解释机制，但调优后的正式确认必须另留预注册顺序/seed group，不能把开发后再测同一条件当独立泛化。
2. P3 必须先于 response-gain extra budget：当前收益判断还没有证明能稳定胜过低成本构造，直接让其控制总预算会同时放大选择误差与计算成本。
3. P2 不因当前 concat 简单就盲目替换。新增图条件注意力应检验“选出的文本是否改善共同 student”，并计入新增选择成本；不是再次比较文本数量或追求更像摘要的文字。

### 8.2 分阶段推进

建议顺序为 **比较控制 -> P3 选择可靠性与成本 -> P3-B 受控拓扑 -> P1/P2 单项候选 -> P4/P5 扩展验收**。本报告完成这些方向的设计与排序，不表示已执行下一轮模块优化。外部 TAGSAM/STAD 补强仍按用户决定暂停，大图仍需下一次小图验收后再决定。

后续每项均是候选任务，不是本轮新增的已验证模块：

| 阶段 | 怎么做 | 要回答的问题 |
|---|---|---|
| P0/P3 的比较控制 | 固定类块和节点枚举；单独评估 GPU 重复训练数值变化；新基准改动须给全部对照共同使用 | 差值是否只是行排列、训练随机性或实现口径所致 |
| P3 选择成本与可靠性 | 先验证复用训练前缀、读取多长度检查点的数值等价；再用有限候选、独立 seed group 检查选择后 regret、回退率和成本 | response 的少量增益是否可靠，是否值得额外计算 |
| P3-B 拓扑诊断 | 固定特征、文本、rows 和 row order，比较当前跨边、无跨边、同边数随机端点、质量筛选；测归一化旧块漂移 | 新旧交互改善塑性，还是扰动了历史传播 |
| P1 预算回访 | 先做固定总新增 rows 的类内复杂度/边际调配，再做 extra budget；后者须匹配增加 rows 的对照和等 student 步数控制 | 改善来自更聪明的分配，还是仅仅更多数据/更多更新 |
| P2 图条件文本 | 固定 token 和其它输入，比较片段选择后重编码与集合表示，保留 text-only、属性-only、打乱图条件控制 | 图信息是否能选出比单纯代表性拼接更有用的文本 |
| P4/P5 后续验收 | 有证据再做有界 refresh/merge；补 rate 与更多顺序，小图审核后再决定大图 base+4 | 局部改进能否在预算、历史保持和更长任务链上成立 |

多长度轨迹复用只有在 seed、优化器、minibatch 序列、学习率调度相同，且中间评估不改变训练状态/RNG 时才等价，不能直接假定“共享前缀”零风险。若改变图传播算子或训练数值协议，应单列新的共同 student 条件，不能只给 v4 改模型后与旧基线拼表。

注意力优化已形成[单独计划](P2_GRAPH_CONDITIONED_ATTENTION_FOLLOWUP_ZH_2026-09-17.md)，没有在本轮加入或得到性能验证。优先候选是以当前合成簇的属性与合法邻域摘要为 query、源文本片段为 keys，在固定 token 预算下选取有用且不重复的片段，拼接后仍经冻结 MiniLM 重编码。之后才考虑直接 attention pooling 或有界残差集合表示。

必须比较同 token concat、mean、已有 text-only attention、attribute-only query、真实图条件、打乱图条件；固定源簇、合成 X、rows、edges 和 student。普通文本 attention/DeepSets 此前已测且未晋升，不能换名称当作新实验证据。新增可训练参数、片段编码与选择成本都应计入，旧文本表示仍冻结，防止跨阶段表示空间漂移。

### 9.4 结论边界

三顺序只支持有限稳健性判断；跨顺序标准差为三个顺序均值的描述性离散度，不是18次独立实验的置信区间。同一 report-dev 多次用于项目开发，不能消除开发过拟合。新顺序改变早期类别、pool 大小、累计 rows 和训练步数，因此测试的是固定压缩率协议在不同到达顺序下的表现，不是所有中间量完全相同的纯类别顺序干预。

所谓历史任务 forgetting 为过去任务最佳得分与最终得分之差；主方法每阶段重新初始化 student，因此该指标同时包含记忆质量、类别竞争及支持集变化的影响，不能直接理解成同一网络权重被新任务覆盖。
