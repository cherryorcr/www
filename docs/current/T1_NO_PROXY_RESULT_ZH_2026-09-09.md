# T1 免训练预测器验证：全部候选失效——"无代理可用"定理式观察

日期：2026-09-09
数据：服务器 `problem_validation_results/t1_predictor_validation.json`
设置：11 个已保存 artifact（v2×4、v3×4、headroom×3，同协议同预算同 k），已知 dev F1（41.0–54.2，跨度 13pp），5 个候选免训练预测器，Spearman/Pearson 相关。

## 1. 结果：没有任何一个 embedding 级统计量预测 F1

| 预测器 | 含义 | Spearman | p |
|---|---|---:|---:|
| shift_nn | 合成文本emb到真实文本流形的最近邻距离（分布同构假说） | −0.09 | 0.79 |
| shift_mmd | RBF-MMD²（分布同构假说） | −0.14 | 0.69 |
| cover_mean | 真实文本被合成文本覆盖的平均距离（覆盖假说） | +0.14 | 0.69 |
| cover_max | 覆盖半径 | −0.25 | 0.47 |
| pair_cos | 自判别性（v3已证伪的对照） | −0.05 | 0.89 |
| rank组合 | shift+cover 秩和 | +0.06 | 0.85 |

11 个点、13pp 的 F1 跨度、5 个理论动机充分的候选——**全部相关性≈0**。

## 2. 这次被证伪的是我自己的假说

v3 文档中提出的机制解释（"拼接赢在与真实文本分布同构"）在可测量的 embedding 统计层面**不成立**：v1_concat_320 的 shift_nn（0.265）并不比失败的 LLM 变体更低（llm_100w 是 0.261，更"同构"却低 6pp）；oracle 与 kmeans_multi 的所有统计量几乎相同，F1 差 12.8。

## 3. 定律的最终形态：可重训性没有可用代理

把 T1 与此前全部失败合并，出现一个更深的统一解释：

> **在这个问题里，可重训性（独立 student 从头训练后的表现）不存在任何一阶/二阶 embedding 统计量的代理**——判别性、分布距离、覆盖度、类纯度、几何惯性全部与它无关（11 artifacts × 5 predictors，全部 |ρ|<0.25 n.s.；另有 oracle 纯度 100% 无效、best_of_n 判别性最优反而最差两个构造性反例）。
>
> **这正是所有可学习组件系统性失败的结构性原因**：任何优化都需要一个可微/可评估的代理目标，而所有可及的代理都与真实目标（可重训性）不相关——所以"优化什么都没用"不是巧合，是必然。唯一可靠的评估是完整的 student 重训，唯一稳健的构造是不依赖任何代理的直接统计构造。

这把论文的核心 claim 从"我们发现简单方法更好"升级为"**我们给出了'为什么该问题中学习必然失败'的代理不可用性论证**"——五组件证伪是它的实验主体，T1 是它的量化收口。

## 4. 对 T2/T3 补强计划的修订

- **T2 理论包（降格重写）**：maxmin=Gonzalez 2-近似、拼接零分布迁移仍是事实，可保留为"组件性质"陈述；但"覆盖半径→分类误差"的桥接被 T1 数据反对（cover 与 F1 无关），**不能作为定理主张**，否则自相矛盾。理论章节改写为：组件最优性质（覆盖/同构）+ 代理不可用性的实证命题；
- **T3 覆盖引导预算分配（保留但重定目标）**：它的依据不是覆盖代理（已失效），而是预算消融中实测的保持-塑性前沿（±6pp 真实存在）。改为纯实验驱动：直接扫描每数据集的分配曲线并报告前沿，"c 规则"作为工程默认值——不再声称有覆盖理论背书；
- **T1 自身进论文**：作为"评估图凝聚质量必须重训 student、无廉价代理"的首个系统证据（该观察对整个图凝聚社区的评估实践有直接含义）。

## 5. 边界

- n=11、单数据集、单文本塔；预测器限于一阶/二阶 embedding 统计（未测：X-text 配对结构统计、GCN 传播后的联合统计——记为 future work 但预期同样受限于小样本功效）；
- "无代理"是实证命题不是不可能性定理；更强的表述需要更多 artifact 点位与第二数据集。
