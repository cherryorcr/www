# TGC-R4 结果复核：门槛、失败原因与后续算法方向

日期：2026-09-23。状态：基于已有封存结果的复核与研究建议；本次没有运行新的训练，没有修改冻结协议、候选或分数，也没有晋升新主方法。

## 1. 判断

应继续研究学习型持续 TAG 凝聚。C0 适合作为低成本初始化和固定对照，不必被预先指定为最终投稿算法。当前不应在“所有组件都必须超过 C0”与“只能写 C0”之间二选一。

两件事需要分开：

- 对本轮主候选 relation_new，不是仅仅门槛太严：最终平均 -0.040 pp、相对匹配 random -0.341 pp，目前没有值得部署的效果证据。
- 对整个 TGC 方向，之前的解释过于二元化：relation_old 的最终 +1.224 pp、新类 +1.749 pp 是值得继续研究的信号。它没有预注册为主候选，且缺少匹配的旧行随机对照，因此应新立假设验证，不能直接换到主表里，也不应说它已经被否定。

WWW 长论文不要求每个数据集、顺序和 seed 都获胜。可以有清楚的适用条件、接近完整历史访问方法的效用、显著更少的持久存储，或可靠的新旧平衡。但这些必须是同协议、强对照、独立确认后的结论。新问题定义本身，以及给既有 teacher/student 优化换名称，都不能单独保证算法贡献。

## 4. 为什么修改了很多组件仍没有稳定提高

### 4.1 对齐了训练实现，但没有对齐最终学习目标

R4 确实修好了 functional Adam 与正式 CUDA foreach Adam 的路径差异。然而数值一致回答的是“是否在算预期的梯度”，不回答“该梯度是否能改善最终任务”。

R4 优化 32-step scratch student 的关系；本轮增量阶段正式训练是 1008/1024/1328/1504/1776 步。当前超梯度主要作用于早期优化轨迹。更早记住实例匹配，不必然使训练完成后的分类更好。R2B2 的中期短 suffix 曾有正信号，R3 换条件后未复现，所以“把 horizon 调长”也还不是经过证明的修复。

### 4.2 teacher 可拟合，不等于 teacher 提供有用的凝聚目标

direct-distillation KL 从约 3 降到 0.16--0.47，只说明同架构模型能模仿固定支持集上的关系。teacher 训练与 probe 共用支持图，所谓 query validation 不是 teacher 未见图。

外层匹配的是图节点与节点文本的实例关系；正式任务是图节点与类别 prompt 的分类 Macro-F1。实例检索接近 100% 也可能依赖局部细节，不能替代类别语义迁移证据。R4 目前没有相同报告输入上的 teacher 分类、直接蒸馏模型分类及 canonical 长训模型三者对照，因此“teacher 目标对任务有用”这一环节仍未闭环。

teacher 分数高不是蒸馏收益的充分条件，分数低也不在理论上排除正则化收益；它是优先诊断项，不是用一个数值自动否定整个方向的判据。报告标签只用于封存后开发诊断，不可接入 teacher、修订或线上 gate。

### 4.3 保持旧响应可能限制适应，但不能直接归因为约束过强

new-only 名义相对半径 0.1，实际最终缩放为 0.125--0.5，相当于最大约 1.25%--5% 位移；平均约 2.81%。16 步中约 15 步旧 KL 超限，说明当前优化大部分在可行边界外试探，再通过末端缩小整段位移满足约束。

旧目标是 C0 的 32-step 响应，并不是历史原始分布上的最优响应。限制全部旧 query 的关系变化，可能同时限制有益适应。但 free 臂最终仅 +0.087 pp，旧类最差 -2.209 pp，说明单纯取消保护也没有解决问题。

更值得验证的是“更新方向是否与保持约束冲突”，而不是继续扩大半径网格。只有测到可重复的梯度冲突和可行方向收益，才有依据采用约束优化或 trust-region 修改；不能仅凭 active rate 给复杂优化器立贡献。

### 4.4 可编辑范围与实际幅度混在了一起

old-only 修改 2--8 行，平均有效缩放 0.9375；new-only 修改 28--42 行，平均缩放 0.28125。两者参数数目、历史位置、图文来源和有效位移都不同。因此 old-only 较好不等于“旧行必定比新行更重要”，也可能是低维优化或不同扰动幅度的结果。

joint 已测，最终 +0.176 pp，没有复现 old-only 的 +1.224 pp。组件收益不可相加。需要匹配编辑行数/逐行位移的控制，再决定是否设计新旧协同修订。

### 4.5 C0 不是零信息的弱起点

C0 已包含类别规模/离散度配额、联合聚类、图文共享来源、文本重新编码、跨阶段构图。一个新模块要在这个完整系统上产生额外价值，而非只证明自己能降低某种损失。

此前 mean-X、文本注意力、预算和拓扑的受控实验没有找到单一普适瓶颈。它们支持“先证明改动针对了真实错误”，不支持“均值最优”“学习方法无效”或“小图天然不适用学习”。两小图是否掩盖规模优势仍是未检验假设，不能由失败本身推出。

## 5. 门槛应该怎么用

原 R4 的最终 +0.5 pp、最差 -2 pp 等是工程推进条件，不是统计显著性定义或 WWW 录用标准。原主候选决定不变，也不因已看到结果而修改阈值。

下一轮要分开三种决定：

| 决定 | 应依据什么 |
|---|---|
| 是否值得做一个小型新实验 | 有机制动机和局部信号即可；relation_old 已足够，不必先证明普适优势 |
| 是否进入递归/扩大规模 | 新条件复验、匹配随机控制、完整 student；以收益/风险和绝对成本共同判断 |
| 是否作为论文核心算法 | 独立确认、真实递归持续流程、强基线、任务与适用范围、各阶段表现和总体成本 |

指标也要跟论文主张对应：若主张持续全过程更好，阶段平均必须重点报告；若主张最终知识积累更好，可以以最终性能为主，但不能隐去早期代价。非劣效界限必须在新数据开跑前说明理由，区间跨零不是等价或无效证明。多顺序和多 seeds 用于刻画不确定性，不能替代新数据集。

## 6. 建议的最小下一轮

### A. 优先确认 R4 的 old-only 信号

先做窄实验，不再同时加入新文本、预算或拓扑模块：

1. 固定原 relation_old 配方和旧 editable mask 规则；同预算 C0 作为初始化/对照。
2. 加上 old-only matched-random：修改同一批旧行，每行位移范数匹配实际候选。现有 random_new 不能代替。
3. 加上 old-only shuffled-target，判断真实 teacher 关系相较错误对应是否有价值；若实际位移不同，另报告该差异，不能只将 F1 差异归于 teacher 语义。
4. 使用保留顺序和独立 construction/report seed group；开跑前再次核对实际类别分组的历史重合。保留的名字是 order19441/order19442，但名字新不代表条件新。
5. 同时报告 s1、s2 和配对阶段均值。s1/s2 仍可先共享父记忆做归因，但不得称为完整持续算法。

该轮是针对事后信号设立的新假设，不是补写 R4 的预注册。先判断是否存在方向特有且能复现的候选收益，再设计 selector。不能从 R4 的均值按阶段手工切换臂。

### B. 检查 teacher 目标和训练响应的有效区间

在开发诊断中补 teacher、合法支持集上直接蒸馏的 student、C0 student 的同输入分类评价，明确模型训练预算不同，仅用于目标诊断。对现有候选读取完整 scratch 训练轨迹的早/中/后 checkpoint，记录关系误差、类别 prompt margin 和正式分类指标。

主要分辨：目标本身没有任务价值、早期方向后来失效、还是某些阶段的历史约束阻碍改进。margin/分类指标只作离线分析，不进入无标签构造规则。若 teacher 没有显示可迁移信号，不继续大规模扫描同一个 KL 目标；若有信号而候选传不过去，再改合成优化路径。

### C. 若需重设目标，优先检验训练更新匹配

这是尚未实现、尚未验证的候选，不直接命名为已经成立的下一版本。目标是让合成图给 student 的学习更新接近“旧合成记忆 + 当前真实新图”给出的合法更新，而非只在第 32 步拟合某个 teacher 的终点关系。

设合法支持为 U_t，candidate 为 M_t，z_h 包含 student 参数、Adam 一二阶状态和 step。对同一 z_h，分别在 U_t 和 M_t 上执行 q 个更新，得到参数变化 d_ref 和 d_syn。候选目标可写为：

\[
L_{update}=\mathbb E_{h,s,\xi}
\sum_{\ell}
\frac{\|d^{syn}_{h,s,\xi,\ell}-\operatorname{stopgrad}(d^{ref}_{h,s,\xi,\ell})\|_2^2}
{\|d^{ref}_{h,s,\xi,\ell}\|_2^2+\epsilon_\ell}.
\]

实现约束：

- U_t 只含旧 synthetic memory 和当前 raw delta；不能回读历史 raw，也不能冒称全历史 expert。
- 两条更新从相同参数、Adam state 和 step 出发；optimizer、batch=16 和学习率沿用共同 student。支持集与 memory 节点数不同，采样分布/负例集合须单列，不能声称天然等价。
- h 取事前固定的早期/中期位置并覆盖多个初始化，记录逐层方向和幅度，避免只匹配梯度角度或一层的大范数。
- 每轮 outer 重算 candidate 自己的训练前缀；若将前缀 detach，明确这是截断目标，不能称完整长程 hypergradient。不得重用固定 C0 前缀却说已对齐候选全过程。
- 先仅修改有限 synthetic X，旧、新编辑控制分别检验。文本、rows 和正式 topology 保持比较一致；可行性保护仍需独立测量，不能用梯度匹配值取代历史效果验收。
- 最终从头训练全部 canonical steps，并与等位移 random、原关系目标比较。只有完整 student 改善才算成功。

与历史 v7-A 的区别：v7-A 测的是候选梯度离 C0 梯度有多远，并将其作为选择惩罚；这里拟合的是合法支持数据产生的训练更新，并对合成值求优化。与 R2B2 的区别：不固定 C0 前缀后只优化一个新端 loss；状态随候选重算，并明确 Adam 更新与合法参考的对应。

梯度/轨迹匹配本身是既有凝聚思路，不构成本项目天然的新颖性。潜在研究点在于混合原始/压缩支持下的传播一致性、可适应历史合成状态与保持约束的兼容方式；是否超出既有方法，要依文献比较、关键对照和结果判断。

## 7. 完整算法如何组织

最终可以是一套完整持续算法：

```text
旧 synthetic memory + 当前合法 delta
    -> C0 的预算、联合来源簇、synthetic X/text 初始化
    -> 临时合法支持图与共享 student 训练状态
    -> 经验证的关系修订或训练更新匹配
    -> 有界历史修订与可审计的预算/表示保持
    -> 输出 synthetic TAG，下一阶段只读取该 memory
    -> 任意报告 seed 从头训练共同 student
```

其中 C0 只是初始化。学习步骤若能稳定改善凝聚效用，就可以是完整算法的核心；无需同时重新发明预算、文本、拓扑。反之，若只是加入教师、约束和双层优化而没有独特可复验收益，复杂性本身不能补足创新。

论文核心结论应来自真实递归路径和强共同基线。不能将不同 cell 上各自最优的模块拼成“最终方法”，也不能将无限增加开发实验后选出的结果称独立确认。

## 8. 当前行动建议与证据

优先级为 A（old-only 匹配控制及新条件复验）和 B（teacher/训练阶段诊断），再依据证据决定 C（更新匹配）。C0 保留为固定参照，尚不定稿为最终投稿算法。原 R4 主候选不扩大运行；新的、有不同检验问题的小实验无需先满足论文主方法的全部条件。

本次交付是结果解释纠错和研究路线，不包含新训练。
