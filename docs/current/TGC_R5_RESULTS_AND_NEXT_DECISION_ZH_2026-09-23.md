# TGC-R5 最小实验结果与下一步决策

本轮四项最小任务已完成：old-only 独立确认、共享分配内容/拓扑析因、递归有界维护、固定总新增 rows 的容量调配。共 **792 个正式结果槽位、552 次实际完整 student 训练、552 个不同 checkpoint 重载**，8 个 cell 审计全部通过；另有 40 份匹配对照/来源产物审计和 56 条材料化诊断。这里的 R5 是 TGC 实验轮次，不是此前 v5 算法或论文主方法升级。

**结论：原 relation_old 的独立信号未复现；新共享分配的内容与拓扑出现正交互，递归联合版本平均提高 1.20 pp，但顺序依赖明显。值得围绕联合构造继续研究，尚不能定稿为稳定优于 C0 的方法。** 旧节点关系修订和配额转移叠加后均降低了当前递归版本的平均表现，暂不作为默认组件。

## 2. 协议与方法

所有正式 student 都使用共同两层 GCN、冻结 MiniLM 输入和可训练文本投影、双向图文 InfoNCE，batch=16、Adam lr=0.001、steps=max(50,min(2048,16K))，从头训练。memory 为累计合法池节点数的 5%；每阶段各臂 rows、完整训练步数相同，联合轮各臂边数也相同。

报告主指标是 **report-dev 上、全部类别 prompt 竞争下、当前已见节点的 pooled Macro-F1（百分数）**。不是测试集分数或监督分类训练准确率。旧/新是相应节点切片，不应直接等权相加代替总体 Macro-F1。下游评价使用共同全图 transductive 输入；构造及 teacher 只收到旧 synthetic memory 和当前 raw delta。

当前池类别标签用于 C0 初始化和分配 mask，report/test 标签不参与构造、teacher 或候选选择。离线 loader 仍加载完整数据 fixture，因此访问保证是逻辑切片和审计，不是操作系统物理隔离，也不属于完全无标签凝聚。

- 独立确认：order19441/order19442，report seeds=120..125；teacher 8200/8201，inner 8300/8301，validation 8310/8311，probe 8290。开跑前检查本地 176 份历史 manifest，未找到同分组；这个范围不覆盖缺失历史文件。
- 联合开发：order19341/order19342，report seeds=100..105；teacher 8400/8401，维护 inner 8500/8501、validation 8510/8511。沿用开发条件，不能称为独立确认。
- 两轮分别隔离快照，所有 memory 先生成并封存，再统一正式评分；本轮看到分数后没有修改构造常数或挑选报告子集。

联合机制不是三个独立 teacher 打分模块。先在合法支持集训练两个 teacher，将其图与文本表示拼成共享表示 H；学习来源分配 P，最小化表示重构、邻域传播压缩、初始分配 KL 和质量漂移。旧行映射为单位矩阵，新行使用同一个 P 生成加权合成 X、片段文本和投影拓扑。输出文本仍为至多 5 个来源、320 字符拼接后重新编码；拓扑最终为二值对称边。详细目标、常数和流程见[执行协议](TGC_R5_EXECUTION_PROTOCOL_ZH_2026-09-23.md)。

这是 teacher 空间的可学习压缩目标，**不是完整 student 训练的精确超梯度**。容量调配用重构+传播误差选择，不是 student marginal gain，也未增加总预算。旧边冻结是本轮的归因选择，不是用户强制约束。

### 4.1 正交互确实出现，但不等于普遍胜出

交互定义为 joint − content − topology + C0，固定条件和 seed 配对计算。最终四条件分别 **+1.71、+6.59、+2.54、+0.37 pp**，均值 **+2.80 pp**；s1 均值 +0.99 pp。仅 Cora/19342 的单 cell 六 seed 区间未跨零，其余跨零，未做多重比较校正。

这支持继续检验“内容与传播图必须协同构造”，反对只因两个单项最终为负就拒绝联合实验。但 Citeseer 的 joint 仍低于 C0：正交互可以只是减轻单项失配，不能自动解释成净正收益。

### 4.2 真正瓶颈转向递归稳定性

recursive 最终相对 C0 的四个差值为 **+8.21、-3.11、+1.03、-1.31 pp**；Cora 两顺序平均 +2.55，Citeseer 两顺序平均 -0.14。四条件描述性区间为 [-6.70,+9.11]，不支持稳定跨顺序优势。仅作敏感性说明：去掉 +8.21 的条件，其余三条件均值约 -1.13；不能因此删掉该条件重新报告。

同一 Cora/19342，shared-parent joint 为 +4.66，而递归为 -3.11。递归相对 shared 的配对差是 -7.77，六 seed 区间 [-12.30,-3.24]。相反 Cora/19341 递归相对 shared 提高 +6.83，区间 [3.03,10.62]。说明父 memory 状态能够强烈影响下一次 teacher 与凝聚过程，不能只优化单阶段终点后假定会累积。

这还不能将问题单独归因于图、文本或 teacher；父 memory 同时携带已改变的 X、文本和边，需下一轮因果控制。

### 4.3 维护与容量目前不宜默认叠加

maintenance 相对 recursive 最终平均 **-1.00 pp**，旧类差值由 +0.57 降至 -1.38，同时构造组件成本显著增加。与独立 old-only 复验一致：当前关系目标及短训约束不足以保证长期维护收益。这不是否定允许旧 memory 修订。

capacity 相对 recursive 最终平均 **-1.51 pp**，四条件只有 Citeseer/19341 提高；其余下降。代理重构/传播误差更低未转化为平均 F1 收益。它检验了固定预算下的一行转移与对应 merge/split，没有完成 response-based marginal allocation 或 adaptive extra budget。

## 6. 后续优先级

**主研究候选：固定 C0 预算初始化 + teacher 共享来源分配 + X/片段重编码/块内边联合构造 + 递归携带。暂不默认叠加旧 X 关系修订和配额搜索。** 这是研究选择，不是主方法晋升或最终论文结论；C0 保持共同冻结控制。

1. **先定位递归反转。** 在已知正/负条件上固定当前 delta 与 row budget，分开替换上一步 X、文本、拓扑的父状态；增加固定 reference teacher 与随父 memory 重训 teacher 的控制。判断是父内容分布变化、传播变化，还是 teacher 随历史合成误差漂移。开发诊断不能充作新的泛化确认。
2. **验证 teacher 是否必要。** 同一优化器、目标结构、输出预算，比较教师表示 H、冻结原始图文表示、随机初始化模型表示，以及固定 C0 分配。只有实际完整 student 对照才能支持 teacher 的算法贡献。
3. **检查 soft 到实际产物的差距。** 分别测原文片段重编码替代 soft pooled text 后、二值边替代 weighted projection 后的目标和 student 响应。weighted graph 如进入正式 student，必须给全部对照同样算子并单列协议，不能只给新方法改模型。
4. **据诊断做一个稳定化改动。** 候选是限制新分配偏离/传播变化、对低可信 teacher 采用不确定性加权，或用合法支持的训练更新匹配校准共同分配；先证明触发的真实瓶颈，避免直接叠加多个约束。允许有限旧修订，但需要能与全过程收益对应的保护标准。
5. **冻结后独立确认。** 新类别分组、新 report seeds，预先声明最终/阶段平均/旧新类与成本目标；同时配上 k-center/medoid、同预算全历史重凝聚和相关静态 TAG 基线，再决定大图 base+4、多个 rate 和 LP。当前两开发顺序不能替代这些工作。

本轮没有完成完整 teacher-guided budget/text-attention/topology/maintenance 全套最优算法，没有监督上限或外部方法的新一轮比较，也没有证明文献新颖性。共享 assignment 和 teacher 压缩本身已有相关思路；潜在贡献应来自合法混合支持、递归压缩误差控制与图文传播协同的可复验证据，而不是仅因新增 teacher 或优化器。
