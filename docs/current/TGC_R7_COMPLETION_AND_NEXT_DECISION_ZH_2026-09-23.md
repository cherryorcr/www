# TGC-R7：构造稳定性、目标校准与独立确认结项

日期：2026-09-23  
状态：**稳定性、目标校准、完整递归开发和独立确认全部完成；R7候选有正向独立信号，但暂不宣布为稳定主方法。**

## 1. 结论先行

这轮首先验证了 R5 结果中的一个真实问题：相同 teacher seed、相同输入和相同 minibatch 下，GPU 稀疏传播在第一次 teacher 更新后就可能发生微小数值分叉；这个分叉会改变软分配 `P` 和合成 `X`，并在完整 student 重训中放大。将小图构造阶段改为 CPU 归一化、稠密矩阵计算后，重复构造的 teacher、`H`、`P` 和最终 memory 可以逐字节复现。

但数值稳定本身不是性能改进。目标校准进一步表明，实际 teacher 重构误差、图文关系 KL、梯度方向和一次更新收益都不能稳定预测完整 student 的最终 Macro-F1。因此本轮没有把这些 response/proxy 信号加入正式算法。

在完整递归和新类别顺序确认中，原始 TGC-R、确定性 TGC-R 和有界分配版本的最终 F1 均高于各自 C0，但新类 F1 普遍下降，阶段平均不稳定。当前最合理的判断是：

> TGC-R 已经从“开发条件上的偶然提升”推进到“在独立条件下可重复观察到最终阶段正向信号”的候选，但它主要改善历史类保持，尚未解决新类塑性，因此还不能作为无条件替换 C0 的最终主方法。

本报告不以最好的单个 teacher seed 或单个顺序作为结论；确认结果按两个构造 teacher 组平均，并保留所有失败条件。

## 4. 构造稳定性结果

### 4.1 数值差异出现的位置

在 Cora/Citeseer 的四个开发条件上，普通稀疏路径的输入、初始化、teacher minibatch 和邻接数值相同，但 teacher 参数在第 1 次更新后即出现差异。三次普通构造的最终 F1 范围约为 **1.03--2.54 pp**，最大合成属性逐元素变化约 `1.99e-3`；文本和边在这些重复中保持相同。

对完全相同的固定 memory，72 对历史与新 student 重训分数仍然完全一致，说明主要波动来自 memory 构造而不是 report student 自身。

在相同合法图上重复五次固定参数前向/反向：

| 路径 | 前向重复 | 梯度重复 | 最大梯度绝对差 |
|---|---|---|---:|
| CUDA sparse | 不完全相同 | 不完全相同 | `3.17e-8` |
| dense | 完全相同 | 完全相同 | `0` |

这定位了一个数值来源，但不是对所有 GPU、所有稀疏内核的普遍定理。稠密路径只用于 Cora/Citeseer 小图诊断，不能直接作为大图实现。

### 4.2 固定父状态的构造结果

四个开发条件上最终 F1 的平均值：

| 方案 | 最终 F1 | 相对 C0 |
|---|---:|---:|
| C0 | 54.4267 | 0 |
| 封存 R5 recursive | 55.6312 | +1.2045 |
| 普通 sparse 重构，三次平均 | 53.6519 | -0.7749 |
| 确定性开关 sparse，三次平均 | 54.3478 | -0.1012 |
| 稠密等价构造 | 54.7239 | +0.2972 |

封存 R5 的 +1.20 pp 仍可复现；重新构造的普通路径却不稳定，说明此前的提升不能只归因于 student seed 数量，也不能直接作为新方法的稳定平均收益。

## 5. 目标校准结果

在固定父 memory 上，预先固定的四个候选最终 F1 为：

| 候选 | 定义 | 最终 F1 |
|---|---|---:|
| `alpha=0` | 平滑初始分配 | 53.7046 |
| `alpha=0.25` | 25% 学习分配 + 75% 初始分配 | 54.0520 |
| `alpha=0.5` | 50% 学习分配 + 50% 初始分配 | 53.4339 |
| `alpha=1` | 完整学习分配 | 54.7239 |

四个条件内的 proxy 排序结果：

| Proxy | 平均 Spearman | Top-1 命中 |
|---|---:|---:|
| 实际 teacher 重构误差，越低越好 | +0.20 | 2/4 |
| 图文关系 KL，越低越好 | -0.20 | 1/4 |
| 梯度余弦，越高越好 | 0.00 | 1/4 |
| 一次合法 Adam 更新收益，越高越好 | -0.50 | 1/4 |

每个相关系数只有 4 个候选，不能作显著性推断；但方向已经足够否定“继续把更低 proxy loss 当成成功标准”的做法。响应诊断保留为分析工具，不进入主方法和候选 selector。

## 6. 完整递归开发结果

下面按四个开发条件等权，最终阶段为主；`bounded` 是固定 `alpha=0.5` 的有界分配。

| 方法 | 最终 F1 | 相对 C0 | 阶段平均差 | old 差 | new 差 | 最差条件 |
|---|---:|---:|---:|---:|---:|---:|
| C0 | 54.4267 | 0 | 0 | 0 | 0 | 0 |
| 原始 sparse R5 | 54.0296 | -0.3971 | -0.3510 | -1.4855 | +0.7982 | -2.7807 |
| 稠密 R5 | 53.9042 | -0.5225 | -0.4003 | -1.7808 | +0.8023 | -5.2543 |
| 有界 `alpha=0.5` | **54.9870** | **+0.5603** | -0.2132 | -0.5585 | **+1.7785** | -4.3144 |

这批结果说明有界分配在开发条件上改善了最终 F1 和新类塑性，但阶段平均仍为负，且最差条件退化明显，不能只依据 +0.56 pp 进入主表。

## 7. 独立确认结果

确认批次使用三种新类别顺序；原始、稠密和有界版本均对两个 teacher seed group 分别运行，表中先在两个 group 上平均。

### 7.1 最终阶段主表

| 方法 | 最终 F1 | 相对 C0 | 阶段平均差 | old 差 | new 差 | 正收益条件 | 最差条件 |
|---|---:|---:|---:|---:|---:|---:|---:|
| C0 | 50.9189 | 0 | 0 | 0 | 0 | 0/6 | 0 |
| 原始 TGC-R | 52.2389 | +1.3201 | +0.4583 | +2.9033 | -1.1404 | 3/6 | -6.4278 |
| 稠密 TGC-R | **52.3454** | **+1.4265** | **+0.5705** | +2.8498 | -0.8243 | 3/6 | -5.6126 |
| 有界 `alpha=0.5` | 51.9742 | +1.0553 | -0.3448 | **+3.0229** | **-2.0593** | 3/6 | -4.7404 |
| k-center | 52.5859 | +1.6670 | +4.5414 | +4.1353 | -2.6752 | 4/6 | -15.3024 |

确认结果给出两个重要判断：

1. 原始和稠密 TGC-R 在新顺序上仍取得约 `+1.32/+1.43 pp` 的最终阶段提升，说明 R5 的正向信号不是只存在于原来的两个开发顺序。
2. 这个提升主要由 old F1 提升构成；三种 TGC 版本的 new F1 均低于 C0。有界分配没有解决塑性，反而把 new 差扩大到 `-2.06 pp`。

k-center 的最终均值最高，但它是保留真实节点的 coreset，且 final 最差条件为 `-15.30 pp`，不能据此把它与合成 TGC-R 直接混称为同一种凝聚机制。

### 7.2 成本

确认批次增量构造组件的平均计时和 student 计时：

| 方法 | 构造秒/增量 | Student 秒/次 | 最终逻辑 memory 字节 |
|---|---:|---:|---:|
| C0 | 0.295 | 3.944 | 355,368 |
| 原始 TGC-R | 1.931 | 3.944 | 355,218 |
| 稠密 TGC-R | 1.775 | 3.942 | 355,218 |
| 有界 `alpha=0.5` | 1.787 | 3.942 | 355,216 |
| k-center | 0.005 | 3.947 | 407,821 |

TGC-R 的 student 训练成本几乎没有变化；额外成本主要在构造阶段，约为 C0 的 6--7 倍。稠密路径还不能作为大图方案，因此大图前必须实现可扩展且确定的 sparse/CPU reduction，而不是直接把小图 dense 代码搬过去。

## 8. 当前方法评价

### 可以保留的核心

- **teacher-guided shared assignment**：训练 teacher 相比同架构随机 teacher 在 R6 开发诊断中 4/4 条件为正；R7 也没有否定其方向性价值。
- **内容和传播联合材料化**：同一个 `P` 同时生成合成 `X`、重编码文本和二值拓扑，避免独立优化三种字段造成不一致。
- **递归 history 约束**：每阶段只读取旧合成 memory 与当前 delta；允许未来做有界旧合成修订，但不回放历史 raw graph。
- **C0 fallback**：C0 作为低成本、稳定的初始化/控制；不是因为 TGC-R 已经无效，而是当前仍需要在新类塑性失败时提供保守回退。

### 当前不能宣称的内容

- 不能说 TGC-R 普遍超过 C0、k-center 或静态 TAG 凝聚。
- 不能说 response proxy 已经能够选择最优候选。
- 不能把 dense construction 当成大图可扩展实现。
- 不能把 old F1 提升写成同时解决 continual forgetting 和 new-class plasticity；本轮只支持前者的部分改善。

## 9. 下一步决策

R7 后不再继续调节 response loss、KL、重构误差或 `alpha` 网格。下一步应该只解决已经被确认的瓶颈：**TGC-R 对当前新 delta 的可学习性不足**。

### P7-N：C0-anchored plasticity-preserving TGC-R

保持 teacher、共享 `P` 和联合拓扑不变，只在当前 delta 的新合成块加一个 C0 anchor：

\[
X_{new}=(1-\lambda)X^{C0}_{new}+\lambda X^{TGC}_{new},
\]

文本必须分别由 C0/TGC 的来源片段重新编码后做同样的有界融合，不能直接平均两个不对应的 embedding；拓扑先使用共同边预算，比较 C0 new-edge、TGC new-edge 和一致性 gate 三个控制。`lambda=0`、`0.25`、`0.5` 预先固定，旧 synthetic block 不回放 raw data，历史部分不改写。

验收指标：最终 F1、阶段平均、old/new F1、最差顺序、构造成本和与 k-center 的差距。只有同时改善 new F1 且不牺牲旧 F1 的候选，才继续做长链/大图。

### P7-D：可扩展确定性构造

在 P7-N 之前或并行实现 sorted COO + CPU double/确定性 segmented reduction，对 teacher 传播和 assignment objective 给出与 dense 小图一致的数值审计。此项是复现基础设施，不单独作为算法贡献。

### 暂停项

动态预算、旧 memory maintenance、response selector、weighted edges、embedding-only pooling、大图扩展和 LP 扩展均暂缓。它们不是永远放弃，而是要等新类塑性和可扩展确定性路径先有证据。
