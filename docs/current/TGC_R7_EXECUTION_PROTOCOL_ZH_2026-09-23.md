用户已授权依次推进四步。R7为实验批次，不预先命名新的论文主方法。历史R5/R6产物与共同student保持不变。候选可在旧合成memory和当前delta上计算；禁止历史原始图回读和report/test标签参与构造。有界旧合成修订允许，但本轮先聚焦共享分配。

## 1. 固定输入构造重复（先于新目标设计）

- Cora/Citeseer，开发顺序19341/19342，固定R5封存s1父memory和合法s2 delta，5%累计rows。
- 三次原数值构造、三次确定性构造，均使用teacher seeds8400/8401；另做确定性构造seeds8460/8461和8470/8471。
- 两个参照为封存C0和封存R5递归端点；所有产物共同student seeds100..105评分，先全部构造/封存，再评分/重载。
- 逐步记录teacher初始化、梯度、参数和minibatch哈希；记录支持图、H、P、最终X/文本/边。区分相同seed重复与不同构造seed变化；不按分数选择最佳重复。
- 确定性开关仅作用于构造，评价student不更换算子。CUBLAS_WORKSPACE_CONFIG为所有方法共同进程设置；封存产物重训同时检测该设置是否改变原评价。
- teacher数学运算与采样保持原实现；哈希记录有同步开销，其耗时不作为最终算法成本。

## 2. 目标校准（依第一步结果补充并在评分前冻结）

保留训练teacher、共享P、重编码文本和二值边。通过已有开发条件上有限且固定的候选，比较teacher重构误差与实际memory图文关系/训练更新信号对完整student收益的指向。分析须按数据集/顺序内配对，不以跨数据集绝对分数相关代替。不能以降低proxy作为验收，也不直接复活昂贵短训selector。

## 3. 最小稳定化（依诊断冻结）

只实现一个有明确假设的改动，保留原R5和数值稳定R5对照；记录C0初始化、共享分配和实际输出的一致性。原实现已有KL与mass正则，不能把重复添加正则当新机制。若候选没有可重复收益，则如实给出停止/改向结论，不以挑选最好seed提升结果。

## 4. 独立确认

配方确定后才启动新类别分组、新构造seed和student seeds。核对实际类别分组与已扫描历史不重叠；已见R6确认条件只可用于开发诊断。比较C0、k-center、原R5与选定候选，报告最终/阶段均值、旧新类、最差条件、构造方差和计时。是否推进长链、大图、LP依独立证据决定，不要求每格获胜，也不能由单一大涨掩盖平均退化。

## 数值诊断后的执行补充（新候选评分前）

首个条件已观察到：初始化、minibatch、邻接相同，teacher第1次更新即出现差异；仅开启确定性开关仍不能消除。新增独立快照`calibration`，不改写首批协议/产物。

- teacher的合法支持邻接在CPU归一化并转为稠密矩阵，GPU确定性矩阵乘；共享P优化也使用等价稠密表达。模型、损失、采样、步数不变，共同下游student不变。
- 对四个开发条件再做三次完全相同的稠密构造，要求teacher轨迹、H、P和最终memory逐字节一致。稠密实现只用于小图，本轮不声称可直接扩展大图。
- 候选：原封存C0/R5；稠密R5；`P_alpha=(1-alpha)P0+alpha*Pstar`，alpha预定为0、0.25、0.5。P0是平滑初始分配，非原C0。所有字段仍从同一个P共同生成；旧父memory固定。
- 三个响应诊断：合法支持与实际memory之间的梯度余弦、图文关系KL、一次重置状态Adam更新后合法支持InfoNCE的改善。teacher位置为0/32/128，两个teacher，每个4组batch16；来源按固定初始簇匹配，旧合成节点直接对应，来源不重复。
- 该诊断与已失败v7-A的“相对C0、0/1/2步梯度距离”不同，但仍可能失败。只做目标有效性检验，不部署选择器或把这些分数用作正式F1。
- 后续只允许一个最小算法变化：统一限制P相对初始分配的改变量。alpha=0.5作为预定温和候选，alpha=0/0.25作为诊断。是否加入响应损失依校准证据决定；没有证据就不对无效proxy继续求低值。

## 校准后执行决策

四个开发条件的三次稠密重复全部逐字节一致；封存C0/R5的48对共同student重训与历史分数相同。三项响应信号未表现稳定排序，故本轮不将它们作为新优化目标。alpha=.5在固定父状态下平均不优，但局部转移不能代替完整递归，因此按预定值完成自身父memory递归对照，既不改为本批最好alpha，也不放弃报告负结果。

递归开发比较C0、原稀疏R5、稠密R5、alpha=.5稠密候选；开发顺序19341/19342、报告seeds100..105、teacher8400/8401。
