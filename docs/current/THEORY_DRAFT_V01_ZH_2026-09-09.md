## 0. 记号与设定

- 数据流：阶段 t 到达 delta 图 Δₜ = (Vₜ, Eₜ, Xₜ, Tₜ)，X 为节点特征，T 为节点文本；阶段结束后 Δₜ 不可再读；
- 预算：第 t 阶段累计预算 kₜ = ⌊ρ·Σ|V₀..ₜ|⌋（ρ=0.05）；
- 构造器 C(Δ, k)：确定性映射，输入一个 delta 与配额 k，输出 k 行合成块（本方法中为 maxmin+Lloyd 聚类 → 簇均值 X + top-g 截断拼接文本 + 自编码 embedding + mass）；
- Append 算子：Mₜ = Mₜ₋₁ ⊕ C(Δₜ, kₜ − |Mₜ₋₁|)（旧行逐字段不动，⊕ 为行拼接）；
- 可重训性 R(M)：从 M 出发独立初始化 student、固定协议训练后在真实评测图上的期望 Macro-F1（对 student seed 取期望）；
- 冻结文本编码器 E: 文本 → 单位球面上的 embedding。

## 定理 1（可换序性：持续约束零代价）

**陈述.** 设 C 为任意确定性构造器，配额序列 (q₀,…,q_T) 固定（qₜ = kₜ − kₜ₋₁）。则在线 append 产物与允许重读全部历史的离线分层构造逐字段相等：

  M_T^online = C(Δ₀,q₀) ⊕ … ⊕ C(Δ_T,q_T) = M_T^offline-stratified

**推论 1.1.** 对确定性逐阶段构造器族，"历史不可重读"约束的可重训性代价恒为零：R(M^online) = R(M^offline-stratified)。

**证明骨架.** 每个块 C(Δₜ, qₜ) 只是 Δₜ 与 qₜ 的函数；在线与离线的输入逐块相同、构造器确定性 ⇒ 输出逐块逐字节相同 ⇒ 拼接后相同。□（约 5 行；关键前提是确定性与"块间无交互"，本方法两者都满足。）

**实验对应.** corrections 等价审计：从 raw 重建分层构造与保存的 append memory，x/text_emb/mass/stage 在 atol=1e-5 内一致、texts 精确相等（Cora 与 Citeseer）。

**边界（正式版必须写明）.**
- 只对"分层配额离线构造"成立，**不**声称等于最优离线凝聚器（联合池构造是另一算法，且实验中更差：full_history 重凝聚 Cora 53.6 vs append 58.1 test）；
- 含删行（c 规则）时，离线侧需重放同一删行规则才保持等式；
- 拓扑在全 memory 上重连，不属于"逐字段相等"的字段集（等式针对行数据，不含边）。

## 定理 2（组件性质：覆盖近似最优、旧阶段精确不变、文本零漂移）

### 2(a) maxmin 播种是 k-center 覆盖的 2-近似

**陈述.** 本方法的 maxmin（farthest-point traversal）播种即 Gonzalez (1985) 算法：其覆盖半径 r(S) = max_v min_{s∈S} d(v,s) 满足 r(S) ≤ 2·r(OPT)，且除非 P=NP，(2−ε)-近似不存在（Hsu & Nemhauser 1979）。

**证明.** 直接引用经典结果；只需核对实现与 Gonzalez 算法一致（首点固定、逐次取最远点——已一致）。□

**诚实边界.** 覆盖半径与可重训性的关系是**实证不成立的**（T1：cover_max 与 F1 的 ρ=−0.25 n.s.）。因此 2(a) 只作为"该组件在其自身几何目标上近似最优"的性质陈述，不用于推导性能界。

### 2(b) append 下旧阶段行数据精确不变；recluster 无此保证

**陈述.** Append 算子下，∀s<t，Mₜ 中来自阶段 s 的行满足 rows_s(Mₜ) = rows_s(M_s)（逐字节相等）。存在输入使 recluster 算子将旧行任意改变（构造反例：两个旧簇被合并，均值 X 与融合文本均改变）。

**证明骨架.** Append 定义即为不动旧行（一行代码的语义）；recluster 反例取两簇中心距 < 新点吸引域即可。□

**实验对应.** Gate 1''/2''：append 旧阶段 test F1 两数据集最高（73.3/70.7），recluster 一致更低（68.3/67.8）；12/12 配对 old-F1 全胜。

**诚实边界.** 数据不变 ≠ 响应不变：拓扑每阶段重连，旧节点的 GCN 消息传播可变。定理只声称数据层等式，性能保持是实验结论。

### 2(c) 拼接文本的 embedding 零漂移性质（草稿级）

**陈述（弱形式，可严格证）.** 拼接文本 T' 的每个 token 均来自真实文本集合的 token；对 bag-of-words 型编码器，E(T') 落在成员文本 embedding 的凸组合上（精确）。对一般 Transformer 编码器，退化为经验性质：本实验中 v1 拼接与全部 9 个 LLM 生成变体在流形距离统计上不可分（T1），但生成文本无任何"token 来自真实集合"的结构保证。

**正式版待办.** Transformer 下的严格界需要注意/位置编码的连续性假设，可能只能给出"截断长度 → 局部扰动"的 Lipschitz 型弱界，或降级为性质观察。**这是三个定理中最弱的一条，正式版可考虑并入讨论节而非定理。**

## 定理 3（分离性：可重训性无 embedding 统计代理）★

**陈述（实证分离命题）.** 存在同协议、同预算、同 k 的 artifact 对 (A,B)，使得其文本 embedding 的一阶/二阶统计（对真实流形的最近邻距离、MMD²、覆盖均值/半径、自身 pairwise 余弦）逐项 ε-接近，而 |R(A) − R(B)| > 12 pp。因此 R **不是**这些统计量的连续（Lipschitz）函数；任何以这些统计量为目标的优化对 R 无控制力。

**Witness（已在手）.**

| 统计量 | oracle_label | kmeans_multi | 差 |
|---|---:|---:|---:|
| shift_nn | 0.2792 | 0.2756 | 0.004 |
| MMD² | 0.0180 | 0.0207 | 0.003 |
| cover_mean | 0.4431 | 0.4403 | 0.003 |
| pair_cos | 0.2328 | 0.2500 | 0.017 |
| **dev F1** | **53.75** | **41.00** | **12.75** |

**系统性证据.** 11 artifacts × 5 predictors，全部 |Spearman ρ| < 0.25、p > 0.33（t1_predictor_validation.json）。另两个方向性反例：oracle 类纯度 100% 不超过 74.6% 纯度的基线（53.75 vs 54.17）；best_of_n 判别性全场最优（pair_cos=0.169）而 F1 倒数第二（43.49）。

**推论 3.1（学习失败的结构性解释）.** 任何可学习凝聚组件需要可评估的代理目标 L̂；若 L̂ 是上述统计量（或其单调函数），则优化 L̂ 对 R 无保证。本文测试的五类学习组件（响应匹配 ASM、响应保持、重聚类、生成式文本融合、判别性选择）的代理均落入此类，其系统性失败（P2/P5/Gate1''/v2/v3，共 20+ 变体）与推论一致。

**诚实边界.**
- 这是**实证分离命题**，不是不可能性定理：n=11、单数据集、单文本塔；未排除存在更高阶或跨模态（X-text 联合、传播后）统计代理；
- 正式表述用"在测试的统计量族内无代理"，不用"不存在任何代理"；
- 加强路径（后补）：第二数据集重复（n→20+）、加入传播后统计、给出 witness 的第二个独立实例。

## 三定理与论文叙事的对应

```
定理1（换序性）   → "持续约束免费"：方法的合法性支柱
定理2（组件性质） → "组件各自在其几何目标上（近似）最优"：方法的构造理由
定理3（无代理）   → "为什么不能学习"：五组件失败的统一理论解释，
                    也是对社区评估实践的元结论（评估凝聚必须重训 student）
```

三者互不依赖、逐条可辩护；最强的是定理 1（精确等式+机器验证）与定理 3（分离 witness 在手）。
