# In-loop CaT-Q：构造端归因实验

日期：2026-10-08。本文只讨论构造端组件归因，不把组件对照算作新的公开论文基线。

> 已完成：9/9 个数据集/顺序组合，54 条五阶段链，324 份 memory 评价、972 次 Student 训练。324 份评价 memory 与 54 组统一文本配对通过归档审计。相关回归测试 77 项通过。
>
> 核心判断：学习 Q 与 in-loop DM 有实验支持，但不能把完整方法的全部收益归因于直接文本梯度，也不能声称残差在所有数据集都必要。主构造器和 Student 本轮没有修改。

## 1. 这轮回答什么

此前实验已经看到主方法在 SportsFit、BookHis 优于同协议 CaT-nearest5 适配，但无法仅从最终 F1 判断原因。尤其是：把主方法的文本换成 nearest 文本后，成绩没有明显降低，并不能直接证明文本在构造过程中也没有作用。

本轮将问题拆成两层：

1. **原生文本评价**：每个对照从头构造自己的五阶段 memory，使用自己选出的真实文本，测量完整闭环方法的效果。
2. **统一文本评价**：构造结束后，所有对照的最终 memory 换成同一份、逐行一致的历史 CaT-nearest5 文本，保持 X、标签、mass、depth、stage、边不变，再训练同一个 Student。

第二层控制了最终文本差异，用于比较不同构造得到的 X 等内容在这个共同文本条件下的表现。它不是一个新训练方法，也不能推广成“对任意文本，某种 X 都更好”。替换文本不回流到下一阶段构造。

## 2. 冻结协议

- 数据集：WikiCS、SportsFit、BookHis。
- 类别顺序：参考顺序 9101，加两个独立顺序 9102、9103；本轮 construction seed 只有 **271006 一个**。
- 每个 memory 使用 Student seeds 150、151、152，先在顺序内平均，再跨三个顺序统计。不能把三个 Student seeds 当成三个独立 construction seeds。
- 五阶段 base+4；每个数据集各顺序采用同一 memory rows 序列，而非各顺序重新计算 5% fixed-rate。
- Prompt Student、MiniLM、2048 training steps、batch 24、320 字符、Q 的 30 步优化均保持不变。
- 构造器只接收当前 raw delta 与该对照自己的旧 synthetic prefix；不改写旧前缀，不加合成拓扑或 boundary sketch。
- 评价使用 **report-dev**，没有打开 sealed test。这里是基于类别 prompt 的分类，不是已证明的未见类别/跨数据集 zero-shot。

| 数据集 | 五阶段累计 memory rows |
|---|---|
| WikiCS | 247, 324, 356, 379, 410 |
| SportsFit | 3817, 4486, 4812, 5305, 6057 |
| BookHis | 579, 592, 601, 1429, 1454 |

访问限制指凝聚构造器的接口边界。评价程序仍持有模拟流和原图评价数据，不能把接口审计说成操作系统级别的文件访问隔离。

## 3. 对照到底改了什么

主方法使用：

\[
X_j=\frac{\sum_i Q_{ij}x_i}{\sum_i Q_{ij}}+R_j,\qquad
\|R_j\|_2\leq0.05\|X_j^{pool}\|_2.
\]

Q 为同类内、带容量约束的可学习分配；文本采用真实 top-1 payload 的硬前向、软反向。CaT 风格的分布匹配在 Q 优化循环内进行，不是提前把 CaT 的 X 优化完再拼接新模块。

| 对照标识 | 唯一主要干预 | 不能误解为 | 顺序数 |
|---|---|---|---:|
| `uq_dm_edgefree` | 原样重建冻结主方法 | 挑选旧批次最高成绩充当当前 full | 3 |
| `no_node_text` | 文本初始化权重与 payload pair loss 权重都设为 0 | 完全不含文本信息；仍保留类别 prompt、可能文本派生的 X，最后仍材料化文本 | 3 |
| `no_residual` | R 不更新且保持为 0 | 固定 X；Q 仍通过梯度改变 pooled X | 3 |
| `no_distribution` | 关闭 in-loop distribution matching（DM） | 关闭全部梯度；GM、传播与 anchor 仍保留 | 3 |
| `free_x` | 独立参数化 X，与 Q 分别更新，保留同一目标与条件 trust region | 无约束 CaT、独立于 Q 的任意自由 X | 3 |
| `no_text_init` | 只去掉初始化中的文本代价 | 去掉后续图文 GM | 1 |
| `no_payload_gm` | 只去掉 GM 内的节点图文 pair 项 | 去掉全部 GM；graph-to-class-prompt 梯度匹配仍存在 | 1 |
| `stop_text_gradient` | 切断 Q 到文本表示的直接梯度，仍材料化当前 Q 的硬文本 | 文本不再影响构造；其仍影响图分支的 GM 目标 | 1 |

`free_x` 从同一个 `pool(Q0)` 开始，保持
\(\|X_j-pool(Q)_j\|_2\leq0.05\|pool(Q)_j\|_2\)。Q 还决定文本、传播目标及移动的可行区域。因此它比较的是匹配约束下的优化参数化，不是严格移除全部 Q-X 依赖，更不能据其成绩证明所有自由 X 方法都弱于 Q。

`no_text_init` 同时关闭 prototype 选择签名和 Q0 代价中的文本项；本轮没有单独分离这两个初始化环节。通用配置中虽然保留了 `cat_anchor`、旧 X 更新和拓扑参数，但该主版本没有使用预先优化的 CaT anchor、旧 X 更新或合成边学习，不能把未启用字段写成主方法组件。

各消融是相对于 full 的条件效应，存在模块交互，**不能把若干消融差值线性相加，声称恰好分解了相对 CaT 的全部提升**。尤其 Q 初始化、约束及优化参数化并没有被这一个 `free_x` 对照彻底分离。

### 4.4 可以得出什么

1. **DM 的作用有支持，强度依数据集而异。** 去掉 DM 的原生 F1 在 9/9 个组合都下降。SportsFit 平均下降 11.64 pp，统一文本后仍下降 9.61 pp，后者区间为 [-11.81, -7.42]。因此这部分收益不能仅归因于最终文本选择。BookHis 的 F1 区间仍跨零；其 Accuracy 平均下降 3.10 pp，区间 [-4.75, -1.45]，两个指标需要一起解释。
2. **通过 Q 生成 X 的参数化有支持，尤其是 SportsFit。** 独立 X 对照在 SportsFit 原生文本下下降 7.09 pp F1、10.28 pp Accuracy；统一文本后下降 7.37 pp F1，区间 [-10.03, -4.71]。其他两图尚没有同等强度的区间证据。这个对照改变了梯度路径与优化几何，不证明 Q 的表示集合严格优于所有自由 X 方法。
3. **节点文本参与不是处处有益，但也不能整体删除。** SportsFit 关闭节点文本路径后，F1 平均下降 2.71 pp，三个顺序均下降。WikiCS、BookHis 的总体 F1 没有显示完整文本路径的平均优势。BookHis 去掉节点文本后总 F1 上升 0.76 pp，但 New F1 从 48.66 降到 43.94；这也是 old/new 取舍，不能只挑总 F1 或 New F1 一列解释。
4. **残差不是已证实的普遍必要组件。** 原生文本下，无残差在 WikiCS、BookHis 的三个顺序全部更高，在 SportsFit 的三个顺序全部更低。BookHis 换成共同文本后又出现相反的平均方向，说明 X 构造、Q 变化和最终 payload 会发生交互。目前不能按数据集挑选是否启用残差，再把拼接结果称为统一主方法。
5. **优化目标下降不等于组件有独立分类收益。** 完整方法的 45 个阶段中，DM 的训练 bank 与未参与优化的 holdout bank 初末值均下降；GM 日志初末值也全部下降。但此前 no-GM 对照仍没有稳定显示 GM 的额外分类增益。日志只能说明优化确实发生，不能代替消融。

这些结果说明：

- SportsFit 的参考顺序中，文本初始化的影响比直接文本梯度更明显。去掉初始化后，统一文本条件下仍下降约 2.98 pp F1；不能把该收益仅解释成最后挑了一条更好的文本。
- BookHis 中，关闭部分文本路径的原生文本分数更高，但统一文本后完整方法更高。这符合“构造得到的 X 与最终材料化文本之间存在交互”的解释，不支持简单说文本有用或无用。
- WikiCS 没有明确显示文本分支的普遍增益。
- 原生文本评价与统一文本评价回答不同问题。不能挑其中较好的一张表替代正式方法成绩；也不能从单顺序结果宣布直接文本梯度已经得到充分验证。
- 当前没有分离每个损失对 Q 的梯度夹角，不能把这些分类结果直接说成已证明的梯度冲突。日志中的总梯度非零只能证明参数参与了优化。

## 6. 与之前证据的关系

此前 `UNIFIED_Q_VALIDATION_RESULTS_ZH_2026-10-07.md` 的 fixed-Q 参考顺序对照中，学习 Q 相对固定 Q 的 F1 差值为 WikiCS +8.26、SportsFit +21.00、BookHis +7.78 pp。它支持在该受限构造下学习 Q，而非保留初始化分配。

此前三顺序、三 construction seeds 的 no-GM 对照，相对 full 的 F1 差值为 -0.03、+0.17、+0.85 pp，三个区间均跨零。这不证明严格等效，但不支持 GM 已有稳定的额外性能贡献。no-GM 仍通过 DM/传播等目标反向传播，不是启发式或无梯度版本；它也不再包含直接文本损失梯度，不能保留与 full 完全相同的多模态联合优化主张。

以上是独立批次证据，不与本轮重跑合并成更多独立 seeds。此前 P0/P1 的外部比较及同 memory Student-loss 对照仍单独见 `UNIFIED_Q_P0_P1_FINDINGS_ZH_2026-10-08.md`。CCTP 是 CaT 的 TAG 文本附着适配名称，Adaptive coherent 是内部候选；本轮八个对照都不能新增到“外部论文基线数量”里。

## 7. 完整性、复现与局限

54 条五阶段构造链、270 次原生 memory 评价、54 次统一文本评价全部完成，共 972 次 Student 训练；9 个队列任务退出码均为 0。归档重建核对 324 份已评价 memory 的 hash、54 组固定内容文本替换，全部通过；核对构造期预算、旧前缀、slot 标签、干预配置、记录的来源/重新编码检查、Sinkhorn 可行性和 trust region。旧前缀检查针对原生构造链，不把最终整套文本替换误称为另一条冻结前缀构造链。

相关单元/回归测试 **77 passed**。审计会校验构造时记录的文本来源与重编码结果，但离线归档审计本身没有再次加载 MiniLM 编码全部字符串；它也不是 OS 级文件读取追踪。

## 8. 后续建议

**保留 Q + in-loop DM 这一主体，有比此前更明确的依据；但不应把“所有文本/残差分支都得到验证”写进论文。** 本轮保留冻结 full 作为可追溯主方法候选，没有根据消融成绩自动替换实现。

建议下一轮严格按以下顺序：

1. 对 full、无残差和关键文本对照补独立 construction seeds。沿用统一规则，不为不同数据集分别挑赢家；尤其需要覆盖 BookHis 的复现波动。
2. 文本方面先区分初始化收益与直接文本梯度收益；记录各损失的 Q 梯度贡献/夹角，以及 Q 的软表示改善是否转化成最终真实文本质量改善。已有初始化消融本身还没有分离 prototype 选择与初始代价。
3. 若修改，只针对一处已诊断问题，例如硬材料化一致性或残差约束；不要通过再换 Student 提高绝对分数来替代构造端证据。删除没有稳定收益的辅助项，也不等于删除可学习 Q 或变成无梯度启发式。
4. 按原计划补高保真公开基线、冻结 memory 的跨 Student 迁移与封存 test。外部对照与组件消融继续分表。

后续公开方法高保真适配、多 construction seeds 的构造端消融、不同 Student 架构迁移、混合到达协议及 sealed test，均未被这轮归因实验替代。若优化文本路径，应先诊断硬材料化与软代理的一致性，不同时加入 EM、拓扑和旧记忆刷新。
