## P0

固定已归档 X，逐阶段生成并冻结 common nearest1/nearest5 文本。两种构造器均使用同一 GECC 传播特征作为查询库，图内同类检索。

共同对照采用按类别批量 float64 cosine 排序；原生 GECC 使用 float32 逐行查询。近似并列可能引起来源排序变化，不能把重算 nearest5 与原生 GECC 当作同一个 memory。原生结果完整保留，共同策略结果另列。X、标签、质量、阶段、拓扑逐张量保持不变；来源合法性和重新编码分别检查。

原版残差触界率需要取得 Q，故进行辅助构造重放。早期审计发现相同配置的 GPU 重放可能存在浮点与硬选择差异；初始原型、特征误差、文本变化数均记录。辅助重放不替代已归档主表 X，不声称其统计精确描述历史每个 bit。固定 X 的几何与 holdout DM 直接使用原档案。

失败的严格逐字节重放试验保留在 p0 和 p0_v2 输出目录，不能计作完成 cell。实际 P0 归因实验保存在 p0_v3 目录。

## P1 条件门与单项干预

在全部 P0 开发 cell 完成后判断：共同文本策略下跨架构差距是否仍存在；可达性、残差触界和表示统计是否支持值得检验的生成空间限制。均值距离主要是尺度变化时，不把它当作已经解释分类差距。

若进入 P1，仅把 feature_pooling 从 raw 改成 message：Q 聚合已有合法一跳消息 H，而非原始 X。初始化代价、Sinkhorn、硬文本/ST、各损失权重、30 步优化、5% residual cap、Student、访问权限全部保持不变。初始 pooling、每步 X、投影半径基准、最终材料化一起切换；不引入预训练 CaT X、多跳混合、额外拓扑或新分类器。

开发晋升参考在 P1 分数揭晓前固定：两种 Student 的跨三图平均 Final F1 均为正改善；至少两图不呈现一致退化；不得隐瞒任一图/Student 平均超过 1 pp 的退化，也不能以明显损害 Accuracy/Old F1 换取单表收益。满足这些只是进入后续独立确认的依据，不是显著性或不劣证明。

如果原始平均差距仍主要由文本解释，P1 不应被先验视为主改进。若 P1 改善表示拟合但分类仍混合，可进入单独的 P2 配对统计检验；不得同时改变多个因素。
