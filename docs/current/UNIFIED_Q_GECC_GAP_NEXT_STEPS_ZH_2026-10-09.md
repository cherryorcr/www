# In-loop CaT-Q 与 GECC 的差距：论文判断与后续实验计划

日期：2026-10-09。本文为研究规划，不是新实验结果。本轮仅核对代码、分析并整理计划，没有修改主算法、启动训练或访问最终 test 指标。

## 1. 当前证据能说明什么

最新确认覆盖三个数据集、每图两个可行顺序、两个 construction seeds、两个 Student 架构、三个 Student seeds，均为 report-dev。差值为原 In-loop CaT-Q 减 GECC-hard + TAG 适配版，单位 pp：

| 数据集 | GCN Macro-F1 | GCN Accuracy | SGC Macro-F1 | SGC Accuracy |
|---|---:|---:|---:|---:|
| WikiCS | -0.06 | -0.85 | -0.78 | -0.61 |
| SportsFit | +0.51 | +0.08 | -3.32 | -1.90 |
| BookHis | +0.82 | +0.46 | -0.73 | -1.46 |

GCN 的 F1 配对区间三图均跨零，不能宣称稳定胜出，也不能把不显著误写成已经证明不劣。SportsFit/SGC 四个组合均落后，是优先诊断对象；其余图也必须作为防退化检查，不能只围绕一个数据集调参。

GECC 在这里不是完全不使用 TAG 文本的旧基线：它已使用当前 delta 内的 graph-nearest5 文本附着、320 字符上限、同一 MiniLM 和图文 Student。若输入 X 本身由文本编码生成，也不能把取消 payload 分支称为完全无文本；需要在论文中交代特征来源。

本轮 Q-medoid 只降低了硬投影失真，没有稳定提高分类，因此不升级、不按数据集选择变体，原 q_max 主线继续保留。此前 shared/split-Q、no-GM 与文本归因的混合/负结果继续有效。

## 2. 不全面 SOTA 能否支撑 WWW 长文

不需要每个数据集都排名第一。具有清楚价值的新问题、可复用协议、非平凡方法贡献、可信的机制证据及有竞争力的性能/成本取舍，可以构成长文。但这不是说增加一个 setting 就能弥补任何算法证据不足。

目前应定位为有竞争力的研究候选，而不是已经证据充分的投稿版本：

- 问题贡献：需说明历史 raw 不可回读、文本需可材料化与追溯、memory 随到达变化等约束为何来自真实需求；不能未经进一步文献核对就声称首次提出。
- 方法贡献：共享 Q 确实提供统一的参数化接口，但 Sinkhorn、随机特征匹配、ST 和梯度匹配本身不是新发明。当前实验尚未证明其组合带来稳定、独特的配对信息收益。
- 持续贡献：当前主要是互斥类别到达、冻结旧前缀。逐阶段凝聚加 append 的适配基线也能合法工作，必须解释本方法比这种做法额外解决了什么。
- 经验贡献：不能只展示优于 CaT 的图或 GCN 的结果。SGC、GECC、失败 cell 和 Accuracy/Old-New 取舍均须保留。
- 效率贡献：当前 SportsFit 构造较 GECC 快，但 WikiCS/BookHis 并不占优，且已有计时不是独占硬件端到端 benchmark，不能先宣称普遍更高效。

没有依据给出可靠的录用概率。当前可以继续写问题与方法，但若不补强上述证据，作为 WWW 方法型长文仍有明显风险。

“整体分数已经不错”也不等于达到上限。BookHis 的高 Accuracy 与较低 Macro-F1 同时存在；SportsFit 的 SGC 仍有明确基线差距。应补同 Student 的 full-raw 参考与预算曲线判断可压缩空间。full-raw 使用更多访问/存储，必须单列；其有限训练结果不是数学上的性能上界。

## 3. 为什么专门设计的方法不保证胜过 GECC

只有候选解空间包含基线、优化目标与最终评价一致且优化足够充分时，才可能从最优值角度讨论不劣。本项目不满足这些前提：有硬容量与残差界，使用代理 DM/GM 而非直接最大化测试 F1，且优化步数有限。

### 3.1 GECC 适配版的代码事实

实现位于 [external_continual_mechanisms.py](D:/Aprojects/continue_tag_condensation/code/v2_llm_fusion/external_continual_mechanisms.py:386)。它先计算：

\[
H_G=0.3\widehat A_{\Delta}X_{\Delta}+0.9\widehat A_{\Delta}^{2}X_{\Delta}.
\]

0、0.3、0.9 是 0/1/2-hop 的系数，不是跳数。随后每类做 20 次 hard Lloyd 聚类，用类内 SSE 加簇大小不均衡罚项选一次重启，直接存储 H_G 空间中的中心，再附着 nearest5 原文。平衡罚项只是重启选择分数，不是严格等容量约束。

这是本地机制适配，不等于完整官方 GECC，尤其不是其累计历史 raw 重聚类或调优 fuzzy 版本。当前不能把任意差异都归因于某个原论文模块。

### 3.2 本方法存在一个具体、可测的表示限制

当前 [Q 约束](D:/Aprojects/continue_tag_condensation/code/v2_llm_fusion/unified_q_multimodal.py:194) 在每类内满足行和为 1、列和为 n_c/m_c；[X 构造](D:/Aprojects/continue_tag_condensation/code/v2_llm_fusion/unified_q_multimodal.py:812) 为：

其中 n_c 是该类 raw 节点数，m_c 是该类 slot 数，m_j=\sum_iQ_{ij} 是第 j 个 slot 的分配质量。

\[
X_j^{pool}=\frac{1}{m_j}\sum_i Q_{ij}X_i,
\qquad X_j^S=X_j^{pool}+R_j,
\qquad \|R_j\|_2\leq0.05\max(\|X_j^{pool}\|_2,10^{-3}).
\]

在精确平衡的理想条件下，可直接推出：

\[
\frac{1}{m_c}\sum_{j\in c}X_j^{pool}
=\frac{1}{n_c}\sum_{i\in c}X_i=\mu_{X,c}.
\]

也就是说，Q 可以重新组织类内分布，却不能独自改变该类的平均 X。实际实现还有已审计的 Sinkhorn 数值容差。

与此同时，[DM 目标](D:/Aprojects/continue_tag_condensation/code/v2_llm_fusion/unified_q_multimodal.py:763) 来自合法 reference 的一跳消息 H=AX，而不是原始 X。GECC 的中心则来自传播后的特征。GECC 可用的表示未必落在本方法的同类 raw-X 凸组合加小残差空间内。

进一步由非负 Q、等容量和三角不等式可得一个宽松的线性类均值移动上界：

\[
\|\mu_{S,c}-\mu_{X,c}\|_2
\leq B_c
=0.05\left(\frac{1}{n_c}\sum_{i\in c}\|X_i\|_2+10^{-3}\right).
\]

若一跳消息类均值到 raw-X 类均值的距离显著超过 B_c，则在忽略数值误差的理想约束下无法精确匹配这个线性均值。这可用来诊断可达性，但不是 F1 下界，也不证明非线性 DM 必然无解。必须分清尺度变化与方向变化；不能把归一化模型不敏感的尺度误差当成主要失败原因。

现有 DM 匹配多个固定随机 ReLU 编码器中的类别矩，并非简单 raw-X 均值；GM 已含图文损失，也不是完全没有配对约束。上述推导只揭示一项结构性限制，是否解释实际差距仍需实验。

## 4. P0：先做可达性和 GECC 差距诊断

优先复用已保存 memory、审计和合法阶段接口；已完成的 medoid、shared/split-Q 及旧固定文本实验不重复搜分。不同协议/顺序/种子的历史表不能直接相减。

1. 对全部三图五阶段计算 raw-X 与一跳消息的类均值差、方向余弦、上述 B_c、实际残差触界比例、holdout 随机编码器 DM 误差。检查限制是否集中在落后阶段，而不只在 SportsFit 挑例子。
2. 固定凝聚 X，分别让 CaT-Q 与 GECC 使用同一 nearest1、nearest5 附着策略，另保留各自原生文本。相同策略不等于相同文本，文中必须区分。控制 memory 应逐阶段由当前 delta 生成并冻结，不能最终阶段回读历史 raw 补文本。
3. 用 GCN/SGC 相同步数与种子评价上述控制；这属于归因消融，不新增“外部论文基线”。若需完全相同文本，再使用按类别/阶段预先固定的公共 payload sidecar，注明其会移除自然的 X-text 对应关系，不能冒充最终方法。
4. 配对分析 X 的类内几何、线性可分性与漂移，而不是只比较原型平均距离。不得用 report/test 节点训练新诊断分类器后再称该结果为零样本评估。

决策门：若公共文本后差距仍在且可达性/残差诊断支持结构空间问题，优先进入 P1；若主要差距来自文本附着，先完成第 6 节配对目标验证。若两者均无证据，报告未定位，不自动加入两个模块。

## 5. P1：优先候选，仅改变 Q 的特征生成空间

暂称 message-space Q pooling，不提前升格为最终名称。

直接使用现有合法 reference 已缓存的一跳消息：

\[
H_t=\widehat A_{\Delta_t}X_{\Delta_t},\qquad
X_j^S=\frac{\sum_iQ_{ij}H_i}{\sum_iQ_{ij}}+R_j.
\]

Q 仍同时生成文本软表示并通过同一 Q-max/ST 规则材料化原文。没有先跑 CaT/GECC 得到一个已优化的 X；只是将 Q 聚合的对象改成已有结构消息。raw 当前 delta 的结构仍被使用，合成 memory 仍 edge-free，不能称为新合成拓扑方法。

第一版保持 Q 初始化分数、Sinkhorn、文本规则、DM/GM、权重、Student、训练步数和访问边界不变。所有 feature-pooling 的初值、每步构造、残差半径基准与最终保存必须一致改用 H；不能只改最后保存。5% 的相对半径不变，但表示空间改变，不能声称可行解集完全相同。

优点假设是：先消除 raw-X 生成空间与一跳匹配目标之间可能不必要的矛盾。它借鉴 GECC/CaT 的结构表征思想，不照搬 GECC 聚类中心，也不将这个常见传播操作本身宣称为充分创新。

必须承认的新冗余：在 edge-free、R=0 时，现有传播一致性损失会恒为零；R 非零时，它主要变成一种残差方向约束。第一版保留该项以隔离生成空间变化，若有效，再用一次删除该项的消融检验它是否重复。不要把这种退化为恒等的约束包装成新的独立贡献。

先做三图、一个已见开发顺序、两个构造种子的六个开发 cell，原版/该候选/CaT/GECC 同协议，三 Student seeds、GCN/SGC。只构造一个新增候选，原版与基线满足精确协议及来源条件时复用；旧结果与新结果不因相似名称就直接拼表。开发 cell 明确不作为后续独立确认。

若该诊断不支持此方向，则不先跑大矩阵。若失败，保留结果，再决定是否进入另一个假设；不同时加入 GECC 多跳系数、放宽残差、去平衡或改代理架构。

## 6. P2：仍需验证的 TAG 特有收益

只有在 P0 指向文本配对问题，或 P1 改善特征但仍无法证明图文配对收益时，才单独测试类内联合分布匹配。候选目标是：

\[
L_{joint}=\sum_c \operatorname{MMD}^2\left(
\{(H_i,e_i):y_i=c\},\{(X_j^S,T_j^{ST}):y_j=c\}\right).
\]

需要用能看见配对关系的乘积核或固定交互随机特征；将两套独立均值损失相加不等于联合分布匹配。有限随机特征近似只保留所测统计，不保证唯一恢复联合分布。大图应采用分块/低维随机交互特征，不建立全量 raw-pair 矩阵。

最小机制控制为：正确配对目标、仅边际统计目标、类内打乱配对的目标。打乱只作用于新增目标的 reference 配对，固定实际文本池、Q 初始化与材料化来源，避免把多个变化混在一起。保持相同文本容量及计算预算；单 slot 类不能单独据此证明类内多模态保真。

现有 GM 已包含图文信息，所以新目标必须证明增量信息，而不能仅声称“以前没用图文关系”。先只替换或增设这一项；若有效，再检查它与 GM/传播约束是否重复，保留独立作用。旧 no-GM 的混合结果不能被隐藏，也不意味着为了名字中有梯度而必须保留某个 GM 损失。

这一阶段的目标不是借一个时髦模块增加组件数量，而是回答：为什么共享 Q 比各自保留图/文本边际信息更有用？正确配对优于打乱、同预算增益、独立架构保持收益，才是更有说服力的 TAG 方法证据。

## 7. P3：独立确认与持续 setting 证据

冻结一个候选后，在三图至少三个新的可行顺序、三个新 construction seeds、相同三个 Student seeds 上确认。顺序只按计数可行性筛选并保留拒绝记录。相同 memory 评价 GCN/SGC，不因某个架构不好而不报告。不能将构造已用的架构称为完全未见架构。

参考规模为 3 图 × 3 顺序 × 3 构造种子 × 4 方法 = 108 条五阶段链；两个 Student、各三个种子，仅最终 memory 就是 648 次训练。先有小规模机制信号，再投入这一级成本；逐阶段评价单独预算，不虚构 stage-average。

主报告包括 F1、Accuracy、Old/New、逐阶段曲线/遗忘、worst cell、positive-cell ratio、配对区间、内存 rows/字节/token、构造与训练时间和显存。模型选择使用开发集；保留封闭 test 到设计冻结之后。

为证明 setting 的价值，另补以下预注册协议，不与主表混算：

- 低预算曲线：在所有方法上预先固定例如 1%/2%/5% 三档，记录 class-floor 导致的实际预算；不是看到哪档有利再只报告该档。
- 真实 fixed-rate：预算随当前实际到达量变化，同一 cell 各方法严格匹配；不同顺序不能按绝对 F1 排名来判断方法优劣。
- 旧类别重新到达/新旧混合到达：仍不可回读历史 raw，只访问旧 synthetic 与当前 delta。若允许更新旧 memory，所有方法统一授权并计入预算；这是新协议，不悄悄放松本方法限制。区分“新类别 F1”和“旧类别新到达节点 F1”。
- 长阶段链：结合混合到达定义可行的 10/20 阶段，而非强行把类别数不足的数据集拆成不合法的新类阶段。
- full-raw/global recondensation：作为额外访问与成本参考单列，同时给同训练预算和合理训练充分度说明，不称为严格上界或公平同访问基线。

上述压力测试不能用于挑出让 GECC 失败的场景。若 GECC 同样能解决约束，应该把它保留为强基线，并承认哪些 setting 难题并不需要新算法。

## 8. 晋升与停止规则

准确率路线：独立顺序上相对 GECC 的平均收益、最差退化和 Old/New 取舍均可接受，且没有以牺牲另一 Student/主要指标换取未披露的单表收益。

竞争力路线：即使未全局 SOTA，也需预注册实际有意义的不劣容忍界，并用相应区间检验；同时证明一种独立优势，例如同效果更小实际 memory、稳定更低成本、旧类重到达适应或可审计文本保真。不能用零差异检验不显著替代不劣证明。

贡献路线：新 setting 的现实需求、最接近文献区别、方法的新机制以及对应证据必须同时清楚。均值守恒推导是解释设计限制的分析，不独自构成 WWW 级理论贡献；借鉴传播/聚类/MMD 应明确引用，而不是改名当新发明。

若两个预先限定的单改方向都没有可重复收益，应收缩方法主张或定位为问题/基准与系统分析工作；那条路线也需要足够广泛的实证和研究发现，不能靠换叙述自动达到长文标准。无论结果如何，当前有限实验都不能证明“再也无法优化”。

## 9. 当前建议

保留原 In-loop CaT-Q 作为比较锚点，保持 GECC 强基线不变。下一轮先做表示可达性与统一文本附着诊断，最优先的单改候选是使用已有一跳消息生成 X 的 Q pooling。图文联合分布目标是后续条件分支，不与它同时加入。暂不扩展 EM、合成拓扑、LLM 生成文本或大规模参数扫描。
