# In-loop CaT-Q：P0/P1 归因实验与后续方向

日期：2026-10-08。P0/P1 已全部完成。本文区分参考顺序对照和多顺序确认；不使用封存 test，不按本批结果调整主方法。

## 1. 范围与进度

- 主方法仍为冻结的 `uq_dm_edgefree`：学习 Q 和受限残差，保留 GM、DM、传播与正则目标；未添加 EM、合成拓扑或旧 X 更新。
- WikiCS、SportsFit、BookHis 的参考顺序 P1 和同 memory Student-loss 对照已完成。
- P0 的三个预注册类别顺序 9101/9102/9103 全部完成，无缺失组合；最终均值与配对区间见下表及结果目录的 `summary.md`。
- 本批完成 9 个数据集/顺序组合：27 条主方法/历史候选/CaT 链、12 条文本替换链，以及 9 组最终 memory 的新旧训练目标对照。共 39 条五阶段链、204 条 memory 评价记录、612 次 Student 训练。
- P2-P5 的更高保真公开基线、多构造种子、架构迁移、扩展协议与封存 test 尚未因此完成。

## 2. 协议控制

所有当前比较固定 base+4 的五阶段链、参考 memory rows、pool/report 划分、MiniLM、320 字符上限、Prompt Student、2048 steps、batch 24、Student seeds 150/151/152、construction seed 271006。独立类别顺序为 9101/9102/9103。

CaT 与 Adaptive coherent 在每个阶段共用同一次 CaT 构造得到的 X，而不是分别重新构造两个近似相同的 X。文本对照严格保持 X、标签、mass、depth、stage 和边不变。各方法只接收当前 delta 和合法 synthetic prefix，不把完整评价容器传给构造器。

Student-loss 对照使用同一个最终 memory、相同初始化参数结构、相同 steps/batch/seeds、相同原图传播算子与类别 prompt。唯一的主要干预是训练目标族：历史逐行双向 InfoNCE，或当前多正样本 InfoNCE + prompt CE + margin。它不是完整历史协议重跑，不能把历史预算、数据顺序或传播算子的影响归到这一项上。

## 3. 三顺序结果：主体是否值得保留

以下为三个顺序的均值 ± 顺序标准差，单位为百分数。每个顺序内先平均三个 Student seeds；仅使用一个 construction seed。这里的 CaT-nearest5 是 CaT 机制的同协议 TAG 适配，不是官方完整复现；Adaptive 是内部历史候选，不能算作另一个外部论文基线。

| 数据集 | 方法 | Final Macro-F1 | Final Accuracy | Old F1 | New F1 |
|---|---|---:|---:|---:|---:|
| WikiCS | **In-loop CaT-Q（主方法）** | **79.86 ± 0.92** | **82.85 ± 1.61** | 79.97 | 78.83 |
| WikiCS | CaT + nearest-5 | 80.35 ± 0.18 | 83.44 ± 0.31 | 80.51 | 78.88 |
| WikiCS | Adaptive coherent | 80.47 ± 0.39 | 83.61 ± 0.44 | 80.60 | 79.27 |
| SportsFit | **In-loop CaT-Q（主方法）** | **78.60 ± 0.74** | **83.93 ± 1.71** | 78.58 | 78.74 |
| SportsFit | CaT + nearest-5 | 73.75 ± 3.08 | 81.94 ± 6.16 | 73.54 | 74.95 |
| SportsFit | Adaptive coherent | 74.54 ± 1.03 | 82.98 ± 3.83 | 74.24 | 76.17 |
| BookHis | **In-loop CaT-Q（主方法）** | **41.97 ± 2.62** | **80.34 ± 1.94** | 41.39 | 48.38 |
| BookHis | CaT + nearest-5 | 24.83 ± 5.62 | 75.45 ± 4.59 | 24.47 | 28.75 |
| BookHis | Adaptive coherent | 23.47 ± 5.62 | 74.61 ± 5.59 | 23.16 | 26.81 |

粗体标记主方法，不表示该列最优。Old/New 是最终阶段旧类/本阶段新类的 F1，不是所有阶段的平均。

| 数据集 | 主方法减 CaT 的 F1（pp） | 配对 95% CI | 正收益顺序 | 最差顺序差值（pp） |
|---|---:|---:|---:|---:|
| WikiCS | -0.49 | [-2.34, +1.35] | 1/3 | -1.18 |
| SportsFit | +4.85 | [-1.09, +10.79] | 3/3 | +2.15 |
| BookHis | +17.14 | [+8.32, +25.97] | 3/3 | +14.19 |

区间是三个顺序差值的配对 t 区间，没有把三个 Student seeds 当成九个独立顺序。样本仍少，也未作跨比较的多重检验校正；不能把未跨零的区间理解为完整的投稿级泛化证明。

- **BookHis 的收益最明确**：不仅最终 F1，阶段平均 F1 也是 48.03 对 30.73；三个顺序都改善，而非一个好顺序拉高均值。
- **SportsFit 有正向但仍需确认的信号**：最终 F1 三个顺序均提升，阶段平均 F1 为 81.97 对 78.38；但最终 F1 的配对区间跨零，不能写成已确证的统计显著优势。
- **WikiCS 没有优势**：平均 F1/Acc 均略低。区间跨零不等于方法等效，也不能据此宣布非劣。
- 合并查看九个数据集/顺序组合，主方法相对 CaT 为 7/9 正收益；它是描述性计数，不把跨数据集分数直接当同一总体做检验。
- BookHis 的 Accuracy 远高于 Macro-F1，提示类别不均衡下二者应同时解释，不能用约 80% Accuracy 掩盖小类问题。

这轮支持继续保留方法主体，但不支持“所有数据集 SOTA”或“文本模块已证明必要”。更强公开基线还应单独完成，不能只靠 CaT 和内部历史候选得出最终结论。

## 4. 为什么历史 CCTP 约 50，而现在约 80

以下仅用参考顺序，数值为 Final Macro-F1 / Accuracy（百分数），每项平均三个 Student seeds。同一行新旧目标的 memory 完全相同。

| 数据集 | 方法 | 历史逐行 InfoNCE 目标 | 当前 Prompt 目标 |
|---|---|---:|---:|
| WikiCS | CaT + nearest-5 | 53.41 / 58.66 | 80.55 / 83.79 |
| WikiCS | Adaptive coherent | 72.49 / 76.24 | 80.87 / 83.85 |
| WikiCS | In-loop CaT-Q | 49.90 / 53.82 | 80.85 / 84.07 |
| SportsFit | CaT + nearest-5 | 23.29 / 23.01 | 77.28 / 87.47 |
| SportsFit | Adaptive coherent | 49.99 / 71.51 | 75.45 / 86.07 |
| SportsFit | In-loop CaT-Q | 26.54 / 29.73 | 79.44 / 85.72 |
| BookHis | CaT + nearest-5 | 18.12 / 28.58 | 30.79 / 80.28 |
| BookHis | Adaptive coherent | 19.21 / 64.36 | 28.97 / 80.33 |
| BookHis | In-loop CaT-Q | 16.54 / 26.41 | 44.98 / 82.55 |

WikiCS 上 Adaptive 相对 CaT 的 F1 差距由约 +19.08 pp 变为 +0.32 pp；SportsFit 上由约 +26.70 pp 变为 -1.83 pp。这次不再只是跨历史表猜测：在相同 memory 下，改变训练目标族已经足以大幅改变绝对分数及相对排序。

但不能进一步声称“全部由 prompt CE 单独造成”。多正样本规则、prompt CE、margin 及损失配比是作为一个整体切换的，没有逐项分离。直观上，当前目标既改变了同类样本的正负关系，也直接提供类别语义监督，使得 CaT 已有的 X 更容易被下游利用。

当前主方法在旧目标下也没有稳定优于 Adaptive。这是训练目标依赖的证据，不是不同架构泛化的完整实验；后续不能仅凭当前 Prompt Student 的分数宣称普适凝聚优势。

## 5. 文本归因：固定 X 后究竟发生了什么

下表仍为参考顺序，不能用三个 Student seeds 代替三个独立构造实验。所有 random-5 均为同类随机选择，不是从全图跨类别乱选文本。

| 固定的 X 与文本策略 | WikiCS F1 / Acc | SportsFit F1 / Acc | BookHis F1 / Acc |
|---|---:|---:|---:|
| CaT X + nearest-5 | 80.55 / 83.79 | 77.28 / 87.47 | 30.79 / 80.28 |
| CaT X + nearest-1 | 81.10 / 83.76 | 76.96 / 87.00 | 31.52 / 80.69 |
| CaT X + random-5 | 80.70 / 83.68 | 78.41 / 87.78 | 33.14 / 80.43 |
| CaT-Q X + 原生 Q-top1 | 80.85 / 84.07 | 79.44 / 85.72 | 44.98 / 82.55 |
| CaT-Q X + nearest-1 | 81.15 / 84.16 | 79.97 / 85.73 | 45.66 / 81.75 |
| CaT-Q X + nearest-5 | 81.04 / 84.02 | 80.24 / 86.28 | 47.01 / 82.17 |

由此可以说：

1. 主方法在 BookHis 的整体收益没有因文本替换而消失；它不是完全依赖某一套 Q-top1 文本才成立。
2. 目前没有证明原生 Q-top1 的最终文本选择优于简单的 nearest 策略。三个数据集的 nearest-1/5 对照平均 F1 都略高，但这仍是单顺序诊断，不能据此宣称显著优越。
3. CaT 的 graph-nearest-5 也没有在本次参考顺序中稳定优于同类 random-5。因此不能仅凭最终分类指标，声称复杂文本选择已经有充分独立贡献。
4. BookHis 上 nearest-5 提高 F1 的同时 Accuracy 略降，不能把单一指标变化描述成全面改善。
5. 不能从这些对照严格推出“全部提升来自 X”：跨 X 家族的 nearest 选择仍会改变文本来源。现有证据只是更支持继续研究 Q/特征构造，同时补强文本分支的作用解释。

这些是后处理归因对照。其修改后的文本不回馈下一阶段主方法的 X 构造；如果要把 nearest-5 或其他文本规则纳入方法，必须另跑闭环持续构造，不能直接使用本表作为新方法主成绩。

## 6. 接下来如何保持主体而针对问题优化

不改 Q + 受限残差的核心参数化，不扫描最终 F1，不为凑组件数量而追加模块。当前三顺序确认已完成，下一轮优先做：

- 文本路径诊断：记录文本相关梯度对 Q 的贡献、与 DM 梯度的夹角、Q 更新后硬文本是否真的切换，以及软代理改善是否转化为真实文本质量改善。
- 目标一致性诊断：现在的 proxy 同时包含类别 prompt 目标。需判断它是否主要优化了类别可分性，而没有充分约束节点级图文对应关系。
- 必要时仅调整文本耦合目标或硬材料化一致性，不同时加入 EM、拓扑与旧记忆刷新。任何修改均须在新的预注册闭环实验中验证。
- 并行补高保真公开基线；Adaptive、nearest/random payload 不是新增的外部论文基线，不能用它们增加“公开基线数量”。
- 冻结 memory 做架构迁移；当前新旧损失对照不能替代这一项，也不能证明未见类别或跨数据集 zero-shot。

一个优先检查的机制假设是：生成 X 的加权重心与 `argmax(Q)` 选出的文本代表未必一致。最大的单点权重并不意味着该点最接近加权重心，更不意味着其文本最匹配加上残差后的 X。因此，“同一个 Q 同时产生 X 和文本”提供了参数耦合，却不自动保证硬材料化最优。需先量化这种偏差与结果的关联；若得到支持，再设计由统一目标导出的硬投影或量化一致性约束。它目前是待验证解释，不是本轮已经定位的唯一失败原因。

还应区分“没有额外文本 payload”与“完全没有文本信息”：数据集给定的 X 可能本来就是文本派生特征。最终论文必须注明各图 X 的来源，不能把 CaT 的特征分支未经核实地描述成纯拓扑、无文本输入。

当前结果支持继续保留方法主体，但不支持把“统一 Q”自动等同于“已经证明图文耦合的全部增益”。这正是本轮归因实验发现的、下一步需要补强的部分。

建议后续按两个工作包推进：先冻结当前版本，完成高保真公开基线与 construction seed 确认；同时只给文本路径加诊断日志，不改变优化。诊断得到明确证据后，最多提出一个新的硬材料化一致性版本，单独预注册验证。旧方案的结果原样保留，不用新版本覆盖。
