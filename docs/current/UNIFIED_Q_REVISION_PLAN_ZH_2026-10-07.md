# Unified-Q 一致性修复与受控优化

## 冻结内容

本轮保留同一 GraphTextPromptStudent、MiniLM、320 字符/单条真实文本、30 步外层优化、3000 步 CaT、2048 步 Student 和 Student seeds 150/151/152。Student 的默认训练损失不变；新增样本加权参数仅供凝聚代理使用。

构造只接收当前 raw delta 和各方法自己的 frozen synthetic parent。旧 X/文本/旧旧边不更新，不启用 boundary sketch。主候选预先指定为 `uq_semantic`，不按最佳 report-dev cell 重新组合模块。

## 改动与归因

| 方法标识 | 与前一层的区别 | 用途 |
|---|---|---|
| cat_cctp | CaT-MMD + nearest top-5/320 字符文本 | 同协议外部机制适配基线，不是官方完整 TAG 复现 |
| uq_consistent | 去重传播、保留旧边、合法边数、缓存稀疏原始图；旧初始化与节点平均损失 | 修复后锚点 |
| uq_balanced | 在一致性修复上引入新旧组与组内类别均衡 | 梯度目标权重归因 |
| uq_semantic | 再引入特征/邻域消息/文本联合多样性初始化 | 预先指定主候选 |
| uq_text_frozen | 相对 uq_semantic，文本分配固定在 Q0 | 文本路径消融 |
| uq_topology_frozen | 相对 uq_semantic，拓扑固定在 Q0 | 拓扑路径消融 |
| uq_edge_free | 相对 uq_semantic，不生成新拓扑 | 拓扑存在性对照 |
| uq_alternating | 相对 uq_semantic，交替更新 Q 与 R | 相同外层反传次数的交替优化对照，不称严格 EM |

`uq_consistent` 不应称为旧版原样复现：去重原始边也修复了边数计数，过滤了零质量候选边，禁用边界时初始化也不再读取它。旧版结果只保留为历史诊断。

## 梯度目标

存在旧/新两组时，各组损失质量为 1/2；首阶段只有新组，质量为 1。每组内部按类别均分，再按该类行数均分。真实侧和合成侧采用同一定义。

交叉熵和 margin 使用该行权重。图文对比损失同时加权 anchor 和候选分布，而不只是乘一个最终样本权重。因此重复复制同类相同样本并相应分摊质量，不会改变加权对比损失。

原始图使用稀疏去重邻接。大图图文损失按 anchor 分块并 checkpoint，仍使用完整候选集，不进行负样本抽样；单元测试对比值、一阶与二阶梯度。Q 本身仍有稠密 n_delta × m 存储，不能宣称已经完全消除规模风险。

## 初始化

每类 slot 数保持预算决定。联合归一化特征、邻域消息和文本形成签名；先选靠近类中心的真实种子，再用维护最近距离的 farthest-point 选择补充种子。每个种子提供对应的 X、真实邻域消息和文本 prototype。它是确定性覆盖初始化，不声称求得全局最优聚类，也不固定每类 1/2/3 个文本。

## 协议分层

1. 归因层：WikiCS/BookHis，沿用 order9101 和历史固定预算表，construction seed 271006，八个方法完整五阶段。
2. fixed-rate 检查：另开结果目录，按实际累计 delta 行数计算 round(0.05 N_seen)，必要时显式使用 class floor。不得与固定预算表合并计算平均收益。
3. 独立确认：固定方法与参数，用独立顺序及 construction seeds 比较，不根据确认结果重新扫描参数。若尚未完成，结果报告必须明确待补。

测试标签不进入构造或选择。当前指标是 report-dev，不称最终独立 test。原始图的全图传播属于 transductive 评估，与构造器历史 raw 访问限制区分。

## 审计与输出

每阶段验证 budget、finite、旧 memory 前缀和旧旧边不变；验证构造硬图与加载后 Student 传播矩阵一致、前向硬文本与实际文本编码一致。记录新旧损失质量、文本唯一率、Q/R 梯度范数、残差比例、边数、时间、峰值显存、数据 mask/阶段 IDs/源代码 hash。

每个方法仅保留最新阶段 memory，并保存完整阶段统计。输出目录可恢复运行，代码或协议 hash 改变时拒绝混写。不删除旧实验，不覆盖旧结果，不推送仓库。

## 边界

修复不是效果保证。交替优化也不是严格 EM 或收敛保证。旧记忆更新、新旧跨阶段边在本轮因果归因之后再独立设计，不与这一轮共同改变。新增类别文本输入是模型接口能力，未见语义类别的泛化仍需独立评估。
