# Unified-Q-EF 论文中文译稿

本文档对应正式英文稿 `paper_www/main.tex` 当前版本中的摘要、Introduction，以及 Problem Definition and Continual Protocol 两个部分。公式和方法名称保留英文记号，便于与英文正文逐项核对。

## 摘要

文本属性图（text-attributed graph, TAG）的持续凝聚旨在数据分阶段到达、且已经见过的原始节点不能再次访问时，维护一个紧凑的图文记忆。现有基准并未直接覆盖这一设定：持续图凝聚方法通常不保留文本负载，而文本属性图凝聚和蒸馏方法大多面向静态图，或者采用不同的数据访问与训练协议。

本文提出 **Unified-Q-EF**，一种面向历史受限持续 TAG 凝聚的、图感知但无显式合成边的可微分配框架。其类别掩码 Sinkhorn 矩阵 (Q) 统一控制合成槽位分配、特征聚合以及真实文本负载路由。我们在构造循环内部使用类别级分布匹配和与 Student 兼容的梯度目标优化 (Q)，并使用与构造前向过程相同、可审计的真实文本来源来材料化每个槽位的文本。在固定比例的累计保留协议下，主比较采用名义上的 5% 工作点，同时使用仅访问当前增量、冻结历史合成前缀以及统一的基于 prompt 的图文 Student。Unified-Q-EF 在 ArXiv、SportsFit 和 BookHis 上分别取得 Macro-F1/Accuracy 为 52.25/71.59、78.60/83.93 和 41.97/80.34。相对于匹配的 GECC 适配版本，Macro-F1 分别提升 1.16、1.28 和 0.74 个百分点；相对于匹配的 CaT-CCTP 适配版本，在这三个数据集上也均取得更高结果。

在另一个使用相同 Student 家族的、匹配的无边 full-history 参考实验中，紧凑记忆在所评估的大图上基本保持 full-history 的 Macro-F1，并保留至少 96.36% 的 full-history Accuracy。在 WikiCS 上，Unified-Q-EF 具有竞争力，但没有超过 CaT-CCTP，说明该方法并非在所有数据集上都占优。受 STAD、DANCE 和 SR-GM 启发的简化对照使用旧版 Student 单独评估，不用于声称优于这些原始方法。总体而言，结果表明 Unified-Q-EF 为历史受限持续 TAG 中的特征凝聚与文本保留提供了一个统一且可审计的耦合方案。

## 1 引言

### 1.1 动机

图凝聚的目标是用少量合成节点、特征和关系替代大图，同时尽可能保留凝聚记忆对下游学习的效用。梯度匹配方法表明，紧凑的合成集合可以保留大规模图中的重要训练信号 [GCond]。文本属性图使这一问题更加复杂：每个节点不仅有数值特征和图上下文，还可能有文本、标题、描述或其他语义属性。因此，一个凝聚后的 TAG 记忆并不是单一矩阵，而是一个需要由下游图文模型一致解释的多模态接口：

$$
M_t=(X_t,T_t,A_t,Y_t),
$$

其中 (X_t)、(T_t) 和 (Y_t) 分别表示合成特征、文本负载和标签，(A_t) 表示可选的合成拓扑。本文的主方法保存 ((X_t,T_t,Y_t))，不显式保存合成边。

静态 TAG 凝聚通常是在给定原始图上一次性构造摘要。本文研究的则是一个持续访问边界：数据分阶段到达，构造器不能重新读取早期原始增量。在每个阶段，构造器只能使用当前增量和此前保存的合成记忆。该协议带来以下相互关联的问题：

1. 在一个随累计到达数据量增长、同时保持类别覆盖的固定比例累计预算下，本阶段应该新增多少个合成槽位；
2. 当前原始节点应该如何分配到这些槽位；
3. 一个槽位应该如何保持其特征负载与文本负载之间的对应关系；
4. 历史记忆应该冻结、刷新，还是与新槽位建立连接；
5. 生成的记忆能否迁移到不同的下游 Student 架构。

如果在图凝聚完成后再附加文本，文本负载就不会参与特征构造。反过来，如果一个类别中的所有合成节点共享同一段文本，又会丢失类内语义多样性。因此，我们需要一个能够保持数值证据与文本证据对应关系的构造接口。本文使用类别约束的分配矩阵 (Q)，将其作为特征池化、文本路由和构造反馈的共同接口。共享且可微的分配过程在遵守持续访问边界的同时，把这些决策联系起来。

### 1.2 问题设定

我们研究历史原始数据不能被重新读取时的持续 TAG 凝聚。令当前增量为

$$
\Delta_t=(V_t^{\rm raw},X_t^{\rm raw},T_t^{\rm raw},Y_t^{\rm raw},E_t^{\rm raw}),
$$

令 (M_{t-1}) 表示上一阶段保存的合成记忆。构造器接收的输入为

$$
\mathcal{I}_t=\{\Delta_t,M_{t-1}\}.
$$

其中，(E_t^{\rm raw}) 表示由当前构造池节点诱导出的边；历史原始特征、文本和边不属于构造器输入。本文的主要实现 Unified-Q-EF 使用无显式合成边的记忆：历史前缀冻结，每个阶段只追加新的合成行。冻结前缀是本文采用的追加式设计选择，并不是持续学习的一般性要求。当前增量的拓扑仍然用于计算局部消息和传播目标；“无边”指保存下来的合成记忆，而不是说输入完全没有图结构。本文另行定义拓扑感知版本 Unified-Q-T，它根据 (Q) 生成候选合成边。拓扑版本的初步节点分类和结构任务结果单独报告，不替代无边主方法的主比较。

### 1.3 方法概览

本文提出 Unified-Q-EF，一种用于持续 TAG 凝聚的统一可微分配接口。其构造循环包括：

1. 根据当前增量的类别规模分配新的槽位及其标签；
2. 使用当前特征、单跳消息和文本嵌入初始化类别感知的分配；
3. 使用类别掩码 Sinkhorn 算子得到容量平衡的 (Q)。其行将当前原始节点质量分配到槽位，其列平衡同类槽位获得的软支持量；
4. 使用同一个 (Q) 池化合成特征，并路由真实文本负载；
5. 使用梯度匹配、CaT 风格的分布匹配和传播匹配，联合优化 (Q) 的 logits 以及受限的特征残差；
6. 将新构造的特征、真实文本负载、标签和来源元数据作为新的记忆块追加保存。

同一个 (Q) 在构造损失计算之前同时产生池化特征和软文本路由。来自这些损失的梯度会在循环内部更新 (Q)，从而把支持某个槽位的原始证据与兼容 Student 的目标联系起来。硬文本材料化规则属于实现层面的保持一致性措施：它保证构造前向中使用的文本来源，与最终保存的可审计字符串和嵌入相同。软支持平衡并不能保证所有硬选择文本都互不相同，因此文本多样性和分配覆盖率仍需单独测量。

### 1.4 贡献与范围

本文有三项主要贡献：

1. 将历史受限持续 TAG 凝聚形式化为一个固定比例的累计节点预算问题，并给出一个可审计的追加式评估协议，其中明确规定仅访问当前增量以及各基线的身份；
2. 提出 Unified-Q-EF，其共享的类别掩码可微分配 (Q) 同时控制特征池化、真实文本路由和构造反馈，而不是在特征凝聚完成后再把文本作为后处理附加上去；
3. 在多个数据集上进行评估，覆盖多个类别顺序、跨 Student 迁移、成本统计和负向消融。最强的正向信号出现在 SportsFit、BookHis 和 ArXiv 上，而 WikiCS 和 Cora 则揭示了仅共享分配不足以保证提升的条件。

在所评估的 TAG 基准上，实验使用统一的历史受限协议测试记忆保留和迁移能力。结果表明，相较于匹配的 CaT 和 GECC 机制适配版本，本文方法在若干大图上取得提升。组件消融用于分析构造循环中的哪些部分支持这些提升，同时明确共享分配在哪些设定下并不足够。拓扑感知分支是一个初步扩展；跨阶段关系的保留以及面向结构任务的训练式模型仍需要进一步验证。

## 2 问题定义与持续协议

### 2.1 持续 TAG 凝聚

设第 (t) 阶段到达的构造数据为增量

$$
\Delta_t=(V_t^{\rm raw},X_t^{\rm raw},T_t^{\rm raw},Y_t^{\rm raw},E_t^{\rm raw}),
$$

其中 (V_t^{\rm raw}) 是当前构造池节点，(E_t^{\rm raw}) 是这些节点诱导出的边。在类别增量实验中，每个阶段引入一组互不相交的类别，构造池不包含验证节点和测试节点。构造器生成新的合成行，并将其追加到此前记忆：

$$
M_t=M_{t-1}\oplus M_t^+.
$$

对于无边主方法，每个新构造的记忆行包含一个特征、一个文本负载和一个标签。新的记忆块为

$$
M_t^+=(X_t^{\rm syn},T_t^{\rm syn},Y_t^{\rm syn}),
\qquad A_t^{\rm syn}=\varnothing,
$$

其中合成张量只包含第 (t) 阶段的新行，空邻接矩阵是隐式的，不被保存。这是存储形式的选择，并不表示输入增量没有图结构：(E_t^{\rm raw}) 仍然可以被构造器使用，用于计算局部结构信号和传播目标。

我们采用**固定比例的累计节点预算**。在构造开始前选择一个保留比例 (ho\in(0,1])，并在所有阶段保持不变；随着累计到达数据量增长，保存的记忆行数也会增长。这里在问题定义中保留符号 (ho)，避免把协议绑定到某个特定数据集的压缩比例；具体工作点和敏感性实验放在后面的实验设置中。令 (mathcal C_t) 表示当前增量中的类别集合。基于比例的分配包含一个类别覆盖下限：

$$
\begin{aligned}
    \bar K_t&=\operatorname{round}(\rho N_t^{\rm pool}),\\
    K_t&=\max\{\bar K_t,|M_{t-1}|+|\mathcal C_t|\},\\
    m_t&=K_t-|M_{t-1}|,
\end{aligned}
$$

其中

$$
N_t^{\rm pool}=\sum_{s\leq t}|V_s^{\rm raw}|
$$

表示截至第 (t) 阶段已经到达的构造池节点数，(m_t) 是新增合成槽位数。因此，记忆大小随到达数据增长，并以累计构造池的 (ho) 比例为目标。这是固定比例，而不是固定的绝对记忆大小，也不是按字节计算的存储比例。为了覆盖类别而超过 (\\bar K_t) 的部分会记录在审计清单中。

每个当前类别首先获得一个槽位。剩余槽位按照当前类别数量的比例，通过最大余数规则分配，同时限制某个类别的槽位数量不超过该类别原始节点数。本文不手工规定每类固定几个槽位。如果当前预算和原始节点数无法覆盖所有当前类别，则拒绝该配置，而不是静默丢弃某个类别。

基于比例的记忆预算在 CaT 中有先例 [CaT]。这种预算相对于数据规模表达压缩程度，不需要针对不同长度的数据流固定相同的行数。类别覆盖下限保证在小预算取整时，不会让某个少数类别完全从类别增量和 Macro-F1 评估中消失。具体工作比例、确认实验中预先注册的预算调度以及敏感性分析在第 5 节和结果章节中说明。

### 2.2 访问边界

在构造阶段，唯一允许使用的、随阶段变化的图数据输入是

$$
\operatorname{Input}_t=\{\Delta_t,M_{t-1}\}.
$$

历史原始特征、文本和边不能重新读取。此前的合成前缀是只读的：它可以作为上下文使用，但不能被更新或重新优化。Student 使用保存的记忆进行训练。在推理时，评估器在转导协议下使用完整原始图的特征和邻接来计算节点表示；评估标签只用于计算指标。评估端的访问与构造器边界分开，CaT 中也采用了转导式类别增量评估。主配置包括：

- 只读的合成前缀；
- 保存时无显式边、但与自环兼容的合成记忆行；
- 冻结的 MiniLM 文本编码器；
- 新特征和新文本只来自当前增量；
- 用于审计的归档哈希、来源标识、预算字段和划分掩码。

禁止重新读取历史原始数据定义了访问边界；冻结合成前缀则是额外的**追加式设计选择**。CaT 将新凝聚图累积到记忆中，GECC 也研究了冻结旧节点并增长记忆的控制版本。这些工作为追加式比较提供了先例，但 GECC 的原生方法可以更新其代表节点。在本文配置中，冻结前缀可以保留既有特征和文本来源，在缺少相应原始证据时避免反复修改旧摘要。一个早期的旧特征更新控制在两个数据集上降低了 Macro-F1，因此本文采用保守的冻结默认设置；但这一结果并不能说明所有历史记忆更新都无效。冻结的是记忆内容，而不是 Student 参数，因此它本身并不等同于阻止遗忘。

因此，“无边”只适用于保存的合成记忆，而不适用于构造输入。这个区别很重要：本文方法在构造过程中是图感知的，但没有声称主记忆格式能够保留所有跨阶段拓扑。拓扑感知扩展 Unified-Q-T 将单独评估。SFGC 也研究了图感知构造与无显式合成边表示之间的关系；这并不意味着显式合成边对所有下游任务都不必要。

### 2.3 下游预测

下游模型是基于 prompt 的 Student。训练使用记忆标签、prompt 监督以及图文配对损失。预测时不再拟合额外的任务专用分类头，而是比较图表示 (h_i^g) 与每个类别 prompt 的表示 (p_c)。其中 (p_c) 表示经过 Student 文本投影后的归一化类别表示：

$$
\hat y_i=\arg\max_c\cos(h_i^g,p_c).
$$

所有方法共享预先定义的类别 prompt。Student 可以看到 prompt 描述，但训练不会使用构造池之外的原始节点标签。本文将该接口称为**基于 prompt 的余弦读出**。GraphCLIP 也使用类似的 prompt 相似度规则进行 zero-shot 迁移，但它将预训练模型直接应用于目标数据集，不再进行额外的目标数据训练。本文的构造和 Student 训练都使用目标数据集构造池中的标签。因此，两者在预测接口上相关，但本文属于有监督的持续评估协议，并不是 GraphCLIP 式的跨数据集 zero-shot。仅仅不训练任务专用线性分类头，不能单独证明这是 zero-shot 学习。

### 2.4 指标

我们报告最终阶段 Macro-F1、Accuracy、Old F1 和 New F1，同时报告阶段平均性能、最差顺序、构造时间、Student 训练时间和 GPU 峰值显存。Macro-F1 在参与评估的类别上取平均，Accuracy 在同一个评估掩码上计算。Old F1 和 New F1 分别在相同联合预测下，对历史类别和当前引入类别的逐类 F1 取平均。我们区分最终检查点上类别组切片的平均值，以及跨连续检查点的轨迹平均值。在稳定性分析中，还会在预先确定的构造种子、类别顺序和 Student 种子上报告均值、标准差、配对置信区间、正差异单元比例和最差单元。所有主方法和严格基线使用相同的类别顺序、累计保留比例、Student 步数、batch size、文本编码器和评估掩码。

### 2.5 比较层级

为了避免把协议差异错误归因于算法，结果分成五个层级：

1. **严格主比较：** Unified-Q-EF、CaT 机制适配版本和 GECC 机制适配版本；
2. **跨架构迁移：** 使用同一份冻结记忆，换用 Prompt GraphSAGE 进行评估；
3. **内部组件归因：** no-GM、no-DM、fixed-(Q)、no-residual、Q-medoid 以及相关变体；
4. **历史与简化参考：** 使用旧实现或旧 Student 的 PUMA/TAGSAM 覆盖结果，以及 STAD/DANCE/SR-GM inspired controls；
5. **检查点、离线及文献参考：** GraphCLIP 检查点、full-history raw data、GCond、SFGC，以及不满足共同构造与评估协议的其他方法。

**匹配适配版本**必须说明保留了哪些发表机制，并核对共同的访问边界、预算、Student 和评估掩码；它不等于官方端到端复现。省略核心模块的简化对照、旧 Student 结果和官方检查点评估分别标注。仅使用官方代码或权重，既不能证明原生协议被完整保留，也不能证明与主表可比。

## 译稿核对说明

- “fixed-rate cumulative node budget”统一翻译为“固定比例的累计节点预算”，强调记忆行数会随累计到达数据增长，不是固定行数，也不是字节比例。
- 5% 是后续实验中的名义工作点，不在问题定义中把协议限定为 5%。ArXiv 旧主表的 6,773 行按当前合法构造池计算为 5.71%，因此正文中单独披露，不能直接当作严格 5% 曲线上的点。
- “edge-free”只表示主方法不保存合成拓扑；当前增量的原始边仍用于构造阶段的局部消息和传播目标。
- Student 的 prompt 余弦读出与 GraphCLIP 的预测接口相似，但当前实验仍使用目标构造池标签进行训练，因此不应表述为严格 GraphCLIP zero-shot。
- 历史前缀冻结是追加式实现选择，有早期旧特征更新实验作为动机，但不是持续学习问题的普遍要求。
