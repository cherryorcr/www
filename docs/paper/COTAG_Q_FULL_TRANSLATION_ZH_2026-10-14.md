## 论文信息

**标题：CoTAG-Q：面向历史访问受限持续式 TAG 凝聚的共享图文分配**

作者：Rui Chai、Ruijie Wang。

会议元数据：The Web Conference（WWW），2027，地点待定。当前使用 ACM `sigconf` 格式。

## 摘要

持续式文本属性图（text-attributed graph，TAG）凝聚需要在不重新访问历史原始数据的情况下，将图信息和可读的节点文本保存在紧凑记忆中。仅面向图的持续凝聚方法需要额外的文本接口，而静态 TAG 凝聚方法并未直接处理这一访问约束。我们提出 CoTAG-Q，一种以共享图文分配矩阵 \(Q\) 为核心的持续式 TAG 凝聚方法。类别受限、容量平衡的分配将图感知特征池化与真实文本路由耦合，使文本侧反馈能够调整用于构造合成特征的同一组支持权重。通过梯度匹配、类别级分布匹配和槽位级传播匹配，联合优化分配 logits 与受限的特征修正。当前图的结构指导记忆构造；最终得到的无显式边记忆则向冻结的历史前缀追加新行。

在累计为合法构造池节点数 5% 的节点预算和统一的基于 prompt 的 Student 下，针对三种类别顺序和三个构造种子的配对评估表明：在 ArXiv、SportsFit 和 BookHis 上，CoTAG-Q 相比 CaT-CCTP 适配版本的 Macro-F1 提升了 5.58–19.66 个百分点。在 BookHis 上，CoTAG-Q 相比 GECC-hard-TAG 进一步提升了 3.47 个百分点，且全部九个配对单元均取得正收益。在另一个独立的 full-history 对比中，相对于无显式边的完整历史原始数据参考，保留约 5% 的节点（ArXiv 为 5.71%）能够保留 100.45–109.50% 的 Macro-F1，以及 96.36–100.03% 的 Accuracy。这些结果说明，在历史访问受限的条件下，联合构造图文记忆具有实际价值。

**关键词：**文本属性图；持续式图凝聚；历史访问受限；共享图文分配；可微文本路由；基于 prompt 的读出。

## 1 引言

### 1.1 研究动机

文本属性图（TAG）将关系结构与节点级语言信息结合起来。节点可以由标题、摘要或短文档描述，而对节点的预测也依赖数值属性和图上下文。图凝聚旨在用规模显著更小的训练记忆替代大图，同时保留下游模型所需的信息。在 TAG 中，这种记忆具有多模态性质：一个有效的合成条目需要保留相互兼容的特征、标签和可解释的文本负载。

这一问题的持续式版本不同于反复运行静态 TAG 凝聚方法。数据分阶段到达，构造器可能无法重新读取早期阶段的原始节点。在阶段 \(t\)，它必须根据当前增量和已保存的记忆构建新的记忆块。这一访问边界带来实际矛盾：构造器需要保留过去的信息，却不再拥有最初承载这些信息的原始特征、文本或边。同时，它还必须决定保留多少当前增量数据、如何向少数类分配槽位，以及如何使合成特征与文本负载保持语义兼容。

### 1.2 面临的挑战

我们关注持续式 TAG 凝聚中相互关联的三个挑战。

**历史访问受限的构造。** 静态凝聚方法可以反复查看完整源图，但这里不具备这一条件。合法的阶段 \(t\) 构造器只能接收当前增量和上一阶段保存的合成记忆。因此，方法必须明确哪些信息由记忆本身向后传递，而不能隐式依赖历史原始数据。对于类别增量流，这尤其重要，因为槽位分配中的一个小错误就可能使少数类从记忆中消失。

**多模态一致性。** 在持续式图基线中，特征凝聚与文本附着通常被实现为两个独立操作：图构造器先生成合成特征，随后文本负载适配器选择源文本。这是合理的工程对照，但所选文本不能影响特征分配或构造目标。TAGSAM 和 STAD 等静态 TAG 方法包含实质性的文本感知机制，因此问题并非所有既有工作都忽略了文本。本文处理的缺口是：在历史访问受限的设定下，缺少一个同时用于特征支持和真实文本路由、且可审计的统一分配接口。

**超越单一 Student 的迁移。** 凝聚记忆可能因为构造过程隐式过拟合了某个下游编码器而显得有效。因此，我们将构造过程与评估 Student 分离，并将同一份冻结记忆用于第二种图编码器。这检验了记忆能否迁移到主要读出模型之外，而不声称其适用于所有架构。

### 1.3 我们的方法

我们提出 CoTAG-Q：一种以共享图文分配矩阵 \(Q\) 为核心、采用图感知构造和无显式边主记忆的持续式 TAG 凝聚框架。每个阶段，当前图提供节点特征、文本嵌入和局部消息。我们创建一组新的合成槽位，并通过类别掩码可微分配矩阵 \(Q\) 将当前原始节点连接到这些槽位。同一个 \(Q\) 用于计算四个相关量：

1. 池化后的合成特征；
2. 真实文本嵌入上的软路由；
3. 传播匹配所使用的图消息路由目标，以及循环内目标的合成输入；
4. 用于将可审计真实文本负载写入记忆的硬选择源标识。

分配初始化综合了同类节点的特征相似度、一跳图消息相似度和冻结 MiniLM 的文本相似度。对数空间 Sinkhorn 归一化使每一类槽位接收到的质量保持平衡。构造过程中，利用与 Student 兼容的梯度匹配项、CaT 风格的分布匹配和传播匹配，在循环内优化分配 logits 与小幅受限的特征残差。最终记忆保存由学习后的分配选出的真实源文本；直通路由使构造前向和保存的文本负载使用同一来源，同时保留通向 \(Q\) 的可微路径。

主记忆不保存显式边：它只保存特征、文本、标签和审计元数据，不保存合成邻接矩阵。这是有意限定的研究范围，并不意味着忽略输入图。当前阶段的边用于局部消息和构造目标。我们将另一个写入合成边的分支称为 CoTAG-Q-T，并将其作为结构性下游任务的扩展进行评估。

### 1.4 贡献与研究范围

本文的贡献如下：

1. 形式化历史访问受限的持续式 TAG 凝聚：构造仅访问当前增量，采用固定比例的累计节点预算。只追加的记忆无需重新访问原始来源即可保留历史合成行，并明确区分构造器访问权限与评估端的传导式预测。
2. 提出 CoTAG-Q，使用一个类别受限的可微分配矩阵 \(Q\)，耦合图感知特征池化、真实文本路由和循环内的 Student 兼容目标。文本侧反馈可以改变构造特征的支持权重，而非仅在特征优化后附着文本。硬一致的材料化使保存的文本负载可读且可重新编码。
3. 在五个数据集上评估适配方法和对照，并在三个大图上完成九单元的类别顺序／构造种子配对评估，辅以组件诊断、跨架构迁移和构造成本测量。在 BookHis 上，相比 GECC-hard-TAG 获得稳定的 3.47 个百分点 Macro-F1 增益；独立的 full-history 比较说明，小节点保留比例下仍能保留较高的预测效用。

本文面向基于 prompt 的节点分类，使用图感知、无显式边的训练记忆。共享 \(Q\) 在构造上保证特征和文本采用相同的分配权重；其对预测、参数数量和构造成本的影响，通过独立分配对照进行评估。拓扑分支单独研究。上述范围区分了记忆的预测效用、显式拓扑保持和未见类别零样本迁移。

## 2 问题定义与持续式协议

### 2.1 持续式 TAG 凝聚

设阶段 \(t\) 到达的合法构造数据为

\[
\Delta_t=(V_t^{\rm raw},X_t^{\rm raw},T_t^{\rm raw},Y_t^{\rm raw},E_t^{\rm raw}),
\]

其中，\(V_t^{\rm raw}\) 包含当前构造池节点，\(E_t^{\rm raw}\) 包含本阶段可用的边。验证节点和测试节点不进入构造池。以 \(M_{t-1}\) 表示上一阶段保存的合成记忆。合法构造器接收

\[
\mathcal I_t=\{\Delta_t,M_{t-1}\},
\]

并返回追加后的记忆

\[
M_t=M_{t-1}\oplus M_t^+.
\]

对于无显式边主方法，每个新行包含特征、文本负载和标签：

\[
M_t^+=(X_t^{\rm syn},T_t^{\rm syn},Y_t^{\rm syn}),\qquad A_t^{\rm syn}=\varnothing.
\]

空的合成邻接关系以隐式方式表示，不进行保存。这不意味着输入增量不具有图结构：构造器可访问 \(E_t^{\rm raw}\)，并将其用于局部结构信号和传播目标。

### 2.2 固定比例的累计预算

我们使用固定比例的累计节点预算，而非固定绝对记忆容量。令 \(\rho\) 在构造前确定，\(N_t^{\rm pool}=\sum_{s\leq t}|V_s^{\rm raw}|\) 表示阶段 \(t\) 之前累计观察到的合法构造节点数。名义累计目标为

\[
\bar K_t=\operatorname{round}(\rho N_t^{\rm pool}).
\]

为避免舍入导致某类从类别增量记忆中消失，我们使用明确记录的类别覆盖下限：

\[
K_t=\max\{\bar K_t,|M_{t-1}|+|\mathcal C_t|\},\qquad m_t=K_t-|M_{t-1}|,
\]

其中，\(m_t\) 为新槽位数，\(\mathcal C_t\) 为当前增量中出现的类别集合。如果覆盖下限使 \(K_t\) 超过名义目标，会在审计清单中记录实际比例。主要比较采用 \(\rho=5\%\)，分母为合法构造池，而非包含留出节点的完整图。

每个当前类别先分配一个槽位。剩余槽位按照当前类别节点数的比例，通过最大余数法分配；每类配额不超过该类可用原始节点数。这既避免了“每类三个槽位”一类人工规则，也防止小类消失。如果调度无法在可用原始行范围内覆盖全部当前类别，则拒绝该调度并报告，而不是默默改变任务。

固定比例形式参考 CaT 的比例式持续记忆设计：随着数据流增长，记忆也增长，但跨数据集和阶段的压缩程度保持可比。主要比较使用预先规定的 5% 工作点。第 6.2 节中的独立 report-development 凝聚率敏感性研究检验其性能与构造成本权衡；它不是对比例选择过程的独立检验。

### 2.3 访问边界与记忆语义

构造访问规则为

\[
\operatorname{Input}_t=\{\Delta_t,M_{t-1}\}.
\]

不能重新读取历史原始特征、文本和边。主协议中的合成前缀为只读：其行可以作为已保存上下文使用，但新增记忆块时不重新优化这些行。这一只追加设计叠加在原始数据访问边界之上，并非唯一可能的持续学习策略。冻结前缀能够隔离每个新增量的构造，并在原始来源不可用时保留已有文本负载。使用较早拓扑实现的旧记忆更新试验在两个数据集上得到了更低的 Macro-F1（见附录 A）；这支持将刷新实验单独报告，但不能证明刷新一定损害最终方法。

构造时，可用当前增量计算图消息。Student 训练时，各方法通过共同接口、训练预算、文本编码器和 prompt 定义使用各自保存的记忆。评估时，传导式评估器可以按照数据集协议使用完整图的特征和邻接关系；这一评估端权限与构造边界分离，不会向构造器开放历史原始数据。

因此，主方法的保存接口为

\[
M_t=\{X_t^{\rm syn},T_t^{\rm syn},Y_t^{\rm syn},\text{audit}_t\},
\]

审计字段包含来源标识、划分掩码、实际预算和构造哈希。CoTAG-Q 不保存合成边。拓扑分支 CoTAG-Q-T 构造并保存独立的合成邻接矩阵，作为扩展评估，不纳入无显式边主结论。

### 2.4 文本处理与 Student 读出

匹配的 Prompt Student 比较面板使用相同的冻结 MiniLM 编码器。文本按共同规则清理，并在编码前限制为 320 个字符。此限制是实现层面的记忆和分词器控制，并非认为更长文本没有信息；同一规则应用于这些面板内所有使用文本的方法。历史 Legacy Student 实验和使用本地 Qwen 的 STAD 参考具有不同模型约定，因此单独报告。

主要下游模型为基于 prompt 的图文 Student。训练使用记忆标签、类别 prompt 和图文配对损失。预测时不额外拟合任务专用分类头，而是比较图表示 \(h_i^g\) 与各类别 prompt 的归一化表示 \(p_c\)：

\[
\hat y_i=\arg\max_c\cos(h_i^g,p_c).
\]

这是基于 prompt 的余弦读出，与 GraphCLIP 使用的读出相关，但并非严格的未见类别零样本学习：构造和 Student 训练仍使用当前评估协议中的标签。主要比较使用 Prompt-GCN，迁移和稳健性检查使用相同记忆与文本接口下的 Prompt-SGC 和 Prompt-GraphSAGE。

### 2.5 评估协议

报告最终 Macro-F1 和 Accuracy。对于持续式分析，还报告 Old F1 与 New F1；新旧组由类别到达阶段定义。主要报告区分三类证据：

1. **事后固定掩码配对评估：**登记凝聚率、合法池、类别顺序集合、构造种子集合和 Student 种子集合。留出掩码已经被反复查看，并非新鲜盲测或 sealed test。
2. **Report-development 比较：**用于调试、凝聚率敏感性和方法开发，但不据此重写主要固定掩码表。
3. **仅作参考的评估：**官方检查点、简化的 inspired 对照，或原生任务和访问边界不同于持续式 TAG 凝聚的方法。

主要九单元比较包含共同 Student 和访问边界下的 CaT-CCTP、GECC-hard-TAG。另一个单顺序五数据集面板在相同 Student 下增加选择对照、PUMA-inspired、GCond-x 核心和受限 SFGC 核心，但各构造器预算不相等。TAGSAM、STAD、DANCE、SR-GM 和 GraphCLIP 的实现或评估状态在第 3 节说明；适配实验从不表述为官方复现。独立分配、no-GM、no-DM、fixed-Q、类共享文本和随机文本等内部变体属于组件消融，而非外部基线。

## 3 相关工作与基线适配

### 3.1 图凝聚与无显式边记忆

图凝聚构造小规模训练集，使其效用逼近更大图。GCond 匹配真实图与合成图产生的梯度，可以联合优化合成特征和参数化邻接矩阵。其 GCond-x 设定已表明：构造过程中可以使用图，但下游凝聚表示实际上不保存显式边。SFGC 通过训练轨迹匹配研究了相关的无图方向。这些工作说明，使用图信息构造而不保存合成边是已有设计选择；本文不将其作为新的基本技术。GCondenser 是该类方法的基准与评估工具集，并非额外的构造算法。

CaT 是最接近的持续式图凝聚先例。它通过类别级分布匹配和 Training-in-Memory 为新到达数据构建凝聚图记忆，并跨阶段累计记忆。其特征更新基于梯度，但核心操作不等同于 GCond 对完整参数梯度场的匹配。CaT 没有为 TAG Student 定义可读文本负载接口。因此，我们的 CaT-CCTP 保留 CaT 风格的特征构造，再加入 TAG 评估所需的共同当前增量文本附着。

PUMA 利用伪标签、高效传播和重新训练策略扩展持续式图学习。其原生假设与历史访问受限 TAG 记忆不完全一致。我们的单顺序 PUMA-inspired 使用本地伪教师包装，而非完整官方方法；它是有效的参考，在部分数据集上也有竞争力。

GECC 面向图规模和记忆规模增长时的可扩展凝聚。它在每个类别内部聚类传播特征，包含硬分配与软分配变体，并在演进过程中池化聚类代表。因此，类别级软分配与质心池化均属于已有技术。主要匹配基线 GECC-hard-TAG 保留硬聚类分支，并加入与本文方法相同的文本接口和 Student；不声称复现了全部原生 GECC 变体。

### 3.2 静态与多模态 TAG 方法

TAGSAM 是静态 TAG 凝聚方法，通过文本块选择与合并，以及属性相似性匹配进行构造。它直接处理可读文本和图文学习，因此本文贡献并非简单地“使用文本”。区别在于访问边界：TAGSAM 可从静态源图构造，而本文构造器必须在不重新读取历史原始节点的情况下追加新块。施加本文的类别增量槽位配额和冻结前缀，会改变其监督与优化假设，因此报告为适配。

STAD 研究半监督静态 TAG 蒸馏，结合图感知和无图编码器、协同自训练、Wasserstein 风格 sketch，以及从聚类关键词生成文本。将这些组件替换为本地特征聚类与源文本选择，可作为参考，但不是忠实复现。因此，简化大图行标记为 STAD-inspired。另一组 STAD 核心适配使用本地 Qwen 生成，并改变内部半监督划分；两组均未复现原始静态协议。

DANCE 面向联邦 TAG 学习，其轮次设定、层次化邻居文本证据、可读摘要和自表达拓扑重构解决的是另一个系统问题。将根节点文本与邻居文本拼接的本地持续式包装并未复现这些机制，因此明确标为 DANCE-inspired。

SR-GM 研究静态多模态凝聚，使用模态梯度冲突投影和梯度场的 Dirichlet 阻尼。它启发我们测量图与文本目标的冲突，但其原生优化调度和模态不同于本文持续式 TAG 协议。小型代理细化可作为机制参考，不能作为官方复现。

GraphCLIP 是图文预训练与迁移模型，而非凝聚算法。其 prompt 风格读出启发了本文 Student 接口，但在本地子集上评估冻结 GraphCLIP 检查点，只是官方检查点参考，而非共同预算下的凝聚基线。

### 3.3 什么是公平基线

数值比较使用三类标识：

- **官方复现：**保留发表论文的任务、数据访问假设、核心目标、下游模型和评估协议。任务改变时，仅使用官方代码或权重，并不足以使实验成为官方复现。
- **匹配的机制适配：**保留核心机制，但改变访问包装、记忆格式、文本接口和 Student，使其能够在持续式 TAG 协议下比较。
- **简化的 inspired 对照：**只保留高层思想，并省略某个原生核心模块。它具有参考价值，但不能证明优于发表的完整算法。

九单元外部表包含匹配的 CaT-CCTP、GECC-hard-TAG。五数据集单顺序共同 Student 表还包含四种选择对照、PUMA-inspired，以及适配的 GCond-x 和 SFGC 核心。受限 TAGSAM 和本地 Qwen STAD 核心因构造预算或监督方式明显不同而单独报告。任何适配核心的低分都不代表完整发表算法的表现。

### 3.4 已实现的外部适配

CaT-CCTP 从当前真实特征初始化合成特征，并在一跳传播目标的随机线性与 ReLU 投影中进行类别级分布匹配优化。随后，CCTP 按图特征相似度对同类当前增量节点排序，选择最多五个源文本，分配总计 320 个字符的预算，拼接所选字符串，再用共同 MiniLM 重新编码。文本负载在特征构造后附着，不反馈至 CaT 更新。

GECC-hard-TAG 在每类内部对当前增量传播特征进行平衡硬聚类，使用簇内误差和规模惩罚，从可审计的多个硬聚类重启中选择最优结果，再应用相同的五来源文本适配器。包装使用共同冻结前缀和 Student，因此是匹配的机制适配，而非对原生 GECC 基准的复现声明。

较早的简化 STAD-inspired、DANCE-inspired 和 SR-GM-inspired 使用 Legacy Student，保留为独立历史参考。较新的五数据集 PUMA-inspired、四种选择对照、GCond-x 核心和受限 SFGC 核心，在单顺序面板中使用共同 Prompt Student 和掩码。受限 TAGSAM 和本地 Qwen STAD 核心也在三个大图上使用该 Student，但构造预算或监督不同，列入单独参考表。GraphCLIP 的冻结检查点属于不同模型参考，而非构造器比较。

### 3.5 与 CoTAG-Q 的关系

本文在上述基线未直接提供其交互方式的设定中，组合了已有技术。Sinkhorn 归一化、池化、梯度匹配、分布匹配和可读源文本选择均是已知操作。方法贡献在于：历史原始数据不可用时，让一个类别受限分配矩阵 \(Q\) 成为特征支持、文本支持和构造反馈的共同接口。这使保存的文本具有可审计来源，并使构造目标指向同一个分配。

共享分配是一种结构假设，而非保证精度提高的机制。因此，加入独立特征／文本分配和随机或固定分配对照。现有独立分配结果未证明仅凭共享就能提高 F1。无显式边 CoTAG-Q 与拓扑分支 CoTAG-Q-T 单独评估，因为它们支持不同下游结论。

## 4 方法：共享图文分配

### 4.1 构造接口与可训练变量

**图注（`fig:method_flow`）：**CoTAG-Q 的构造过程。当前图、特征和文本证据初始化类别受限分配。循环内目标联合更新其 logits 和受限特征修正。保存的记忆包含特征、真实文本负载和标签；合成边属于单独的 CoTAG-Q-T 扩展。

![当前英文稿的方法流程图](D:/Aprojects/continue_tag_condensation/paper_www/figures/unified_q_flow.png)

阶段 \(t\)，CoTAG-Q 读取当前合法增量 \(\Delta_t\) 与冻结合成前缀 \(M_{t-1}\)。第 2 节的固定比例调度为 \(n_t\) 个当前节点分配 \(m_t\) 个新槽位。每个当前类别至少有一个槽位，其余按节点数比例分配。用 \(\mathcal I_c\)、\(\mathcal J_c\) 分别表示类别 \(c\) 的原始行和槽位。上下文明确时省略阶段下标。

构造变量为分配 logits \(Z\in\mathbb R^{n\times m}\) 和特征修正 \(R\in\mathbb R^{m\times d_x}\)。类别掩码 Sinkhorn 算子将 \(Z\) 映射为 \(Q\)，其中 \(Q_{ij}\) 表示原始节点 \(i\) 对槽位 \(j\) 的贡献。同一个 \(Q\) 池化特征并路由文本。不更新原始特征或文本编码器；历史记忆行和构造代理参数在该循环中也保持固定。输出为追加的特征、可读文本和标签块：

\[
M_t=M_{t-1}\oplus\{(x_j^{\rm syn},t_j^{\rm syn},y_j^{\rm slot})\}_{j=1}^{m}.
\]

循环前没有单独的 CaT 优化：CaT 风格分布匹配直接置于联合更新内部。图用于记忆构造，而主方法保存的记忆没有合成边。

### 4.2 图文证据与原型初始化

\(\operatorname{Norm}(v)\) 表示带数值保护的逐行欧氏归一化。区分原始特征 \(x_i^{\rm raw}\) 与单位长度版本 \(u_i=\operatorname{Norm}(x_i^{\rm raw})\)。当前文本合并多余空白并限制为 320 个字符，尽可能回退到词边界。冻结 MiniLM 产生

\[
e_i=\operatorname{Norm}(\operatorname{MiniLM}(t_i^{\rm clean})).
\]

候选池包含当前合法增量中的全部文本。预处理后再编码，因而构造嵌入对应可保存的字符串。不需要生成文本或访问历史原始文本。

我们针对不同目的使用两种结构信号。令 \(A\) 为当前增量去重后的无向二值邻接矩阵，不含自环。初始化消息为

\[
h_i=\operatorname{Norm}((AU)_i+10^{-6}u_i),\qquad U=[u_1;\ldots;u_n].
\]

它描述邻居特征的方向，小幅自项为孤立节点提供回退。匹配目标使用带自环的归一化算子：

\[
\widehat A=D^{-1/2}(A+I)D^{-1/2},\qquad H=\widehat A X^{\rm raw},
\]

其中 \(D\) 为 \(A+I\) 的度矩阵。\(H\) 基于原始、未归一化特征计算。因此，初始化方向与传播匹配目标是明确不同的量。

为初始化槽位，定义联合签名：

\[
v_i=\operatorname{Norm}([\sqrt{w_x}u_i;\sqrt{w_h}h_i;\sqrt{w_e}e_i]).
\]

每类第一个原型为余弦相似度最接近该类归一化平均签名的节点；后续原型最大化与此前选中签名的最小余弦距离：

\[
i_{r+1}=\arg\max_{i\in\mathcal I_c\setminus\mathcal P_r}\min_{\ell\in\mathcal P_r}(1-v_i^{\mathsf T}v_\ell).
\]

各选中节点提供特征、消息和文本原型 \((p_j^x,p_j^h,p_j^e)\)。初始类内 logits 为

\[
Z_{ij}^{0}=w_xu_i^{\mathsf T}p_j^x+w_hh_i^{\mathsf T}p_j^h+w_ee_i^{\mathsf T}p_j^e,\quad i\in\mathcal I_c,\ j\in\mathcal J_c.
\]

所有数据集主配置使用 \((w_x,w_h,w_e)=(1,0.75,0.35)\)。原型确定初始化后保持固定；后续学习 \(Z\)、\(R\)，而非反复选择新原型。

该初始化提供图文支持先验，而非已完成凝聚的特征。初始池化特征会随分配变化而改变。文本先参与原型和兼容性评分，再参与可微代理损失。

### 4.3 类别受限、容量平衡的分配

某类含 \(n_c\) 个原始行和 \(m_c\) 个槽位，对 \(Z_c/\tau\) 使用 Sinkhorn 归一化，边缘约束为

\[
Q_c\mathbf 1=\mathbf 1,\qquad Q_c^{\mathsf T}\mathbf 1=\frac{n_c}{m_c}\mathbf 1.\tag{Q 边缘约束}
\]

每个原始节点贡献单位总质量；同类槽位接收相同总容量。等价地，这是在上述约束下最大化 \(\langle Q_c,Z_c\rangle+\tau\mathcal H(Q_c)\) 的熵正则分配，其中 \(\mathcal H(Q_c)=-\sum_{ij}Q_{ij}\log Q_{ij}\)。

实现从 \(L=Z_c/\tau\) 开始，交替进行对数空间行、列缩放：

\[
L_{ij}\leftarrow L_{ij}-\operatorname{LSE}_k L_{ik},
\]

\[
L_{ij}\leftarrow L_{ij}+\log(n_c/m_c)-\operatorname{LSE}_k L_{kj}.
\]

\(\operatorname{LSE}\) 为 log-sum-exp。先执行 30 轮缩放；若最大行质量误差或相对列质量误差超过 \(10^{-4}\)，继续迭代，最终确认配置最多为 4,096 轮。主温度 \(\tau=0.35\)。

只有合法类别块进入计算。尽管未使用的 logits 被分配有限哨兵值 \(-10^4\)，完整 \(Q\) 初始化为零，只填入合法块。因此，跨类别贡献严格为零，而不是很小的负池化权重。

容量平衡避免绝大多数原始质量被少量槽位占据、其余槽位缺少支持，但不要求不同槽位选择互不相同的硬文本；文本来源多样性单独测量。以 \(Q_0\) 表示由 \(Z^0\) 得到并脱离梯度图的初始分配。

### 4.4 共享特征支持与真实文本路由

令 \(a_j=\sum_iQ_{ij}\)，在原始尺度上池化特征：

\[
\bar x_j(Q)=\frac{\sum_iQ_{ij}x_i^{\rm raw}}{a_j},\qquad x_j^{\rm syn}=\bar x_j(Q)+r_j.\tag{Q 特征}
\]

初始化 \(R=0\)，并限制每个修正：

\[
\|r_j\|_2\leq\epsilon_x\max(\|\bar x_j(Q)\|_2,10^{-3}),\qquad\epsilon_x=0.05.\tag{残差半径}
\]

修正允许槽位偏离严格平均值，同时避免成为自由优化、与来源无关的特征。每次更新后，投影尺度基于当前池化特征重新计算。

同一分配还定义软文本表示：

\[
\widetilde e_j(Q)=\operatorname{Norm}\left(\frac{\sum_iQ_{ij}e_i}{a_j}\right).
\]

为保存可读文本，主方法选择一个同类来源：

\[
i_j^\star=\arg\max_{i\in\mathcal I_{y_j^{\rm slot}}}Q_{ij},\qquad t_j^{\rm syn}=t_{i_j^\star}^{\rm clean}.
\]

不同槽位可以选不同文本，也可以在某文本在多个列中权重最大时选中同一个文本。这是节点专属选择，不是预设的类共享负载。

Argmax 没有有用的普通导数，因此构造使用直通文本值：

\[
e_j^{\rm ST}=e_{i_j^\star}+\widetilde e_j-\operatorname{sg}(\widetilde e_j).\tag{文本直通估计}
\]

其中 \(\operatorname{sg}\) 停止梯度。数值前向值为选中的真实文本嵌入；相对于 \(Z\) 的反向导数由经过 \(Q\) 的软路由提供。不对 argmax 本身求导。这是代理梯度，而非离散文本选择的精确导数。

最后一次更新后重新计算 \(Q\)，使用相同选择规则保存清理后的字符串、来源标识和重新编码的嵌入。保存嵌入与构造时所选嵌入的差异须在 \(10^{-4}\) 内。这一材料化约定避免从软训练表示到另一种保存负载的未报告切换。编码器和原始文本字符串始终固定。

### 4.5 循环内图文匹配

各损失提供互补监督：梯度匹配比较整体图文记忆产生的学习信号；分布匹配保留当前类别级图统计；传播匹配约束各槽位表示的图消息。

**与 Student 兼容的梯度匹配。** 实例化一个随机初始化的两层 GCN 代理，图与文本投影参数记为 \(\theta\)。真实侧输入为两个块的块对角组合：带自环的冻结前缀，以及使用 \(\widehat A\) 的当前原始图。合成侧输入为相同前缀与新槽位，全部使用单位传播。主方法两侧均不增加跨阶段边。

代理损失为

\[
L_{\rm proxy}=0.5L_{\rm pair}+L_{\rm prompt}+0.1L_{\rm margin}.
\]

\(L_{\rm pair}\) 为以同类条目作为正样本的双向多正样本图文 InfoNCE；\(L_{\rm prompt}\) 是投影后的类别 prompt 余弦相似度上的交叉熵；\(L_{\rm margin}\) 在正确 prompt 与最强错误 prompt 之间使用 0.20 的间隔。旧类和新类均存在时，两组各分配一半损失质量。组内类别权重相等，然后在其节点间均匀分配。这样可避免规模大的当前类别压倒已保存历史监督。

代理参数固定，参数梯度为

\[
g_r=\nabla_\theta L_{\rm proxy}(M_{t-1}\oplus\Delta_t),\qquad g_s=\nabla_\theta L_{\rm proxy}(M_{t-1}\oplus M_t^+).
\]

真实梯度脱离梯度图，每阶段缓存一次。每个构造步重新计算合成梯度并保留其求导图。最小化

\[
L_{\rm GM}=1-\cos(g_r,g_s)+0.25\left|\log\max(\|g_r\|_2,\eta)-\log\max(\|g_s\|_2,\eta)\right|,\qquad\eta=10^{-8}.\tag{GM}
\]

反向传播涉及二阶导数：反馈经池化特征和直通文本路由到达 \(Z\)，经合成特征到达 \(R\)。代理仅用于构造；下游 Student 在保存的记忆上重新训练。

特征路径为 \(Z\rightarrow Q\rightarrow X^{\rm syn}\rightarrow g_s\)，文本路径为 \(Z\rightarrow Q\rightarrow\widetilde E\rightarrow E^{\rm ST}\rightarrow g_s\)。二者汇合于同一个代理梯度和分配更新。因此，文本损失梯度可以改变同时池化特征的支持权重，后续更新也可以改变所选源文本。源字符串固定；token 或生成文档不是优化变量。

**CaT 风格的分布匹配。** 参考 CaT 的随机投影类别统计匹配，抽取固定投影矩阵 \(W_b\)，定义 \(\phi_b(v)=\operatorname{Norm}(\operatorname{ReLU}(vW_b))\)。对于每个当前类别：

\[
\mu_{bc}^{r}=\frac{1}{n_c}\sum_{i\in\mathcal I_c}\phi_b(H_i),\qquad\mu_{bc}^{s}=\frac{1}{m_c}\sum_{j\in\mathcal J_c}\phi_b(x_j^{\rm syn}).
\]

损失为

\[
L_{\rm DM}=\frac{1}{B}\sum_{b=1}^{B}\sum_{c\in\mathcal C_t}\|\mu_{bc}^{s}-\mu_{bc}^{r}\|_2^2.\tag{DM}
\]

主配置使用四个 Xavier 初始化、宽度 512 的投影。真实目标为固定当前图消息，合成消息为单位传播下的特征自身。该项在循环内更新 \(Z\)、\(R\)，属于图特征分布匹配，而非独立的节点级图文联合分布目标。

**槽位级传播匹配。** 对每个槽位，计算路由图目标与合成方向：

\[
h_j^{\rm target}(Q)=\operatorname{Norm}\left(\frac{\sum_iQ_{ij}H_i}{a_j}\right),\qquad h_j^{\rm syn}=\operatorname{Norm}(x_j^{\rm syn}).
\]

余弦损失为

\[
L_{\rm prop}=\frac{1}{m}\sum_j\left(1-(h_j^{\rm target})^{\mathsf T}h_j^{\rm syn}\right).\tag{传播匹配}
\]

与类别均值匹配不同，此项作用于单独槽位。目标路由和合成特征均依赖 \(Q\)，因此也影响分配。它将当前结构信息转移至特征，而不重构或保存合成边。

### 4.6 联合更新与记忆材料化

完整主方法目标为

\[
L=L_{\rm GM}+L_{\rm DM}+0.5L_{\rm prop}+0.1L_Q+0.1L_X,\tag{总目标}
\]

初始化与修正惩罚为

\[
L_Q=\frac{\|Q-Q_0\|_F^2}{nm},\qquad L_X=\frac{1}{md_x}\sum_j\frac{\|r_j\|_2^2}{\max(\|\bar x_j(Q_0)\|_2,10^{-3})^2}.
\]

修正惩罚使用初始池化尺度；“残差半径”约束使用当前池化尺度。旧行不可变，因此没有旧记忆刷新损失；没有预训练 CaT 特征，因此也没有 CaT 热启动锚定。

Adam 联合更新 \(Z\)、\(R\)，共 30 个构造步，学习率分别为 0.15、0.005，总梯度范数裁剪阈值为 5。代理隐藏维度和输出维度均为 384。每次更新后，将修正投影回半径约束内。主数据集共享这些配置。这是同时进行的可微优化，而非 EM，也不是文本编码器与图特征的交替优化。

阶段级算法如下：

1. 按固定比例累计调度分配带标签槽位；加载当前增量和只读合成前缀。
2. 编码清理后的当前文本，计算图信号，选择联合原型，初始化 \(Z^0,Q_0,R=0\)。
3. 缓存真实代理梯度和随机投影类别目标。
4. 重新计算 \(Q\)、池化特征、硬前向／软反向文本和各损失；联合更新 \(Z,R\)，再投影 \(R\)。按固定构造预算重复。
5. 重新计算最终分配，材料化特征和真实文本，验证文本嵌入约定，追加新块。

审计字段包括来源标识、类别配额、边缘误差、构造种子和配置哈希。构造完成后丢弃稠密 logits 和分配矩阵。前缀每阶段均不变，仅优化新增行。

### 4.7 研究范围、拓扑扩展与计算成本

共享分配是耦合机制：改变 \(Z\)，会同时改变特征支持、文本路由和传播路由目标。这不同于在图记忆已经构造完成后附着文本。Sinkhorn、梯度匹配和 CaT 风格类别统计是组成技术；将它们整合于共享真实文本构造接口之下，是本文方法设计。对于 \(n\) 个当前节点与 \(m\) 个槽位，共享使用 \(nm\) 个分配 logits，而独立特征／文本分配使用 \(2nm\)。减半的是分配 logits 数，不是总模型参数或峰值工作内存。预测和实际构造成本分别在组件研究中比较。

CoTAG-Q 主要面向图文节点分类。图感知构造并不意味着保存的记忆保留显式边集。CoTAG-Q-T 使用 \(Q\) 诱导的当前边，并在 boundary 变体中通过历史支持 sketch 保存合成拓扑。这些变体改变保存接口，针对结构任务单独评估。

稠密 logits 与分配需要 \(O(nm)\) 工作存储；一次 Sinkhorn 扫描访问 \(\sum_c n_cm_c\) 个合法条目。稠密实现中的特征和文本池化成本为 \(O(nm(d_x+d_e))\)。梯度匹配增加二阶代理求导；共享代理实现还分配大小为 \(O((|M_{t-1}|+m)^2)\) 的稠密合成算子，即使其数值为单位矩阵。冻结文本编码与当前图消息可在阶段内缓存。检查点机制减少保留的激活，但不会消除这些稠密工作张量。保存的无显式边记忆按合成行数增长，而非按临时分配矩阵增长；构造时间与峰值内存独立于保存预算报告。

### 5.2 下游 Student

主要 Student 使用两层 GCN 风格图分支，配合冻结 MiniLM 嵌入和可训练共享文本投影，称为 Prompt GraphText Student。构造代理与 Student 重训使用相关但不完全相同的双向多正样本 InfoNCE、prompt 交叉熵和 prompt-margin 损失。预测时，比较图表示与类别 prompt，不训练任务专用分类头。九单元面板和新五数据集 Prompt 面板共享 batch size 24、2048 个 Student 步、MiniLM、评估掩码和 Student 种子 150／151／152；未统一构造器迭代预算或原生机制。历史 Legacy Student 对照和冻结 GraphCLIP 检查点评估不属于共同 Student 声明；本地 Qwen STAD 虽然下游 Student 训练相同，构造阶段生成和监督却不同。

该读出用于在共同语义空间中评估特征与文本保留。Prompt 相似度接口受 GraphCLIP 等图文迁移模型启发，并非复现其预训练或零样本协议。同类记忆行可以共享或具有相近文本，多正样本对齐避免将这些行视为对比负样本。Prompt 监督使训练与类别 prompt 读出一致；冻结基础文本编码器控制编码器漂移，并为不同构造器保留共同表示空间。匹配的 Legacy／Prompt Student 实验支持这一完整读出配置（附录 A），但没有隔离各 Student 损失的贡献。因此，构造器增益在固定 Student 内测量，不能归因于更换 Student 所带来的绝对提升。

为检验记忆是否绑定某种下游架构，将同一份冻结记忆迁移到 Prompt GraphSAGE Student，不重新优化 CoTAG-Q 记忆。因此，该实验测量构造器迁移，而非针对架构重新调参后的效果。

### 5.3 访问与评估协议

每个阶段，构造器只读取当前增量和现有合成前缀，不重新读取完整历史原始图。三个大图主要配对评估以当前合法池最终 5% 为目标，仅进行整数行舍入；旧行冻结，所有主要记忆无显式边。登记累计行调度可能使中间阶段比例随类别顺序变化，尽管最终目标比例固定。留出掩码在构造前固定，但随后反复查看；报告属于事后评估，而非新鲜盲测。每个顺序／构造单元内平均三个 Student 种子，配对置信区间以九个单元为单位，而非将 27 次 Student 运行视为独立重复。这些区间描述已评估顺序和种子的变化，条件是重复使用的掩码；没有校正适应性方法开发。Report-development 和留出评估使用同一已训练 Student 上的不同掩码。后续留出诊断单独报告，不用于选择新主方法。报告最终 Macro-F1、Accuracy、Old F1、New F1 和阶段平均 F1。

归档 ArXiv 调度最终含 6,773 行，基于保留 report-development 节点之前的 135,473 个合格节点计算。相对于当前 118,539 个构造节点，实际保留比例为 5.71%，而非精确 5%。该归档比较内所有方法使用同一调度。保留旧结果并披露分母，固定比例敏感性面板则单独评估：每个阶段按照当前合法池重新计算比例，ArXiv 5% 最终为 5,927 行。旧 ArXiv 调度不作为该曲线上的点。

5% 与冻结前缀是共享实验选择，并非一般持续学习的要求。前者设定共同压缩程度，后者分离新增量凝聚与历史记忆刷新。较早比例和旧特征更新对照在附录 A 中按原版本和局限报告，不并入当前组件消融。Full-history 保留率表评估归档名义比例调度，包含披露的 ArXiv 比例；GraphSAGE 表在不重调构造器的情况下测试不同图架构上的保存记忆。

### 7.1 内部组件消融

#### 7.1.1 共享 Q 的归因

- **Shared-Q：**特征池化、文本路由和构造目标使用同一个分配。

- **No-residual：**去掉受限特征残差，仅保留 \(Q\) 加权池化。

### 7.2 梯度与材料化诊断

硬前向与保存嵌入的最大差异约为 \(10^{-7}\)，验证了前向与保存规则的数值一致。这不测量将软混合替换为一个真实文本损失了多少信息，也不能证明材料化对预测无害。软／硬余弦差距、来源多样性、槽位覆盖率和分配熵描述不同表示性质。例如，下列历史诊断报告以 nat 为单位的平均行熵和原始梯度范数。记录的分配梯度相对于 logits \(Z\)，而非直接对归一化 \(Q\) 求导：

| 数据集 | 熵 | \(\|\nabla_Z L\|\) | \(\|\nabla_R L\|\) |
|---|---:|---:|---:|
| WikiCS | 1.674 | \(8.49\times10^{-5}\) | \(1.54\times10^{-2}\) |
| SportsFit | 1.170 | \(2.32\times10^{-5}\) | \(6.56\times10^{-3}\) |
| BookHis | 0.259 | \(7.09\times10^{-5}\) | \(3.61\times10^{-2}\) |

非零 logits 梯度验证了可微分配更新。其原始范数小于残差梯度，但两个参数空间的维度、尺度、优化器状态和投影约束不同。因此，这些数值不能确定各分支对特征更新或预测收益的贡献比例。该因果问题需要 no-residual、fixed-Q 等匹配干预回答，而非仅比较未归一化范数。

### 7.3 探索性 EM-GECC-X 分支

基于结合传播初始化与直接合成特征优化的动机，还实现了名为 EM-GECC-X 的受限探索分支。它用 GECC 风格传播特征聚类初始化新槽位，将类别掩码软责任矩阵视为潜变量，在计算责任与对新合成特征做梯度更新之间交替。试验冻结历史前缀，使用相同累计 5% 调度与 Prompt Student，并从当前增量材料化硬真实文本来源。因此，它是受控方法尝试，而不是额外外部基线。

试验在预登记的小图门槛后主动停止。一个顺序、一个构造种子、三个 Student 种子下，完整 EM-GECC-X 在 Cora 和 Citeseer 的 Macro-F1／Accuracy 分别为 70.14／74.29、56.31／64.26；匹配 GECC-hard-TAG 为 82.11／85.36、65.81／69.80。去除梯度匹配分别恢复 9.51、11.58 个 F1 点，但仍未证明新方法优势。对应 EM-no-geometry 分支也不稳定。所有硬文本来源在交替轮次中保持不变，因此不能简单归因于保存负载切换。

该试验不支持所测交替方案的收益，置于主算法与外部基线排名之外。负结果限于其代理、新旧权重和特征更新配置，不证明 EM 一般存在局限。任何修订交替方案都需要独立固定的评估，而非在已反复查看的掩码上继续选择。

### 7.4 组件发现与负结果

现有组件研究支持以下解释：

1. 某些数据集去除 GM 后方法仍有效，说明初始化和 CaT 风格分布匹配重要。这不能证明 GM 无用，因为代理与最终 Student 不完全相同。
2. 固定 \(Q\)、仅更新残差在 WikiCS 上明显受限，说明特征修正不能单独替代分配学习。BookHis 上较小差距表明类别不平衡和文本重复可能主导结果。
3. Q-medoid 与硬 top-1 材料化相近，因此观测收益不能归因于任意一个硬文本规则。
4. 较早拓扑版 Unified-Q 对照中，以受限或无界步骤更新旧 \(X\) 均得到较低 Macro-F1，尽管 BookHis Accuracy 增加。附录 A 单独报告该试验。冻结前缀是保守设计；最终版本历史记忆刷新研究仍未完成。
5. 保持度数的拓扑重连在各数据集上方向不一致，无显式边主表没有跨阶段边，因此不将拓扑结果合并到主要排名。

### 7.5 早期 CCTP 与 CaT 分数为什么变化

较早实验报告 CaT／CCTP 约 50%，而 Prompt Student 实验达到 70–80%。审计将变化主要归因于 Student 和评估算子：Prompt Student 使用多正样本图文对齐、prompt 交叉熵、margin 损失，以及不同图算子。这不是在评估器不变的条件下凝聚算法突然改善的证据。因此，主表只纳入相同 Prompt Student、记忆预算和评估掩码下的结果。

### 7.6 组件证据的解释

在持续式访问边界下，该设计通过一个可微分配连接特征传输、真实文本路由和 Student 兼容反馈。Sinkhorn、梯度匹配、分布匹配和直通估计是已知技术。共享提供紧凑耦合接口和相同支持权重；相对独立分配的精度仍依赖数据集。相对于 GECC-hard，最明确主要收益在 BookHis；组件对照在所测单元中支持分布匹配和分配更新的有效信号，但未单独确定共享是完整方法预测收益的来源。

## 8 局限与未来方向

### 8.1 拓扑与旧记忆更新

主方法采用无显式边合成记忆并冻结旧前缀，因此未完整解决持续式 TAG 的两个核心问题：哪些旧合成节点应接收来自新槽位的边，以及旧记忆如何响应后续证据。传播匹配将一跳原始信息压缩至 \(X\) 和代理目标，但无显式边记忆不能恢复未观察到的跨阶段边。

初步扩展 CoTAG-Q-T 通过 \(Q^\top A_\Delta Q\) 写入新槽位之间的边；另一个 boundary-sketch 对照，在不重新读取历史原始特征和文本的情况下，加入合法当前节点到旧合成节点的支持统计。两个分支在 Cora、Citeseer 上都未一致改善节点分类。三个留出边划分上的固定槽位级链路探针，使 Cora AUC 从无显式边的 0.8325 增至有拓扑的 0.8591，但 Citeseer 从 0.8479 降至 0.8388。它不是训练式 GAE／GNN 链路预测评估，因此 CoTAG-Q-T 保留在主算法之外，不作一般结构任务声明。

### 8.2 代理与读出的依赖

构造代理使用多正样本 InfoNCE、prompt 交叉熵和 margin，与最终 Student 目标相关但不相同。真实组的平衡方式也不同于下游训练的记忆行采样。非零分配 logits 梯度证明优化存在，并不证明最终预测的正贡献。No-GM、共享／独立对照未建立 GM 或共享的稳定增益。所测 Student 架构下排名也变化，限制了将完整收益归因于某个目标或参数化。

### 8.3 文本材料化

方法选择并重新编码真实文本，而不生成新自然语言负载。这保留可读来源，但限制表示能力。前向与保存嵌入数值一致，不意味着选择一个来源保留了软混合全部信息。单单元软保存对照改善 BookHis，显示该权衡。共享 \(Q\) 同样只保证共同支持权重，而非任意特征残差与文本的语义一致。

### 8.4 基线保真度

相对 CaT-CCTP 的差值比较的是完整 TAG 适配：CaT 风格特征匹配后附着图近邻同类文本，文本不反馈至特征构造。此比较没有隔离共享 \(Q\) 的收益。GECC-hard-TAG 同样省略原生模糊分支和累计质心修订；其 BookHis soft 参考是单单元适配，不是原生 GECC 的多顺序证据。

受限 TAGSAM、本地 Qwen STAD 保留部分核心机制，但改变优化预算或监督与生成。GCond-x、SFGC 适配也改变原生训练协议；BookHis 最后单类别阶段使当前代理没有判别性特征梯度。低分不能证明优于完整发表方法。共同下游训练提高可比性，但不消除构造器差异。

### 8.5 零样本与下游任务范围

主要下游任务为基于 prompt 的节点分类。构造和 Student 重训使用当前流定义的类别，预测不训练分类头。这不是严格未见类别的跨数据集零样本学习。独立拓扑扩展的固定链路探针显示有限结构效用，但未证明无显式边主记忆支持训练式链路预测。更广泛跨任务声明需要共同边划分、各基线记忆的训练式 GAE／GNN 评估，以及多种子的结构保持测量。

### 8.6 评估范围

项目中反复查看了固定评估掩码。配对区间量化这些掩码条件下所采样顺序和构造种子的变化，不考虑适应性方法选择。只有一个顺序或构造种子的组件对照，范围小于主要九单元表。历史调度（包括 ArXiv 5.71% full-history 比较）与精确 5% 研究分开报告。进一步改变需要独立固定的数据与协议，才能进行新鲜确认。

### 8.7 工作内存与可扩展性

5% 预算限制保留节点行数，不限制构造工作内存或总保存字节数。稠密分配需要 \(O(nm)\) 存储，代理目前即便使用单位算子，也分配稠密合成矩阵。SportsFit 在主要 5% 时为 24.08 GiB，固定配置下 10% 失败。共享相对于独立路由减少分配参数，但未消除这些成本，也不保证优于图方法适配的一般效率。稀疏分配和隐式单位算子是自然的可扩展性方向。

## 9 结论

本文提出 CoTAG-Q，在不重新访问历史原始数据的条件下进行持续式 TAG 凝聚。共享、类别受限分配连接图感知特征池化与真实文本路由，使文本反馈能够调整构造特征的支持。循环内匹配联合更新分配 logits 和受限特征修正，一致材料化将可读文本负载保存到只追加的无显式边记忆。

累计 5% 节点预算下，九单元配对评估表明 CoTAG-Q 在 ArXiv、SportsFit、BookHis 上优于 CaT-CCTP，并在 BookHis 相对 GECC-hard-TAG 获得稳定 3.47 点 Macro-F1 增益。ArXiv 与 GECC-hard 接近，SportsFit 平均更有利于 GECC。独立 full-history 比较显示较高预测效用保留，冻结记忆 GraphSAGE 评估证明迁移到第二种架构。受控分配研究发现，相对于独立分配，共享具有更少分配参数和更低实测构造成本，但没有仅由共享带来的稳定精度收益。

结果支持共享图文构造作为历史访问受限持续记忆的实用接口，其预测收益依赖数据集。稀疏分配、更强的原生核心 TAG 比较和带拓扑评估，是改善可扩展性及扩展任务范围的方向。

Prompt Student 对多个构造器提高绝对分数，因此提升是下游配置效果，不是仅归属于 CoTAG-Q 的增益。构造器排名也与 Student 交互，例如 Legacy Student 下 BookHis 的 CaT 高于 CoTAG-Q。因此，严格比较固定 Student。GraphSAGE 同记忆迁移检验额外架构，排名依赖数据集，而非确立普遍下游优势。

GraphCLIP 为通过图表示与 prompt 余弦相似度预测提供先例。其零样本协议将预训练模型直接用于目标数据集，不再进行目标训练。本文使用目标构造池标签，因此属于监督式 prompt 读出，即便没有拟合任务专用线性分类器。未见类别或跨数据集零样本性能需要单独评估。

## 修改建议：与上述忠实译文分开

### 总体判断

当前稿件已经包含摘要、九节正文、完整方法公式、多组结果和协议附录，可以围绕现有方法继续写作。最清楚的实证是：三个大图稳定优于 CaT-CCTP，BookHis 稳定优于 GECC-hard-TAG；小比例记忆保留较高的特定 Student 预测效用，并可迁移到 GraphSAGE。

目前最大的写作问题是，正式稿仍像“实验审计记录”：主结果同时放入多种版本、掩码、调度和 Student 的结果，再反复解释为何不可混用。主要算法证据也不能支持“共享 Q 导致主要精度提升”或“GM 必不可少”。这些问题可以通过收紧论点、重组证据和补齐少量关键对照改善；不能靠强调简化基线的低分来解决。

### 优先级一：明确主张与证据的对应

建议将核心挑战写为：**历史原始数据不可重访时，如何用一个可学习支持关系共同构造数值特征与可读文本，而不把文本处理变成特征构造后的独立步骤。**

创新落点在共享支持关系、图文反馈路径与持续访问接口的结合。Sinkhorn、GM、DM、无显式边记忆和直通估计都已有先例，不能分别列成独立算法创新。第 1、3、4 节可以围绕一条因果路径统一表述：

\[
\text{文本侧损失}\longrightarrow Z\longrightarrow Q\longrightarrow\text{特征支持／文本路由的共同变化}.
\]

但“路径存在”不等于“路径产生主要收益”。建议按下表约束摘要、贡献列表和结果解释：

| 拟表达的主张 | 当前证据 | 建议表述 |
|---|---|---|
| 整体方法有效 | 三大图对 CaT 九单元全胜；BookHis 对 GECC 九单元全胜 | 可以正面强调，同时说明 ArXiv 接近 GECC、SportsFit 平均稍弱 |
| 共享比独立分配更准 | 三组受控 CI 均跨零；BookHis 共享均值更低 | 不作此结论；突出共享权重的构造保证与实测资源权衡 |
| 分配必须学习 | ArXiv、SportsFit fixed-Q 单单元明显变差 | 说明当前单元支持更新分配；避免推广为多种子稳定因果结论 |
| GM 带来稳定收益 | no-GM 差值为 +0.19、−0.05、−0.48 | 当前不支持；把 GM 写为设计目标，而非已验证的普遍关键贡献 |
| DM 有作用 | 三个单单元移除 DM 后均下降 | 可以报告，仍需标明采样范围 |
| 硬文本优于软文本 | BookHis 软保存更好 | 强调可读、可重新编码与来源可追溯的接口价值，承认表达能力权衡 |
| 5% 达到完整图性能 | 当前是特定 edge-free full-history 参考，ArXiv 为 5.71% | 写为相对于该参考的预测效用保留，不能称完整拓扑训练上界 |

共享权重保证的是相同支持，不保证添加残差后一定语义一致。可以减少“semantic alignment”的绝对措辞，使用“support coupling”或“shared support”，让方法名称与证据更贴合。

### 优先级二：把论文正文从历史日志改成结果叙述

建议正式正文按以下顺序组织结果：

1. **主要外部比较：**共同 Prompt Student 下的五数据集扩展表，明确适配状态及单单元范围。
2. **稳健确认：**三个大图九单元表及配对差值图，以此决定强基线结论，避免单单元排名取代九单元平均。
3. **压缩效用：**full-history 参考与凝聚率曲线；明确参考为 edge-free、固定 Student 训练预算，并在表注披露 ArXiv 5.71%。
4. **迁移与成本：**GraphSAGE 同记忆结果、构造时间和显存。跨架构表使用历史记忆，需要一次集中说明版本范围。
5. **内部消融：**共享／独立、no-GM、no-DM、fixed-Q、残差、文本保存，以及必要诊断。

将 `tab:main_prompt`、`tab:stability_delta` 及对应旧图移到附录／实验档案。正文继续并列这些表容易让读者误以为 SportsFit 已稳定优于 GECC。旧 Legacy Student 参考、停止的 EM 方案、停止的 GECC-soft 实验和长路径登记，适合移到复现补充材料；必要的保真限制必须保留，但只集中交代一次。

原始记录不应删除或改写。移出正文只改变论文组织，不意味着隐藏负结果；关键负结论如共享未获稳定精度优势、软保存更好、SportsFit OOM，仍应在对应讨论中直接报告。

### 优先级三：补齐真正影响归因的最小对照

英文稿明确说最终快照中的 random-initialization、class-shared、random-5 不完整，BookHis fixed-Q 未完成。不能再概括为“所有消融已完成”。

若要加强核心算法结论，优先补齐并统一版本，而不是增加 EM、attention 或拓扑模块：

- 在共同最终实现中，固定残差、初始化、目标、参数预算和种子，比较共享／独立分配，并同时报告精度和资源。
- 分开 random initialization + learned Q、structured initialization + fixed Q、random initialization + fixed Q；其他配置保持不变。现有 random-Q 同时关闭残差，无法单独归因。
- 区分“只替换保存文本”的 class-shared／random-5 干预，与“构造时去掉文本反馈”的干预；两类问题不同。
- 明确定义并给出数值：slot coverage、唯一文本来源比例、类内文本多样性、归一化 assignment entropy、soft/hard cosine gap。只有名称而无最终版本汇总表，不足以支持摘要中的一致性效果。
- 若正文强调输入结构的必要性，补或整理同配置 no-graph-message／no-propagation-target 对照。当前图感知机制写得清楚，但尚缺贴近该主张的直接消融。

No-GM 当前没有稳定收益。应依据重复确认决定是否保留，不应仅为让方法显得复杂而保留。若保留，要说明它服务于 Student 兼容构造的设计意图，并承认当前增益依赖代理；不能说已证明所有组件互补有效。

### 优先级四：把强基线适配讲清楚，而非追求表格行数

第 3 节的分类基本合理，但目前“共同 Student”“同预算”“机制适配”容易让读者误认为原方法核心预算也相同。建议在一个紧凑表中统一提供：

| 必须列出的字段 | 作用 |
|---|---|
| 原论文／代码版本及保留模块 | 让读者核对机制保真度 |
| 持续包装与历史访问修改 | 说明为适应任务必需的变化 |
| 文本适配 | 分清最近五文本、原生文本选择、生成、可学习路由 |
| 迭代／重启／教师训练预算 | 防止“同 5%”被误解为相同构造计算预算 |
| 原生模块是否省略 | 说明低分的解释范围 |
| 结果属于哪组表 | 避免历史参考进入主要排名 |

BookHis 最后单类别阶段使 GCond-x／SFGC 代理失去判别性梯度，是适配器问题的实质限制。正式稿需说明为什么没有使用历史合成记忆补充分类输出，或将这些行作为受限参考保留；不能把 14.52 之类低分作为战胜完整 SFGC 的核心证据。

PUMA-inspired 在多个数据集上较强，应认真解释其本地伪教师和筛选机制。TAGSAM、STAD 构造预算或监督发生改变，不能因为共同 Student 就称高保真官方复现。已停止的 GECC-soft 可保留完成状态，无须为扩充方法数继续重试。

### 优先级五：补清协议和数据，而不是再堆数据集

第 2 节的 fixed-rate 表述合理，但建议把以下内容集中补到实验设置或补充材料：

- 数据集正式名称与出处，尤其说明 SportsFit、BookHis 对应哪个原始数据版本／类别子集；给出节点数、边数、类别数、文本来源、类别不平衡程度。
- 构造／report-development／留出划分的比例和节点数，阶段数、每阶段类别列表、完整三种类别顺序与构造种子。
- 区分“原始历史存储受限”与“评估端可访问完整图”。当前是构造访问受限，不是整个系统在任何时间都禁止接触历史图。画一张构造、Student 训练、评估三个阶段的访问图，比反复文字解释清楚。

### 优先级六：改善方法章节的表达

第 4 节当前信息充分，但公式和实现常数挤在一起。建议分成“表示构造”“统一优化”“算法与复杂度”三层：

- 主文保留 \(Q\) 的约束、特征池化、文本路由、直通式、三项目标和总目标；把 30／4096 扫描、哨兵值、容差、裁剪和具体学习率集中到实现表。
- 给出伪代码，明确 \(Z,R\) 是优化变量，\(Q\) 是由 \(Z\) 求出的中间量；代理 \(\theta\) 固定，但计算其梯度并对合成梯度求二阶导。
- 将 \(U,h,H\) 的用途写成小表：归一化原始特征用于初始化；邻居方向用于原型；未归一化原始特征经 \(\widehat A\) 传播后用于匹配。
- 在总目标后用一句话解释不同粒度：GM 匹配模型学习信号，DM 匹配类别统计，传播项约束槽位消息。现有单单元证据不足以直接称三者均必需。
- 检查流程图的箭头：\(R\) 应在循环内进入 \(X^{\rm syn}=\bar X(Q)+R\)，不应表现为选完硬文本后才追加的后处理；反馈箭头应回到 \(Z,R\)，不是直接优化原始文本或 Student 权重。
- 为传播项的 \(Q\)-依赖目标补一句解释：目标与合成方向共同变化，不是独立固定结构监督，不能宣称理论保证保留拓扑。

图文支持共享是准确概念；“同一来源”需要区分 \(Q\) 的软支持集合与硬选择的单个源节点。图特征来自加权池化，不能让读者误以为最终特征和文本都直接取自同一个原始节点。

### 优先级七：让诊断与结论有直接表格支撑

第 7.4 节关于“WikiCS fixed-Q 明显受限”“BookHis 类别不平衡和文本重复主导”“Q-medoid 与 top-1 相近”“保持度数重连不一致”的解释，没有在该处给出直接对应的版本、单元数和数值表。建议补明确证据索引或移到附录；尤其不能仅凭结果差距推断类别不平衡或重复文本就是原因。

非零梯度只证明优化路径存在。建议增加相对更新量或匹配干预证据，而非用未经标准化的 \(\|\nabla_Z L\|\) 与 \(\|\nabla_R L\|\) 大小解释“哪个模块贡献更大”。当前英文稿对这一点的限制说明是正确的，应保留。

统计部分需要集中说明：单元是 order × construction seed；Student 种子先平均；CI 的计算方法；positive-cell ratio 和 worst cell 的定义。九单元来自交叉设计，其独立性假设也需要说明。可以补按顺序的汇总或与该设计相符的不确定性分析，而不是把 27 个 Student 结果当独立样本。

### 优先级八：摘要、局限与版式收紧

摘要的逻辑现在基本连贯：问题 → 两类先例的缺口 → 共享支持机制 → 结果。建议进一步压缩方法常数与适配术语，将最强证据放在后半段：BookHis 的稳定强基线增益，三个大图较高的特定 full-history 效用保留。CaT 的大幅差距可以保留，但不应替代 GECC 这一更强比较，也不把受限 TAG 核心的低分写成静态 TAG SOTA 的结论。

Full-history 保留率需保留“edge-free raw-data reference”限定；超过 100% 不意味着全面优于完整原图训练。尽量在正式表中给出相同当前 5% 调度下的参考，避免摘要持续混用 5% 主实验与 5.71% 历史结果；在未完成该比较前保留当前披露，不改造已有数字。

第 8 节七个小节偏多且与第 3、5、6、7 节重复，建议收为三类：任务／拓扑范围，评估与基线范围，表示／资源权衡。正文应正面说清已经解决的部分，再集中交代边界，而不是每段重复“不是官方／不是零样本／不是盲测”。

当前 ACM `sigconf` 可作为写作格式，但提交前仍需按目标 WWW 年份的实际征稿要求核对匿名、页数、作者／机构信息、会议元数据、参考文献样式。引用中不少条目仍为 arXiv，需要核对正式发表版本和准确题名；本译稿未替换这些来源。已有预览编译环境失败记录，因此还应在可用编译环境中确认实际页数、双栏表宽、图中文字和警告；不能把源文件检查等同于成功排版。
