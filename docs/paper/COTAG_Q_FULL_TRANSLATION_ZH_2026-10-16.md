## 摘要

静态文本属性图（TAG）凝聚从可完整访问的源图中学习紧凑的图文数据，而持续式图凝聚则在图数据分阶段到达时维护小规模记忆。当历史原始节点、边和文本无法重新访问时，结合这两种能力面临困难：每个新记忆条目都必须同时保留有用的图派生特征和可读文本负载。本文提出 CoTAG-Q，一种历史访问受限的持续式 TAG 凝聚方法。它从当前图结构、特征和文本中学习一个受类别约束、容量平衡的支持分配矩阵 \(Q\)。同一个分配矩阵用于特征池化和真实文本路由，并通过循环内分布匹配和与学生模型兼容的目标优化构造过程。新条目追加到冻结的历史合成前缀；主方法的记忆不保存合成边，但构造过程使用当前图。在精确的累计 5% 节点保留率、三种类别顺序和三个构造种子下，CoTAG-Q 在 ArXiv、SportsFit 和 BookHis 上相对协议匹配的 CaT 适配版本提高了 5.58–19.66 个 Macro-F1 百分点。相对更强的 GECC-hard-TAG 适配版本，它在 BookHis 上平均提高 3.47 点，且全部九个配对单元均取得正增益；在 ArXiv 上基本持平，在 SportsFit 上低 0.49 点。固定 \(Q\) 或移除循环内分布匹配，分别使 Macro-F1 下降 8.91–21.67 和 1.30–14.74 点。同一批 ArXiv 记忆可以迁移到 GraphSAGE 学生模型；在匹配的有限训练预算下，5% 记忆保留了完整历史参考模型 98.23–103.33% 的 Macro-F1。这些结果表明，在历史访问受限的持续式 TAG 凝聚中，可学习的图文支持关系是一种有效的构造接口。

**关键词：**文本属性图；持续学习；图凝聚；多模态记忆；可微分配。

## 1 引言

### 1.1 研究动机

文本属性图（TAG）将关系结构与节点级语言结合起来。静态 TAG 凝聚可以在完整源图可访问的情况下构造图文条目 [4,5]。不断演化的 Web 目录和相互链接的文档集合持续积累关系与文本。当学习器无法保留先前的原始快照时，Web 图学习面临的一个关键挑战，是如何在紧凑、逐步构造的记忆中保留二者共同的训练效用。持续式图凝聚则在数据分阶段到达时维护紧凑记忆，主要针对图特征 [1,3]。联邦 TAG 凝聚研究相关但不同的访问边界 [6]。在本文设定中，即使构造器无法重新访问早期阶段的原始特征、文本和边，一个有用的凝聚条目也必须保留数值表示、标签以及可读文本负载。因此，记忆不仅是更小的训练集，也是过去的多模态信息影响后续构造的持久接口。

本文在一个明确的访问规则下研究这一接口。在阶段 \(t\)，构造器接收当前增量与阶段 \(t-1\) 保存的合成记忆，但不能访问历史原始数据。构造器必须在保留类别覆盖的同时追加一个小规模记忆块，并且不能隐式使用原始历史。关键问题不是静态 TAG 方法能否利用文本，而是持续式构造器如何决定：哪些当前节点支持每个新特征，以及应该为其保存哪条真实文本。

### 1.2 问题与设计目标

核心设计目标，是在当前原始节点与合成槽位之间建立可学习的支持关系。先使用仅处理图的凝聚器，再采用独立的文本附着规则，是一种有力且有价值的对照；但在这种做法中，文本附着不参与特征构造目标。本文考察的是：在仅允许访问当前增量的条件下，一个可审计的统一分配，能否同时提供特征支持和文本支持。这一目标并不意味着所有文本感知 TAG 方法都在结构上割裂了两者；TAGSAM 和 STAD 已经包含实质性的文本机制。本文的贡献在于持续式构造接口，以及在相同访问边界下对该接口的评估。

### 1.3 我们的方法

我们提出 CoTAG-Q，一种构造过程感知图结构、主记忆不保存显式边的持续式 TAG 凝聚方法。当前节点特征、一跳图消息和冻结 MiniLM 编码器得到的文本嵌入，共同初始化一个受类别约束的分配矩阵 \(Q\)。容量平衡的 Sinkhorn 算子将分配 logits 转换成可用的支持权重。同一个 \(Q\) 随后用于：

1. 将当前特征池化为新的合成行；
2. 路由真实文本嵌入，并选择具有可审计来源的文本字符串；
3. 提供槽位级图消息目标；
4. 接收来自循环内构造目标的梯度。

分配矩阵与受限的特征修正共同优化。优化循环包含 CaT 风格的类别统计分布匹配、传播匹配，以及与学生模型兼容的图文目标。最终文本负载由硬选择构造前向中使用的同一条清洗后的源文本材料化，而软路由为 \(Q\) 提供替代梯度。因此，该方法不会先生成一个不透明的文本向量，再用一条无关字符串替换它。

主记忆保存特征、标签、真实文本和审计元数据，不保存合成邻接矩阵。这是明确的方法范围边界。构造过程中仍使用当前增量图；单独的 CoTAG-Q-T 分支会为结构任务材料化合成边。本文的主要结论针对无边记忆上的、基于 prompt 的节点分类；拓扑保持作为扩展进行评估，而不并入主方法。

### 1.4 贡献与范围

本文有三项贡献：

1. 我们形式化并审计了历史访问受限的持续式 TAG 凝聚设定：构造仅访问当前增量，记忆采用累计固定比例，历史合成前缀保持冻结。这使记忆保留的信息明确且可复现。
2. 我们提出 CoTAG-Q，使用受类别约束的可学习支持关系，共同组织图感知特征池化和真实文本路由。该方法将支持关系转化为需要优化的构造变量，而不是固定的池化规则或事后文本附着规则。
3. 我们区分机制证据与基准覆盖。在三个大图的九个顺序/种子单元上，CoTAG-Q 持续优于匹配的 CaT 适配版本，并在 BookHis 上比 GECC-hard-TAG 提高 3.47 个 Macro-F1 百分点。控制实验表明，学习 \(Q\) 和循环内分布匹配是最可靠的预测性能来源；同记忆 GraphSAGE 迁移和匹配的完整历史保留率实验则评估了鲁棒性与压缩效用。

这些结果不支持普遍 SOTA 的主张。在主比较中，GECC-hard-TAG 在 SportsFit 上仍然更强，在 ArXiv 上则与本方法统计上持平。同样，消融实验没有显示共享分配、额外的配对反馈路径或单独的梯度匹配具有普遍的准确率优势。我们在完整方法的定义中保留这些组件，是因为它们实现了统一的构造接口；同时明确报告其权衡，而不将其描述为已经独立证明的精度来源。

主要下游任务是使用图感知无边记忆的 prompt 节点分类。带拓扑的 CoTAG-Q-T 分支独立于主方法，prompt 读出也不被宣称为严格的未见类别零样本学习。

## 2 问题定义与持续式协议

### 2.1 持续式 TAG 凝聚

设阶段 \(t\) 到达的合法构造数据为

\[
\Delta_t=(V_t,X_t,T_t,Y_t,E_t),
\]

其中，\(E_t\) 仅包含当前增量中可访问的边，预留评估节点不属于构造池。令 \(M_{t-1}\) 为上一阶段结束后保存的记忆。合法构造器接收 \(\{\Delta_t,M_{t-1}\}\)，不能重新访问历史原始数据，并输出

\[
M_t=M_{t-1}\oplus M_t^+.
\]

主方法的无边记忆保存如下行：

\[
M_t^+=\{(x_j^{\rm syn},t_j^{\rm syn},y_j)\}.
\]

它不保存合成邻接矩阵。不过，构造过程仍通过局部消息和传播目标使用输入图。

### 2.2 固定比例记忆与阶段分配

我们采用累计比例，而不是固定的记忆行数。若 \(N_t\) 为截至阶段 \(t\) 已观察到的合法构造节点数，则目标记忆大小为

\[
\bar K_t=\operatorname{round}(\rho N_t),\qquad
K_t=\max\{\bar K_t,|M_{t-1}|+|\mathcal C_t|\},
\]

其中，\(\mathcal C_t\) 是当前增量中的类别集合，第二项是类别覆盖下限。新增槽位数为

\[
m_t=K_t-|M_{t-1}|.
\]

首先为每个当前类别保留一个槽位，再根据当前各类别的节点数，用最大余数法分配其余槽位，并以可用行数为上限。如果类别覆盖下限改变了名义目标，则记录实际有效比例。

主实验采用预先指定的累计比例 \(\rho=5\%\)。这遵循 CaT 使用的按比例配置持续记忆的惯例 [1]：记忆随数据流增长，而不同数据集之间保持可比较的压缩程度。附录 A 中的比例实验是敏感性分析，不是用于选择方法的循环。

### 2.3 访问边界与评估

构造新记忆块时，历史合成前缀为只读。原始文本来源不再可访问后，这种仅追加的选择可以保留此前已材料化的文本，并隔离当前增量的影响；这不同于声称旧记忆不可能更新。附录报告了一项记忆刷新先导实验。

所有协议匹配的方法采用相同的文本清洗规则、冻结 MiniLM 编码器、记忆比例、类别顺序、学生模型架构、优化步数和评估掩码。我们报告最终 Macro-F1 和 Accuracy，Old/New F1 仅用于持续学习诊断。Prompt 读出通过比较图表示与类别 prompt 表示进行预测：

\[
\hat y_i=\arg\max_c\cos(h_i^g,p_c).
\]

这是基于 prompt 的分类器，不是严格的未见类别零样本学习：构造和学生模型训练仍使用所述协议中可获得的标签。GraphSAGE 迁移和拓扑感知结构探针作为单独的鲁棒性检查报告。

## 3 相关工作与基线适配

### 3.1 图凝聚与持续式记忆

GCond 和 GCond-x 表明，可以在构造紧凑、实际上无边的训练集时使用原图 [9]。SFGC 探索了相关的无图轨迹匹配方向 [12]。CaT 是最接近的持续学习先例：它通过分布匹配和记忆内训练（Training-in-Memory）追加类别平衡的记忆 [1]。PUMA 将伪标签和高效传播引入持续图学习 [3]。这些方法构成本文对比中的特征凝聚一侧，但它们均未规定在历史原始数据不可重访条件下的可读文本负载接口。

### 3.2 静态与多模态 TAG 方法

TAGSAM 通过文本选择和属性匹配完成静态 TAG 凝聚 [4]；STAD 结合了半监督图文蒸馏、草图化和文本合成 [5]；DANCE 研究带有邻居文本与拓扑机制的联邦 TAG 凝聚 [6]；SR-GM 则处理多模态梯度冲突 [7]。这些方法对源图的访问方式和优化约定，与采用冻结合成前缀的持续数据流不同。GraphCLIP 是图文迁移模型，而非凝聚方法 [11]；它为本文的 prompt 读出提供了启发，但不是直接的记忆基线。

### 3.3 基线适配与公平性

我们区分三个层次的证据。**官方复现**保留论文发表时的任务、访问假设、核心目标、学生模型和指标。**协议匹配的机制适配**保留方法的核心构造机制，但将原始数据访问限制在当前增量，并在本任务中采用统一的记忆接口和 Prompt Student。**简化的启发式对照**仅保留方法的高层思想，不能用来证明优于完整的原论文方法。

主表使用两个协议匹配的持续式适配版本。**CaT-CCTP** 保留 CaT 的类别级分布匹配，并从当前增量中五个同类来源附着文本。**GECC-hard-TAG** 使用源于 GECC 的平衡硬聚类和质心池化，以硬分配和冻结的历史前缀替代原生模糊隶属度与累计质心修订。它采用相同的文本附着规则和统一学生模型。这两个结果都不称为官方 TAG 复现，因为原论文没有定义与本文相同的持续式 TAG 接口。主表保留五来源适配器，作为强对照；固定特征并改用单个最近文本的重放实验，仅作为诊断报告。

附录记录了受 PUMA、DANCE 和 SR-GM 启发的对照，以及受预算限制的 TAGSAM、STAD-core、GCond-x、SFGC 和 GraphCLIP 参考实验。其监督方式、原生预算或模型约定的变化，与相应数值一并说明。特别地，简化适配器的低分不被解释为原论文方法较弱的证据。

### 3.4 与 CoTAG-Q 的关系

CoTAG-Q 的单项构件都是已有的：图感知池化、Sinkhorn 归一化 [8]、分布匹配、梯度匹配以及源文本选择。方法的贡献在于持续式构造接口：在无法重访历史原始节点时，使一个受类别约束的分配矩阵 \(Q\) 成为图特征、真实文本和构造反馈的共同支持变量。实验区分了这一结构性方案与更窄的问题，即共享 \(Q\) 是否总能提高准确率。

## 4 方法：学习图文支持关系

### 4.1 构造接口

![CoTAG-Q 构造流程：当前增量输入、支持关系学习、特征与文本路由、循环内匹配和记忆追加](D:/Aprojects/continue_tag_condensation/paper_www/figures/method_overview.png)

**图 1：CoTAG-Q 构造流程，图中的数值仅为示意。**当前图结构、特征和文本初始化 logits \(Z\)。带类别掩码的 Sinkhorn 缩放产生 \(Q\)，由它池化特征并将真实文本路由到新行。下方路径匹配真实与合成信息，并更新 \(Z,R\)；历史前缀保持只读。只有特征、标签和可读文本被追加到主方法的无边记忆中。

在阶段 \(t\)，方法读取 \(\Delta_t\) 和冻结的历史前缀 \(M_{t-1}\)，分配 \(m_t\) 个具有类别标签的新槽位，并共同优化分配 logits \(Z\in\mathbb R^{n\times m}\) 与受限特征残差 \(R\in\mathbb R^{m\times d_x}\)。带掩码的 Sinkhorn 算子将 \(Z\) 映射为 \(Q\)，其中 \(Q_{ij}\) 表示当前节点 \(i\) 分配给槽位 \(j\) 的质量。同一个 \(Q\) 用于两种模态：

\[
M_t=M_{t-1}\oplus
\{(x_j^{\rm syn},t_j^{\rm syn},y_j)\}_{j=1}^{m}.
\]

这里没有预先执行的 CaT 优化。CaT 风格的分布匹配，是同一个循环内更新中的一项损失。

### 4.2 图文初始化

将每条当前文本清洗并截断至 320 个字符，使用冻结的 MiniLM 编码一次：

\[
e_i=\operatorname{Norm}(\operatorname{MiniLM}(t_i)).
\]

令 \(A\) 为当前无向邻接矩阵，且

\[
\widehat A=D^{-1/2}(A+I)D^{-1/2}.
\]

我们计算局部结构信号

\[
h_i=\operatorname{Norm}((AU)_i+10^{-6}u_i),
\qquad u_i=\operatorname{Norm}(x_i),
\]

以及传播目标 \(H=\widehat A X\)。在每个类别内，对联合表征

\[
v_i=\operatorname{Norm}
[\sqrt{w_x}u_i;\sqrt{w_h}h_i;\sqrt{w_e}e_i]
\]

进行最远点原型选择，为每个槽位初始化一个原型。首先选择最接近归一化类别均值的节点，然后贪心地选择其余最远的联合表征。每个原型的三个组成部分都来自同一个被选中的节点。由此得到初始 logits：

\[
Z_{ij}^{0}=w_xu_i^\top p_j^x+w_hh_i^\top p_j^h+w_ee_i^\top p_j^e,
\quad (w_x,w_h,w_e)=(1,0.75,0.35).
\]

这只是初始化先验；后续仍会学习支持关系。

### 4.3 平衡的支持分配

对于类别 \(c\)，设当前节点行数为 \(n_c\)、槽位数为 \(m_c\)，对 \(Z_c/\tau\) 应用熵正则化的 Sinkhorn 归一化：

\[
Q_c\mathbf 1=\mathbf 1,\qquad
Q_c^\top\mathbf 1=(n_c/m_c)\mathbf 1.
\tag{1}
\]

类别掩码使跨类别分配质量严格为零；每行质量为 1，每个同类槽位获得相等容量。实现中采用对数空间的行列缩放，\(\tau=0.35\)，迭代轮数从 30 轮扩展至最多 2,048 轮，以满足 \(10^{-4}\) 的边缘误差容限，并记录每个阶段的误差。相等的列容量可以防止支持关系塌缩到少数槽位。

### 4.4 特征池化与真实文本路由

令 \(a_j=\sum_iQ_{ij}\)。合成特征为

\[
\begin{aligned}
\bar x_j(Q)&=\frac{\sum_iQ_{ij}x_i}{a_j},\quad
x_j^{\rm syn}=\bar x_j(Q)+r_j,\\
\|r_j\|_2&\leq0.05\max(\|\bar x_j\|_2,10^{-3}).
\end{aligned}
\tag{2}
\]

同一支持关系产生软文本表示：

\[
\widetilde e_j(Q)=\operatorname{Norm}
\left(\frac{\sum_iQ_{ij}e_i}{a_j}\right).
\]

为了使记忆可读且可审计，最终负载采用分配质量最大的、经过清洗的源文本：

\[
i_j^\star=\arg\max_{i:y_i=y_j}Q_{ij},\qquad
t_j^{\rm syn}=t_{i_j^\star}.
\]

构造过程中采用直通估计值：

\[
e_j^{\rm ST}=e_{i_j^\star}+\widetilde e_j-
\operatorname{sg}(\widetilde e_j).
\]

其前向值是实际选中的真实文本嵌入，而反向的替代梯度通过软路由传递。在最后一次更新之后，重新计算 \(Q\)，使用相同的来源选择规则，对保存的字符串重新编码，并验证嵌入的一致性约定。这个过程不引入生成文本，也不使用历史原始文本。

### 4.5 循环内优化目标

我们使用一个随机初始化后固定参数的两层图文学生代理模型，隐藏维度和输出维度均为 384。其损失为

\[
L_{\rm proxy}=0.5L_{\rm pair}+L_{\rm prompt}+0.1L_{\rm margin}.
\]

其中，\(L_{\rm pair}\) 是对称图文对比损失，将所有同类条目视为正样本；\(L_{\rm prompt}\) 是类别 prompt 交叉熵；\(L_{\rm margin}\) 针对得分最高的错误类别 prompt 使用 0.20 的间隔。旧组与当前组的总权重相等；每个实际存在的组内，各类别权重相等。

在代理模型参数固定时，缓存真实侧梯度

\[
g_r=\nabla_\theta L_{\rm proxy}(M_{t-1}\oplus\Delta_t),
\]

并在每个构造步骤重新计算合成侧梯度 \(g_s\)。梯度匹配目标为

\[
L_{\rm GM}=1-\cos(g_r,g_s)+0.25
\left|\log\|g_r\|_2-\log\|g_s\|_2\right|.
\]

由于 \(Q\) 同时控制 \(x_j^{\rm syn}\) 和 \(e_j^{\rm ST}\)，梯度会通过特征和文本两条路径流入同一组 logits。

遵循 CaT [1]，分布匹配在四组固定的随机 ReLU 投影空间内比较类别统计量：

\[
L_{\rm DM}=\frac{1}{B}\sum_{b,c}
\|\mu_{bc}^{\rm syn}-\mu_{bc}^{\rm real}\|_2^2,
\]

其中 \(B=4\)，

\[
\phi_b(x)=\operatorname{Norm}(\operatorname{ReLU}(xW_b)),
\]

每个固定的 \(W_b\) 通过 Xavier 方法初始化，宽度为 512。均值 \(\mu_{bc}\) 由类别 \(c\) 内的 \(\phi_b\) 求平均得到；平方差在类别和维度上求和，再在投影组之间求平均。真实侧统计使用当前 \(H=\widehat A X\)，合成侧统计使用新生成的无边行。槽位级传播项为

\[
L_{\rm prop}=\frac{1}{m}\sum_j\left[
1-\cos\left(\frac{\sum_iQ_{ij}H_i}{a_j},x_j^{\rm syn}\right)\right].
\]

我们将 \(R\) 初始化为零，并使用初始池化特征的尺度归一化其惩罚项：

\[
s_j^0=\max(\|\bar x_j(Q_0)\|_2,10^{-3}),\quad
L_R=\frac{1}{md_x}\sum_j\|r_j/s_j^0\|_2^2.
\]

完整目标为

\[
L=L_{\rm GM}+L_{\rm DM}+0.5L_{\rm prop}
+0.1\|Q-Q_0\|_F^2/(nm)+0.1L_R.
\tag{3}
\]

Adam 联合更新 \(Z\) 和 \(R\) 共 30 步，两者的学习率分别为 0.15 和 0.005，梯度裁剪阈值为 5。这是同时进行的可微优化，而不是 EM 过程：文本编码器、原始数据、历史前缀和代理模型参数均保持固定。

### 4.6 阶段算法与适用范围

实现过程如下：

1. 分配槽位，加载当前增量与冻结的历史前缀。
2. 缓存文本和图信号，初始化 \(Z,Q_0,R\)。
3. 缓存真实侧的代理模型目标和类别统计目标。
4. 重复计算 \(Q\)、池化特征、直通文本表示和三类损失，再更新 \(Z,R\)。
5. 将新行材料化，附带审计字段追加到记忆中。

构造完成后，丢弃稠密 \(Q\) 和临时代理模型张量。

对于 \(n\) 个当前节点与 \(m\) 个槽位，稠密分配需要 \(O(nm)\) 的工作内存，以及 \(O(nm(d_x+d_e))\) 的池化时间。梯度匹配还引入二阶微分。这些开销解释了为什么 5% 的记忆比例不意味着构造阶段只消耗 5% 的资源。主记忆不保存边，其验证任务是基于 prompt 的节点分类。CoTAG-Q-T 单独保存由 \(Q\) 诱导的拓扑以服务结构任务；它不用于重新定义无边主方法的结论。

### 5.2 学生模型与指标

主要下游模型是两层 Prompt GCN，采用冻结的 MiniLM 文本编码器和类别 prompt 余弦读出。Prompt GraphSAGE 仅用于同记忆迁移。所有构造方法共享相同的 prompt 定义、文本预处理、2,048 步学生模型训练、24 的批大小，以及 150/151/152 三个学生模型种子。GraphSAGE 只将图分支改为两层均值聚合器，保留相同的记忆和训练协议。我们报告最终 Macro-F1 和 Accuracy；Old/New F1 与阶段平均 F1 是次要的持续学习诊断指标。首先在每个顺序/构造单元内对学生模型种子求平均，再基于这些单元均值计算总体均值、样本标准差和配对 95% \(t\) 置信区间。

### 5.3 协议与基线

主实验比例为合法构造池的精确累计 5%，并记录类别覆盖下限。主比较使用三种类别顺序、三个构造种子和三个学生模型种子。测试掩码在当前比较之前已经固定；该证据被标记为事后固定掩码评估，而不是一次新的盲测。完整历史结果是允许访问更多数据的参考，不会用于构造凝聚记忆。

主要外部基线为 CaT-CCTP 和 GECC-hard-TAG。二者保留其核心特征机制，并采用相同的仅当前增量访问封装、记忆格式、五来源文本附着和 Prompt Student。更广泛的适配、使用官方检查点的参考以及原生预算实验在附录中单独报告，不与主排名合并。

### 5.4 可复现性

构造器的 DM 使用四组宽度为 512 的固定随机投影，\(\tau=0.35\)，联合 Adam 更新 30 次，并在各数据集上使用相同超参数。文本在 MiniLM 编码前清洗并截断至 320 个字符。每次运行记录类别顺序、构造与学生模型种子、实际比例、类别配额、Sinkhorn 边缘误差、来源标识和配置哈希。构造时间与 CUDA 峰值分配量独立于学生模型训练进行测量。

### 6.3 构造开销

保存的记忆很小，但构造过程并非没有代价。CoTAG-Q 在 ArXiv、SportsFit 和 BookHis 上的平均 CUDA 峰值分配量分别为 17.33、24.08 和 2.91 GiB，而两个匹配基线均低于 1.1 GiB。稠密 \(Q\)、其可微归一化状态以及代理模型的二阶微分，是构造内存的主要来源。在 ArXiv/SportsFit 的阶段零审计中，将稠密合成单位矩阵替换为稀疏算子仅节省 0.06/0.11 GiB。更大的瓶颈应通过稀疏或分块分配，以及代理模型更新中的检查点技术来处理。

## 7 消融与讨论

消融实验考察构造过程的哪些部分对观察到的行为是必要的。它们使用一个已登记的类别顺序、三个构造种子，以及每个构造单元的三个学生模型种子；这些实验不用于选择新的主配置。

### 7.1 学习 Q 与分布匹配

**表 4：核心对照。**最终 Macro-F1，报告三个构造单元均值之间的均值 ± 标准差。

| 构造方法 | ArXiv | SportsFit | BookHis |
| --- | ---: | ---: | ---: |
| CoTAG-Q | 52.96 ± 0.21 | 80.02 ± 0.30 | 48.53 ± 0.85 |
| 固定 Q | 40.20 ± 0.20 | 58.35 ± 0.48 | 39.62 ± 0.17 |
| 移除 DM | 51.05 ± 0.64 | 65.28 ± 0.82 | 47.23 ± 0.97 |
| 移除 GM | 53.20 ± 0.19 | 80.47 ± 0.56 | 48.47 ± 1.11 |

固定 \(Q\) 使 ArXiv、SportsFit 和 BookHis 的 Macro-F1 分别下降 12.76、21.67 和 8.91 点；全部三个构造种子都支持学习支持关系优于固定支持关系。移除 DM 分别使其下降 1.91、14.74 和 1.30 点。这些对照支持在该构造器中将支持关系与凝聚特征共同优化的价值。相比之下，完整方法减去无 GM 方法的差值仅为 -0.24、-0.45 和 +0.06 点。GM 作为统一的、与学生模型兼容的接口组成部分予以保留，而不被描述为已经独立证明的准确率来源。

### 7.2 文本反馈与共享支持

文本感知初始化的效果在 SportsFit 上最明显：移除它使 Macro-F1 下降 2.51 点，Accuracy 下降 6.87 点。配对反馈路径没有表现出普遍的独立增益，完整方法减去无配对反馈方法的差值分别为 -0.16、-0.28 和 +0.39 点。详细的 \(2\times2\) 文本析因实验、软/硬材料化比较、共享/独立 \(Q\)、分配熵、文本覆盖率和余弦差距诊断见附录 B。

这些结果区分了两个主张。在所测试的构造器中，学习类别内的 \(Q\) 能够提升准确率。共享同一个 \(Q\) 则使分配 logits 的数量减半，并对齐特征与文本的来源支持；其准确率效果随图而变化。

### 7.3 结果解释

主要证据因此分层组织：主表建立了持续式 TAG 访问规则下的端到端效用；消融实验则将可学习支持关系和循环内 DM 识别为可靠机制。附录提供额外的表示与实现对照。

## 8 局限与未来方向

### 8.1 局限

**访问与拓扑。**无边记忆不会保留跨阶段合成边，也不会修订旧行。CoTAG-Q-T 是独立扩展，其初步链路探针收益依赖数据集；因此，当前论文的结论是节点分类效用，而不是在一般结构任务上的优越性。

**开销与规模。**稠密 \(Q\) 与代理模型的二阶微分，使构造过程显著比 CaT-CCTP 或 GECC-hard-TAG 消耗更多内存。块稀疏分配、代理模型更新中的检查点技术以及流式 Sinkhorn，是重要的工程改进方向。

**证据范围。**主比较采用三个大规模 TAG 和事后固定掩码。附录包含小图与更广泛的适配，但仍希望补充更强的原生复现以及独立封存的确认实验。Prompt Student 通过所述构造协议获得监督；本方法不是严格的未见类别零样本学习。

## 9 结论

本文研究了历史原始节点、边和文本无法重新访问时的持续式 TAG 凝聚。CoTAG-Q 在各类别内部学习平衡分配，作为图感知特征池化、真实文本路由和循环内构造反馈的共同支持关系。它在构造时使用当前阶段图结构，并向冻结的无边记忆追加可读条目。

在精确累计 5% 比例下，CoTAG-Q 在全部三个大图上优于匹配的 CaT 适配版本，在 BookHis 上优于更强的 GECC 适配版本，在 ArXiv 上持平，在 SportsFit 上略低。控制证据将学习 \(Q\) 和循环内分布匹配识别为可靠的预测性能机制。同记忆 GraphSAGE 迁移和匹配的完整历史保留率表明，结果并不局限于一种 GCN 读出，也不依赖保留大量原始行。

该方法同时揭示了一项实际权衡：统一的可微构造器比最终保存的记忆本身更昂贵；若没有独立的拓扑扩展，无边接口也无法支持结构任务。这些局限明确了后续方向，包括可扩展的分配存储、拓扑保持，以及独立的封存评估。

### B.4 组件与表示对照

完整的共享 \(Q\) 实现使用一个 \(n\times m\) 分配矩阵，而不是独立的特征/文本分配矩阵。相对 split-Q，它的准确率差值并非总为正；但共享接口减少了分配 logits，并保持来源溯源信息对齐。在较早协议下，共享/分离分配的 F1 对照为：

| 分配方式 | WikiCS | SportsFit | BookHis |
| --- | ---: | ---: | ---: |
| 共享 Q | 80.38 | 78.92 | 41.97 |
| 分离 Q | 80.93 | 78.82 | 42.50 |

这些历史对照与精确 5% 的主评估分开；它们不能证明共享 \(Q\) 会带来一致的准确率收益。

分配诊断显示，在 ArXiv、SportsFit 和 BookHis 上，硬分配槽位覆盖率分别为 1.0000、0.9998 和 1.0000，归一化熵分别为 0.1200、0.2385 和 0.0827，软/硬文本余弦差距分别为 0.3853、0.2037 和 0.4693。几乎每个槽位都获得支持，而且几乎所有保存的文本都彼此不同。这一差距量化了将软混合材料化为单条可读来源文本时丢失的信息。

**表 13：构造阶段的文本对照，指标为最终 Macro-F1。**

| 构造方法 | ArXiv | SportsFit | BookHis |
| --- | ---: | ---: | ---: |
| CoTAG-Q | 52.96 | 80.02 | 48.53 |
| 无文本初始化 | 53.52 | 77.50 | 46.79 |
| 无配对反馈 | 53.13 | 80.30 | 48.14 |
| 两者均关闭 | 53.32 | 77.64 | 47.87 |

保留“硬前向、硬存储”的一致性约定，是为了可读性和来源审计。仅存储软表示，以及类内共享文本/随机五来源文本负载的对照效果依赖数据集；它们不替代主方法的材料化规则。

### B.5 开销审计与拓扑扩展

构造峰值分配量在 ArXiv 上为 17.33 GiB，在 SportsFit 上为 24.08 GiB，在 BookHis 上为 2.91 GiB。将稠密单位矩阵替换为稀疏算子，只将阶段零分配量从 ArXiv 的 11.56 GiB 降至 11.50 GiB，以及从 SportsFit 的 23.44 GiB 降至 23.33 GiB。因此，稠密分配状态仍是主要优化目标。拓扑分支将 Cora 槽位级链路探针的 AUC 从 0.8325 提高至 0.8591，但将 Citeseer 的 AUC 从 0.8479 降至 0.8388；该实验不是经过训练的 GAE/GNN 评估，因此不用于支撑主结论。
