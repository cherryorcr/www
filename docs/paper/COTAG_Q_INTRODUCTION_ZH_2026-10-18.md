## 1 引言

文本属性图（Text-Attributed Graph，TAG）将图关系与每个节点上的自由文本结合起来。这种数据形式已经广泛出现在引文网络、商品目录以及其他 Web 规模的数据集合中：图结构提供关系上下文，而文本保留仅靠拓扑结构无法获得的语义内容。实际部署中的 TAG 很少是静态的。新的文档、商品或账户会以增量形式不断到达，每个增量可能同时包含新的边和新的文本。如果始终保留完整历史并在累积图上重新训练，信息保留最直接，但成本会随着历史规模增长，而不是随着新到达的数据量增长。

图凝聚通过一小组训练条目替代大规模训练图，因此提供了一条有吸引力的路径。然而，在持续式场景中，凝聚还必须满足一个额外的接口约束：构造器必须在某个增量仍然可访问时决定把什么写入记忆，因为已经释放的增量中的原始节点、边和文本之后可能无法再次访问。因此，问题不只是如何压缩一个 TAG，还包括如何在每个访问边界上写入一个合法且有用的多模态记忆。

**现有的凝聚接口。** 现有工作分别处理了这一问题的不同部分，但它们采用的访问接口并不相同。静态图凝聚方法从一个在构造期间始终可访问的源图中学习紧凑训练信号 [GCond, SFGC]。持续式图凝聚方法在新图增量到达时维护紧凑记忆 [CaT, PUMA, GECC]；这些方法为可追加的数值记忆提供了重要先例，但其基本记忆接口并不要求每个保留条目都包含可读文本。静态 TAG 凝聚方法则通过文本选择、属性匹配或多模态蒸馏显式处理节点文本 [TAGSAM, STAD]，但其构造过程假定优化期间仍然可以使用源图。上述方法在各自原始任务上都是有效的。它们组合起来留下了一个更具体的问题：当阶段 (t) 的构造器只能读取当前增量和冻结的凝聚前缀时，如何同时保留图派生训练信号，并材料化真实文本？

**持续式 TAG 凝聚的挑战。** 这种接口组合产生了普通图凝聚或静态 TAG 凝聚单独不会同时面对的两个挑战。图 1 将访问边界和相应的实测后果放在一起说明。

**（i）历史数据不可重访。** 在阶段 (t)，当前增量仍然可访问，因此可以计算它的邻域消息。增量释放后，后续构造器无法重新计算这些消息，无法重新凝聚累积的原始图，也无法重新访问写入旧记忆条目时使用的源文本。因而，历史记忆不只是一个方便的特征缓存。在受限访问协议下，它是释放后的图派生证据能够进入未来阶段的唯一合法接口。这使构造发生的时间变得关键：即使最终只能保留少量记忆行，也必须在访问边界之前提取图信号并写入记忆。

图 1(a) 的统计使这个问题具体化。直接消融去掉构造器中的图派生分布匹配后，ArXiv、SportsFit 和 BookHis 上的最终 Macro-F1 下降 (1.30)--(14.74) 个百分点。这说明图信号不能在释放后仅凭保留下来的文本重新恢复。相邻的 5% memory 对比是一个可行性参考：在相同的有限 Student 预算下，累计记忆相对于 full-history 训练保留了 (98.23)--(103.33%) 的 Macro-F1。它说明在释放前写入的信息可以在原始增量消失后继续发挥作用，但并不声称保留率本身构成因果证明。

**（ii）池化特征不是可读文本。** 特征凝聚天然是连续操作。例如，一个合成特征可以平均多个源节点：

\[
x_j^{\mathrm{syn}}=a_j^{-1}\sum_i Q_{ij}x_i.
\]

但记忆必须保存一条真实且可读的字符串。对应的软文本表示

\[
\widetilde e_j=a_j^{-1}\sum_i Q_{ij}e_i
\]

通常并不是任何实际字符串的编码。如果在特征凝聚完成后再选择文本，被选中的源文本可能并不支持这个池化特征；如果直接保存优化后的文本向量，记忆又会失去可读性和可审计性。因此，真正的难点是：在尊重文本离散性的同时，保留一个共同的源节点支持关系。

图 1(b) 量化了这一差异。固定支持关系而不是学习支持关系，会使 Macro-F1 下降 (8.91)--(21.67) 个百分点。另一个诊断比较构造过程中使用的软文本路径与最终可以保存的硬源文本，其余弦差距在三个大 TAG 上为 (0.20)--(0.47)。后一个结果不是精度消融，但它说明软文本嵌入本身不能直接视为记忆负载。两个统计共同说明，支持关系学习和文本材料化必须在同一个构造接口中考虑。

**图 1：为什么持续式 TAG 凝聚需要访问感知的图文接口。**（a）一个增量释放后，其图消息和源文本无法重新计算，因此构造器必须在释放前写入有用信号。左图是直接的挑战证据：省略图派生匹配会降低 Macro-F1；右图是可行性参考，比较累计 5% memory 与匹配的 full-history 训练。（b）特征池化是连续操作，而保存的文本必须是真实源字符串，因此同一个支持关系需要同时控制特征池化和文本材料化。左图给出固定支持关系的直接证据；右图测量软路径与硬保存文本之间的材料化差距。所有数值都来自本文协议下的诊断实验，不是示意分数，也不是普遍优越性的声明。

**CoTAG-Q 框架。** 本文提出 CoTAG-Q，一种围绕单一访问感知图文支持关系设计的持续式 TAG 凝聚框架。在阶段 (t)，类别约束矩阵 (Q) 将当前增量中的节点映射到新创建的记忆槽位。同一个关系承担两个作用：其列权重用于池化图感知特征，其支持度最大的源节点用于确定每个槽位实际保存的文本。共享支持关系的目的，是让源节点关系显式且可审计；本文并不声称这种参数化在每个数据集上都必然带来更高精度。

该框架直接遵循访问边界。在当前增量释放前，我们先在当前可访问图上进行特征传播。传播表示用于初始化支持关系，并作为分布匹配和传播匹配的图派生目标。随后历史 synthetic prefix 保持冻结，新记忆行被追加。因此，后续阶段只使用当前增量和已保存的记忆接口，不依赖隐藏的历史原始数据副本。该设计不重建完整的历史拓扑，主记忆也有意不保存显式边；只有当下游任务明确需要合成边时，才单独考虑 CoTAG-Q-T 扩展。

支持关系在构造循环内部优化，而不是在特征凝聚完成后再固定。类别掩码将槽位限制在标签兼容的节点上，平衡的列质量避免所有支持质量集中到少数槽位。分布匹配保留图感知特征的类条件统计，传播匹配保留释放前计算的关系信号。文本分支在前向计算中使用 (Q) 选出的真实源字符串；优化期间使用软文本嵌入作为反向替代路径，使图文目标能够更新 (Q)。这里的软路径不是 argmax 的精确导数。保存记忆时重新使用同一个硬选择规则，从而使最终文本负载保持可读且可审计。

这一设计将两个挑战与方法组件直接对应起来。访问感知传播和仅追加记忆保存释放后无法重新计算的信息；学习到的支持关系以及一致的硬材料化规则，则把连续特征池与有效的离散文本负载连接起来。在累计 5% 保留率下，CoTAG-Q 在 ArXiv、SportsFit 和 BookHis 上相对于匹配的 CaT 适配版本提升 (5.58)--(19.66) 个 Macro-F1 百分点。相较于更强的 GECC-hard 适配版本，CoTAG-Q 在 BookHis 上提高 3.47 点，在 ArXiv 上表现相近，在 SportsFit 上低 0.49 点。这些是统一协议下的机制适配比较，而不是官方端到端复现；本文不声称在所有设置下达到 SOTA。

**贡献。**

1. 我们提出历史访问受限的持续式 TAG 凝聚问题：每个阶段只接收当前增量和冻结的凝聚前缀，而每个保留条目都必须同时提供图感知数值内容和可读文本。
2. 我们提出 CoTAG-Q，一种访问感知的图文凝聚接口，在同一个构造循环中学习类别约束的支持关系，用于特征池化和真实文本路由。图派生匹配目标使构造器能够在当前源数据消失前写入关系证据。
3. 我们提出硬前向、软反向的文本规则，在允许优化支持关系的同时保持保存负载离散且可审计，并显式测量软路径与材料化文本之间的残差，而不是假定两者完全相同。
4. 我们对学习支持关系、分布匹配、full-history 保留、不同 Student 架构迁移、构造成本以及独立拓扑扩展的适用范围给出受控实证。
