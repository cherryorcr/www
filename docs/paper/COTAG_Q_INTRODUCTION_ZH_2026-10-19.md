# CoTAG-Q 第一部分中文翻译

文本属性图（text-attributed graphs，TAGs）将图关系与每个节点上的自由文本结合起来，自然地出现在大规模 Web 内容网络中，例如学术引文网络、电子商务和共购网络、在线知识社区以及关联文档集合。在这些网络中，图结构提供关系上下文，而节点文本（如标题、描述或帖子）则提供拓扑结构无法表达的语义信息。随着新的内容、关系以及有时还包括新的类别不断加入，这些网络持续更新。虽然在累积图上重新训练能够保留历史信息，但存储和训练成本也会随完整历史不断增长。

图凝聚通过一小组规模更小的训练样本替代大规模训练图。在持续场景中，每个到达的数据增量都必须在相应原始数据离开合法访问窗口之前，被转换为有用的记忆。后续阶段可能只能获得当前增量数据以及前序阶段写入的记忆。对于 TAG 而言，每个被保留的记忆项还必须携带可读的文本负载。因此，记忆不只是一个更小的训练集。它还是一个接口，用于将已经释放的图与文本信息传递给后续阶段。

**研究空缺。** 现有研究分别提供了这一问题所需的不同组成部分。静态 TAG 凝聚方法利用完整可用的源图构造同时包含图和文本信息的紧凑数据。持续图凝聚方法研究有限回放预算下如何保留图训练效用。联邦凝聚和多模态凝聚方法考虑了具有不同访问边界的相关场景。图与语言对齐方法则主要面向可迁移的 TAG 预测，而不是持续记忆构造。现有工作尚未明确规定以下持续接口。当前图必须在数据释放前被转换为紧凑记忆，新的记忆行在后续阶段不断加入，并且每个被保留的行都必须既包含图信息，又保留可读文本。本文研究的正是这一历史受限的持续 TAG 凝聚问题。

**两个挑战。** 数据访问边界与多模态负载共同带来了两个相互关联的挑战，具体如图 1 所示。

**（1）图依赖证据必须在不可逆的数据释放后仍然存在。** 邻域信息由当前图产生，在原始增量被释放后，无法从孤立的节点特征或文本字符串中恢复。后续阶段无法重新计算已释放节点的邻域，也无法将这些节点与未来数据重新联合凝聚。因此，构造器必须在类别和图模式持续变化的情况下，决定哪些关系证据应当被提交到有限的记忆中。由此得到的记忆承担的是状态交接的作用，而不只是一个样本集。因此，稳定性与可塑性之间的权衡成为持续凝聚的核心。

**（2）连续的特征构造必须最终产生离散的文本负载。** 凝聚过程会综合多个节点的信息，但存储的文本必须是一个真实、可读的源文本负载。连续的池化表示不一定对应任何实际字符串。因此，事后选择文本可能破坏合成特征与其文本之间的对应关系。存储优化得到的文本向量又会丢失来源信息和可审计性。持续 TAG 凝聚器需要一个共同的支持关系以及一致的文本生成规则，使特征构造与可读文本保持一致。

**设计原则与 CoTAG-Q。** 上述两个挑战带来三个设计原则。第一，应当在数据释放前提取图派生证据。第二，特征构造与文本路由应当使用同一个可审计的支持关系。第三，构造时使用的文本规则应当与最终存储的文本保持一致。

我们围绕这些原则提出 CoTAG-Q。在每个阶段，当前图用于构造新的记忆项，历史合成前缀保持冻结，只追加新的记忆行。一个受类别约束的图与文本支持关系同时组织图感知的特征构造和真实文本路由。主记忆在构造时使用图信息，但不为节点分类任务保存合成边。当结构型下游任务需要合成拓扑时，单独评估 CoTAG-Q-T。具体算法细节将在方法章节中介绍。

在固定凝聚率下，CoTAG-Q 在三个主要大规模 TAG 数据集上优于匹配的 CaT 适配版本。在统一的有限学生模型训练预算下，它能够保留与完整历史数据结果接近的 Macro-F1，并且在不改变已构造记忆的情况下迁移到 GraphSAGE 学生模型。实验部分将给出详细的对比、稳健性分析和方法局限。

**贡献。**

- 我们在明确的历史访问边界下形式化持续 TAG 凝聚问题。每个阶段接收当前增量数据和已存储的凝聚前缀。每个被保留的记忆行都必须包含图感知的数值内容和可读文本。
- 我们提出 CoTAG-Q，在当前源数据被释放前，通过受类别约束的图与文本支持关系共同进行图感知特征构造和真实文本路由。
- 我们建立了一致的构造和存储接口来处理可读文本，并在相同的持续协议下评估记忆保留率、跨架构迁移、构造成本和独立的拓扑扩展。
