## 先理解整体：我们究竟在学什么

假设本阶段收到 2,000 个图节点。每个节点有数值特征、文字、类别标签，以及与其他当前节点相连的边。我们希望把这些数据凝聚成少量训练样本，供后续模型使用，同时不再保存、重访之前阶段的原始图。

每个合成样本最终保存三样东西：一个合成特征向量、一段选中的真实文本、一个类别标签。这里把一个合成样本的位置叫作 slot，即“合成槽位”。

方法主要学习一张表：**哪些原始节点，以多大权重，共同支持哪个合成槽位。** 这张表就是 Q。同一个 Q 用于聚合数值特征、计算文本软表示、选择最终保存的文本。

真正交给优化器更新的变量是分配分数 Z 和小幅特征修正 R。Q 由 Z 通过 Sinkhorn 变换得到；合成特征和文本路由再由 Q 得到。因此，优化 Z 就会改变 Q，也会改变由 Q 构造的图文样本。

这版方法没有预先运行 CaT 把特征优化好。CaT 风格的分布匹配位于同一个优化循环中。

## 4.1 构造接口：输入和输出

### 本阶段允许读取什么

| 对象 | 内容 | 本阶段是否改变 |
|---|---|---|
| 当前增量 Δ_t | 当前合法节点的特征、文本、标签和可用边 | 原始数据固定 |
| 历史 memory M_{t-1} | 之前保存的合成特征、文本和标签 | 完全冻结 |
| 分配分数 Z | 当前原始节点到新增槽位的可学习分数 | 更新 |
| 特征修正 R | 每个新增槽位的小幅向量修正 | 更新 |
| 文本编码器 MiniLM | 将文本转换为向量 | 冻结 |
| 构造用 proxy | 计算图文任务损失和参数梯度 | 参数固定 |

历史 memory 可以参与评价，但不能被修改。历史原始节点、原始文本和原始图不能重新读取。Q 的行对应当前原始节点，列对应本阶段新增槽位；它不包含重新分配旧原始节点的权限。

### 新增多少个槽位

槽位数量由第二部分的累计凝聚率决定：先计算累计应该保留多少行，再减去历史已经保存的行数。

例如，前面累计有 10,000 个合法节点、已经保存 500 行；现在新增 2,000 个节点。按累计 5% 计算，新目标是 600 行，因此本阶段新增 100 行。这里假设类别覆盖下限没有额外触发。

类别分配先保证每个当前类别至少有一个槽位，再按类别样本数分配剩余名额。实际数量还受到取整、最大余数分配、可用样本数上限的影响。5% 是累计节点保留比例，不是固定行数，也不是显存比例。

### 输出是什么

\[
M_t=M_{t-1}\oplus\{(x_j^{\mathrm{syn}},t_j^{\mathrm{syn}},y_j)\}_{j=1}^{m}.
\]

也就是把新增图文样本追加到旧 memory 后面。主版本不保存合成节点之间的边。文本 embedding、来源标识和审计信息可随产物保存，但 dense Q 及其优化计算图不属于最终必须保留的 memory。

## 4.2 图文初始化：给 Q 一个合理起点

这一部分只决定初始分配，后面仍然会学习和改变分配。

### 为每个原始节点准备三种信息

第一种是自身特征：

\[
u_i=\operatorname{Norm}(x_i).
\]

它回答“这个节点自身是什么样”。Norm 表示把向量归一化，方便比较方向。

第二种是邻域信息：

\[
h_i=\operatorname{Norm}\left(\sum_k A_{ik}u_k+10^{-6}u_i\right).
\]

它回答“这个节点周围是什么样”。例如两篇文章内容接近，但一篇主要连向理论论文，另一篇主要连向应用论文，它们的邻域信号可能不同。很小的自身项为没有邻居的节点提供回退信号。

第三种是文本语义：

\[
e_i=\operatorname{Norm}(\operatorname{MiniLM}(t_i)).
\]

每段文本先清理、截断到 320 个字符，再用冻结的 MiniLM 编码。构造过程中不训练 MiniLM，也不直接修改原始文字。

另外预先计算一个后面用于监督的传播目标：

\[
H=\widehat A X,\qquad \widehat A=D^{-1/2}(A+I)D^{-1/2}.
\]

H 可以理解为原始节点经过一次归一化邻居信息聚合后的特征。h 和 H 都用了图，但用途不同：h 用于初始化相似度，H 用于后面的分布匹配和传播匹配。

### 选初始代表节点

把每个节点的自身特征、邻域信号和文本向量拼接成联合签名：

\[
v_i=\operatorname{Norm}[\sqrt{w_x}u_i;\sqrt{w_h}h_i;\sqrt{w_e}e_i].
\]

在同一个类别里，先选择最接近该类平均签名的节点；然后反复选择离已有代表集合最远的节点，直到每个槽位都有初始代表。这样既有一个较典型的起点，也尽量覆盖不同局部模式。

一个槽位的特征原型、邻域原型、文本原型，都来自同一个被选中的原始节点。不会把节点甲的特征、节点乙的邻域和节点丙的文本随意拼成初始化原型。

### 从代表节点得到初始分数

\[
Z_{ij}^{0}=u_i^\top p_j^x+0.75h_i^\top p_j^h+0.35e_i^\top p_j^e.
\]

这句话的含义是：原始节点 i 与槽位 j 的代表越像，初始上越倾向于支持这个槽位。因为各分量已归一化，点积可以理解为余弦相似度。

这些系数是当前实现的固定超参数，不能只凭系数大小推断三个模态的实际贡献。优化开始后直接更新 Z，不需要每一步重新挑选原型，也不要求 Z 永远等于上述相似度公式。

## 4.3 Sinkhorn：让分配合法、平衡且可学习

### Q 是一张什么表

若当前有 n 个节点、要新增 m 个槽位，则 Q 的形状为 n×m。Q_ij 表示节点 i 分给槽位 j 的支持质量。

它不是图的邻接矩阵。邻接矩阵描述“节点和节点是否相连”，Q 描述“原始节点如何被压缩到合成槽位”。

每个节点只允许支持同类别的槽位。实现直接对各类别子矩阵分别做 Sinkhorn，然后填回全零矩阵，所以跨类别 Q 值确实为零；不能把 logits 中的 -10,000 理解为最终仍然参与聚合的负权重。

### 为什么不直接 softmax

如果只对每个原始节点做 softmax，很多节点可能都偏向同一个槽位，其他槽位就几乎没有支持。Sinkhorn 同时约束两个方向：

\[
\sum_jQ_{ij}=1,\qquad \sum_iQ_{ij}=\frac{n_c}{m_c}\quad\text{（类别 c 内）}.
\]

第一条表示每个原始节点总共贡献一份质量。第二条表示同一类别里的每个槽位收到相同总质量。例如某类有 100 个节点、5 个槽位，每个槽位应收到约 20 份质量。

Sinkhorn 从由 Z/τ 确定的正权重出发，反复进行行、列缩放，直到两类和约束同时近似满足。实现使用 log 空间提高数值稳定性；温度为 0.35，从 30 次缩放起步，必要时增加到最多 2,048 次，并记录是否达到 10^-4 边际误差容限。

公式上，它等价于为正权重矩阵寻找两组缩放系数：

\[
Q_c=\operatorname{diag}(\alpha_c)\exp(Z_c/\tau)\operatorname{diag}(\beta_c).
\]

这里 exp 是逐元素取指数；左乘对角矩阵调整行，右乘对角矩阵调整列。α、β 是 Sinkhorn 根据约束算出的缩放量，不是另外交给 Adam 学习的参数。实际在 log 空间计算，避免直接指数运算造成数值溢出。

**容量平衡限制的是每列的总量，不要求每列包含相同的节点或相同权重。** 所以 Q 仍然有能力区分不同语义模式。类别之间的槽位数量也不必相等，它们在前面的配额步骤已经确定。

### 一个贯穿后面的例子

以下数值与新版流程图一致：两个类别各有 3 个节点、各分配 2 个槽位。它不是实际 5% 实验配置：

| 原始节点（类别） | 槽位 1（蓝） | 槽位 2（蓝） | 槽位 3（橙） | 槽位 4（橙） | 行和 |
|---|---:|---:|---:|---:|---:|
| 1（蓝） | 0.75 | 0.25 | 0 | 0 | 1 |
| 2（蓝） | 0.65 | 0.35 | 0 | 0 | 1 |
| 3（蓝） | 0.10 | 0.90 | 0 | 0 | 1 |
| 4（橙） | 0 | 0 | 0.80 | 0.20 | 1 |
| 5（橙） | 0 | 0 | 0.50 | 0.50 | 1 |
| 6（橙） | 0 | 0 | 0.20 | 0.80 | 1 |
| 列和 | 1.50 | 1.50 | 1.50 | 1.50 | |

槽位 1 主要由节点 1、2 支持，槽位 2 更偏向节点 3。每个原始节点可以同时支持多个同类槽位，这就是软分配。以蓝类为例，n_c/m_c=3/2，所以两个槽位各收到 1.5 的总质量。

类内掩码只约束归属关系，不意味着删除当前原始图中的跨类别边。只要属于当前合法增量，图传播仍然可以使用这些边。

## 4.4 从同一个 Q 得到特征和文本

### 数值特征：加权平均，再小幅修正

\[
a_j=\sum_iQ_{ij},\qquad \bar x_j=\frac{\sum_iQ_{ij}x_i}{a_j},\qquad x_j^{\mathrm{syn}}=\bar x_j+r_j.
\]

在上面的例子中，槽位 1 的池化特征为：

\[
\bar x_1=\frac{0.75x_1+0.65x_2+0.10x_3}{1.5}
=0.5x_1+\frac{13}{30}x_2+\frac{1}{15}x_3.
\]

Q 的第一列和为 1.5，所以需要除以 1.5 才得到归一化的加权平均。若 x₁=(1,0)、x₂=(0.8,0.2)、x₃=(0.2,0.8)，则池化结果为 (0.86,0.14)，再加上小幅 r₁ 才是保存的合成特征。Q 中“节点到槽位”的质量，与列归一化后“槽位由哪些节点组成”的权重，方向不同，但来自同一张表。

r_j 是可学习 residual，初始为零，用来弥补单纯加权平均的表达限制。更新后它的范数受到约束：

\[
\|r_j\|_2\leq0.05\max(\|\bar x_j\|_2,10^{-3}).
\]

这里的 0.05 表示修正幅度相对池化特征的上限，与“保留 5% 的节点”是两个不同概念。优化 X 有两条路径：调整 Q 改变原始节点的组合，以及调整 R 改变组合后的特征。

### 文本软表示：沿用同一组支持

\[
\widetilde e_j=\operatorname{Norm}\left(\frac{\sum_iQ_{ij}e_i}{a_j}\right).
\]

对于槽位 1，文本软向量就是 0.5e₁+(13/30)e₂+(1/15)e₃ 再归一化。它可以用于可微计算，但通常不能唯一翻译回一段自然语言。

### 最终保存文本：选质量最大的真实来源

\[
i_j^\star=\arg\max_{i:y_i=y_j}Q_{ij},\qquad t_j^{\mathrm{syn}}=t_{i_j^\star}.
\]

上面的槽位 1 保存节点 1 的清理后文本，即图中的 “graph learning”；槽位 2 保存节点 3 的文本，槽位 3、4 分别保存节点 4、6 的文本。当前主版本每个槽位选择一个来源，不是随机选五段，不是 LLM 生成，也不是把向量解码成新句子。

同一 Q 保证两种模态有共同的支持依据；但特征是多个节点的混合，文本是其中一个来源，所以二者不必完全同义。容量平衡也不自动保证不同槽位选择不同文本。

### 离散选文本，为什么还能学习

argmax 本身不能提供普通的连续梯度。实现使用 straight-through（直通）近似：

\[
e_j^{\mathrm{ST}}=e_{i_j^\star}+\widetilde e_j-\operatorname{sg}(\widetilde e_j).
\]

sg 表示 stop-gradient：保留数值，但反向传播时不计算它的导数。

前向时，后面两项数值抵消，所以模型看到的就是选中的真实文本 embedding。反向时，sg 项不传梯度，于是借助软表示把梯度传给 Q，再传给 Z。这是一种代理梯度，不是 argmax 的精确导数。

它实际调整的是“各候选文本受到多少支持”，不修改字符，也不改变 MiniLM 参数。分配改变后，最高分的来源可能发生切换，最终存储的文本也随之改变。

更精确地说，反向使用以下代理链路：

\[
\left.\frac{\partial L}{\partial Z}\right|_{\rm text}
=\frac{\partial L}{\partial E^{\rm ST}}
\frac{\partial\widetilde E}{\partial Q}
\frac{\partial Q}{\partial Z}.
\]

这里乘法表示对应的雅可比链式求导，不是把普通数值逐项相乘。假如当前选了节点 1 的文字，但图文损失的代理梯度倾向节点 2 的语义，Z 的更新可以使 Q₂₁ 增大、Q₁₁ 减小；Sinkhorn 同时重新平衡整类的行列质量。只有当硬排名改变时，选中文字才切换。这个例子只是说明可能的更新方向，不保证实际梯度每一步都如此。

因此，文本 ID 连续几步没有变化，不代表 Q 没有更新。相反，代理梯度更新也不能保证硬文本每次切换都会改善下游准确率。

最后一次更新后重新计算 Q，按同一规则选取来源、保存字符串、重新编码并检查 embedding 一致性。这里的一致性是保存与前向表示的实现约定，不是“软硬表示之间一定没有差距”的数学保证。

## 4.5 优化目标：怎样判断当前凝聚结果好不好

只说“加权平均并挑一句话”还没有解释为什么结果有用。损失函数负责把下游可用性和原始图信息转化为更新 Z、R 的信号。

### A. 构造用 proxy 与最终 Student 不同

构造用 proxy 是随机初始化的两层图文模型，当前设置的隐藏维度、输出维度都是 384。它在本阶段不做参数更新，只负责在同一组参数 θ 上评价真实侧和合成侧。

最终评估的 Student 则是在 memory 构造完成后独立初始化并真正训练的模型，主实验训练 2,048 步，使用规定的 Student seeds。不能把构造的 30 次 Z/R 更新和最终 Student 的 2,048 次参数更新混为一谈。

### B. proxy 的任务损失

\[
L_{\mathrm{proxy}}=0.5L_{\mathrm{pair}}+L_{\mathrm{prompt}}+0.1L_{\mathrm{margin}}.
\]

| 子损失 | 通俗含义 |
|---|---|
| pair | 让图分支表示与同类文本表示相互接近；同类样本都是正例，并非仅同一个源节点是正例 |
| prompt | 让节点更接近正确类别的 prompt，用类别交叉熵监督 |
| margin | 要求正确 prompt 的分数相对最强错误 prompt 有足够间隔；实现的 margin 为 0.20 |

图文向量会分别经过 proxy 的图分支和文本投影进入共同表示空间。冻结 MiniLM 与“后续 Student 的文本投影可训练”也不矛盾。

### C. GM：比较两份数据会让同一模型怎样学习

真实侧数据是旧 synthetic memory 加当前原始增量；合成侧数据是同一份旧 memory 加新构造的槽位：

\[
g_r=\nabla_\theta L_{\mathrm{proxy}}(M_{t-1}\oplus\Delta_t),\qquad
g_s=\nabla_\theta L_{\mathrm{proxy}}(M_{t-1}\oplus M_t^+).
\]

这里的“真实侧”并不代表可以访问完整历史原始数据。历史侧只有合法保存的 synthetic memory。旧组和当前组具有相同总权重，组内各个出现的类别等权。

如果用真实数据训练一步，会得到一个建议的参数变化方向；如果用合成数据训练一步，也会得到一个方向。GM 希望两个方向接近，同时梯度大小不要差得太远：

\[
L_{\mathrm{GM}}=1-\cos(g_r,g_s)+0.25\left|\log\|g_r\|_2-\log\|g_s\|_2\right|.
\]

真实梯度可以缓存，因为真实侧和 proxy 参数固定。合成梯度必须每步重算，因为 Z/R 改变了合成数据。

关键是有两层求导：先对模型参数 θ 求任务梯度；再计算梯度差，并把这个差对 Z、R 求导。实际更新的仍然是凝聚变量，不是 proxy 参数。这是构造中二阶自动微分开销的来源。

特征通路为 Z → Q → X_syn → proxy loss → GM。文本通路为 Z → Q → 软文本的代理梯度 → 硬前向图文损失 → GM。两条路径最终都能反馈到 Z。

### D. DM：匹配每个类别的图特征统计

真实图先产生 H=ÂX；合成侧使用新增无边行的 X_syn。分别通过四个固定的随机投影：

\[
\phi_b(x)=\operatorname{Norm}(\operatorname{ReLU}(xW_b)).
\]

每个投影宽度为 512。对同一类别，分别求真实侧和合成侧的投影均值，并使它们接近：

\[
L_{\mathrm{DM}}=\frac{1}{4}\sum_{b,c}\|\mu_{bc}^{\mathrm{syn}}-\mu_{bc}^{\mathrm{real}}\|_2^2.
\]

可以把四个投影理解为四种固定观察方式：从这些角度看，每类合成数据的平均表现应当接近真实图。投影包含非线性，因此不只是强迫原始向量的一个均值相同；但它也不是完整分布一致性的证明。

这里的非线性有具体意义：若 R=0、容量约束精确成立，只对池化后的原始特征取类均值，会得到

\[
\frac{1}{m_c}\sum_{j\in c}\bar x_j=\frac{1}{n_c}\sum_{i\in c}x_i.
\]

这个均值本来就不随 Q 的具体排列改变。先经过非线性投影再求均值，才会对“哪些节点被组合进同一个槽位”敏感。实际 DM 还以图传播后的 H 为真实目标，并允许受限 R 修正，因此不能把它理解为简单重复一次原始特征均值计算。

这就是借鉴 CaT 的部分：让少量合成特征匹配真实图传播后的类别统计。区别在于这里把损失放进 Q/R 的联合优化循环，借助 Q 改变组成合成样本的支持关系。

当前主方法的这一项只直接比较图特征统计，不是已经改成了完整的节点级图文联合分布匹配。文本主要通过初始化、真实文本路由和 proxy 路径进入构造。

### E. propagation：每个槽位也应反映它所支持的邻域信息

\[
L_{\mathrm{prop}}=\frac{1}{m}\sum_j\left[1-\cos\left(\frac{\sum_iQ_{ij}H_i}{a_j},x_j^{\mathrm{syn}}\right)\right].
\]

DM 看整个类别的统计；propagation 逐个槽位检查。若某个槽位主要支持某一组原始节点，它的最终特征就应与这些节点传播后的聚合方向相近。

例如，在同一类别里，两组节点分别有两种邻域模式。即使整个类别的均值已经匹配，各槽位仍然可能把这两种模式混乱地组合；这个损失试图约束槽位自身与其邻域目标的对应。

它与 DM 监督的粒度不同，但并不意味着两项在每个数据集上必然互补，其实际收益仍需消融判断。

**H 固定不等于整个传播参考固定。** 图 (d) 第三行的参考是 D_a⁻¹QᵀH；虽然 H 缓存后不变，Q 每步变化，因此这一侧也每步重算、参与反向传播。相反，第一行的真实侧 proxy 梯度、第二行的真实侧类别投影均值可以缓存。图特意把第三行标为 “depends on Q”，避免把三种匹配都误解为“合成数据拟合完全不变的目标”。

### F. 两个约束项：防止无控制地漂移

Q-anchor 惩罚 Q 偏离初始 Q_0 太多，为最初的图文结构先验保留一定影响。它是软惩罚，不会固定 Q。

R 的惩罚约束归一化后的修正幅度。其归一化尺度是初始池化特征范数；另外还有前面提到的相对当前池化特征的 5% 硬幅度上限。

完整目标为：

\[
L=L_{\mathrm{GM}}+L_{\mathrm{DM}}+0.5L_{\mathrm{prop}}+0.1\frac{\|Q-Q_0\|_F^2}{nm}+0.1L_R.
\]

Adam 联合更新 Z、R 共 30 步，学习率分别是 0.15 和 0.005，梯度裁剪阈值为 5。原始图、原始特征、原始文本、旧 memory、MiniLM 和 proxy 参数都固定。

这里没有 E-step/M-step，也没有独立更新一个概率生成模型的似然；应称为联合可微优化，不能直接称为 EM。

## 4.6 一次完整阶段按什么顺序执行

1. 读取当前合法增量和冻结的历史 memory，计算新增槽位数、类别配额。
2. 清理并编码当前文本，计算初始化用邻域信号和监督用传播特征 H。
3. 选图文代表节点，建立初始 Z，经过 Sinkhorn 得到 Q_0，把 R 设为零。
4. 缓存真实侧 proxy 梯度、随机投影及类别统计目标。
5. 每一步由当前 Z 重新计算 Q，再构造池化特征、加上 R，并选择文本进行硬前向。
6. 计算 GM、DM、propagation 和两个约束项，将梯度传回 Z、R；更新并限制 R 幅度。
7. 重复至 30 步，重新计算最终 Q、特征和文本来源，检查保存字符串与 embedding 的一致性。
8. 把新样本追加到历史 memory，记录审计信息，释放 dense Q 和构造临时张量。
9. 在独立的下游评估步骤中，用完成的 memory 训练 Student。

从优化角度看，循环是：

\[
(Z,R)\longrightarrow Q\longrightarrow(X^{\mathrm{syn}},T^{\mathrm{syn}})\longrightarrow L\longrightarrow\text{更新 }(Z,R).
\]

## 几个最容易混淆的问题

### 无边是不是意味着完全没有使用图

不是。当前图的 A 决定初始化邻域信号 h、传播目标 H，以及真实侧 proxy 的图传播。合成侧通过损失吸收这些图信息。

“无边”只描述最终 memory 不保存样本之间的 synthetic edges。主版本在 memory 上运行 GCN 时，邻接只有自身连接；因此该阶段的图卷积没有跨合成节点的消息传递。实验读出可以在协议允许的评估图上使用原始图结构，但这不意味着构造器获得了历史原始图访问权。

把图信息压进特征，不等于可以从 memory 精确重建原始连边。因此当前结果主要支持节点分类；需要显式拓扑的结构任务由 CoTAG-Q-T 单独研究。

### “联合”到底联合了哪些内容

联合的是特征支持和文本支持：同一套 Q 决定数值特征的聚合，以及文本的软路由和真实来源。图结构作为固定的输入与监督进入构造。

这不等于同时学习原始邻接 A、原始特征 X、文本字符串和语言模型。主版本没有可学习的 synthetic topology。

### 冻结历史 memory，就完全没考虑旧知识吗

旧 memory 出现在真实侧和合成侧 proxy 任务中，新槽位是在它存在的条件下接受评价。最终 Student 也在保存的新旧 memory 上学习。

不过，旧 memory 的内容和特征确实不会被改写；当前主版本也不重建新旧 synthetic edges。保留历史样本和让评价考虑历史样本，不等于解决了完整的新旧拓扑建模问题。

### 这与“先 CaT 后附着文本”有什么区别

后处理路线先确定特征，再依据已经确定的特征给它附加文本。当前路线把支持 Q 放在特征和文本的上游：构造尚未结束时，分布匹配、传播目标和图文 proxy 已经能够改变支持和特征。

因此，文本在初始化和代理梯度路径里能够影响 Q，而不只是凝聚结束后的附加项。但不能由这条可微路径的存在直接推断它一定贡献了更高准确率。

### 为什么凝聚率只有 5%，构造却可能很费显存

Q 的大小为 n×m。即使 m 仅约为 n 的 5%，Q 仍有约 0.05n² 个元素，而不是原始特征矩阵大小的 5%。实际 n、m 以本阶段及累计配额为准。

除此之外，还要存储梯度、优化器状态、Sinkhorn 中间量和 proxy 计算图。GM 使用二阶自动微分，进一步增加构造开销。Q 在构造后被释放，后续 Student 训练的资源消耗要单独测量，不能用构造峰值代替。

### 哪些部分已有较直接的效果证据

当前正文的核心消融中，固定 Q 后 ArXiv、SportsFit、BookHis 的 Macro-F1 分别下降 12.76、21.67、8.91 个百分点；去掉 DM 分别下降 1.91、14.74、1.30 个百分点。这支持“在当前构造器里学习分配、进行循环内 DM”具有实际作用。

这组实验是一个注册类别顺序、三个 construction seeds、每个构造单元三个 Student seeds，不能把它表述为所有设置上的必然结论。共享 Q 优于独立 Q、GM 独立提高准确率，是另外两项需要分别检验的命题；现有结果并未显示二者都有稳定的精度优势。

论文可据此清楚地区分：共同支持是设计方式，学习支持和 DM 是目前证据较直接的有效机制，端到端基线比较衡量整个方法是否适用于当前持续 TAG 任务。
