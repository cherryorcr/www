# 第四部分 实验（中文翻译）

本部分围绕四个研究问题组织实验：

- **RQ1：** 与匹配的凝聚方法和样本选择方法相比，本文得到的 memory 是否有效？
- **RQ2：** 哪些构造机制解释了 memory 的有效性？
- **RQ3：** memory 能否迁移到不同的 Student，并保留相对于完整历史数据的效用？
- **RQ4：** 构造成本以及更新步数与性能之间存在怎样的权衡？

## 4.1 实验设计

### 数据集与数据流

主要实验数据集为 ArXiv、SportsFit 和 BookHis，分别覆盖引文图和商品图场景。为了扩展数据集覆盖范围，我们在更广泛的比较面板中加入 Cora 和 Citeseer。

在跨数据集主实验中，三个大图都采用统一的五阶段 `base+4` 结构：第一个阶段为 base stage，之后依次到达四个类别增量阶段。由于不同数据集的原始数据流不同，各阶段的类别数仍保持数据集自身的设置，而不是强行设为相同数量：ArXiv 为 8/8/8/8/8，SportsFit 为 5/2/2/2/2，BookHis 为 5/2/2/2/1。我们另外保留原始的三阶段 ArXiv 数据流（13/14/13），作为独立的协议敏感性确认实验；该结果不与统一的 `base+4` 面板混合统计。

构造器只能访问当前阶段合法的构造节点及其诱导边。测试节点标签不会用于 memory 构造，也不会用于 Student 训练。

### 表 1：数据流与 memory 规模

| 数据集 | 合法节点数 | 最终 memory 行数 | 阶段数 | 类别安排 |
|---|---:|---:|---:|---|
| ArXiv（统一 base+4） | 118,539 | 5,927 | 5 | 8/8/8/8/8 |
| ArXiv（确认实验） | 118,539 | 5,927 | 3 | 13/14/13 |
| SportsFit | 121,137 | 6,057 | 5 | 5/2/2/2/2 |
| BookHis | 29,086 | 1,454 | 5 | 5/2/2/2/1 |

表 1 中的 `base+4` 表示一个 base stage 加四个类别增量阶段，并不要求五个阶段包含相同数量的类别。所有最终 memory 都按照累计 5% 的保留率计算。

### 统一 Student

所有需要公平比较的方法都使用同一个两层 Prompt GCN、冻结的 MiniLM、完全相同的类别 prompt 和 320 字符文本预处理。Student 训练使用 2,048 个更新步、batch size 24，以及 Student seeds 150/151/152。

训练目标同时使用 memory 标签、prompt 监督和图文配对损失。推理在原始图上进行 transductive 预测，并且不使用留出节点标签。需要强调的是，构造阶段的历史原始数据访问限制，并不等价于下游推理阶段必须完全去除原始图结构。

为了检验架构迁移能力，我们进一步使用两层均值聚合 GraphSAGE 替换图编码器，而不重新调整构造过程。GraphSAGE 直接复用已经归档的 memory。

### 对比方法与复现保真度

CaT-CCTP 保留 CaT 风格的特征分布匹配；GECC-hard-TAG 保留传播特征聚类和池化机制。两个方法都接入相同的 current-delta wrapper、冻结历史前缀、累计 5% 保留率、统一 Student，以及相同的五来源文本适配器。

此外，我们评估了 Random、K-center、Cluster-medoid 和 Herding 四种选择控制方法，并纳入 GCond-x 的官方核心适配、受限版本的 SFGC，以及有明确限定的 TAGSAM/STAD 参考结果。本文明确区分以下两类结果：

- **机制适配（adaptation）**：在原论文机制之外改变其数据访问接口、训练协议或持续式包装，使其能够进入当前任务；
- **官方复现（official reproduction）**：尽可能保留原方法的原生端到端协议，不改变其核心数据访问和训练流程。

预算缩减、数据生成器变化和其他接口改动都在附录中明确记录。某个适配版本分数较低，不能单独证明该原生方法在其原始任务上较弱，也不能直接据此得出本文方法优越的结论。

PUMA 不再放入主比较表。它仍可作为相关工作中的背景方法或附录参考，但不参与本文主表的统一 Student 排名。

### 指标与统计范围

主比较面板使用三个类别顺序和三个构造种子，每个构造单元内部再平均三个 Student seeds。因此主面板共有九个 order/seed cells。我们报告最终 Macro-F1、Accuracy、cell mean 的样本标准差以及名义的配对 95% t 区间。

这些区间描述的是在当前检查过的 mask 条件下，类别顺序和随机种子造成的变化，不包含方法被自适应选择所产生的额外不确定性。

五数据集扩展面板使用一个类别顺序、一个构造种子以及三个 Student seeds。额外的 held-out-mask 检查会在新的合法节点池上重建所有方法，并使用一个顺序和三个构造种子。两类统计范围分别分析，不进行混合。Old/New F1 和阶段平均 F1 放在补充结果中。

### 实现与资源测量

所有数据集都使用第四部分方法章节中给出的构造超参数。每个运行记录访问 mask、类别容量、随机种子、实际保留率、Sinkhorn 误差、文本来源标识以及配置哈希。

我们分别测量构造阶段、Student 训练阶段和推理阶段的资源。完整历史数据的比较使用相同的有限 Student 训练预算，并使用由合法节点池诱导出的图，而不是使用已经收敛的 full-data oracle。

## 4.2 RQ1：比较性能与实际效用

### 多顺序比较

表 2 比较了在统一五阶段 `base+4` 协议下完整复现的三个构造器。相对于 CaT-CCTP，本文方法在 ArXiv、SportsFit 和 BookHis 上分别提升 16.61、5.58 和 3.47 个 Macro-F1 百分点。ArXiv 的配对比较在九个 cells 中全部为正。

相对于更强的 GECC-hard 适配版本，结果具有明显的数据集依赖性：

- ArXiv 提升 0.62 个百分点，区间为 [-0.45, 1.69]，九个 cells 中有 6 个为正；
- SportsFit 中 GECC 高 0.49 个百分点，区间为 [-1.50, 0.52]；
- BookHis 提升 3.47 个百分点，区间为 [2.20, 4.74]，九个 cells 全部为正。

在 BookHis 上，本文方法的 Old/New F1 从 GECC-hard 的 45.48/43.86 提升到 48.39/53.45。因而，统一比较面板支持的是：本文方法相对于 CaT 具有稳定优势，相对于 GECC 则在部分大图上具有条件性的优势，而不是在所有图上都统一占优。

## 4.3 RQ2：哪些构造机制真正重要

核心消融实验固定初始化方式、residual、未被移除的其他目标以及训练预算。每个实验使用一个类别顺序、三个构造种子，并在每个 cell 内平均三个 Student seeds。

### 表 3：核心组件消融

| 构造器 | ArXiv | SportsFit | BookHis |
|---|---:|---:|---:|
| CoTAG-Q | 52.96±0.21 | 80.02±0.30 | 48.53±0.85 |
| Fixed Q | 40.20±0.20 | 58.35±0.48 | 39.62±0.17 |
| No DM | 51.05±0.64 | 65.28±0.82 | 47.23±0.97 |
| No GM | 53.20±0.19 | 80.47±0.56 | 48.47±1.11 |

### 学习支持关系与保持分布

固定 Q 会使三个数据集上的 F1 分别下降 8.91--21.67 个百分点；移除 DM 会使 F1 下降 1.30--14.74 个百分点。每一个构造 cell 都支持学习型 support 和 DM。

这些结果支持的结论是：构造器应在构造过程中学习 support，而不能把初始化时的 pooling 视为充分结果。需要注意的是，这些实验并不能把同样的收益专门归因于“两个模态共享 Q”这一点。

### 文本和图信号分别带来的作用

移除文本感知初始化后，SportsFit 的 F1 下降 2.51 个百分点，Accuracy 下降 6.87 个百分点，配对区间为 [0.48, 4.55]。这是目前最清晰的单独文本收益。

一个只去掉构造阶段图信号的控制实验，在 ArXiv、SportsFit 和 BookHis 上的 F1 变化分别为 +0.55、-0.75 和 +0.30 个百分点，下游图推理不变。因此，图来源的构造信号在 SportsFit 上有帮助，但并不在所有数据集上统一有利。

### 接口收益与精度归因

在受控比较中，其他构造选择保持不变。共享 Q 使用一个 logit 矩阵替代两个矩阵，使 ArXiv 的构造峰值显存从 15.99 GiB 降至 12.08 GiB，SportsFit 从 32.60 GiB 降至 24.72 GiB。其 F1 差异并不一致。

同样，No-GM 的分数与完整构造器接近。因此，GM 仍保留在本文主方法的评估版本中，但该消融并不能证明 GM 独立带来了精度收益。

硬前向文本规则保证构造过程中的文本和最终保存的文本 payload 一致；固定特征、相同文本预算的控制实验则没有显示其相对于最近邻或随机附着具有普遍精度优势。附录进一步报告文本附着控制和 slot 诊断。

## 4.4 RQ3：Student 迁移与完整历史效用

### 相同 memory 下的架构迁移

对每种方法复用全部九个 ArXiv memory，Prompt GraphSAGE 在 CoTAG-Q、GECC-hard-TAG 和 CaT-CCTP 上分别得到 53.93、52.60 和 50.24 F1。

在不改变构造器和已存文本的情况下，CoTAG-Q 比 GECC 提升 1.34 个百分点，并且九个 cell 的差值全部为正。这说明 memory 的效用不只针对主实验中的 GCN Student；但它并不意味着在所有数据集、所有架构上都能取得普遍优越性。

### 5% 保留率下的效用

表 4 比较了凝聚训练与完整合法历史数据及其诱导图。使用相同的有限 Student 训练预算时，CoTAG-Q 保留了完整历史 Macro-F1 的 98.23%--103.33%，Accuracy 的 95.58%--99.14%。

保留率超过 100% 可能来自有限预算下的优化和采样差异；这里的 full-history 参考并不是已经收敛的完整图最优结果。

| 数据集 | Full-history F1 | 5% F1 | F1 保留率 | Accuracy 保留率 |
|---|---:|---:|---:|---:|
| ArXiv | 53.47 | 52.96 | 99.04% | 97.60% |
| SportsFit | 81.46 | 80.02 | 98.23% | 95.58% |
| BookHis | 46.96 | 48.53 | 103.33% | 99.14% |

## 4.5 RQ4：资源开销与更新敏感性

### 构造阶段与使用阶段

在主实验中，CoTAG-Q 的构造峰值显存为 2.91--24.08 GiB，而两个匹配基线都低于 1.1 GiB。主要开销来自稠密 support、可微归一化以及二阶 proxy 状态。把稠密 identity operator 替换为稀疏形式，在 ArXiv 上只节省 0.06 GiB，在 SportsFit 上只节省 0.11 GiB；因此，identity operator 不是主要瓶颈。

独立的阶段审计显示，memory-based Student 训练阶段在 ArXiv、SportsFit 和 BookHis 上的峰值显存分别约为 508、512 和 201 MiB；在原始图上推理时分别为 1,679、1,711 和 486 MiB。这两个阶段的分配在匹配方法之间是共同的。

这些阶段测量解释了为什么一个保存规模很小的 memory 仍然可能有昂贵的构造阶段：压缩降低的是长期存储和 Student 训练阶段的负担，不等价于构造过程本身也低成本。这里的测量也不是完整历史训练速度的基准测试。

### 额外构造更新

本文保留注册时的 30-update 预算。在 No-GM 的开发诊断中，更长的运行并不能稳定提升下游 F1：ArXiv 在 60 updates 时变化为 -0.14 个百分点；BookHis 在 60 和 100 updates 时分别变化为 -2.25 和 -1.58 个百分点。已经完成的轨迹在更晚阶段趋于平坦，但只有 65 条已完成阶段轨迹中的 20 条满足预先定义的实用平台判据。

更长的 SportsFit 运行因 OOM 失败。附录给出完整轨迹和失败记录。该结果支持采用当前的有限训练预算，但不能声称完整 GM 目标在 30 updates 时已经对所有阶段严格收敛。

## 第四部分小结

实验结果支持以下较为谨慎的结论：

1. 在相同累计 5% 保留率、相同 Student 和统一持续协议下，CoTAG-Q 相对于 CaT 具有稳定优势；相对于 GECC-hard，其优势主要在 ArXiv 和 BookHis 上体现，SportsFit 上则接近但略低。
2. 真正有稳定证据支持的是 support 学习和 in-loop distribution matching，而不是共享 Q 本身必然提升精度。共享 Q 的明确收益主要体现在统一图文支持接口、减少分配参数和降低部分构造显存。
3. CoTAG-Q 的 memory 可以迁移到 GraphSAGE，并在有限 Student 预算下保持接近完整历史训练的性能。
4. 当前方法的资源优势主要体现在保存 memory 和下游 Student 使用阶段；构造阶段仍然可能受到稠密 support、二阶状态和 GPU 显存限制。

因此，正文应将方法优势表述为“在历史受限的持续 TAG 凝聚中提供统一、可学习且可审计的图文 memory 构造接口，并在若干大图上取得有竞争力的性能”，而不应声称共享 Q 在所有数据集上都带来独立的精度提升，或声称构造阶段始终比其他方法更省资源。
