```latex
\subsection{研究动机}

文本属性图（text-attributed graphs，TAGs）将关系结构与节点级语言信息结合起来。静态 TAG 凝聚可以在完整源图可用时构造图--文本样本~\cite{tagsam,stad}。不断演化的 Web 目录和关联文档集合会持续累积关系与文本信息。当学习器无法保留历史原始快照时，如何在紧凑、增量构建的记忆中保留历史数据共同用于训练的价值，便成为 Web 图学习中的一个关键挑战。持续图凝聚则主要面向图特征，在数据分阶段到达的过程中维护紧凑记忆~\cite{cat,puma}。联邦 TAG 凝聚研究了相关但不同的数据访问边界~\cite{dance}。在这种场景下，一个有用的凝聚样本必须同时保留数值表示、标签和可读文本负载，即使构造器无法重新访问早期阶段的原始特征、文本或边。因而，记忆不只是一个更小的训练集；它还是一个持久化接口，使过去的多模态信息能够继续影响后续阶段的构造。

本文在一个具体的数据访问规则下研究这一接口。在第 (t) 个阶段，构造器可以获得当前增量数据以及第 (t-1) 阶段保存的合成记忆，但无法访问历史原始数据。它必须在保留类别覆盖的同时追加一个小规模数据块，并且不能隐式使用原始历史数据。这里的问题并不是静态 TAG 方法能否使用文本，而是：在仅访问当前增量数据的约束下，持续构造器应如何决定哪些当前节点为每个新的合成特征提供支持，以及哪些真实文本应当与该特征一同存储。

\subsection{问题与设计目标}

本文的核心设计目标，是在当前原始节点与合成槽位之间建立一种可学习的支持关系。先使用仅处理图的凝聚器，再独立附加文本，是一种有力且有用的对照方案；但在这种做法中，文本附着过程并未参与特征构造目标。于是我们提出如下问题：能否使用一个统一且可审计的分配关系，同时为特征和文本提供支持，并且在仅访问当前增量数据的条件下保持协议合法？这一目标比“所有文本感知 TAG 方法在结构上都将两者解耦”这样的表述更为有限；TAGSAM 和 STAD 已经包含了实质性的文本机制。本文的贡献在于研究持续构造接口，并在相同的数据访问边界下对其进行评估。

\subsection{方法概述}

我们提出 \method{}，一种具有无边主记忆的图感知持续 TAG 凝聚方法。当前节点特征、单跳图消息以及冻结的 MiniLM 文本嵌入共同初始化一个受类别约束的分配矩阵 (Q)。容量平衡的 Sinkhorn 算子将分配 logits 转换为可用于构造的支持权重。随后，同一个 (Q) 同时承担以下作用：

\begin{enumerate}[leftmargin=*,nosep]
    \item 将当前特征池化为新的合成行；
    \item 路由真实文本嵌入，并选择可审计的文本来源字符串；
    \item 提供槽位级图消息目标；
    \item 接收循环内构造目标产生的梯度。
\end{enumerate}

该分配关系与一个有界的特征修正项联合优化。优化循环包括 CaT 风格的类别统计分布匹配、传播匹配，以及与 Student 兼容的图--文目标。最终存储的文本负载来自与硬构造前向过程中使用的同一份清洗后源文本，而软路由则为 (Q) 提供替代梯度。因此，该方法不会先生成一个不透明的文本向量、再用一个彼此无关的字符串替换它。

主记忆存储特征、标签、真实文本和审计元数据，但不存储合成邻接矩阵。这是本文明确设定的范围边界。当前增量图仍然会在构造阶段被使用，同时我们单独设计了 \topomethod{} 分支，为结构任务生成合成边。本文的主要结论针对无边、基于 prompt 的节点分类；拓扑保持则作为扩展进行评估，而不是并入主方法。

\subsection{贡献与范围}

本文有三点贡献：
\begin{enumerate}[leftmargin=*,nosep]
    \item 我们在仅访问当前增量数据、采用按累计数据量增长的固定比例记忆以及冻结合成前缀的条件下，形式化并审计了历史受限的持续 TAG 凝聚问题。这使得记忆实际保留的信息变得明确且可复现。
    \item 我们提出 \method{}，通过一个受类别约束的可学习支持关系，共同组织图感知的特征池化与真实文本路由。该方法将支持关系作为可优化的构造变量，而不是固定的池化规则或事后文本附着规则。
    \item 我们将机制证据与基准覆盖范围分开报告。在三个大图上的九个顺序/种子重复单元中，\method{} 相较于匹配的 CaT 适配版本取得稳定提升，并且在 BookHis 上相较于 GECC-hard-TAG 提升了 3.47 个 Macro-F1 百分点。受控实验表明，学习 (Q) 和循环内分布匹配是最可靠的预测机制；在相同记忆上的 GraphSAGE 迁移以及与 full-history 匹配的结果，则分别用于评估方法的稳健性和压缩记忆的实用价值。
\end{enumerate}

实验结果并不支持“在所有场景下达到 SOTA”的普遍性结论。在 SportsFit 上，GECC-hard-TAG 更强；在 ArXiv 上，两者在统计意义上相当。同样，消融实验并未显示共享两个分配关系、额外的成对反馈路径或单独使用梯度匹配能够普遍带来精度优势。我们仍然保留这些组件来定义完整方法，因为它们共同实现了统一的构造接口；同时，我们明确报告它们的代价与权衡，而不把它们表述为已经被单独证明的精度来源。

本文的主要下游任务是基于 prompt 的节点分类，使用图感知的无边记忆。支持拓扑的 \topomethod{} 分支是独立扩展；本文也不将 prompt 读出称为严格意义上的未见类别零样本学习。

\xf{
文本属性图（text-attributed graphs，TAGs）广泛存在于学术文献网络、电子商务平台和在线知识社区中。它们通过节点级文本与关系结构共同刻画 Web 内容的语义信息和组织结构。近年来，图神经网络与语言模型的结合推动了结构信息和文本信息的联合学习~\cite{NEURIPS2023_37d00f56}。已有研究通过图与文本摘要之间的对比学习来获得可迁移表示，并使用自然语言支持下游任务~\cite{zhu2025graphclip}。随着 Web 内容规模和关系复杂度不断增长，TAG 凝聚试图通过构造能够保留结构与语义信息的紧凑训练数据，缓解内容理解与组织中的模型训练可扩展性问题~\cite{han2026text}。然而，Web 平台会不断加入新内容和新类别，数据形态也逐渐从一次性收集的静态图转变为分阶段到达的图--文本数据流，因而要求模型持续获得新知识。已有研究表明，图--文本对齐模型在连续任务之间会出现明显遗忘，因此在持续 TAG 学习中保留历史知识十分重要~\cite{wang2026g2lora}。当历史原始数据无法重新访问时，凝聚数据还必须在不同阶段之间充当记忆，保存历史信息以支持后续学习。因此，如何将持续到达的图--文本数据凝聚为一种同时保留训练效用和可读文本负载的记忆，是支持图--文本模型持续更新的关键问题。
}

\xf{
在历史原始数据无法持续保存或重新访问的 Web 图--文本学习场景中，这一问题尤其突出。随着内容不断累积，有限记忆难以充分捕获历史数据分布；同时，新增数据与历史记忆之间的规模不平衡可能使训练偏向新任务，并加剧遗忘~\cite{liu2023cat}。图凝聚通过少量、具有较高训练效用的合成样本来近似大规模原始数据；已有方法通过梯度匹配学习凝聚图，或将原图中的结构知识编码到节点特征中，而不显式存储合成边~\cite{jin2021graph,zheng2023structure}。然而，将这些静态图凝聚方法用于持续 TAG 学习时，需要使用紧凑表示在不同阶段之间充当记忆，同时还必须解决数值特征无法直接替代下游模型所需的可读文本负载这一限制~\cite{lai2026semi}。因此，有必要研究历史受限的持续 TAG 凝聚，并确保有限记忆在支持新类别学习和旧类别识别的同时，能够保留有用的图--文本信息。
}

\xf{
已有研究通过回放、伪标签、分布建模和节点映射来改善持续记忆、图泛化和推理能力~\cite{choi2024dslr,liu2024puma,gao2024OpenGC,gao2024MCond}。另一些研究将梯度解耦与结构正则化结合起来，或选择可追踪的邻域文本以支持高效联邦学习~\cite{shen2026decoupling,pmlr-v306-chen26cr}。尽管这些研究推动了持续记忆和图--文本压缩的发展，但它们主要关注数值表示的保留或可访问原始数据的利用，而忽略了在无法重新访问历史原始数据的条件下，如何联合优化合成特征与可读文本。

在受到存储和历史访问限制的在线用户交互网络中，一个更贴近实际部署的场景是：数据持续到达，而历史节点及其关系逐渐无法再用于模型更新。当合成记忆承担历史信息保存功能时，新的记忆就必须由当前可访问的数据和已有记忆共同构造~\cite{qi2024revealing}。这引出了一个核心问题：如何协调合成特征构造与可读文本选择，使二者能够共同支持跨阶段学习？要回答这一问题，需要克服以下三个相互关联的挑战：
}

\xf{
\textbf{挑战 \MakeUppercase{\romannumeral 1}：特征与文本的对应关系。}
当前数据仍然可访问，但压缩后的记忆只能提供不完整的历史参考，因此难以在新类别与旧类别之间实现平衡学习。
}

\xf{
\textbf{挑战 \MakeUppercase{\romannumeral 2}：非对称的数据访问。}
合成特征通常概括多个节点，因此仅共享类别标签并不足以保证合成特征与所选文本之间保持对应关系。
}

\xf{
\textbf{挑战 \MakeUppercase{\romannumeral 3}：离散文本优化。}
离散文本选择需要接收梯度反馈，同时还必须保证优化过程中使用的文本与最终存储的可读文本保持一致。
}

\xf{
我们提出 \method{}，一种在历史访问受限条件下进行持续 TAG 凝聚的方法。其核心思想是优化当前节点与合成样本之间的支持关系，通过共享的可学习权重将特征构造与真实文本选择连接起来。节点特征、邻域信息和文本表示用于初始化分配关系；随后，Sinkhorn 归一化生成支持矩阵 (Q)，将分配限制在同一类别内，并在每个类别的合成样本之间平衡支持量。

一个固定的图文代理通过匹配以下两种情况下的参数梯度，将保留的历史知识纳入记忆构造：一是历史记忆与当前增量组合，二是同一历史记忆与新合成样本组合。该过程同时平衡历史组与当前组，以及每个组内的不同类别。相同的 (Q) 控制特征池化，并从支持权重最高的源节点中选择文本，使特征源与文本源之间的对应关系能够通过凝聚目标进行联合优化。

对于离散文本选择，直通估计器在前向传播中使用被选中的文本嵌入，同时通过软加权表示将梯度传回 (Q)。最终的源节点选择和文本编码会被重新执行并进行验证，以保持构造输入与最终存储文本之间的一致性。类别分布匹配和传播匹配进一步将当前类别统计信息与邻域信息纳入同一优化过程；有界残差允许对池化特征进行小幅修正。最终得到的特征、标签和真实文本会被追加到冻结的历史记忆中，从而形成一种利用图信息构造、但不存储合成邻接矩阵的紧凑记忆，并用于后续基于类别 prompt 的节点分类。
}

\xf{
我们在大规模 TAG 上通过预测性能对比、受控消融实验和压缩实验评估 \method{}。在一个书籍共同购买图上，与适配到相同评估协议的强持续凝聚基线相比，该方法的相对 Macro-F1 提升了 7.65\%。受控消融实验表明，与固定支持关系相比，学习支持关系能够使 Macro-F1 的相对提升最高达到 37.14\%。在使用固定类别顺序和匹配的有限训练预算进行比较时，仅包含累计训练节点 5\% 的记忆，在所有评估数据集上至少保留了 full-history 数据所达到的 Macro-F1 的 98.23\%。这些结果表明，学习支持关系是提高图与文本凝聚记忆训练效用的一种有效机制。进一步地，结果说明，在连续多个数据增量之后，紧凑记忆仍然能够保留较高的分类效用，而构造器不需要重新访问历史原始数据。
}
```
