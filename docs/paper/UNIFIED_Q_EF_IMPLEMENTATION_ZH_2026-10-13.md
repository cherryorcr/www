# Unified-Q-EF：当前实现的逐步说明

本说明对应 2026-10-13 核对的论文第四部分及最终确认实验中的 `uq_dm_edgefree` 配置。论文英文正文见 [04_method.tex](../../paper_www/sections/04_method.tex)，主要实现见 [unified_q_multimodal.py](../../code/v2_llm_fusion/unified_q_multimodal.py)，最终调度见 [run_uq_final_confirmation_20261012.py](../../tools/run_uq_final_confirmation_20261012.py)。

方法全名为 **Unified-Q-EF: Graph-Aware Edge-Free Continual TAG Condensation**。它用当前图的边帮助构造少量特征和文本行，再把这些行与旧记忆一起交给下游模型训练。保存的主方法记忆没有合成边；构造时仍然使用真实图结构。

## 1. 每个阶段究竟允许读什么、输出什么

阶段输入有两部分：当前合法增量图 `delta`，以及上一阶段保存的合成记忆 `parent`。当前增量包含原始特征、文本、标签和增量内部的边。历史原始图、历史原始文本不重新读取。

旧合成记忆始终保持原样。当前阶段只增加新槽位，不重新训练旧槽位的特征、文本或标签；主方法也不引入新旧槽位之间的边。

累计预算按**固定比例**计算：约为累计合法构造节点数的 5%，随数据量增加而增加。它不是固定节点数，更不是固定字节数。新增槽位数等于本阶段累计预算减去旧记忆行数。

当前各类至少获得一个槽位，剩余槽位按节点数比例分配。若预算不足以覆盖当前类别，调度有类别最低配额修正；最终表保留实际行数比例和修正记录，不把超出的情况隐去。

例如，当前阶段有 100 个合法节点、新增预算为 10 行，那么生成 10 个合成槽位。同类的多个槽位有各自的特征和文本选择，可以表示该类的不同内容。5% 计算使用合法构造池节点数，不使用全图所有节点数。

每一行最终保存：

| 字段 | 保存内容 |
| --- | --- |
| `x` | 连续合成特征 |
| `texts` | 清理、长度限制后的真实文本字符串 |
| `text_emb` | 同一冻结 MiniLM 对保存字符串的编码 |
| `labels` | 槽位的类别标签 |
| 文本来源和构造元数据 | 原文来源 ID、预算、种子、配置及检查记录 |
| `edge_index` | 主方法为空；训练时使用自环传播 |

## 2. 优化的变量是 Z 和 R，Q 是从 Z 算出来的

设当前节点数为 \(n\)，新增槽位数为 \(m\)。真正交给 Adam 的变量是：

\[
Z\in\mathbb R^{n\times m},\qquad
R\in\mathbb R^{m\times d_x}.
\]

\(Z\) 是分配分数，\(R\) 是小幅特征修正。Sinkhorn 把 \(Z\) 转换为合法的非负分配矩阵 \(Q\)。\(Q_{ij}\) 表示当前真实节点 \(i\) 向合成槽位 \(j\) 提供多少支持。

同一张 \(Q\) 同时用于特征聚合、文本路由和槽位传播目标。因此，文本分支对 \(Z\) 的反馈，也能改变特征聚合的支持权重。

这里没有先调用 CaT 把最终特征优化好，再给它补文本。当前版本把 CaT 风格的分布匹配放进同一个优化循环，直接约束由 \(Q\) 和 \(R\) 得到的新特征。文本编码器、原始节点特征、原文字符串以及构造代理模型的参数都不是此循环的更新变量。

## 3. 初始分配从特征、邻域和文本共同得到

先处理当前合法文本：合并多余空白，限制到最多 320 个字符，尽量在完整单词边界结束，然后用冻结 MiniLM 编码。候选池为当前增量中的全部合法文本，不额外调用语言模型生成内容。

对节点 \(i\)，构造三种初始信号：

\[
u_i=\operatorname{Norm}(x_i),\qquad
h_i=\operatorname{Norm}\big((AU)_i+10^{-6}u_i\big),\qquad
e_i=\operatorname{Norm}(\operatorname{MiniLM}(t_i)).
\]

\(A\) 为去重、无自环的当前无向二值邻接矩阵。\(h_i\) 描述邻居特征的方向，微小的自身特征项给孤立节点提供回退。这里的归一化特征只用于初始相似度；后面池化使用原始特征的尺度。

将三种信号按权重 \((1,0.75,0.35)\) 拼接并归一化，在每类中选择代表原型。第一个原型接近类均值，后续采用 farthest-point 选择，让原型覆盖类内不同区域。

每个选中的真实节点提供该槽位的特征、邻域和文本原型。初始分数为：

\[
Z^0_{ij}=u_i^\top p_j^x+0.75h_i^\top p_j^h+0.35e_i^\top p_j^e.
\]

原型用于给优化提供起点。它们不等于最终合成特征；后续更新 \(Z\) 后，槽位支持可以变化，池化特征和文本来源也可以变化。

## 4. Sinkhorn 到底做什么

Sinkhorn 反复调整每一行和每一列的总质量，让相似度高的对应关系获得较高权重，同时防止大部分节点都集中到少数槽位。

对有 \(n_c\) 个真实节点、\(m_c\) 个槽位的类别，目标约束为：

\[
\sum_j Q_{ij}=1,\qquad
\sum_i Q_{ij}=n_c/m_c.
\]

第一式表示每个真实节点贡献的总质量是 1；第二式表示同类各槽位获得相同的支持总量。\(Q\) 是软分配，不要求一个真实节点只支持一个槽位。

例如，同类四个节点、两个槽位可以得到：

\[
Q_c=
\begin{bmatrix}
0.8&0.2\\
0.7&0.3\\
0.3&0.7\\
0.2&0.8
\end{bmatrix}.
\]

每行和为 1，每列和为 2。两个槽位都得到支持，但一个偏向前两个节点，另一个偏向后两个节点。

类别之间禁止分配。代码中的 \(-10^4\) 是未使用 logits 的占位值，并不是池化权重。Sinkhorn 仅计算同类块，完整 \(Q\) 的跨类位置保持**精确为零**，不会拿负权重参与特征聚合。

实现采用 log-space 行列缩放，温度为 0.35。最终确认配置从 30 次缩放开始，检查行误差和相对列误差；需要时增加迭代，最多 4,096 次，容差为 \(10^{-4}\)。有限迭代得到的是经过误差检查的近似平衡。

## 5. 用同一个 Q 得到特征和文本

槽位特征为：

\[
\bar x_j(Q)=\frac{\sum_iQ_{ij}x_i}{\sum_iQ_{ij}},\qquad
x_j^{syn}=\bar x_j(Q)+r_j.
\]

\(\bar x_j\) 是支持节点的加权平均，\(r_j\) 允许稍微修正这个平均。初始化 \(R=0\)，每次更新后限制 \(\|r_j\|\) 不超过当前池化特征范数的 5%，并设置数值下限。

文本先有一个可微的软表示：

\[
\widetilde e_j=\operatorname{Norm}
\left(\frac{\sum_iQ_{ij}e_i}{\sum_iQ_{ij}}\right).
\]

最终保存的却是一段真实字符串：取同类候选中 \(Q_{ij}\) 最大的节点文本，当前配置 `materialize_top_k=1`。这不是对几个文档进行生成式融合，也不是每类固定共享一段文本。多个槽位可以选到不同文本，也允许重复；平衡约束本身不保证文本来源唯一。

硬选取的 `argmax` 没有可用的普通导数。因此构造前向使用：

\[
e_j^{ST}=e_{hard}+\widetilde e_j-
\operatorname{stopgrad}(\widetilde e_j).
\]

前向数值就是被选中文本的 embedding。反向时，梯度通过软表示传给 \(Q\)，再传给 \(Z\)。可以理解为：模型看真实文本，优化器借助软分配估计“应怎样改变文本支持”。这是 straight-through 代理梯度，不是对原始文本单词求导，也不是 `argmax` 的精确导数。

最后再次用同一规则选文本、保存字符串并重编码，检查保存 embedding 与选中文本的构造 embedding 误差不超过 \(10^{-4}\)。训练前向与保存对象一致是文本实现的约束；它本身不能证明比 soft-only 存储更准确。

## 6. 在一个循环里优化三个匹配目标

先用当前图计算固定传播目标：

\[
H=\widehat A X,\qquad
\widehat A=D^{-1/2}(A+I)D^{-1/2}.
\]

这是原始特征经归一化自环邻接传播后的结果，与初始化时归一化邻域方向 \(h_i\) 是两种不同的量。

| 目标 | 当前实现比较什么 | 直接作用 |
| --- | --- | --- |
| GM：多模态梯度匹配 | 当前真实图加旧合成记忆，和新旧合成记忆，对同一个固定代理模型产生的参数梯度 | 同时反馈到特征、文本支持和 \(R\) |
| DM：CaT 风格分布匹配 | 当前真实传播特征 \(H\) 与新合成特征，经固定随机非线性投影后的类别均值 | 保留图特征的类级统计，更新 \(Z,R\) |
| Prop：传播匹配 | \(Q\) 聚合的真实传播目标方向与每个槽位的特征方向 | 将局部图信息写入单独槽位，更新 \(Z,R\) |
| 分配/特征约束 | \(Q-Q_0\) 与归一化 \(R\) 的平方惩罚，加上 \(R\) 的硬半径限制 | 约束构造偏移 |

**GM 的两层梯度要区分。**首先计算损失对代理参数 \(\theta\) 的梯度，得到真实侧 \(g_r\) 和合成侧 \(g_s\)。然后比较这两个梯度，外层损失再对构造参数 \(Z,R\) 求导。

真实侧使用旧记忆自环加当前真实图，合成侧使用新旧记忆自环。旧记忆两侧相同，但其监督会参与整个代理梯度。代理为固定随机初始化的两层 GCN，图和文本投影维度均为 384；构造过程中不对它做训练步。

代理损失为 `0.5 × graph/text multi-positive loss + prompt CE + 0.1 × prompt margin`。多正例项使用同类文本作为正例；旧组和新组各分到一半损失质量，组内类别等权。它不是直接逐节点重建原图，也不是单独的节点级图文联合分布损失。

梯度匹配比较梯度方向，以及带权重 0.25 的对数范数差。真实侧梯度分离并缓存，合成侧保留计算图；外层反向涉及二阶求导。

DM 使用四个固定随机投影，各宽 512，经过 ReLU 和行归一化后比较类均值。当前主版本是图特征 DM；另做过的 joint-DM replacement 是实验候选，没有替换主版本。

主方法总目标为：

\[
L=L_{GM}+L_{DM}+0.5L_{prop}+0.1L_Q+0.1L_X.
\]

分配惩罚 \(L_Q\) 为 \(Q-Q_0\) 所有元素的均方；修正惩罚 \(L_X\) 使用初始池化特征的范数归一化。修正的硬半径则使用每步当前池化特征的范数。

Adam 同时更新 \(Z\) 和 \(R\)，学习率分别为 0.15 和 0.005，执行 30 步，全局梯度范数裁剪为 5，每步结束后投影修正量。这是联合可微更新，没有 E-step/M-step，也没有更新文本编码器。

## 7. 一次阶段构造的完整顺序

1. 按累计比例调度确定新增槽位与类别标签，读取当前 delta 和只读旧记忆。
2. 清理并编码当前文本，计算初始邻域方向与传播匹配目标。
3. 选择类内图文原型，初始化 \(Z,Q_0\)，将 \(R\) 设为零。
4. 缓存真实侧代理梯度与 DM 类统计。
5. 重算 \(Q\)，由它生成特征和硬前向/软反向文本；计算总损失，同时更新 \(Z,R\) 并限制 \(R\)。重复 30 步。
6. 重算最终分配，保存新特征、真实文本及其来源，检查一致性，再追加到旧记忆。

构造结束后不持久保存 dense \(Z,Q\)。下游 Student 从头训练，不继承随机构造代理的参数。当前共同 Prompt Student 的预算为 2,048 步、batch 24；它使用类别监督和 prompt 读出，不应叫作未见类别意义上的严格零样本。

## 8. 与 CaT、GECC 及拓扑分支的关系

CaT 提供了图传播后的类统计匹配思路。当前方法保留这个思路，但把待优化特征写成 \(Q\) 聚合加受限修正，并在同一个循环内加入真实文本反馈和多模态梯度匹配。

GECC 的类内聚类/软池化也是接近的先例。Sinkhorn、GM、随机投影 DM 本身都有已有工作。当前设计区别是：持续访问约束下的同一分配同时控制特征与可保存的真实文本，并通过同一个构造目标更新。方法的必要性仍要用与独立分配、固定分配及基线的实测证据说明，不能仅由“共享 Q”推出精度一定更好。

`Unified-Q-T` 增加由 \(Q\) 诱导的合成边，是单独的结构任务扩展；boundary 版本还增加历史支持 sketch 的假设。它们不属于主版本的最终节点分类表。下游在真实测试图上仍然使用真实图传播，所以“无合成边”也不等于“测试时不使用图”。

dense 分配的工作内存为 \(O(nm)\)。GM 引入二阶求导，当前代理实现还分配 dense 合成邻接算子，即使其值是单位矩阵。这些开销发生在构造时，不等于最终保存记忆的大小；成本应与 GECC 的快速聚类单独报告。

## 9. 现有证据支持的优势

最终共同协议为：真实累计约 5% 合法池预算、相同 Prompt Student、3 个类别顺序 × 3 个 construction seeds × 3 个 Student seeds。下表为 sealed test；先平均每个顺序/构造 cell 的三个 Student，再计算九个 cell 的均值。

| 数据集 | 方法 | Macro-F1 (%) | Accuracy (%) |
| --- | --- | --- | --- |
| ArXiv | Unified-Q-EF | 52.91 | 71.15 |
| ArXiv | CaT-CCTP | 34.98 | 60.41 |
| ArXiv | GECC-hard | 52.68 | 70.94 |
| SportsFit | Unified-Q-EF | 80.08 | 85.52 |
| SportsFit | CaT-CCTP | 74.50 | 85.56 |
| SportsFit | GECC-hard | 80.57 | 89.01 |
| BookHis | Unified-Q-EF | 48.81 | 81.05 |
| BookHis | CaT-CCTP | 29.16 | 79.23 |
| BookHis | GECC-hard | 45.34 | 81.26 |

BookHis 对 GECC-hard 的配对 F1 差值为 +3.47 pp，95% CI 为 [2.20, 4.74]，9/9 cell 为正，是当前最明确的收益。ArXiv 差值约 +0.22 pp；SportsFit 为 -0.49 pp，两者配对区间均包含零。精度收益是数据集相关的，不能描述为每个图都超过 GECC 两个百分点。

共享 Q 对独立特征/文本分配没有稳定精度优势，现有归因结果应原样保留。这不改变共享分配是实际构造接口的事实，但论文需要把“接口设计”与“主要提升来自哪里”的因果主张分开。

完整历史保留率来自单独的历史 report-dev 配对，不能用新 sealed 分数替换旧分子。较早 ArXiv 参考使用 5.71% 行数比例；最终确认使用当前合法池的真实约 5%。

所有数据集、基线适配身份、来源和不同 Student 的数值见 [按数据集完整总表](../../results/baseline_master_by_dataset_20261013/all_results_by_dataset.md)。
