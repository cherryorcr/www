# 基于 CaT/PUMA 的持续 TAG 凝聚：与 DANCE 的差异、创新位置及研究路线

日期：2026-09-06。性质：研究设计文档，不是已验证的方法报告。本轮仅整理已有代码、实验和一手文献记录，没有运行实验或修改算法代码。

**范围已更新：用户随后明确以持续 TAG 凝聚为研究对象，TAGSAM 为主要静态方法参照，GraphCLIP 为唯一下游模型。** 最新约束见 [GraphCLIP 唯一目标模型的研究范围](D:/Adocs/简历/research/graph-condensation/TAGSAM/GRAPHCLIP_ONLY_CONTINUAL_TAG_SCOPE_ZH_2026-09-06.md)。下文监督 CaT/PUMA 主协议、其他模型训练及跨架构迁移的建议不再执行；文献差异和对应保持机制仍可作为历史研究草案参考，不能覆盖最新选择。

## 1. 建议的选题与核心判断

工作题目：**面向演化文本属性图的图文对应保持凝聚**。

研究目标：继承成熟的持续图凝聚流程，在历史原始图文不可回访时，维护一份可独立训练模型的 synthetic TAG；重点解决合成单元在跨阶段重组、替换后，图状态与其文本代表之间的对应关系能否保持。

建议的继承关系是：**CaT/PUMA 提供持续流程与基础凝聚器，TAGSAM/DANCE 提供已有文本处理的参考，新研究集中于图文对应在记忆替换中的保持。** D2/A2 保留为基线或初始化；不要求继承双专家或固定融合权重。

必须区分三层内容：

| 层次 | 内容 | 当前地位 |
|---|---|---|
| 已有能力 | 凝聚当前图、记忆训练、文本编码/选择、静态图文匹配 | 继承或复现，不算本项目创新 |
| 问题设定 | 时间增量 TAG、受限历史访问、明确压缩预算 | 研究条件；其中多项已被近邻覆盖 |
| 待研发机制 | 旧合成单元被替换时，共同约束图状态、文本载荷及其代表关系 | 候选算法贡献，尚未证明有效或充分新颖 |

**不能把“CaT + DANCE”直接写成创新，也不能现在保证最终方法达到投稿标准。** 最终要成立的贡献是：测出一种已有方法没有充分控制的持续图文对应损失，给出有针对性的更新方法，并证明其收益不能被普通联合凝聚、文本选择、蒸馏或静态 ASM 解释。

## 2. 最终与 CaT、DANCE 的差异应在哪里

| 比较维度 | CaT/PUMA | DANCE | 本项目拟研究的差异 |
|---|---|---|---|
| 数据演化 | 持续任务到达，原实验包含 class/task 增量 | 联邦客户端间协作，模型随通信轮更新 | 中心化 TAG 随时间出现新节点/边；通信轮次不能代替时间到达 |
| 历史访问 | 已限制为 incoming graph 与 memory；并非免费读取全部历史 | 刷新时仍在 original local TAG 上前向并读取邻居、文本 | 与 CaT 相近；相对 DANCE 需处理旧原始图文已不可访问的条件 |
| 更新对象 | 当前图凝聚后追加到历史 memory | 在可访问本地图上重新选择 core、证据并重建拓扑 | 允许旧 synthetic 单元与新数据共同重组，输出下一代可训练 TAG |
| 典型状态 | synthetic features/labels；CaT 自环，PUMA 无边 memory | 代表节点、邻居/文本证据 embedding、局部审计记录和拓扑 | synthetic X、固定或受控 A、监督状态、实际训练文本、必要质量/来源信息 |
| 文本作用 | 原方法没有专门的 TAG 文本机制 | 文本/邻居选择、证据聚合、图文融合是核心内容 | 文本随合成单元重新分配，并影响凝聚约束和独立训练 |
| 核心目标 | 类内分布匹配与新旧训练平衡 | 降低 TAG 联邦训练成本，适应模型变化并保留可检查证据 | 减少多次压缩/替换引起的图文对应与历史训练效用损失 |
| 预算 | 每任务凝聚预算，memory 随任务累积 | 节点压缩率及邻居、文本、通信成本 | 主报固定 root 比例并核算真实字节；固定总容量是另立协议 |
| 需要证明的新内容 | 超过同预算 Append 与普通再凝聚 | 在受限历史信息上完成有效更新 | 提出的对应保持机制有独立、跨阶段收益，而非任务换名 |

两个容易误写的地方：

1. **不读取旧原图不是相对 CaT 的创新。** CaT 已有这一访问边界。[S1]
2. **固定比例不意味着必须重凝聚。** 若每个增量凝聚后追加，总量也可能满足同一累计比例；联合重凝聚应凭减少冗余、改善代表分配或保持性能获得价值，不能预设 Append 必然超预算。

DANCE 的可读摘要也要与训练输入区分：原文训练链路主要消费选中文本块形成的 evidence embedding；LLM 摘要属于本地可读审计内容，不能把二者混写。[S3]

## 3. 从哪些已有成果继续

### 3.1 优先继承 CaT/PUMA 的流程

CaT 原始更新可写为：

\[
\widetilde G_t=C_{\rm base}(\Delta G_t),\qquad
M_t=M_{t-1}\cup\widetilde G_t.
\]

CaT 用随机 GNN 表示空间中的类内分布匹配优化 synthetic X，固定标签和自环邻接，再在凝聚记忆上更新模型。PUMA 进一步采用一次传播和随机映射等简化，并从 memory 重新训练模型。它们不是本项目 C0 的 GraphCLIP 梯度匹配。[S1, S2]

先保留这些已发表方法的主要训练和凝聚逻辑，建立清楚的 CaT/PUMA + TAG 适配基线。需要重新核验代码和数据接口，但不要求先修到当前自选 C0 胜出。

### 3.2 文本组件先选择最小可用版本

保留受长度/字节预算约束的真实文本，经冻结 encoder 进入模型。所有比较使用同一个文本 encoder、文本消费接口和主模型。文本不得只存在于 metadata 或论文展示中。

TAGSAM 的文本选择及 ASM 可以提供已发表对照；DANCE 的文本块选择、证据来源记录可以借鉴。首版不默认引入 LLM 摘要生成、邻居 gate 或拓扑重建，因为这些会同时改变容量、训练接口和优化目标。

项目旧实验已发现：joint graph-text root selection 有条件的正信号，但 D2 上直接注入文本，以及 root-plus-neighbor evidence，都没有稳定超过对应强对照。因此不能把搬入 DANCE 邻居证据视为已有正结果支持的下一步；旧实验也不等于完整复现并否定了 DANCE。[S8]

### 3.3 任务协议的建议

为尽量忠实继承 CaT/PUMA，**建议先以监督或半监督的持续 TAG 节点分类作为研发主协议**，按到达阶段提供训练标签；旧阶段只使用已保存在 memory 中的监督信息。主指标、类别增量规则和可访问标签须在看新结果前固定。

这是下一阶段的设计建议，不是已经变更的实验协议。既有 GraphCLIP P1/C0 仍属于 label-free 协议，其绝对数值不能与新监督协议混排。若最终保留 GraphCLIP label-free 为主任务，则必须替换 CaT/PUMA 的类别条件构造，不能直接使用类别均衡后仍称无标签。

GraphCLIP 可以保留为文本消费与迁移诊断工具，不再是整个选题必须绑定的模型；也不要求所有 backbone 同时提高。

## 4. 创新集中于一个假设

**核心假设：普通的分阶段凝聚或联合再凝聚，可以保持类别均值和总体分布，却未必保持合成图状态与真实文本代表之间的对应；这种损失可能在反复替换时累积，并影响历史训练效用。**

一个说明性例子：同一类别里原有两组论文，图表示分别对应两种研究方向，文本也分别描述这两个方向。如果重新压缩时图特征合并到一组、文本却只保留另一组的代表，类别标签和两种模态的总体均值可能仍近似正确，但“这段文字描述哪种图状态”已经变化。新阶段引入相邻主题后，这种差异可能影响分类或图文训练。

这是待检验的例子，不是目前已观察到的主因。C0 失败、paired 优于 shuffle，都不能单独证明存在这种持续损失。

普通分布匹配的限制可以用更简单的事实说明：将 `(h1, text1), (h2, text2)` 换成 `(h1, text2), (h2, text1)`，图和文本各自的边际分布不变，但联合对应关系变了。**这一事实本身并不新，TAGSAM 等已经处理静态图文对应。** 新研究必须进一步回答：当旧原始样本不再存在、合成单元数量与身份都能改变时，怎样维护对后续训练有用的对应关系。

首轮诊断必须同时检查相反解释：如果已有 joint selection、同一映射或普通 ASM 已经足够保持对应，则无需为它再发明复杂模块。

## 5. 候选方法应怎样具体化

### 5.1 输入、状态与输出

阶段更新仅接收：

\[
U_t=\operatorname{BuildUnion}(M_{t-1},\Delta G_t),\qquad
M_t=\operatorname{Recondense}(U_t;K_t).
\]

memory 的最小状态为 `M_t = (synthetic X, A, Y, readable T, weights, provenance)`。Y 只出现在已明确的监督协议中；T 是实际用于训练的文本，不是连续向量伪装成自然语言。

第一版沿用基线的结构处理，明确 old memory 与 delta 的 union 规则。若使用 disjoint union，所有同条件方法一致；不得通过查询旧 raw 邻居偷偷恢复跨阶段边。若增量流本身提供到旧 ID 的新边，只有映射/端点状态已合法保留时才能消费，并须记录成本。

### 5.2 一项共同对应约束

用临时分配矩阵 `P_t(i,j)` 表示可访问源单元 i 向新 synthetic 单元 j 分配的比例。行归一化，源质量为 `w_i`，则目标代表质量为：

\[
\widetilde w_j=\sum_i w_i P_t(i,j).
\]

同一分配关系同时用于构造图侧匹配目标、选择文本代表及传递必要来源信息，避免图侧按一套分配、文本侧按另一套分配。旧 synthetic 的质量来自此前已保存状态，不等于它恢复了所有原始样本。

新单元的文本只能从旧 memory 中实际保存的文本和当前增量文本中选择；不得根据历史 ID 回读已丢弃原文。可以从真实片段中选取或拼接，不能把加权平均 embedding 宣称为可读文本。

`P_t` 是阶段内计算工具，不保存历代完整矩阵链；下一阶段只接收预算内的新 memory。若保留额外语义对照样本或关系摘要，它们属于 memory，不能作为免费历史池。

**共同分配、质量传递或 OT 本身都不是新贡献。** 先将它们作为基础版本，与已有 joint graph-text selection、质量加权分布匹配及通用多模态分配比较。

### 5.3 一个可计算的起始目标

为了把假设落实到可测量的目标，可以先用来源明确的图文关系约束作为机制探针，而不是立刻承诺完整新算法。以下损失采用归一化源权重 `bar w_i = w_i / sum_l w_l`，对照权重满足 `sum_k a_k = 1`，避免图规模增长隐式改变约束强度。

令 `h_i` 为同一冻结探针图编码器对可访问单元 i 的表示，`z_i=E_text(T_i)` 为固定文本编码。二者分别归一化，不要求图与文本维度相同。对旧记忆/当前增量中固定抽取的语义对照单元 k，定义：

\[
r(i,k)=\langle h_i,h_k\rangle\langle z_i,z_k\rangle.
\]

它衡量两个配对单元是否同时在图与文本上相近。保持目标的最小版本可写为：

\[
\mathcal L_{\rm corr}
=\sum_i \bar w_i\sum_{k\in Q_t}a_k
\left[r(i,k)-\sum_j P_t(i,j)r(\widetilde j,k)\right]^2,
\qquad
\mathcal L=\mathcal L_{\rm base}+\lambda\mathcal L_{\rm corr}.
\]

其中 `Q_t` 只含旧 memory 和当前训练增量中的对照单元；`a_k` 的旧新配比需预先固定。两侧使用相同 k，所以不要求旧新 synthetic 节点一一对应。对照样本来自可访问训练数据，不是最终评测集。源表示及源关系在一个优化块内停止梯度；更新 X 时冻结该块的分配和文本，离散文本/分配的刷新另按明确顺序进行。

该目标的好处是可计算、可审计，并能分开测量旧旧、旧新、新新关系的误差；不需要再次对 128M 模型做 full-scope 二阶梯度匹配。相应代价是探针表示和关系样本只近似真实训练效用，关系 loss 降低不保证独立 student 提高。

**上述式子只是起始机制探针，联合核匹配和关系蒸馏都有已有工作，不能据此宣称算法原创。** 如果它有效，下一步才研究在合成单元替换中，哪些阶段条件和共同约束不可被普通 ASM、联合核 MMD、通用多模态 OT 或质量校正替代；若这些已有做法同样有效，就应采用更简单的解释。

### 5.4 阶段内算法草案

1. 读取旧 memory 和当前 delta，核对来源、标签权限与预算；第一阶段没有旧 memory，直接采用基线凝聚器。
2. 用相同的旧新质量规则构造可访问 union，初始化总计 K_t 个 synthetic 单元。
3. 用 joint graph-text 构造临时共同分配，并在预算内选择真实文本代表。
4. 在文本和分配冻结的优化块内，用基线目标及候选对应约束更新 X；必要时按预注册间隔重新分配，再继续优化。
5. 序列化新 memory，丢弃本阶段 teacher、对照样本缓存及临时分配；跨阶段需要留下的对象必须显式计费。
6. 用独立 student 验证数据本身的训练效用；另行报告在线模型的持续性能，避免把模型权重中的历史知识误算为 memory 能力。

这不是已经实现的算法；分配、文本刷新和约束强度也不能通过最终留出集挑选。

## 6. 与更近方法的创新边界

| 已有解释 | 为什么不足以直接声称创新 | 必须做的区分 |
|---|---|---|
| 把 TAG 文本加进 CaT | 已有 TAG 方法和文本特征融合 | 超过使用相同文本/模型的 CaT/PUMA + TAG |
| 将旧 memory 与 delta 再凝聚 | 通用递归压缩流程，本身没有专属保持机制 | 超过同凝聚器的普通 union recondensation |
| 图文使用共同聚类/分配 | 接近 joint selection、多模态聚类/OT | 超过共同分配但无历史关系约束的版本 |
| 保持图文相似度 | TAGSAM 已有 ASM | 与包含旧旧、旧新、新新关系的 union ASM 比较，不能只给弱化版 ASM |
| 增加旧模型 KL | 属于常规知识蒸馏/防遗忘 | 相同 teacher、探针、存储和计算预算下比较 KD |
| 保存 count、centroid、warm start | GECC 及既有递归记忆已覆盖 | 质量权重、初始化一致后仍有独立收益 |
| 历史 embedding 拼接 | CCC 已有相关设计 | 输出可重训的数据 memory，区分外挂表示/模型状态的贡献 |
| 多 checkpoint 或更长轨迹 | 静态凝聚文献和本项目历史实验已有 | 不作为默认新增模块；若采用须解释目标和接口具体变化 |

新增算法还需补查多模态 OT、关系蒸馏、持续多模态压缩和保配对凝聚文献。现有 CaT/DANCE 等核验不足以覆盖这整个范围；暂不能给出“首次”的声明。

## 7. 如何测出真正需要解决的损失

先在两阶段设置完成以下比较。基线一致的模型、标签权限、文本预算、训练策略和选模规则，比增加模块更重要。

| 组别 | 比较对象 | 能回答什么 |
|---|---|---|
| 历史替代 | 累计真实数据 vs 旧 synthetic + delta | 历史压缩及 union 接口的差距；两者访问权限不同 |
| 再次压缩 | 旧 synthetic + delta vs 普通重凝聚 | 当前这一次压缩增加了多少损失 |
| 更新方式 | 同一 TAG 凝聚器的 Append vs 普通重凝聚 | 旧单元重组是否有价值，或是否造成额外退化 |
| 共同对应 | 分别分配 vs 共同分配 | 图文来源一致性是否影响训练效用 |
| 专用保持 | 共同分配 vs 加对应保持约束 | 新约束是否超过已有 joint selection/分配 |
| 递归影响 | 受限历史重凝聚 vs full-history 每阶段重凝聚 | 受限访问及反复压缩的累计差距 |

只把这些 F1 差值当配对诊断，不将它们相加为严格误差分解；某个 full-history 算法也不是数学上界。

关系指标与任务指标同时记录：旧旧/旧新/新新图文关系误差、文本来源覆盖、代表质量分布、当前阶段性能、独立历史留出性能、平均阶段性能和遗忘。关系改善而任务不改善，只支持代理指标被优化，不支持方法成功。

判断是否值得继续这项机制，至少需要：存在可重复的对应/替换损失；在相同文本与预算下修复它能改善独立训练；改善不能仅由质量权重、增加文本量或训练时间解释。

## 8. 最小强对照与消融

正式比较至少覆盖以下组，实际先按问题分批验证，不同时开展全部大实验：

- CaT/PUMA + 相同 TAG 模型/文本接口的 Append；分别注明原方法复现与本地适配。
- 同一 TAG 凝聚器的 Append，以及直接 `C(old memory + delta)`。
- 普通/质量加权 MMD、joint graph-text selection、联合核匹配。
- 常规 logit KD，以及包含全部阶段关系的 TAGSAM-style ASM。
- 共同分配，无额外对应约束；图文分别分配；若采用 OT，再加入通用多模态 OT。
- 同文本内容/长度的 correspondence shuffle；固定文本载荷；graph-only 或去除新增文本通道。若 X 已含文本语义，不得把后者称为完全去文本。
- 必要的 old-only、delta-only，以及宽松访问 full-history recondensation。

打乱对照优先在同类/同阶段内进行，并匹配长度和质量，避免仅因类别标签被打乱而制造显著差距。True 优于 shuffle 只是对应敏感性；还必须超过不加该组件的基线。

DANCE 若做正式对照，须区分原联邦/可读本地 raw 的设置和受限历史的改编设置。当前官方代码可用性尚未核实，不能把本地 k-center/evidence 适配标为 DANCE 精确复现。

## 9. 协议与成本

| 项目 | 建议规定 |
|---|---|
| 时间流 | 首版按真实到达顺序构造节点/边增量，固定类别宇宙；新增类别作为另列难度，不能与时间漂移混写 |
| 压缩率 | K_t 由累计可见训练节点数决定；明确舍入规则。Append 可用 K_t-K_(t-1) 分配当期容量，与重凝聚保持同总量 |
| 真实字节 | 报 X/A/Y、真实文本、embedding 缓存、weights、来源映射、保留探针/关系状态和序列化 bytes；不能靠 padding 宣称有效容量一致 |
| 历史访问 | 构造/凝聚阶段不能读取已丢弃 raw；必要历史片段明确保存并计费。外部 teacher checkpoint 的数据来源另行核实 |
| 文本消费 | 同一真实字符串经同一 encoder 和 pooling 进入训练；来源 ID 不能代替文本本身 |
| 模型状态 | 独立 student 只读导出 memory 与各方法共用基座；若在线方法保留模型，另列其参数状态、训练策略和成本 |
| 评估 | 每阶段保留独立历史/当前节点留出；checkpoint 用于选模，确认集只报告冻结配置结果，最终集不得反复用于研发 |
| 成本比较 | 同 root 比例与性能-字节曲线均报告；额外关系约束增加的凝聚时间与峰值内存必须列出，并给同计算预算敏感性 |
| 重复性 | 初筛建议 2 个凝聚 seeds × 2 个 student seeds，正式至少 5 × 3；两种随机性分别报告 |

独立 student 的训练只用 memory，不代表评估阶段也必须仅用 memory 完成所有原图推理。历史留出图可以由隔离 evaluator 作为推理输入，但不得流回凝聚器。既有 ArXiv t3 已暴露，不能重新当作密封最终测试。

## 10. 下一步研究顺序

| 阶段 | 具体工作 | 交付物与判断 |
|---|---|---|
| R0 继承基础 | 核对 CaT/PUMA 原始代码、凝聚目标、memory 更新和重训策略，完成原设置的必要复现；冻结新任务与预算方案 | 来源/协议表、可训练 memory。当前 C0 不再是唯一入口 |
| R1 最小 TAG 基线 | 固定一个文本消费有效的 TAG 模型，建立相同接口的 CaT/PUMA + TAG 和强 joint-selection Append | 基线及配对敏感性报告；不要求本阶段创造静态 SOTA |
| R2 两阶段诊断 | 完成第7节核心比较，测关系失真、重凝聚损失及历史泛化 | 决定“图文对应在替换中损失”这一假设是否值得做 |
| R3 单一机制 | 先测共同分配，再测起始对应约束；与 ASM、KD、联合核/质量匹配逐项比较 | 明确新算子与普通做法的差别；没有独立收益就不保留该模块 |
| R4 形成算法 | 仅在 R3 有证据后，完善持续状态、文本/分配更新及优化规则，补齐最接近的多模态压缩文献 | 可复现算法、来源/成本说明、新颖性差异表；冻结配置 |
| R5 正式验证 | 多个时间阶段、两个主数据集及第三数据集、独立最终留出、有限模型迁移 | 主表、历史保持与成本曲线、机制消融和失效边界 |

阶段判断不再是“静态优化必须胜 frozen-init 才能研究任何持续方法”。继承的凝聚器要能正常训练，但新持续机制可以在单阶段没有提升、在多阶段有稳定保持收益。

也不能预设一定要联合重凝聚：如果同预算 Append 更好且没有可修复的关系损失，就不将“再次压缩”强行作为创新。继续围绕同一持续 TAG 目标检查预算分配或训练平衡等实测问题，而非立即更换题目或叠加多个正则。

## 11. 旧成果如何限制与支持本路线

- C0 证明了当前 GraphCLIP 梯度匹配适配能执行，但独立 student 下降约1.62 pp；它不等于 CaT/PUMA 或 DANCE 路线已失败，也不值得无限期作为唯一门槛优化。[S7]
- O2 和后续短轨迹优化都已经做过。新的共同对应约束必须说明目标、可访问数据或训练消费接口有何变化，不能只把 trajectory 换名重跑。[S9]
- D2/A2 有既有压缩训练正结果，可用作同协议基线/初始化；不能把跨协议绝对 F1 拼在一起，也不默认继承两个专家。
- DANCE 式邻居文本实验已有负结果，普通 text concat 也不稳定。因此首版保持可追溯文本选择，不把增加邻居文本、LLM 或 learned adjacency 设为预定改进。[S8]
- 静态 ASM、联合选择、OT、KD 都有强近邻；即使本机制胜过 CaT，也还不足以证明其算法新颖性。

## 12. 最终论文应能回答什么

1. **问题发现**：在相同预算和文本消费接口下，哪一种历史图文关系会在合成单元替换时丢失？它是否影响独立历史留出上的训练效果？
2. **算法贡献**：所提出的更新算子如何在旧原始图文不可回访时减少这项损失？为什么简单 Append、union ASM、KD、joint selection 或通用多模态分配不能取得同样结果？
3. **持续证据**：收益是否出现在多个阶段、多个凝聚 seeds，并且没有依赖额外隐藏历史、更多文本、更多参数状态或明显更多计算？

可用于讨论的定位表述：

> 本研究继承 CaT/PUMA 的持续凝聚与记忆训练框架，研究合成 TAG 单元在多阶段重组时图状态与真实文本代表之间的对应损失。拟通过共同约束图文重分配及其历史关系，使更新后的压缩数据在无法回访旧原始图文的条件下仍保持训练效用。与 CaT 的差异拟落在旧合成记忆的图文共同更新，与 DANCE 的差异拟落在受限历史条件下的合成数据递推；算法贡献必须由超过普通联合凝聚、ASM、KD 和 joint selection 的持续收益支持。
