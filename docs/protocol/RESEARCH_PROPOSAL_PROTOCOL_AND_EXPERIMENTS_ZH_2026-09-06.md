# 面向 GraphCLIP 的持续 TAG 凝聚：选题、协议与实验方案

**后续讨论已更新起步选择：** 用户明确时间/类别增量、GraphCLIP/原生下游均未确定。当前建议为先修复 TAGSAM 原生 GCN+BERT 链路，以类别分块开发持续凝聚；GraphCLIP 与自然时间流为条件性扩展，见 [首版设置与模型决策](D:/Adocs/简历/research/graph-condensation/TAGSAM/STARTING_ROUTE_SETTING_AND_MODEL_DECISION_ZH_2026-09-06.md)。下文保留为 GraphCLIP/时间流分支的详细候选方案，不能继续视作已确定主协议。实验未启动。

日期：2026-09-06。性质：下一阶段研究提案，尚未实施的新协议，不是实验结果报告。本轮仅核对文献、历史记录并编写文档，没有运行训练或修改算法代码。

本文承接用户已确定的范围：研究持续更新的 TAG 凝聚数据，TAGSAM 为主要静态方法参照，GraphCLIP 为唯一目标训练与评测模型。新的时间划分、拓扑规则和最终测试安排不能追溯覆盖既有 P1/C0 结果。下文“建议固定”表示本提案的明确推荐；数据年份、checkpoint 来源等未核实事实仍须在执行前登记。

## 1. 选题与要回答的问题

**建议题目：面向 GraphCLIP 的持续文本属性图凝聚：受限历史访问下的图文训练信息保持。**

英文工作标题：Continual Text-Attributed Graph Condensation for GraphCLIP under Restricted Historical Access.

目标是：图文数据分阶段到达后，只使用上一阶段的小 TAG 和当前新增数据，更新一份可读文本与合成图组成的训练集；让从相同预训练基座独立训练的 GraphCLIP，在累计历史与当前留出节点上保持有效分类，并检查未来一步泛化。

核心研究问题是：

> 旧原始图文已经不可回访时，如何在反复压缩中保留有用的图文训练关系，同时重新分配有限的合成单元来吸收新数据？这种更新能否优于同预算的分阶段凝聚追加，以及普通联合重凝聚？

这不是“把 TAGSAM 循环运行”即可成立的创新。固定压缩比例下，Append 也可能始终满足预算；联合更新必须通过减少冗余、改善新旧代表分配或降低历史效用损失证明自身价值。

研究输出首先是一个可序列化、可独立训练 GraphCLIP 的小 TAG，不是持续继承的模型权重。暂不增加其他下游模型、类别增量、联邦训练或链接预测，以免同时改变多个问题。

## 3. 真正要解决的困难

### 3.1 首先排除工程与静态优化问题

此前 TAGSAM teacher 已接近论文结果，但凝聚产物表现不稳；遗漏最后一批、master 自环与论文拓扑不一致、特征范数和内层学习率增长都有记录。修复 batching 后性能改善，完整成功复现仍未成立。[S9]

这说明静态压缩误差可能很大，不能把它直接当成持续损失。现有 GraphCLIP C0 使用梯度匹配，不是 TAGSAM ASM；其失败也不能否定尚未验证的 ASM 适配。需要稳定的 GraphCLIP 数据训练链路，不要求先恢复旧 C0 或精确追平论文数字才开展所有持续诊断。

### 3.2 主困难：不可回访历史下的图文训练关系逐次失真

旧 synthetic 单元只是历史数据的近似。新一轮凝聚只能看到这些近似和当前数据，无法重新读取已丢弃的旧文本或恢复旧图的完整关系。如果再次压缩时改变图特征代表、却保留了不匹配的文本代表，单独看两种模态的分布都可能合理，实际图文配对却变差。

例如两个研究主题曾由不同图文单元代表；新增相邻主题后，一个合成单元合并了多个图侧簇，文本却只覆盖其中一个主题。后续 GraphCLIP 对比训练接收的正配对可能失真，旧主题之间的区分也可能下降。

**这目前是待验证假设 H1，不是已经查明的失败原因。** TAGSAM ASM 本来就处理图文关系；如果在合法 union 上直接使用充分实现的 ASM 已经解决问题，就不能再把相似度保持本身包装成创新。

### 3.3 两个必须排除的替代解释

| 假设 | 具体困难 | 可观察信号 | 必要反证对照 |
|---|---|---|---|
| H1：反复重组损害图文关系 | 旧文本候选受限、合成单元身份改变，旧旧与旧新图文关系失真 | 相同文本/结构/预算下，再凝聚比 union 或 Append 更差；旧阶段关系误差与分类效用同步恶化 | 普通 union ASM、联合图文选择、共同分配、通用关系蒸馏都必须比较 |
| H2：旧新质量与对比上下文失衡 | 少量旧 synthetic 代表大量旧 raw，按行均匀采样会低估历史；旧新之间的负例也随 batch 改变 | 只改质量权重/旧新采样比/负例池即可恢复表现 | 所有方法共享原始质量计数、采样与负例规则；若已足够，不需要额外关系模块 |
| H3：结构输入发生变化 | 跨阶段边丢失或 ego 输入改变，造成图侧性能下降 | 不做凝聚，仅改变拓扑协议也出现明显下降 | 完整 raw 下受控结构比较；相同 union 构造和邻域输入下比较方法 |

研究优先聚焦 H1，但必须先检查 H2/H3。paired 优于 shuffle 只证明配对有用，不能单独证明“持续重凝聚损害配对”。outer loss 降低也不证明小 TAG 更适合训练。

## 4. 主协议 P-TAG-Time-v2（建议固定）

### 4.1 数据与到达方式

- 主数据集：带真实文本和 `node_year` 的 ogbn-arxiv。
- 第二数据集候选：TAGLAS PubMed。须先核对 PMID—年份对应、缺失年份、文本来源与现有阶段 membership。已有 manifest 主要记录节点/边数量，不能单凭 `temporal3` 文件名证明时间协议。
- Cora 保留为已有静态诊断资料，不将无可靠年份的随机分块包装为时间流；不再开展其他下游模型训练。
- 开发先两阶段用于归因，正式计划五阶段；阶段数敏感性使用三阶段与十阶段，前提是实际年份和阶段样本量支持。
- 时间边界按年份顺序、尽量接近累计节点数的五等分边界确定，同一年不拆到两个阶段。边界只根据时间/数量元数据确定，不使用分类效果选切点。合并过小年份段的规则和实际边界写入 manifest；年份不足则不能强行声称完成五阶段自然时间实验。
- 第一版为节点、文本和边的新增，不同时研究节点删除、旧文本修改或标签体系变化。引用边若无独立时间戳，以两端发表年份的较大值作为可见时间代理，并明确这不等于真实引用产生时间。
- PubMed 脚本存在“缺失年份填中位数”的历史逻辑。正式自然时间流建议剔除无法核实年份的节点，报告数量和分布，另做缺失处理敏感性；不能将插补年份称为观测日期。[S10]

**事件粒度是一个年份区间的数据批次到达。** 先做下一阶段预测时，可以读取该批次在到达时提供的节点文本和图输入，但不能先进行训练或凝聚；这不是节点逐个到达的在线预测。

### 4.2 历史、当前与未来节点的训练/评测权限

每个阶段到达的节点按 `SHA256(dataset, split_seed, original_node_id)` 做无标签划分：70% 训练、15% checkpoint 验证、15%测试角色留出。标签不参与划分与凝聚；正式报告使用完整留出 roots，不延用 512-root screening 作为最终统计。

已有数据/节点只要被开发查看，其“测试角色”就仍是开发 confirmation，不能因重分区成为独立最终测试。正式最终来源另行登记并审计与旧实验、GraphCLIP 预训练的交集。

| 对象 | 凝聚器及 teacher/student 训练 | 验证/评估器 |
|---|---|---|
| 当前训练节点与文本 | 可读；限当前批次合法训练图 | 可作为推理邻域中的已到达节点 |
| 历史训练 raw | 不可读；只能读上一阶段导出状态 | 离线参考方法/隔离评估服务可读，不能向主方法回传训练目标或梯度 |
| 当前/历史留出节点及其文本 | 不进入训练、凝聚、adapter 拟合、缓存拟合与 teacher 匹配参考 | 可作为节点推理输入；checkpoint 标签仅作选模，测试标签仅作评估 |
| 节点类别标签 | 不作训练标签、class-wise 分配或伪标签筛选依据 | 固定类别文本提示用于预测；真实标签用于指标 |
| 下一阶段节点 | 到达前完全不可读；到达后先评估冻结模型，再开放该阶段训练部分 | 只读预测时已经可见的输入，不读取更晚节点/边 |

此处“无标签”指数据凝聚和参数训练目标不使用类别标签。checkpoint Macro-F1 选模仍使用验证标签，应准确称“有验证标签选模的无类别监督训练”，不能宣称整个研发流程完全 label-free。

### 4.3 图结构：先有清楚的受控协议，再扩大到跨阶段连接

**主归因协议 P0：按时间分批、阶段内图。** 每批训练图只含本批训练节点与它们之间的合法边；不同批次的训练图做不相交并集。跨阶段边在所有方法中统一排除。CaT/PUMA 的无跨任务边设定提供了这一受控选择的先例，但其按类别划分与本项目按时间划分仍不同。

P0 的目的，是先回答“持续压缩图文训练数据是否丢失信息”，而不把旧端点特征如何获取变成额外未知量。**P0 是时间分块 TAG 凝聚，不是完整保留跨时连接的自然动态图协议。** 必须报告删去的跨阶段边比例、阶段内无边节点比例；若造成严重结构退化，P0 只能作诊断，不能独自支撑真实演化 TAG 的结论。

**扩展协议 P1：保留可访问的跨阶段边。** 当前到达边可连接旧端点，但只允许使用预算内已保留的旧端点状态及映射；未保留端点的边采用所有方法共享的丢弃规则，报告覆盖率。不得临时查询完整旧 raw 特征、文本或免费保留全 ID→合成节点映射。端点/映射状态占用主预算的一部分，不能额外赠送给新方法。映射策略先固定为公共输入处理，不能同时作为 H1 实验中新方法的专属优势。

对 full-history 参考也报告“相同受限结构”版本；另列“可访问完整历史拓扑”的信息更充分参考，两者差异用于估计结构访问损失。P1 比 P0 更接近现实，但仍是受限端点覆盖，不能声称恢复完整原图。

**评估邻域规则：** P0 在节点所属阶段的完整阶段内图上推理，允许读取该阶段留出输入但不回传训练；历史阶段的推理图和 ego 采样固定不变，避免把后来邻域增长误算为 memory 保持变化。P1 主历史指标使用到达时已可见的固定推理图，另报截至当前的更新邻域结果。两者均不等于仅凭 synthetic memory 完成原图推理。

### 4.4 凝聚状态、预算与附加记忆

令当前累计训练根节点数为 `N_train,≤t`，主预算为：

\[
K_t=\max(1,\lfloor0.01N_{\mathrm{train},\le t}\rfloor).
\]

比例曲线为 0.5%、1%、2%。该舍入规则属于 v2 建议，不追溯替换旧代码的 `round`。Append 每阶段新增 `K_t-K_{t-1}` 个 roots，因而总数同样为 `K_t`；若小阶段增量为零，保留现有状态并记录，不能偷偷增加一个 root。

产物为 `S_t=(X̃_t, Ã_t, T̃_t, w_t, metadata_t)`：合成特征、结构、实际可读文本、代表质量、必要元数据。没有训练类别标签 `Ỹ`。GraphCLIP 所需 ego、root 标记、PE 和缓存均按真实保存情况登记。

- `w_t` 表示单元代表的训练样本质量，初始 real 样本质量为 1，重组时守恒；仅是近似计数，不声称恢复历史分布。所有可比方法采用同样质量规则，并把不加权作为消融。
- 文本只能来自当前训练文本或旧状态已保存的真实片段。GraphCLIP 重新编码字符串；连续 embedding 不能冒充可读文本，旧 ID 不能作为回读旧文本的通行证。
- 每 root 的 ego 节点/边上限、文本长度上限必须按审核后的 GraphCLIP 统一配置登记；最终表同时报告实际 UTF-8、tensor、PE、缓存、adapter、边界状态以及完整序列化字节。
- 同 root 比例不能保证同内存。新方法与强基线必须再有同总字节上限的比较，所有跨阶段保留的关系摘要/探针/teacher 权重都计费；首版不跨阶段保留 teacher。
- 固定总容量为独立压力测试：建议取第一阶段的 root/字节容量，在后续阶段保持不变。此时 Append 必须淘汰，属于不同预算协议，不混入比例预算主表。

### 4.5 GraphCLIP 训练与主任务

每阶段从同一个登记的 GraphCLIP 基座加载，使用独立 student 随机种子训练 `S_t`。冻结文本编码器；图编码器及允许的 scale/projection 的具体训练范围以实际分支审计为准，对所有方法固定。teacher 在每阶段内也只能从同一基座及合法 union 建立；阶段结束丢弃。

训练目标采用审核后的 GraphCLIP 图文对比训练实现。其 graph-summary/文本预处理和已有优化需要逐项确认，不能把仓库中名为 `CLIP` 的 TAGSAM 模型当成 GraphCLIP，也不能预设本地具备论文全部优化。GraphCLIP 原文使用经 LLM 构造的 graph-summary pairs；本项目若使用 TAGSAM 选出的原文片段，须明确称为训练文本来源的适配，固定所有基线的文本来源，避免把摘要与原文的差异混作凝聚收益。

未来暴露审计也包括输入特征生成。OGB 官方 arxiv 特征使用 MAG 语料训练的词向量，不能只核查 GraphCLIP checkpoint 就宣称所有输入表征都从未见未来语料；若保留这类预计算特征，应披露其来源并限定时间泛化主张。[S5]

下游主任务是**固定类别词表的零样本节点分类**：所有预测在同一个类别提示集合上进行，不告知节点任务 ID 来缩小候选类别，不训练分类头。arxiv 使用数据集 40 类候选；PubMed 的类别名称与提示依据实际标签映射登记。类别名称只经评估接口提供，不能用于 condenser 的类别分配。

相同步数终点、预算内 checkpoint 选模、各自合理收敛上限分开报告。记录 step0、实际 root 覆盖、出现次数及负例组成；不能因 full-real 在短预算内没遍历足够数据，就宣称小集保留全部训练信息。

### 4.6 主指标与未来评测

定义 `R_t,j` 为用阶段 t 的小 TAG 独立训练的 GraphCLIP，在阶段 j 固定留出节点上的 Macro-F1，`j≤t`。

- **主终点：** 最终阶段在全部累计留出节点并集上的 Macro-F1；同时报告每阶段累计曲线及其平均值。
- **必要分解：** 历史阶段平均 `mean_{j<t} R_t,j`、当前阶段 `R_t,t`、完整 `R_t,j` 矩阵。附报 Accuracy，避免总体指标掩盖旧阶段下降。
- **历史效用变化：** `mean_{j<t}(R_t,j-R_j,j)`。可借鉴 BWT 的矩阵形式，但这里衡量凝聚产物更新后的效用变化，不能直接称模型权重遗忘。
- Macro-F1 在评估标签具有真实支持的类别上取宏平均，类别支持集合由固定真实评估分区决定、各方法一致；预测候选始终是完整固定词表。报告每阶段支持数，空支持类别记 N/A，不能当作正确率零或随方法调整。
- **辅助未来指标：** `F_t=MacroF1(θ_t,Q_{t+1})`，先预测后吸收增量。所有方法使用同一时点输入和类别词表；未来分区不参与先前 checkpoint、teacher、文本选择或超参数选择。官方 OGB 的未来年份结果若另报，须单列其权限与划分。
- 图文检索、旧旧/旧新/新新关系误差只作机制诊断，不替代独立分类效用。预训练暴露不清楚时，未来指标只能称时间分区评估，不能称严格未见未来泛化。

## 5. 方法雏形：先建立强基础，再检验单一保持机制

阶段 t 的合法源集合为：

\[
U_t=S_{t-1}\sqcup\Delta G_t^{\mathrm{train}},\qquad
S_t=C(U_t;K_t).
\]

P0 的 `⊔` 表示无跨阶段训练边；P1 用登记的边界规则替代。旧新质量与采样是共享协议，不能只在新方法中校正。

**基础适配 T-ASM：** 继承 TAGSAM 的真实文本选择、合成特征/拓扑初始化与 ASM；GraphCLIP student 在候选小 TAG 上训练，teacher/student 在相同合法参考样本上匹配图文相似度。参考样本只从 `U_t` 取，不能继续使用静态论文完整历史原图。文本与拓扑在一个连续优化块内固定；特征维度、内层优化、二阶路径和可训练步长需要审核。

**强持续基线 Union-ASM：** 使用旧、新训练参考组成的联合批次，保留旧旧、旧新、新新全部可计算的图文相似度块。不能只比较各阶段内部关系，再将补上跨阶段项称为超过 TAGSAM 的充分证据。旧新 InfoNCE loss 简单相加也不等价于包含交叉负例的 union 对比目标。

**候选机制（待 H1 证据支持）：** 在旧 synthetic 与当前训练单元向新 synthetic 单元重组时，用共同分配约束图状态与真实文本选择，并控制重组前后相对一组合法参考的关系偏差。临时分配不需要跨阶段永久保存；保留的文本、质量和任何参考摘要均计入状态。

这一候选的科学问题不是“加一个相似度损失”，而是：**参考本身已是历史压缩近似、单元又会被替换时，什么保持方式比普通 union ASM 更能阻止误差逐阶段累积？**

共同分配、OT、质量加权、关系蒸馏、warm start 本身都有先例。若它们足以解释效果，就采用简单机制并相应收窄贡献；不能先拼装全部模块，再靠消融补故事。算法最终命名与原创性判断在机制证据和更广文献核对之后完成。

## 6. 需要做哪些实验？按问题安排，而不是一次跑完全部组合

### E0：协议与输入核验（必做，不需要训练）

交付 `protocol_v2_manifest`：数据/文本 SHA、原始 ID、年份来源与缺失、各阶段节点/边数、跨阶段边比例、所有 split 的 ID 哈希、GraphCLIP 分支/checkpoint/预训练来源、可训练参数、adapter 拟合范围、ego 与文本预算、最终测试暴露记录。

关键判断：能否支持自然时间与未见节点的主张；P0 是否退化成大面积孤立节点；最终留出是否独立。若不满足，明确降为分块开发诊断，不用改名掩盖。

### E1：GraphCLIP 下的小 TAG 训练效用（最小静态适配）

| 对照 | 用途 |
|---|---|
| 未更新 GraphCLIP 基座 step0 | 分离预训练已有能力 |
| full-real | 相同训练接口下的完整数据参照，不预设其一定最高 |
| random-small、联合图文 k-medoids-small | 强小集基线；使用与新方法相同文本/ego预算 |
| TAGSAM 文本与结构/特征初始化，冻结产物 | 测量选择和构造本身的贡献 |
| T-ASM 优化后的产物 | 检验继承 TAGSAM 的 GraphCLIP 适配是否有效 |

先用现有开发 t1/小规模合法数据完成同初始化比较；再按 v2 的首阶段确认。报告固定步终点与收敛曲线，审计 NaN、特征范数、学习率和梯度路径。这里不重新跑原版 GCN+BERT 大规模论文复现，也不把旧 C0 重试列为强制主线。

进入更大机制实验需要：产物可独立训练、没有明显数值崩溃、与冻结初始化及强小集的差异可重复解释。若 T-ASM 暂无收益，仍可用冻结/选择产物开展两阶段损失诊断；但不能据此声称学到了有效的 synthetic 数据，更不批量扩展失败的优化器。

### E2：两阶段定位损失，区分历史替代与再次压缩

所有组使用同一 GraphCLIP、相同推理图、同一配对/负例规则与质量统计；信息权限不同的组单列。

| 组别 | 实际输入/输出 | 地位 |
|---|---|---|
| Full-history-real | 完整累计训练 raw → GraphCLIP | 信息充分、未压缩参照 |
| Offline-T-ASM | 完整累计 raw 一次凝聚到 K_t → GraphCLIP | 同 root 预算、历史访问更充分的参照；并非数学上界 |
| Union-no-recondense | 旧 S + 当前训练 raw → GraphCLIP | 超过部署预算的诊断组 |
| Append-T-ASM | 各阶段独立凝聚，追加至 K_t | 主竞争基线，固定比例下完全可能合规 |
| Union-ASM | 旧 S + 当前 raw，联合重凝聚到 K_t | 主竞争基线 |
| Streaming-random / joint-coreset | 只看旧保留样本与当前增量，更新至 K_t | 同历史权限的选择基线；禁止重新扫描全部历史来挑 medoids |
| Old-only / Delta-only | 分别只用旧产物或当前数据 | 解释保留/吸收来源的诊断组 |

重点比较：Full-history-real 对 Union-no-recondense，观察历史 raw 被小 TAG 替代后的差异；Union-no-recondense 对 Union-ASM，观察再次压缩的增量代价；Append-T-ASM 对 Union-ASM，检验联合重组是否值得；Offline-T-ASM 对 Union-ASM，观察历史访问/递归路径差异。

这些差异会受到优化与采样交互影响，不能将数值直接当作可独立相加的因果分解。逐项固定文本、结构、权重、初始化和训练预算，必要时再做单因素干预。

### E3：主困难归因与方法机制（在 E2 信号出现后）

1. **重复压缩探针：** 不增加新数据，在同一 K 上比较冻结产物、反复重凝聚产物和计算预算匹配的一次长优化。判断退化来自压缩代数还是优化次数；重新采样/重组与单纯继续优化分开。
2. **质量与负例对照：** 按合成行均匀采样 vs 代表质量采样；固定旧新比例；在固定 batch/negative 数量下比较混合 union 与分阶段 batch。旧新质量、负例上下文不能同时改变后只归因其中一项。
3. **对应保持对照：** 在相同合法文本池、相同结构与预算下，比较 Union-ASM、joint selection/共同分配、普通关系蒸馏、候选方法。打乱配对只作诊断，不能充当唯一弱基线。
4. **分块关系诊断：** 使用固定 GraphCLIP 探针与合法参考，分开计算旧旧、旧新、新新关系误差。相同历史输入也由独立评估服务测量分类；评估参考不能反馈为凝聚目标。
5. **关键判据：** 候选机制同时改善独立 student 分类及相关关系误差，在相同字节、文本候选、teacher 和计算口径下仍优于强基线。若只有辅助 loss 改善，H1 的算法证据不成立。

TAGSAM 原本已有 ASM，新增约束必须与完整 Union-ASM 对比；不能把删弱后的 ASM 当作唯一对手。先对 E2 暴露的一个主要瓶颈动手，不同时加入文本刷新、拓扑学习、多教师和长轨迹。

### E4：正式持续效果与稳健性

- 主矩阵：两个通过时间核验的数据集 × 五阶段 × 1% root；方法包括 step0、Full-history-real、Offline-T-ASM、Streaming-random、joint-coreset、Append-T-ASM、Union-ASM 和候选方法。参考方法与可部署方法分组展示。
- 比例曲线：0.5%、1%、2%，优先对最强两条基线和候选方法执行；同时给同字节比较，避免靠增加文本或额外记忆取得收益。
- 时间颗粒度：固定总体时间区间，三/五/十阶段；同终点累计数据与最终预算，报告阶段数增加造成的成本与性能变化。不存在足够独立年份时不强做十阶段。
- 结构扩展：P0 与 P1，报告边界覆盖、结构信息充分参照及历史推理图固定/更新两种口径。若只在 P0 有效，论文结论限于时间分块图。
- 未来泛化：冻结 θ_t 预测下一阶段，在预测完成后才能用 Δ_{t+1} 更新；先在开发时间流完成协议核验，再一次性报告登记的最终未来窗口。
- 固定总容量压力测试：另表比较有淘汰规则的 Append、streaming coreset、Union-ASM 与候选方法；不将该结果混作 1% 比例主协议。

不扩展其他下游模型。CaT/PUMA 原论文数字不能与这些 GraphCLIP 数字混排；采用它们的思想而修改标签/模型的实现须命名为“CaT/PUMA-inspired adaptation”。DANCE/GECC 若另做 full-raw 适配，只放权限更充分的参考组，不伪装成同条件基线。

### E5：效率、存储与可靠性

- 分开报告每阶段和累计凝聚时间、teacher 时间、GraphCLIP student 时间、文本选择/编码时间、峰值显存、跨阶段状态字节与历史读取字节。
- 总成本包含数据预处理和临时 teacher，不能只报告在小 TAG 上的下游训练加速。若凝聚成本高于 full-real，报告多少次重训可摊销；只有单次使用时不承诺端到端省算力。
- 开发筛选可用 2 个凝聚种子 × 2 个 student 种子；主要正式结论建议 5 个凝聚种子 × 3 个 student 种子。先对每份产物的 student 结果求平均，再比较凝聚种子间的配对差异与区间，不能把 15 次重训当成 15 份独立产物。
- 报告全部预登记种子、失败运行、checkpoint 选择位置与实际步数；主终点和历史分解一起报告，不只挑有利阶段。
- 超参数只由开发数据/当时可见 checkpoint 选择；正式未来窗口不得用于回头挑旧阶段配置。静态 ASM、对照和新方法分配可比的调参预算。

## 7. 论文贡献成立的标准与可能的调整

| 最终观察 | 合理结论与后续方向 |
|---|---|
| Union-ASM 已优于 Append，额外机制无收益 | 已有 ASM 适配足以解释；不强行声称新保持机制。继续识别真正未解决情形或收窄贡献 |
| 质量/负例校正即可恢复效果 | 主瓶颈是代表质量或训练上下文，算法应围绕它发展；不坚持配对替换故事 |
| 候选方法在强 ASM、共同分配、通用蒸馏后仍有稳定收益 | 可发展“受限历史下递归图文关系保持”的算法贡献，并补查更广多模态凝聚/关系保持文献 |
| 只有 full-raw 参考有效 | 历史压缩信息不足，需要研究预算内的历史统计/证据保存；新增状态必须重新同字节比较 |
| 仅 P0 有效，跨阶段边场景失效 | 结论限于分块 TAG，不能宣称解决一般动态图；结构访问成为下一研究瓶颈 |
| 静态训练效用始终不可重复 | 继续处理 TAGSAM→GraphCLIP 目标/接口，不用大规模持续结果掩盖基础不可用；已有诊断仍保留 |

预期贡献应由证据串起来：提出清楚的持续 TAG 数据压缩设置；定位一种可重复的损失；提出针对该损失的更新方法；用独立 GraphCLIP 重训、历史/当前分解与同预算强对照证明有效。协议组合、模型更换、真实文本、ASM、no-old-raw、共同分配等单项都不能直接宣称首次。
