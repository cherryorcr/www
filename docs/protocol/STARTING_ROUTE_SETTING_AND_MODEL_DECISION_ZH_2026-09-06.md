# 持续 TAG 凝聚首版路线：设置、下游模型与修复顺序

日期：2026-09-06。依据：用户最新澄清，时间/类别增量、GraphCLIP/原生下游均尚未确定，可按经验建立默认版本并据证据调整。本轮只读审查与修订研究方案，未运行实验、修改算法或重建数据。

本文更新此前“GraphCLIP 唯一下游”和以自然时间流为主协议的建议。此前实验事实、产物与冻结报告不变。研究目标仍是持续 TAG 数据凝聚，并通过下游独立训练验证凝聚数据的质量。

## 1. 首版建议

**先修复并稳定 TAGSAM 原生链路，以 GCN＋冻结 BERT＋可训练文本投影头作为首个下游；用类别分块的受控数据增量开发持续凝聚。时间增量与 GraphCLIP 后置，是否纳入最终论文由研究目标和实验收益决定。**

这是起步选择，不是新的永久约束。先降低同时变化的因素，才能判断问题来自静态凝聚、持续更新还是模型适配。GraphCLIP 的现代性或模型规模本身，不能证明它更适合检验当前凝聚假设。

| 决策 | 首版默认 | 后续调整依据 |
|---|---|---|
| 研究对象 | 每阶段更新的小 TAG，独立重训评估 | 不将模型权重继承作为凝聚数据有效的替代证据 |
| 下游模型 | TAGSAM 原生 GCN＋BERT＋投影头 | 若论文目标转为图基础模型预训练压缩，或需要验证向更强模型迁移，再优先适配 GraphCLIP |
| 数据到达 | 固定类别顺序分块，不同类别组依次到达 | 若实际问题是年份演化，或需要自然分布漂移验证，再加入真实时间流 |
| 训练目标 | 无类别监督的图文对比训练；ASM 凝聚 | 若要改为监督分类，另立目标与对照，不能悄悄加入 CaT 标签损失 |
| 主评估 | 累计留出节点零样本分类，分历史/当前报告 | 未来一步分类只在时间流定义后增加 |
| 预算 | 累计训练节点数的固定比例，另报真实字节 | 固定总容量另表研究；不默认 Append 必然超预算 |

## 2. 为什么首版用类别分块，而不马上用时间流？

| 设置 | 优点 | 对本项目的额外困难 | 当前用途 |
|---|---|---|---|
| 类别分块 | 语义变化明确、顺序可复现，易观察旧信息保持与新增信息吸收；可参考 CaT/PUMA | 人工构造流；分流端需要标签；跨类别边处理影响结构；类别候选变化可能混淆遗忘 | 首版开发主设置 |
| 自然时间增量 | 接近论文/内容持续到达的应用，适合未来泛化 | 年份质量、阶段不平衡、时间漂移、新旧边端点可见性与预训练暴露同时引入 | 后续现实性验证；若应用明确要求时间预测则升为主设置 |
| 随机分块 | 实现与诊断简单，易匹配阶段规模 | 常接近同分布，可能不足以暴露旧新语义冲突 | 工程检查与“仅重复压缩”对照 |

CaT/PUMA 原实验按每任务两个新类别构造流、测试所有已到达任务，并移除跨任务边。[S1] 我们借鉴数据流和访问规则，不直接继承它们的有标签凝聚、伪标签或原版分类训练。

首个小规模开发可使用已有 Cora 数据：七类按预先固定顺序分成 **2/2/3 类三阶段**，不丢掉第七类；开发先比较前两个阶段，随后完成三阶段。原始 Cora 五类静态复现单列，不能与七类持续结果混排。正式阶段可扩到 arxiv 四十类的五个八类阶段，并更换预登记类别顺序；数据、标签映射和历史暴露仍需核对。

标签由数据准备端用于分流；凝聚器/teacher/student 不使用类别标签或类别名称建立损失。准确表述是：**标签定义的数据流、无类别标签的凝聚与模型训练**。阶段构造本身提供了类别相关先验，不能宣称全流程无标签；若用验证分类指标选模，也要披露验证标签用途。

### 2.1 分类候选与历史评测

首版建议从始至终使用同一个完整类别提示集合：Cora 固定七类，arxiv 固定四十类，不给测试节点任务 ID 来缩小候选。指标只统计当前已到达阶段的留出节点，并同时报告当前阶段和历史阶段。

这样可减少“新增候选类别使旧节点分类更难”对历史保持归因的干扰。它的准确名称是**固定词表下的类别分块 TAG 数据增量与零样本分类**，不是 CaT 中未知类别数、分类输出随阶段增长的原版 Class-IL。后续若报告标准 Class-IL 风格的累计已见类别候选，须单列，且其 BWT 变化不能全部归因于凝聚遗忘。

原生下游在每份凝聚产物上重新初始化 GCN 和文本投影头，加载同一份冻结 BERT，并使用配对的独立训练种子。先报告累计 Macro-F1 与 Accuracy，以及历史/当前分解，不要求只有“未来节点”才算有效下游。

### 2.2 首版只固定必要规则

默认旧阶段只保留预算内小 TAG，当前阶段可读训练图文；训练/凝聚参考排除留出节点，划分和 adapter/teacher 输入范围明确登记。先采用所有方法共享的无跨阶段边规则，报告被移除边比例；若结构退化明显，再切换统一的可访问跨阶段边协议，不能只给新方法额外邻域。

每次根据开发证据调整协议都记录版本与原因，并在新版本下重跑受影响对照；不回写旧结果，不用最终测试挑设置。一次先改变一个主要因素即可，不需要在第一轮冻结全部未来研究。

## 3. 为什么优先原生下游？

TAGSAM 的默认下游是两层 GCN、冻结 BERT 和可训练文本投影；训练图文配对，对类别文本提示做零样本节点分类。它的 ASM 已有学生可微内层训练与 teacher/student 响应匹配链路。[S2]

| 维度 | TAGSAM 原生下游 | GraphCLIP |
|---|---|---|
| 当前可复用部分 | 文本/图接口、teacher/student、内层训练及 ASM 代码已有 | 已有图文训练/evaluation 封装，但完整 ASM 适配尚未验证 |
| 当前风险 | 已知实现差异、凝聚不稳定和评测来源待收敛 | 继承相同凝聚风险，并增加特征映射、ego/root/PE、高阶求导、强预训练基座与训练空间问题 |
| 归因 | 容易保持静态模型与目标不变，只研究持续访问和重凝聚 | 数据凝聚与模型迁移会同时改变，需额外控制 |
| 研究价值 | 能直接证明持续 TAG 凝聚机制；不依赖特定基础模型故事 | 若目标是图基础模型训练数据压缩，或验证跨模型效用，有独立价值 |
| 首版安排 | 开发与主效用验证 | 暂不作为硬门槛；后续按价值选择 |

这不保证原生模型性能会自然恢复。已有记录中 Whole teacher 接近论文，凝聚结果明显较低；batching 修正改善了最好结果，但完整成功复现尚未建立。[S3] 原生路线的优势是待解释因素较少。

GraphCLIP 也可能因更强预训练获得更高绝对分数，但这不等于凝聚数据更有效。已有 P1 中 random-small 常不低于 full-real，当前训练接口的可改善空间尚不清楚；已有 C0 只是梯度匹配的失败证据，不能证明 ASM 适配必败。[S4]

**最终论文可以采用原生下游为主、GraphCLIP 为可选验证；也可以在证据充分时将 GraphCLIP 升为主模型。没有必要为“模型更强”提前承担全部适配工作。单纯更换模型也不构成持续凝聚创新。**

## 4. 哪些 TAGSAM 问题先修？

应先修影响结论可信度的确定问题，再有限度处理稳定性；不把全部静态研究重新做一遍作为持续方向的先决条件。

| 层次 | 具体项目 | 首版处理 |
|---|---|---|
| 必须先闭合的正确性问题 | master 的 `ceil(num_nodes // batch_size)` 丢尾批 | 在实际选用分支检查并修正覆盖；保留原版本记录，验证每轮样本覆盖。不能假定其他分支仍有完全相同代码 |
| 必须明确的论文/代码差异 | master 只有自环，`feature/add_adj` 才有论文所述 link predictor 合成拓扑 | 选 add_adj 为论文对应的参考分支，固定 commit；自环作为显式消融。选择分支不等于已恢复性能 |
| 必须先闭合的评测/来源问题 | 原文 test split 与发布代码无 mask 评估不一致；teacher、保存产物、实际执行参数不一定与描述一致 | 绑定数据、训练/验证/测试、checkpoint 和代码版本；确认导出产物独立重训一致。新协议不直接复用权限不符的旧 teacher |
| 必须检查的可微路径 | student 短训后，外层匹配是否真能回传到 synthetic X；固定参考是否被原地修改 | 在实际分支做最小梯度/状态检查，避免“能运行”却没有正确优化对象。O2 的共享存储 bug 属于旧分支事实，不能未经核验说成 TAGSAM 也有 |
| 优先验证的稳定性假设 | synthetic feature 范数、learned inner step size 膨胀；只裁剪 X 梯度 | 先以固定合理内层学习率建立稳定化对照，再分别测有界步长、X 范数约束或外层步长调整。每项单列，不能同时全部修改后宣称找到主因 |
| 研发必须规范的选模 | 最终迭代可能差于中途产物 | 用验证集选凝聚 checkpoint，冻结后做独立测试；不能从测试集挑最好点。原论文精确复现和该开发选模协议分开命名 |
| 后续研究问题 | 历史 ASM 参考不可回访、文本候选逐次缩减、旧新质量与负例变化 | 在稳定基础上用持续对照定位，不预先宣称是已验证创新 |

学习率约束、范数正则、改拓扑生成、换损失等属于稳定化或方法变体，不能无标记地写作“官方原样复现”。修复后不要求马上追平论文 73.8%；至少要有合法评测、有限且可追踪的优化、可独立重训的产物，以及相对冻结初始化/随机小集的可重复解释。

若固定学习率和已知正确性修复仍不能建立可用静态目标，应继续诊断或选择另一个已有 TAG 凝聚目标；不能靠递归运行不稳定优化器解决问题。两阶段 Append、冻结产物和访问损失诊断可并行开展，但不能将选择基线的成功冒称已完成可学习凝聚。

## 5. 不换模型，TAGSAM 本身如何变成持续凝聚？

静态 TAGSAM 可概括为：在完整训练 TAG 上训练 teacher；选择真实文本并构造合成图；student 在小 TAG 上短训；teacher/student 在同一批原始参考上匹配图文关系，外层更新合成特征。

持续阶段首先变的是可访问数据：

\[
U_t=S_{t-1}\sqcup\Delta G_t^{\mathrm{train}},\qquad S_t=C(U_t;K_t).
\]

第一条正式基线是每阶段独立凝聚再追加的 **Append-TAGSAM**。第二条是只在合法 `U_t` 上建立 teacher 与参考、联合重凝聚的 **Union-TAGSAM/ASM**。两者使用同一凝聚器、质量规则、文本和预算；联合参考批次需包含旧旧、旧新、新新图文关系，而不只匹配各阶段内部。

真正需要解决的困难从这里出现：静态方法可随时从旧原图重新取参考，持续方法只能依靠已压缩的旧状态。旧信息损失可能在 teacher、文本选择和再次合成中累积。如何减少这部分损失，并超过强 Union-ASM 和同预算 Append，才是算法发展位置。图文关系保持仍是候选假设，应先排除权重与结构解释。

因此，**暂不迁移 GraphCLIP，也可以完整研究持续 TAG 凝聚。** 换模型与做持续机制是两个可分离的决定。

## 6. 如果后续选择 GraphCLIP，具体怎么适配？

不能只把 `GCN` 类名替换为 `GraphCLIP`。可先做产物迁移验证，再决定是否用 GraphCLIP 直接指导凝聚。

### 6.1 两种不同层级

1. **产物迁移：** 原生 TAGSAM 生成小 TAG，用登记的输入转换交给 GraphCLIP 训练。它检验凝聚数据向目标模型的适用性，不代表凝聚目标已适配。转换自身改变特征/ego/结构时，也要和同转换的 frozen/random 产物比较。
2. **目标适配：** GraphCLIP 同时作为 teacher/student，student 在 synthetic TAG 上可微短训，ASM 匹配两者在合法参考上的图文相似度。更直接面向 GraphCLIP，但需要实现与验证新的内层训练路径。

### 6.2 四项必要工作

| 适配项 | 必须落实的内容 |
|---|---|
| 文本与特征空间 | 保留真实字符串，用目标 tokenizer/文本塔重新编码；本地封装默认 MiniLM，不能直接当作 BERT 同一空间。GraphCLIP 原文 graph-summary 与 TAGSAM 原文片段来源不同，先固定一种实际消费方式。输入映射只在合法训练数据拟合，跨阶段规则一致，参数计费 |
| 图输入 | 本地封装要求 384 维 X、ego batch、root 索引、PE；可读封装为 12 层 GPS、32 步随机游走 PE。[S5] 由小 TAG 构造这些输入，明确结构采样与训练样本，避免重复 ego 或缓存成为隐藏额外数据 |
| student 内层训练 | 建立函数式、可微参数更新，让外层 ASM 梯度经过 student 更新到达 synthetic X；原生 TAGSAM 的重参数化实现要验证能否支持目标模块。当前 C0 的 `create_graph=False` 与 `no_grad` 参数更新不适合作此内循环，这是不同目标设计，不能直接称其 bug |
| ASM 与持续参考 | teacher/student 在相同合法参考、相同相似度定义上比较；当前增量与预算内历史状态可读，完整旧原图不可读。teacher 跨阶段保留则计入状态；独立评估 student 不继承凝聚器训练权重 |

首个目标适配版本可固定文本、邻接和 PE，只优化 X，控制成本；这属于明确的适配变体，不是全变量优化。计算量太大时可以研究有限训练范围或近似梯度，但必须说明它改变了什么目标，不能将 detach 后的近似宣称精确双层梯度。

以上 GraphCLIP 架构依据本地可读封装，不代表已经完成外部 `models.gt.GPS` 全部源码、原生预训练损失及二阶算子的审核。checkpoint 预训练数据与输入特征来源仍需核实。[S5]

## 7. 下一步的有界工作顺序

1. **原生参考核验：** 确定 add_adj commit、数据与评测；检查尾批、teacher/student/产物来源和可微路径。已有修复能复用则复用，不重跑所有旧实验。
2. **最小稳定性比较：** 同一初始化，比较 corrected-code、固定内层学习率稳定化版本和冻结初始化；以独立重训检验，避免只看 outer loss。先小规模、少数种子诊断，再为核心结论增加独立凝聚种子。
3. **两阶段持续基线：** full-history-real、offline 一次凝聚、旧 S＋当前 raw、Append-TAGSAM、Union-ASM、强选择基线。定位旧数据替代、再次压缩和新旧采样中的主要损失。
4. **按证据形成机制：** 优先只解决一个瓶颈；共同分配、关系蒸馏、质量校正都作为强已有解释对照，不预设新增 loss 就是创新。
5. **扩大一种维度：** 先补更多阶段/类别顺序；自然时间流或 GraphCLIP 迁移选择一个进入下一轮，不同时扩大数据流、模型与预算。最终是否需要二者取决于论文主张。

本次到方案为止。默认版本允许修改，任何新训练需要在后续实际进入执行时按当时协议进行；本轮没有自动恢复实验。
