# Compact Results

This directory contains selected text-based evidence copied from the local
workspace and the remote server. It is not a mirror of the raw result store.
Large per-run JSON files, tensors, checkpoints, caches, and logs remain on
the experiment machines. Each included directory keeps summary fields needed
to audit the tables and claims in `paper/`.

The server-side compact snapshot was collected on 2026-10-31. The collection
procedure and source hash are recorded in
`provenance/RELEASE_MANIFEST.md`.
