# Baseline cards

These cards normalize the existing server manifests into the fields required
by the handoff protocol. There are thirteen cards, including a standalone
`puma_adapter_card.json`; the bundle card covers the five separately reported
continual arms. They describe protocol status and do not turn an adaptation
into an official/native reproduction. Each arm retains its own upstream and
access caveats from the server manifests.

`graphclip_reference_only_card.json` records the frozen official GraphCLIP
checkpoint as a section 3.C reference, outside the continual main table.

`EXTERNAL_BASELINE_CARD_AUDIT_20261002.md` records required-field coverage.
`EXTERNAL_BASELINE_COMPARISON_TABLE_20261002.md` is the generated final-stage
table; reference-only methods remain outside that table.
